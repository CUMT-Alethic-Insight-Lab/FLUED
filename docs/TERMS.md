> 凡冲突或未登记，以本文为准——未登记者视为不存在（黑户）。

## 1. 维护规则（先读）

1. 任何新术语（缩写、英文造词、非日常名词）落地时，**必须原地登记本文**，
   否则视为不存在（黑户），协作者有权拒绝理解；
2. 每条登记字段：术语原文 / 中文全称 / 一句话定义 / 首次出现（文档章节）/
   提出方（人/AI）/ 日期 / 状态；
3. 术语状态机：**候选 → 已注册**（→ 可降级为 `弃用`，须留痕）。
   AI 提名的术语默认 `候选`，用户点头才转正——与证据状态机完全同构；
4. **汇报协议（未注册词禁用）**：任何报告/回复中，凡不在本文的词，首次出现
   必须内联给出中文全称 + 一句话定义；英文造词必须挂中文语义锚，不许只写
   英文术语然后默认对方懂；
5. **造词权下放，命名批准权收回**：任何人/AI 都可以提名词，但只有用户能批准转正；
6. 每次登记/转正/弃用，在第 7 节 changelog 追加一行带日期的记录。
