## 1. 探针与指标定义书

### 1.1 共用探针：E73-A6 闭式字节探针（`byte_probe`，S1 第 266–290 行）

- **映射**：one-vs-all 岭回归。特征 X = 每 chunk 一行被测向量（拼 bias 列），目标 y = 该 chunk 第 s  slot 的
  字节 id（258 类 one-hot）。闭式解 `W = (XᵀX + λI)⁻¹XᵀY`，λ=1.0（默认值，三处调用均未覆盖）。
- **split**：2-fold——`torch.randperm(n, seed=0)` 前半/后半互作训练/测试，acc 取两折均值；样本量 n<40 的 slot 跳过。
- **对照基线**：majority = 该 slot 训练分布最大类频率（同一 y 上算，与特征无关）。
- **单位**：acc ∈ [0,1]，逐 slot 分类准确率；"real−garbage" = 同一 probe 在真实特征与置乱特征上的 acc 差（Δacc）。
- **垃圾态（garbage）构造**：沿 chunk 轴置乱——边际分布不变、chunk↔内容配对打碎。
  - S4（护栏二）：置乱**状态序列** S 再读出（`S = S[:, perm]`，S4 第 66–67 行）；
  - S6（剖面）：置乱**读出行**本身（`rows = rows[:, randperm]`，S6 第 237–238 行）。因读出逐 chunk 独立，
    两者严格同构（S6 docstring 第 21–24 行注明）。置换种子均为 20260819（S4 `seed=20260819`，S6 `PERM_SEED=20260819`）。

### 1.7 对账结论：三张量三对象——"82% 写入清白 vs 信息挤在段首"无矛盾

从代码逐行核实（S1 第 417 行、S4 第 52–76 行、S6 第 216–246 行、S13 第 1944–1987 行），三个数字的
测量点互不相同：

| 数字 | 张量 | 管线位置 | 格/通道 | checkpoint | 维度 |
|---|---|---|---|---|---|
| 82%（0.8163）/ 62%（0.6185） | WriteHead 写值 v（`gates["v"]`，to_v 输出） | **过状态机之前** | c 格 V 通道 | v37_c_is_v371…20260817 | 1024（H·hv） |
| +0.47（+0.4723） | 接口向量 v_rows = realign(q·S_trained) 均值 | 状态机**之后**、decoder_in 之前 | c 格 V 通道 | v37_c_is_v371…20260817（同上） | d_pack |
| +0.126（+0.1264） | k_rows = K~（state_machine_k 读出行均值） | 状态机之后、align_k 之前 | **b 格 K 通道** | **v37ks_b_sm_v372_cloze_tokcenter…20260818** | d_pack |

据此裁决"82% 写入清白 vs 信息挤在段首"是否矛盾：

1. **不是同一张量**：82%/62% 读的是写入端 raw 写值 v（pre-state）；+0.47 与 +0.126 读的是状态读出后的
   接口向量（post-state）。写值有线性和状态读出后还剩多少线性，是两级不同的测量。
2. **不全是同一对象**：82% 与 +0.47 同 checkpoint（c 格 V 通道）；+0.126 在另一个 checkpoint
   （v37.2+cloze+to_k_center 手术 b 格）的另一条通道（K 通道）。
3. **结论：无矛盾。** 两句判词各自成立且互补——
   - c 格：写值 v 保留 82% 线性增量（写入已形成，H1 值侧证伪），且 V 通道接口在 slot0–3 仍有
     +0.33~+0.48 的 chunk-条件信息；E73 的 A5（写值直通）全灭（acc 0.0426）把 c 格崩盘钉在接口
     **下游**（decoder_in→decoder 的输入域锁死，"读出结构病"，E73 判决①）。

## 2. 单位换算：+0.47 与 +0.126 的同口径比对（验收线 0.45 重锚阻塞项）

**两数同口径，无需换算公式。** 逐项核对（S4 vs S6/S7）：

| 口径项 | +0.47（护栏二） | +0.126（剖面） | 是否一致 |
|---|---|---|---|
| 报告量 | real−garbage Δacc | real−garbage Δacc | ✓ |
| 探针 | byte_probe 2-fold one-vs-all 岭回归 λ=1.0，258 类 | 同左（同一函数，S6 第 53–59 行 import 自 S1） | ✓ |
| split/种子 | 16 窗，eval_mask_seed 1042 | 16 窗，eval_mask_seed 1042 | ✓ |
| 垃圾态 | 状态序列沿 chunk 轴置乱（seed 20260819） | 读出行沿 chunk 轴置乱（seed 20260819）——逐 chunk 独立读出下与左严格同构 | ✓（同构） |
| 目标 | clean 字节 id，slot0 | 同左 | ✓ |
| **被测张量** | **v_rows（V 通道接口，realign 后）** | **k_rows（K 通道接口 K~，realign 后）** | ✗ 不同通道 |
| **对象** | **c 格 v37_c_is（v37.1，无 cloze 无手术）** | **b 格 v37ks_b_sm_…_tokcenter（v37.2+cloze+手术）** | ✗ 不同 checkpoint |

同口径差值（slot0）：

```
Δ = 0.4723 − 0.1264 = 0.3459  ≈ 0.35
```

（若先把两数舍入到 +0.47 / +0.13 再减会得到 0.34——0.34 与 0.35 都是这一对底数的舍入形态，
底数以 S5/S7 原值 0.4723 / 0.1264 为准；倍率 0.4723/0.1264 = 3.74×。）

**差异来源**（因口径全同，差异只能归于对象与通道两级）：

1. **通道级**：c 格 V 通道接口（v_rows，内容读出通道）vs b 格 K 通道接口（k_rows，寻址/键通道）。
   两者绝对水平也完全不同：c 格 real acc 0.6375 vs b 格 real acc 0.2777；garbage 侧 0.1652 vs 0.1513。
2. **对象级**：v37.1 无手术 vs v37.2+cloze+to_k_center 手术。手术对值侧的误伤已在写值层面可测
   （E79-M3，S12：手术 b 格写值探针 slot0 0.2298，未手术 b 格 0.5602，c 格 V 通道参考 0.6185），
   是 +0.126 偏低的上游成分之一。
3. 因此 **0.3459 的差不是"同一接口两次测量的偏差"，而是两个格子两条通道的两个接口**——
   任何把它们当同量纲同对象来平均/对比的算法都是口径错误。

**对 0.45 验收线重锚的含义**：0.45 出自 fork 2 预注册（S14 changelog 2026-08-19(四十二)：
"m=4+状态重嵌入校验下**状态行独存回读 ≥0.45**"）——该线是**回读任务 acc** 口径，不是接口探针 Δacc 口径；
两条尺度的桥是"接口 Δacc 是回读 acc 的上游信息上限指示"。重锚时必须指明锚定在哪一格哪一通道：
- 若锚在 c 格 V 通道尺度（护栏二的 +0.47 档），则主线 b 格 K 通道当前接口只有 +0.126@slot0
  （且 slot18+ 掉到 +0.02~0.05），同一信息量要求换算到 b 格相当于现状的 3.74 倍——验收线不可及；
- 若锚在 b 格 K 通道尺度，则 0.45 回读 acc 对应的接口 Δacc 需求无实测标定点（b 格全 slot 均 ≤+0.1264），
  需要一次"b 格接口 Δacc ↔ 回读 acc"的配对测量才能定锚。
**阻塞项结论**：重锚前先裁定锚定格/通道；本文件给出两尺度全部底数，裁定本身属用户裁决范围。
