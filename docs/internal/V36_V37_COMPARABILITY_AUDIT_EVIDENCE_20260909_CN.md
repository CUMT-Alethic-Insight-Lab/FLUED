## 问 3：a 格考场 → d 格 25b 主线的外推链

**已文档化的差异**（逐条有出处）：

1. **段界器锚**：主线 = S0″ 双源教师预训前端冻结接管（`configs/canonical_v37.json` init_checkpoint + freeze_prefixes；CURRENT_STATE :25–26；共识 §1）；E121/E123 配置 `configs/v3_7_d1_w1.json`、`v3_7_e123_combined.json` init_checkpoint 与 freeze_prefixes **均为空**（from-scratch 全解冻）。E110 :181 注记「从零 segmentor 退化签名…与历史冻结前端锚点的差距扩大为前端退化」。
2. **格形态**：a=(index,memory) 直通无状态机（E60 :131）vs d=(state,state) 双状态机（E61 :132；Q15 任务书 §1 格裁定）。
3. **训练预算**：10K vs 主线 20K。
4. **规模**：43.9–50M vs d 格 54.8M——**规模差其实很小**，真正的鸿沟是 1/2/3。
5. **窗内分段体制**：from-scratch 段界器双退化模式（兜底 64 块/窗 vs 碎切 993 块/窗）——E123 handoff v4（`docs/internal/E123_HANDOFF_20260908_CN.md:3-12`），碎切模式下「跨段」粒度 ≈4B，与 d 格 ~64B/段完全不同物。

**外推链合法性/保留条款的成文情况**：

- 有部分注记：E121 诚实边界（「Δ=0 与骨干未熟不可分离」:192）；E122 双基座设计+功率注记（:193）；必要性账「基座依赖测量，基座换代账要重跑」（:229 ②）。
- **但没有任何文档显式书写「a 格 from-scratch 短臂 → d 格 25b 主线」外推链的合法性论证或保留条款**。需求规格 §3 验证序（`FLUED_NEXT_SEASON_DEMAND_SPEC_20260904_CN.md:28`）只写「先上 50M 短臂看双仪表」，未写外推边界；E123 任务书 §7 诚实边界（:114）只覆盖自读出→外部检索、机器人域两处，**不覆盖段界器锚/格形态/冻结差异**。
- 体制分岔事件（2026-09-09）使该缺口从理论变成实锤：同种子同码同数据跨硬件即分盆，且 handoff 自定「此事件必入 changelog + E123 证据行注记」（handoff :8）**尚未兑现**——CURRENT_STATE changelog 末条停在 2026-09-07（:1494–1496），E123 证据行未建（注册表止于 E122 :193）。

**评级：高。**
