## §0 定位

**第一行假设（2026-08-29 用户裁定，逐字落实）：端口仍是损耗源。** E118 中间带读数在案：m̂ 列 0.3541→0.4572，段 3 软化（水位 44.7%→57.7%）但未拆除（损耗残留 76.5%，减半线 0.56 未达），末段饱和——多槽读出的全部设计在此前提下展开：读出端扩宽**不预设端口已无罪**，一切判词走「多槽读出行 × 练钝端口」串联实测，不许各测各的再拼。

**本臂靶子一句话**：Q19 分段损耗台账指认段 2（v̂→m̂ 桥 cos 0.63）+段 3（端口 OOD）——E118 已把段 3 练钝一截，本臂治读出宽度：**读出端从「每段从 delta-rule 压缩状态矩阵读一根固定向量」改为「k 个可学习槽位查询各读一根、拼接后投影回 decoder 入口宽度」**；decoder 入口维度与接口契约不变；改动只在读出端；写入侧（summarizer/WriteHead/状态机）本季度冻结。

依赖关系（文字版）：

```
Q19 闭式台账（段 2 桥损 0.63 / 段 3 端口 OOD）
   ──▶ E118 端口练钝（中间带，端口仍是损耗源）
           ──▶ 本臂（Q20 多槽读出，k 扫描 + CG 结构内化对照臂）
                   │  阳性格 ─▶ 读出端修复路径坐实，写入侧解冻评审材料
                   │  未动格 ─▶ 墙址回指段 1（b 格 K 通道上限 cos 0.699）/写入侧
                   └─ 判负格 ─▶ 前馈读出路线存档，CG 结构内化扶正主线
```

**读出对象登记（代码现状核对事实）**：b 格（k=state, v=memory）里唯一的 delta-rule 压缩状态矩阵是 **K 通道**（`state_machine_k`，吃 summarizer index 行；`flued/v36/model.py:2066-2068`）；V 通道直通（`v_rows = memory`，`flued/v36/model.py:2197-2198`）无状态机。Q19/E118 的 m̂ 链正是从该 K 通道状态读出（`tools/analysis/v3_6/probe_decoder_fuzz_id.py:192-200` `mhat_from_window`：index 行→`write_head_k` gates→`state_machine_k` 自然态→ridge 段 1 解混→部署桥→m̂），b 格自产自销段 1 上限实测 cos 0.699（fuzz_id 前置测量，`outputs/decoder_denoise_fuzz_id_20260829/`）——**该上限是写入侧产物，写入侧冻结故不在本臂靶子内，但它是未动格的归因指向**。

**作用域限定（E118 终审确认项 2 同款）**：本表一切判词行文带「**适用于 slm 系 b 格 K 通道→decoder_in_mem 端口链**」限定语——现役 canonical 为 attn 模式结构性无此端口亦无此状态通道（`configs/canonical_v36.json:65`，`flued/v36/model.py:2055,2075-2076`），不得读成 canonical 端口/读出结论。

## §1 构造设计（预注册）

**对象**：b 格 K 通道压缩状态 → decoder direct 口的读出链。**可训练范围（建议，终审裁定项 4 随行）= 仅新增多槽读出件**（k 槽查询 + 拼接投影 + CG 臂的可学 段 2 投影）；decoder/decoder_in_mem（练钝端口）/backbone/summarizer/WriteHead/状态机全冻在 E118 收官态——**端口作固定基板 = 「端口仍是损耗源」前提的实验化身**。

**臂结构（四臂，串行，同基座同预算同判读格）**：

1. **k=1 臂（消融锚）**：单槽可学习读出 + 投影——现役单向量形态的可学习对照。sanity 期望：训练有素后应 ≈ m̂ 闭式链参照档（0.44–0.48），落此档=接线正确旁证；显著低于则先查接线再读 k>1。
2. **k=4 臂**：注册表口径起步档。
3. **k=8 臂**：扫描上沿。
4. **CG 对照臂（结构内化，MesaNet 模板，无 k 轴）**：段 1 解混不由前馈学习，由 **T=8 步可微 CG 迭代**结构化（对窗内写入对 (k_i, v_i) 的 Gram 正规方程逼闭式解，λ=λopt=1.0 同部署桥口径；T 固定不扫——**迭代深度≠读出宽度**，分工声明依复核报告 §8.2-3）；段 2 桥为可学投影（d_state→d_mem）。答的是 E115 的直接对冲题：「前馈+SGD 学不到闭式解，显式迭代结构可以」。

**读出件规格**：k 槽查询 (k, kda_heads=4, head_k=128)，逐段读 K 通道 post-state（`_fla_chunk_kda` 任意 q 展开先例在库，`flued/v36/model.py:954-978`；torch scan 路径 859 行同形态）；k 根读出拼接 (k×heads×head_v = k×1024) → 单层 Linear 投影回 d_mem=512（decoder 入口宽度）→ 喂冻结的 decoder_in_mem → decoder。参数量随行入册（k=1/4/8 投影 0.52M/2.10M/4.19M，E100 参数/延迟中性实测口径沿用）。

**初始化与零变化律（预注册）**：k=1 槽查询以 fuzz_id 落盘的 ridge 段 1 主方向温启动、投影以部署桥 W 温启动；k>1 臂槽 0 同 ridge 方向、其余槽随机初始化后与已有槽正交化。**零变化律检查（Q18 §5 修订 v1 比率线纪律沿用）**：t=0 温启动读出行过端口读数 ≥ m̂ 参照 −3pp（0.427）——否则初始化没接通，臂作废重查，**不许判负**；t=0 同点随机初始化对照读数随行落盘（温启动/随机 ≥3× 旁证）。

**冒烟条款（点火前）**：500 步冒烟验收四件——① 旋钮接通（多槽读出行确实进 direct 腿损失）；② 零变化律 t=0 读数过线；③ 干净列（真 memory 行过冻结端口）回落 <2pp；④ ckpt 逐键 diff **仅多槽读出件键变化**（冻结实锤，E118「仅 50 个 decoder.* 键」同口径）+ nan_skips=0。冒烟不过不点火。

**种子**：42 单种子先行（方向性实测，E118 同纪律）；阳性格/串联测判词落格后种子加固 {1,2} 两枚（escalation 条款，同 Q18 A′——预算 ×3 只作用于落格臂）。

**预算**：4 臂 × 20K@4096B 串行。单臂 65–124 分钟（E118 实测 5.1 steps/s → 65 min 下界；v37.1 历史 2.7–3.0 steps/s → 111–124 min 上界）；CG 臂迭代税预注册上限 +25%（78–149 min）。**总账 ≈ 4.7–8.7 GPU·h，一晚级**。里程碑探针 sweep：t=0 + 3K 步进七碑（3K/6K/9K/12K/15K/18K/20K，与 E118 逐碑可比）。**早停门槛 = 10K**（E118 条款沿用：本赛季六次瞬态教训，5K 过线可能只是「出现然后被吃」——10K 处主判据过线且有效性门不破才允许提前收官）。

## §2 判读表（预注册）

**作用域限定**：一切判词带「适用于 slm 系 b 格 K 通道→decoder_in_mem 端口链」限定语。

**考场**：四列探针 Q20 版（`tools/analysis/v3_6/probe_decoder_denoise_eval.py` 测量链复用，仪器口径见 §3-6），eval 窗 seed+9999 前 16 窗 + mask_seed=1042，fine 细格 echo byte_acc（E118 §7 同口径）。**五列同测**：

| 列 | 内容 | 职责 |
|---|---|---|
| clean | 真 memory 行过冻结端口 | 冻结/仪器 tripwire（绝对参照带，见有效性门） |
| **q20_k** | **多槽读出行（本臂产出）过练钝端口端到端** | **主判据列——「多槽读出行 × 练钝端口串联测」格，唯一硬通货** |
| mhat | ridge 闭式链行（fuzz_id λopt 部署桥，同函数不动） | 闭式参照列，同场复测（E118 收官值 0.4572） |
| scrambled | 置乱行 | 地板门 ≤0.10 |

**主判据落格（以 k=8 档为主格，逐 k 档落格；数字与 E118 判读表同刻度延续，使「多槽读出是否补上去噪臂未砍掉的损耗」可直接对读）**：

| 结局 | 判词 | 行动出口 |
|---|---|---|
| **及格线：q20_k=8 ≥ 0.56**（= m̂ 参照 0.4572 + 约 10pp，远超窗内噪声；E118「损耗减半线」同数保留） | **多槽读出修复路径成立**——读出宽度是段 2/3 联合损耗的承重约束，串联测闭环 | k 档定型（选最省过线档）；写入侧解冻评审材料成形；Δ 硬通货归 d 格线（Q15 系）补测 |
| 卓越档：q20_k=8 ≥ 0.65 | 段 2/3 联合损耗基本拆除，读出端叙事闭环 | 同上 + CG 臂降级为工程对照（部署成本比较） |
| 中间带：0.48 < q20_k=8 < 0.56（显著超 m̂ 参照 +2pp 以上但未到减半线） | 如实登记「多槽扩宽有效、联合损耗残留」 | 槽初始化/投影容量复诊一次（不改端口）；CG 臂读数定升级路径 |
| 未动格：q20_k=8 ∈ m̂ 参照 ±2pp（0.4372–0.4772） | 读出宽度不是约束——k 槽读出的增量被段 1（K 通道信息上限 cos 0.699）或更上游吃掉，墙址回指写入侧 | 读出端收工存档；写入侧冻结条款季度复审材料（码本键/几何线联动 Q12 备件） |
| **判负格：q20_k=8 < m̂ 参照 −2pp（< 0.4372）** | **可学习前馈读出再败闭式链**——E115 签名（闭式可达而 SGD 摸不到）在读出端再现；前馈多槽路线判负 | **CG 结构内化臂扶正主线**（「要闭式水平就把迭代结构造进读出器」，侦察报告 §4.3 判词落地）；k 扫描存档 |

**k 斜率辅判（非硬通货格）**：k=1 落 m̂ 参照档 = 接线 sanity 旁证；1→4 与 4→8 斜率同行入册。**k=2 加密或有条款（预注册）**：若 Δ(1→4) > +3pp 且 Δ(4→8) ≥ Δ(1→4)/2（曲线未饱和），k=2（或 k=6）加密点单臂补跑——需用户裁定激活，不自动点火。

**有效性门（建议稿，终审裁定项 3）**：双件——① **绝对参照带（硬门）**：里程碑 eval 干净列不得较 E118 收官值 0.8323 回落 >2pp（即 ≥0.8123）；触发=冻结破口或仪器 bug，**loud fail，臂作废重查，不许判负**。② **自锚设施原样**（`train_v36_s1.py:1421-1440` `_q15_callback_check`，800–1000 步自锚、>0.02、×0.5、floor×0.25）：**职责语义改写登记**——因可训练范围=仅新读出件、端口/decoder 全冻，codec 水位权重层面不可漂移，回调线在本臂没有 E118 的可压旋钮（p_noise/p_mhat 不存在）；设施原样复用但锚定对象=读出行训练指标自轨迹，供看门狗与瞬态判读，不再承担「压旋钮救 codec」职责。

**地板门**：scrambled 列必须贴先验（≤0.10，先验 0.071 同档）——读出件若学会「无视状态猜字节」，置乱列会漏；地板不过门的读数作废不发判词。

**零变化律**：§1 已预注册（t=0 温启动 ≥0.427，不过=臂作废重查不许判负）。

**Δ 监护列（作用域照 E118 补注 v2.1 裁定①沿用）**：b 格无 burst 训练史，逐条目 Δ（burst_tail 源段完好−置乱，q15 口径，n=48）是**零基线监护不是判词**——预期 CI 含 0，作用=证明多槽读出无副作用；Δ 硬指标仍归 d 格线（Q15 系）另测。

**通用纪律**：一切过程读数（k 档曲线、训练 loss）涨了不算赢，终点判读表落格才算；每列带 majority 基线与先验门；串联测格是唯一硬通货格。
