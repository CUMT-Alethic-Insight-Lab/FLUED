## 1. 问题陈述

**K 线**（压缩状态内部索引通道，又称内容寻址线）的研究问题：FLUED 的压缩状态（写入头→KDA 状态机→读出查询的串行路径，即**状态通道**）内部，能否长出一个**内容寻址/检索**机制——给定一个查询，模型能从已压缩进状态矩阵的历史段中按内容（而非按位置）取出正确的那一段。

这是核心 claim 收束路线的一部分，理由有三。先交代背景形态：v3.7 共识把 summarizer 直产 index/memory 双通道、interpreter 状态机为可选组件、主干为 3 层因果 SLM；K 线问题就定义为"index 通道经 KDA 状态机压缩进单一状态矩阵后，能否承载内容寻址"。

1. **K/V 二分后的唯一开放轴**。v3.7 四格矩阵（E60–E68）已证 V（内容）通道必须细粒度直读、压入单一状态矩阵即崩盘（容量墙）；K（索引）通道粗化无损。压缩记忆的生存空间于是收敛到"内容旁路直读 + 索引通道进状态"的形态——K 通道是这个形态里唯一还没判生死的组件。
2. **核心 claim 的依赖**。FLUED 的叙事是"压缩状态可以作为长上下文的承载体"。若状态内部永远长不出内容寻址，状态通道就退化为装饰——审计已多次测到这一点：E64/E66 两次 K 屏蔽探针全指标漂移 ≤0.2pp（索引通道零承重），E86 置乱 K 状态行补全仅掉 3.5pp，E88 置空 V/状态通道补全 acc 逐位不动（边际贡献精确为零）。核心 claim 必须收束到字节级语言接口本体，除非 K 线能拿出寻址证据。
3. **负结果也是收束**。按预注册终考纪律（`FLUED_V3_7_FINAL_EXAM_PREREG_20260818_CN.md`），阴性判定（寻址未形成）同样是一个交付物：负结果 + 核心 claim 收束。本文的立场即此——不粉饰、不夸大，判负/作废/暂扣严格分账。

## 3. 四代攻法全账

K 线"检索招募"共四代任务攻法，每一代都带有效性门（**门测理解**：带任务形态基线−盲猜 ≥0.10 且 p<0.01，测"模型懂不懂这个任务形式"；**终点测留存**：脚手架拆除后的 0 示例逐条目 **Δ 仪表**，TERMS.md 已注册：acc 完好 − acc 置乱）。门不过则臂作废、不许判负——这是纪律不是安慰。

| 代 | 构造 | 有效性门读数 | 结局与理由（注册表措辞） |
|---|---|---|---|
| 一、cloze 回执 | 原文片段+尾部 cloze 问句+echo，0.3 概率/0.3 权重（E69–E72） | 有效性门概念此代尚未设立；四格 cloze_byte_acc 贴 0.076–0.080、exact 恒 0，探针与无 cloze 基线重合 | **方向判负**：0.3/0.3 强度与 41–55M 规模下未训出检索技能；手术/白化等配套几何臂随之全线零复活（E76–E90） |
| 二、自然检索 A | 语料内现取 32–64B 来源段、遮 CJK 小片段、段后提问 echo；唯一旁路掩码级剔除，r 爬坡强制走 K→状态→读出（E98） | C−B=0.0000；r=0 旁路全开档 byte_acc 全程 0.0–0.07 | **臂作废不许判负**：模型在答案可直接读取的条件下也未学会 echo，失败在任务形式层（问句理解→定位→取词→echo 复合行为超出 50M 可操作范围），混杂未清，结构性判词不能由此得出 |

四代共性：codec 考场全部健康（甚至逐代改善，b 格 40K direct 0.847 为本世代最佳），检索考场全部未过门。"任务无害、回路未燃"是贯穿四代的一致表型。

- **第三代（示例密集 Q12-A）**：留下了正斜率证据（in-context 边际近翻倍）与窗沿效应的构造规则冲突清单——"查询块永远最后拼接"规则待裁定修订。
- **第四代（40K 脚手架）**：留下了健康配方（2e-4+warmup 200+cosine 到 0，不许回 1e-3 恒定）与隐性承重墙教训；codec 侧 b 格 direct 0.847/backbone 0.800 为本世代最佳读数（口径注记：b 格口径不与 qpool 锚混排）。

## 4. A3 归因章（已定稿）

Q12 修订案附录 A3 备案：若四代攻法仍过不了有效性门，判词候选落在"50M 参数量对此类问答题型的**形式理解上限**"。E103 触发 A3 程序后，E104 的 induction 分数仪器（未注册词，内联定义：测注意力头中 prefix-matching 复制回路强度的探针，基线 2× 为破线判据）给出双时间点×双粒度测量，归因章据此定稿：

判决逻辑分两层拆开看：

- **形式书写层**：E101 format_ok K=0 = 0.9375——模型在零示例、零脚手架下就能写出合规的答案形式。"50M 看不懂问句格式"这一解释在书写层被逐位反证；K=8 档掉到 0.708 的账面差距，E102 逐条目交叉分析查明主因是窗沿效应（echo 被示例挤到位置比 ≥0.99 的条目塌到 0.188），不是形式不懂。
- **内容定位层**：四代的共同坏死点都在"找到并取出正确片段"这一步——cloze 贴地 7.6–8.0%、自然检索四臂全等 0.1301、0 示例 Δ CI 恒含 0。定位坏死 + 形式会写，这个表型组合正是 induction 复制回路缺席的签名，E104 仪器读数把它从表型坐实为机制：细粒度档 trained 最高 head 仅 1.65× 基线、init 1.58×，粗粒度 1.51×/1.45×，双时间点近逐位一致——**回路从未形成，且不是我们的训练砍掉的**（init 点就没有）。

E104 口径注记如实保留：① init 点=同种子新建模型+底座前端（backbone 随机初始化，run 未存 step-0 快照）；② 仪器测窗内复制前体，不为状态通道能力背书（反向不成立入册）；③ 底座预训练史查档悬空标注；④ 首跑细粒度档因维度误用作废，修复后两粒度同判。

**定稿判词**：四代攻法失败的归因从"形式理解上限"（A3 暂扣）改写为"**基础复制回路从未形成**"。修复方向明确：数据层注入突发性（Q13 系）把回路催出来，再回 Q12 形态复测有效性门与 0 示例 Δ——回路在+任务形式在，K 线判决才重新可读。选项 2（机械格式）按 A3 备案**不得自动激活**：它与 magic number 退役裁定方向相反，启用前必须重新裁定。

**方法论注记（窗沿效应，E102；未注册词，内联定义：echo 答案被示例挤到 4096B 窗绝对尾部时格式合规率塌缩的位置效应）**：echo 位置比 ≥0.99 的条目 format_ok 塌到 0.188，低中档 0.94–1.00。Q12 有效性门的 format_ok 账面差距被窗沿条目系统性拉低，门与门槛的真实差距比账面小；任务构造规则"查询块永远最后拼接"与该效应直接冲突，修订待裁定。它与 E92 位置沉淀（乱序后头尾比 4.944 几乎不动）跨尺度同族：本系统对窗尾内容的处理劣化是两个尺度上反复出现的同一族现象。

## 5. 纪律与方法论收获

1. **有效性门：门测理解、终点测留存**（招募臂附录 A1 冻结）。门挂在带示例形态上测"懂不懂题"，主终点挂在 0 示例形态上测"脚手架拆除后还剩什么"；门不过 → 臂作废重跑，不触发判死。E98/E101 两次"作废不许判负"都是这套纪律的实战执行——作废与判负的区分保住了 K 线结构性判词不被污染。
2. **判读金规：损失不作数**。F2 臂（E96）aux loss 5.55→2.67 降得漂亮而逐 slot 剖面纹丝不动——辅助头把压力拿去抛光段首（+0.026）而非补段尾（+0.007），scout 预告的 decoder explain-away（未注册词，内联定义：辅助头用 decoder 侧容量把损失解释掉、病灶不动）假阳性实测兑现。剖面/Δ/仪器读数是判词，损失曲线永不作数。
3. **预注册 ex-ante**。终考预注册在看结果前冻结阈值（D=64 hit@1>0.10 且 p<0.01），三次修订（命中条目归因记录、needle 位次打乱+per-item 必开、magic number 形态整体退役换逐条目 Δ 仪表）全部在首个终考数据产出前落笔并注明动机——修订 3 的退役理由本身是方法论收获：双重 OOD 的任务形态让 Δ=0 分不清"K 不可招募"与"任务对 K 不可赢"。
4. **判死链条带电机制**。Q11 v2 改写：CJK 主臂判零不直接引用结构性判词，须以 ASCII 对照臂复测，两臂皆零才生效；有效性门不过则整条判死链条断电。判词有"电压"，读数不够格时碰都不许碰。
5. **伪死因/真死因分层**。40K 延长臂 1e-3 发散事故：伪死因（dashboard eigh 报错杀训练）与真死因（恒定 LR 拆掉了 cosine→0 这堵刹车墙）分层入册；KDA delta 写入量无内禀上界，失控谱系 E78（state_norm 358 温和版）→本次（4352 爆炸版）同病两表型。
6. **隐性承重墙教训**。cosine→0 在本系统的真实功能是状态范数刹车，不是收敛美学。**任何配方变更，变更说明必须回答"被改组件除了明面功能还承什么重"**。
7. **附带口径教训入册**：raw 键几何漂移≠部署塌（E76/E90/E91 同形态：手术是读出时减统计而非改权重）；dashboard train 态 μ 是 EMA buffer 滞后 artifact；暖 buffer 必须只喂真实 chunk 行（padding 占 ~85%，全量喂把部署 μ 从 0.417 污染到 0.807，首跑作废重测）。
8. **平台义务与小样本口径**。任何指标饱和时必须报平台位置而非只报"过没过"（E81"边界未定"→E87"边界已实测 0.3185"即此纪律的闭环）；档案馆探针 n=12 一律标注"初读口径、待终考 n≥48 三 seed 确认"，终局判词不许建立在初读口径上。
9. **作废与判负的分账纪律**（全链最贵的区分）。判负=假设被证据否定，可以写进机制章；作废=读数不可解读，什么都写不进去。E90 是三档判决**形式作废**+臂判负的复合体，E98/E101 是纯作废——注册表措辞严格区分，本文照录不改写。

## 6. Q13 未决条款（在跑）

**突发性注入臂**（burstiness injection，未注册词，内联定义：在训练数据层人工制造重复片段簇、以催生 induction 复制回路的干预）预注册 2026-08-22 正式冻结并下点火令，构造：每窗现采随机段（32–64B）逐字重复 R=3 次、第 R 次末 2–4 个 CJK 字符遮蔽，损失只打遮蔽段尾；防背护栏（每窗现采、严禁固定段库、epoch 内不重复断言）；配方 2e-4+warmup 200+cosine 到 0（E103 事故后健康配方，不许回 1e-3 恒定）。双主仪表：induction 分数逐里程碑破 2× 基线 + 逐槽位剖面头尾比（vs E88 的 5.15× 基线）。

四格判读矩阵全文引用（2026-08-22 点火令冻结原文）：

- **格一**：任务成（Δ>0）+ induction 破 2× 线 + 剖面压平 → 全赢：回路催出、需求驱动分配，DeepMind 框架本系统复现；
- **格二**：任务成 + induction 平 → 状态通道走了非 induction 的私有路由，机制章立新节（比复现文献更有价值，如实按阳性登记）；
- **格三**：任务不成且双仪表不动 → 回 A1 门纪律查任务理解，假说判词不动；
- **格四（判死"分配跟随需求"的唯一合法格）**：任务成 + induction 破线 + 逐槽位剖面头尾比不动 → 两层判词顺序执行：
  - 第一层先查答案实际路由（路由归因仪表）；
  - 路由在窗内 → 判词="分配跟随需求沿最便宜通道兑现"——假说修正而非死亡（需求被窗内复制满足，memory 行分配不动不是假说的反例）；
  - 路由在状态通道而剖面仍不动 → "需求挂上、回路形成、分配不跟"，假说死于 fork 3 侧，按预注册判死条款生效。
  - **禁止跳层：路由未归因前，第四格不许落任何判词（防冤案也防假胜利）。**

配套路由归因仪表：eval 双消融臂（状态读出行置零 / 窗内早次出现遮蔽，两臂分报互不代报）+ 逐条目"窗内副本存在"审计列 + 构造倾向（早次出现优先落压缩区）。判词顺序纪律是格四的核心：**先归因路由，再谈假说生死**。

Q13 的有效性门与主终点沿用 A1 纪律：门挂在注入形态上（段尾补全 acc 超盲猜先验 ≥0.10 且 p<0.01，门测理解）；主终点=回路形成后回 Q12 形态复测有效性门与 0 示例 Δ（终点测留存）。若 induction 分数在注入 R=3 次段的压力下仍无 head 破 2× 线，则"数据注入也不足以催回路"——A3 形式上限与回路缺席两种归因在"催不出"处合流，K 线在当前规模诚实收束（预注册 §4 原文结局）。

护栏随行：注入只改数据、不改架构；codec 双指标 >2pp 按部分失败登记；预算 20K 步、饱和判定末 2K 逐位走平。

## 7. 外部文献锚点

DeepMind ICL 权衡文献（K3 对标，2026-08-22 入册）：induction 回路在 25–50 亿 token 相变窗口形成，依赖训练数据的**突发性（burstiness）+ 罕见类别**双属性；加量后 ICL 先升后稳而 LM 先验续涨（剂量-权衡曲线）。与我方的关系：

1. **诊断吻合**：我方语料与训练量（~8 千万字节/世代）不满足突发性条件——E104"回路从未形成"与文献的必要条件叙述一致；
2. **构造独立收敛**：Q13 的逐字重复+段尾遮蔽形态与文献干预同构，属独立收敛（外部佐证）；
3. **权衡的小号预演已实测**：E103 的边际收缩（先验 +0.026 快于能力 +0.004）正是文献"先验续涨"权衡的本系统小号版本；剂量-权衡曲线的验证责任已自 Q12 移交 Q13 系；
4. **与"分配跟随需求"假说的关系**（未注册词，内联定义：压缩系统的信息分配会跟随任务需求走——需求挂上、回路形成，则 memory 行/状态通道的信息取舍应随之改变）：文献为该假说提供外部锚点——若突发性真是回路形成的必要条件，则"回路缺席→分配不动"的因果链在文献框架内可解释；Q13 格四即该假说的判死考场，路由归因仪表负责分清"假说死亡"与"需求沿最便宜通道（窗内复制）兑现"。
5. **规模注记**：文献的相变窗口是 25–50 亿 token，我方单世代训练量 ~8 千万字节，差两个数量级。"回路缺席"因此有两种读法——数据属性缺失（突发性，Q13 正在检验）与数据量级不足（相变窗口未到）。Q13 只能分离前者；若 Q13 注入突发性后回路仍不起，量级读法自动上浮为候选，届时按队列裁定。
