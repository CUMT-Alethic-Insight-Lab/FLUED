# v3.7 码本键立项书（评审稿）：构造性保秩的几何硬约束

> 2026-08-21 用户评审稿裁定。前置：E90——去均值/白化两族"与训练动力学谈判"的被动线性约束全部出局（白化在分布匹配时成立、分布移位即复塌）；几何修复的剩余未证伪路径 = **构造性保秩**：键几何是码本的构造属性而非训练动力学，天然免疫分布移位。

## 0. 臂 0（前置，独立落地）：WriteHead 双 trunk 拆分

**护栏五（用户评审增设）**：现行 WriteHead 末层 trunk 是 to_k/to_v 共享的（E0-f 仪表图实证）。码本吸附的 straight-through 梯度若回灌共享 trunk，键的离散化约束会污染 v 的成形——臂还没跑，混杂已内建。因此**双 trunk 拆分必须先落地为独立的臂 0**：

- 拆分单独成 checkpoint 先测，预注册其**零期望**：拆分本身应 ≈ 无变化；若拆分单独特异性移动指标，先入册再谈码本解读；
- 码本臂与基线的唯一合法差异必须是键路径——这是对照纯度的前提；
- 入口闸（已执行）：30 步冒烟对照（b 格 + tokcenter ± split-trunk，E79 解耦冒烟口径），几何与值内容无显著差异方可入册（代码与梯度隔离单测已在仓：`split_trunk` 配置 + `tests/test_v37_split_trunk.py`）。

## 1. 码本臂设计

- **冻结随机码本**：每头 M=4096 个单位范数随机键（hk=128 维下随机单位向量对 |cos| ~ 1/√128 ≈ 0.09 均值），训练/评测全程冻结——几何由构造保证，不跟损失谈判；
- **分配**：to_k 输出对码本打分（logits = to_k_out @ C^T，per head），argmax 吸附；
- **梯度**：straight-through（前向用吸附后的码本行，梯度直通到吸附前的 to_k 输出）；
- **作用通道**：b 格 K 通道（write_head_k），V 侧不动；
- **对照纯度**：与臂 0 基线的唯一差异 = 键路径（码本吸附 on/off）。

## 2. 五道护栏

1. 冻结码本（几何构造保证，分布移位免疫）；
2. STE 梯度纪律（前向硬吸附、梯度直通）；
3. **分配用量熵仪表**（预注册：usage perplexity 随行记录，有效码数跌破 M 的预注册比例即触发失败判词 1——VQ 死码同族内险）；
4. **codec 税预注册线**（direct 退步 >2pp = 部分失败，几何收益不许单独报喜）；
5. **臂 0 先行**（§0，split-trunk 独立落地 + 零期望预注册）。

## 3. 失败判词（预注册四档）

1. **死码坍缩**：usage perplexity 跌破阈值（有效码数 < M 的预注册比例）→ 无论 Δ 如何判负（VQ 经典死法）；
2. **几何达标 + 用量健康 + 复训饱和后 Δ=0** → "构造性保秩不点燃寻址"——支持招募优先排序，几何线判非充分（注意：这不是码本失败，是臂目标未达，措辞分开写）；
3. **分配准确率高但 Δ=0** → "分配对了但下游不消费"——招募仍是绑定约束，K 线判词不变；
4. **codec 税超预注册线**（direct 退步 >2pp）→ 部分失败登记。

## 4. 成功判词

**Δ > 0 且内容驱动分配**——离散索引实现内容寻址；hit@k 口径按"分配对不对"读（自然检索形态，逐条目 Δ 仪表，见招募臂预注册 §3）。
