# 锁 v2（协同适应锁）V 形检验预注册：可判死预测 P

> 2026-08-21 用户裁定，假说欠账还清：锁 v2 从叙事升级为假说。静态证据已有（oracle_vrows≈0.04 vs natural_vrows≈0.39——读出链只认识坍缩统计），本检验测其**动力学版本**——切换瞬态。术语：协同适应锁（co-adaptation lock，TERMS.md 已注册）。

## 1. 原预测与混杂

原预测 P：任一训到平台的格，单向把部署几何瞬间改健康（手术/码本切换，读出链一个参数不动），随后 500 步内状态路径逐条目 Δ 必先降后升呈 V 形（低点显著低于改几何前基线）；**判死条款：几何改善后 Δ 单调不降 → 锁判死**。

混杂（用户裁定拆分理由）：在招募臂中点测，"降"分不清锁的失读期还是招募训练波动；且 40K 平台对象在自然检索任务上的 Δ 本就无定义（它没训过这任务）。

## 2. 试验场与两相设计（冻结）

试验场 = **40K 收顶 0.3185 对象**（补全复训手术版，`retrain_readout_c_tokcenter_40k_20260819`）。

### 相一（冻结瞬态，杀招所在）

- 读出链**全冻结**，单次部署几何切换（坍缩基线 → 健康几何），**切换后零步**即测；
- Y 变量 = **探针级逐 slot 可读性**（natural_vrows 同款仪表，永远有定义），不许用任务 Δ；
- **判死条款落在这一相**：切换零步若健康几何的可读性不低于坍缩基线 → 锁判死，"单边修几何即可"成立，锁的协同跳变主张作废。
- 本质：oracle_vrows≈0.04 那次静态签名的受控复现，但这次切的是**部署几何**、对象是**训到平台的读出链**，混杂最少。

### 相二（恢复动力学，信息量次之）

- 恢复训练，看可读性/Δ 的回升轨迹——V 形的上升臂；
- 回升存在 = 重适配代价实存；迟迟不回升 = 锁的"重适配可恢复"主张也要打折。

### 退路（预冻结）

若平台格连探针基线都接近零 → 如实报"该对象无可降空间"，V 形检验主战场回到**招募臂中点**（等招募臂 Δ>0 存在后做任务 Δ 版复测）。不许届时临时改判词。

## 3. F2 作用域条款（随附冻结）

锁声明作用域在**键-读出界面**，与 summarizer 无交互——fork 3（summarizer 保真度改造）前后若招募 Δ 或键几何指标发生位移，锁的作用域声明**同时判死**。
