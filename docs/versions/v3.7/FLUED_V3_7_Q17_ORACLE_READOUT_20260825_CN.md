# FLUED v3.7 — Q17 oracle 状态读出训练臂（存在性证明 / 锁 v2 判死实验）预注册任务书（冻结）

> 冻结时刻：2026-08-25，点火前。设计来源：K3 协作设计稿（C3 oracle 状态蒸馏退火三件套扶正为救场实验），用户核准并附加四条件（§2 逐条入册）。
> 上游：E73（oracle 写入判决/手工构造）、E80–E87（复训器时代全账）、E104（回路缺席）、E107（Q15 格二影帝结局）、E108（Q16 断点定位站 1 上游）、锁 v2（协同适应锁，TERMS 已注册）。

## §0 定位（为什么是现在）

整条 K 线/fork 线的证据矩阵里**没有一个阳性格**——每一格都是死法，没有一个格子证明这条管道在任何条件下能通过。审稿人必问"让它工作一次给我看看"。Q17 是本赛季第一次**主动制造阳性条件**：手工健康态从诊断仪器（E73 探针）变成训练教材——

1. 手工构造装满内容的健康状态（绕过 summarizer，直接构造 S）；
2. **从零训一条读出链**专读这些状态——锁 v2 预言：没有共适应史的读出链读健康状态应当轻松成功；
3. 蒸馏退火：oracle 态与自然态按课程混合，读出链从"读人造健康态"退火到"读自然态"；退火终点 Δ>0 = 端到端检索第一次点燃，锁 v2 拿到判决性确认（锁=共适应史，不是通道容量）；
4. 连读 oracle 态都训不成 → 容量判词硬化到读出侧本体——最硬的一格负结果。

**venue 挂钩（用户核准规则，入册）**：Q17 阳性（哪怕退火终点 Δ 弱张开）→ 冲 ICLR（"完整失败拓扑+唯一工作点+修复路径"形态）；阴性 → 转 TMLR，规模轴（150M 从零、健康门前置+token 预算延长档）从容跑完再投。venue 决策从赌博变为读数驱动。

## §1 设计（冻结）

**对象与冻结面**：基座 = Q15 正臂收官 checkpoint（`v37ks_d_sm_q15_circuit_20k_ctx4096_20260825b`，d 格——只有 d 格在压缩区剔除下保留 V~ 状态内容路径，b 格在剔除下结构性无答案路径，E107 接线核实）。冻结：byte/encoder/segmentor/summarizer/write_head×2/KDA 递推（无参数学）全部不动、no-grad。**从零重初始化**（固定种子）并训练：**readout_query×2 + realign×2（状态机内部读出投影）+ align_k/align_v + backbone + decoder_in + decoder**——状态→logits 的整条读出链。【修订 v1（2026-08-25 施工审查时）：原条款漏列 realign——`state_machine.realign`（model.py:613）是读出投影本体，且 E80 复训器冻结面原文就是"realign+decoder_in+decoder"；条件 1 的单变量对照要求同一足迹从零，漏掉它等于在链里留一段共适应史。发现时刻=施工审查，未消耗任何训练。】

**oracle 态构造（复用 E73 同款）**：S_or,i = Σ_{j≤i} k_j v_jᵀ（无衰减、无 delta 规则，gates 来自冻结 write_head 对当前窗的真实计算），双通道（S_k 用 index gates、S_v 用 memory gates）。

**范数尺度匹配（条件 2，最大实施风险）**：oracle 态范数（~10³ 档）与自然态（~10¹ 档）差约 200 倍，不对齐则"退火失败"可能只是尺度悬崖（假阴性）。冻结做法：逐窗逐通道缩放 α = median_i‖S_nat,i‖_F / median_i‖S_or,i‖_F（自然态范数在同一批窗上实测），oracle 态乘 α 后进入读出链；α 逐窗落盘随行。

**退火课程（预注册档位，禁止中途改）**：oracle 混合比 p ∈ {1.0, 0.75, 0.5, 0.25, 0.0}，每档 2K 步，共 10K 步；同一窗内双通道同取 oracle 或同取自然（逐窗抽签，专用 generator 固定顺序）。

**训练任务**：burst_tail echo CE（Q15 同管束：R=3 突发性注入 + 压缩区剔除 + 先验筛，筛子基准=基座开工 checkpoint 固定）——只训任务损失，codec 损失不参训（读出链专臂）；codec 双指标在收官 eval 测读作参照列。LR 1e-3 + warmup 100 + cosine→0（状态不经梯度，无 E103 风险面）；batch=1 @4096B。

**收官评估（条件 3，钉死考场）**：退火终点（p=0，全自然态）跑 `probe_burst_route_q15` 六臂逐条目 Δ（源段完好−置乱，n=48，与 E107 同仪表同形态同种子流）——**主终点 = Δ 的 95% CI 是否含 0**。附列：intact byte_acc/exact、四消融臂（叙事对照）。同时回报 p=1.0 阶段 echo byte_acc 轨迹（点火成功判据用）。

## §2 四条件（用户核准附加，逐条入册）

1. **单变量差异点名**：E80–E87 复训器时代已跑过 oracle/自然混合退火（配比 0.8→0.1，oracle 臂全程趴 0.06–0.07，E80；E83 四臂 0.2999 不分彼此；E87 平台 0.3185 封顶）——但那些链**带共适应史**（服务对象就是塌缩态格子）。Q17 唯一变量 = **链从零、无共适应史**。E80–E87 在冻结文本中登记为自带对照臂：同理念不同史；Q17 读数无论阴阳都是干净对照。引用禁令：不许把 E80–E87 的 acc 口径与 Q17 的 Δ 口径直接比数值，只能比"形态是否可点燃"。
2. **范数尺度匹配**：见 §1（α 公式冻结、逐窗落盘）。
3. **Δ 钉死考场**：burst_tail 逐条目 Δ（§1 收官评估），与六代攻法同族同口径；不自创新的 Δ 定义。
4. **阳性判词作用域预写窄**：即便全赢（读 oracle 成功 + 退火终点 Δ 张开），证明的只是"**读出锁 = 共适应史而非通道容量**"——写入侧几何塌缩（键压向同一方向）原样还在，生产自然态仍是塌缩态；工作点到生产的距离 = 写入侧修复（码本键线）。任何"管道修好了"的读法都是越界。

## §3 判读矩阵（预注册）

| 点火判据（p=1.0 段，前 2K 步） | 退火终点 Δ | 判词 |
|---|---|---|
| echo byte_acc >0.30（oracle 态按构造含内容，读不出即读出容量硬化） | — | 若点火失败：**容量判词硬化到读出侧本体**（最硬负结果格），退火不跑 |
| 点火成功 | Δ>0 且 CI 不含 0 | **阳性**：锁 v2 判决性确认（锁=共适应史）；端到端检索首次点燃；作用域按条件 4 |
| 点火成功 | Δ CI 含 0 | **中间格**：健康态可读、退火过不去——锁 v2 的"协同跳变"主张获支持但退火路径未能跨越；如实登记，不申领阳性 |

## §4 纪律

- 判读金规照旧：Δ/剖面/仪器读数是判词，损失曲线永不作数；训练期 echo byte_acc 只作点火判据，不作成功指标（奖励/成功指标分离条款延伸）。
- 逐条目 Δ 全量落盘；α 缩放系数、退火档位切换点、oracle/自然抽签流全部可复现（专用 generator）。
- 预算 10K 步（预计 <1h：编码器冻结，梯度只过读出链）；里程碑每 2K（档位切换点）。
- 收官一次性入册：E 行 + 本任务书收官补记 + venue 挂钩读数报协作链。

## §5 收官判读（2026-08-26 点火失败停臂，判词落锤）

**判读矩阵落格：点火失败——容量判词硬化到读出侧本体（最硬负结果格）**。

- **点火判据读数**：p=1.0 段（前 2K 步）echo byte_acc 峰值 **0.1042@step 800**，随后回落震荡（1060 步 0.061 → 1900 步 0.040），距判据线 0.30 差近 3 倍；loss 单调降（5.17→4.23）但按判读金规不作数。sieve 在岗（拒收率 26%，答案不可先验猜）——0.104 里有真读出成分但远不构成"轻松成功"。
- **机械执行**：按 §3 预注册"点火失败→退火不跑"，step 2520（p=0.75 档）处停臂，剩余 7.5K 步不烧。收官 Δ 探针不跑——链连 oracle 态都读不出，自然态 Δ 平凡为零，无信息量，如实注明不挂账。
- **判词**：锁 v2 的预言"没有共适应史的读出链读健康状态应当轻松成功"**证伪**——从零链 + 手工健康态（α 范数匹配在岗：α_k≈0.006–0.009/α_v≈0.002 全档稳定，尺度悬崖已排除）+ 2K 步预算，读不出。读出侧的瓶颈**不只是共适应史，读出容量/接口形态本身就是墙**：E87 的 0.3185 平台不是锁的余孽，是容量的真容。锁 v2 作用域收缩为"共适应史效应存在但非主约束"，判词降级登记。
- **venue 挂钩执行**：Q17 阴性 → 按 §0 核准规则**转 TMLR**，规模轴（150M 从零、健康门前置+token 预算延长档）从容跑完再投。
- **诚实注记**：2K 步×batch1（~1000 任务样本）是预注册预算内的判决——"轻松成功"若成立应在该预算内显形；读者若主张"更长预算或可训成"，那本身就已证伪"轻松"二字。
