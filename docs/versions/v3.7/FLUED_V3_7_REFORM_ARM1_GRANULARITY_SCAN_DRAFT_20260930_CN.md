## §0 立项理由（登记第一条：措辞把守留下的未分尾款即改造线方向分叉点）

- **未分尾款**：乙案 ctrl 同死把「参数量」（+10.3%）与「摘要器语义」（DiT2+qpool vs mean-pool+MLP 两构造同死）两枚替罪羊排除，伪件与真件唯一共享=**接头动作**（值侧替换＋地址侧广播）；但「接头动作」与「块粒度」在 C=64 单点上不可分——同手术换到更细粒度：若复活，凶手=压缩率；若仍死，凶手=替换/广播本身。此判别是改造线的方向分叉点：**块粒度定罪 → 细粒度写入即改造解**（本臂存活档直接接任）；**接头动作定罪 → 替换式写入整条路线在宿主上死刑**，改造须换非替换形态（加性/门控混合——登记设计空间，本册不开列）。
- **为什么阶梯而不是单点细档**：单点（只跑 C=8）只能二分死活；阶梯（8/16/32）给出剂量响应形态（单调渐退 vs 阈值平台），阈值位置本身就是改造安全域的边界读数；每列 ~0.5 GPU·h（乙档实测标定：20K 训练 0.400＋判决仪器 ~0.1），三新列 ≈1.5 GPU·h，信息/预算比最高。
- **为什么仍在 R3 宿主**：单变量纪律由构造保证（手术其余维度逐项钉死，唯一变量=C）；母列/乙档在册免跑，阶梯两端锚零成本；判决仪器与 R2/R3 同卷同种子是可比性的构成条件；载体全套在架（`tools/baselines/deltanet_r2/`：`r2_spec.py` 母列锚 48,152,896 单源、`r3_spec.py` 三臂单源含乙档全链、`train_deltanet_r3.py` 旗标化训练器）。

## §1 体制裁定（本案第一条：基座冻结与变量钉死）

- **基座冻结**：宿主 = **R2 母列同款 DeltaNet-50M**——fla 0.5.1 `DeltaNetForCausalLM`，参数锚 **48,152,896**（`r2_spec.py` 单源），corpus_v3（sha256 前 16 `ed4ab97810776ce7`），4096B 字节窗，Mistral 32K BPE+BOS 截 2048，**20K 步 from-scratch**，fla 原生 LR 3e-4（warmup 1024／cosine 至 0.1×／betas (0.9,0.95)／wd 0.1／clip 1.0／看门狗 1000）全套照抄 R2/R3。**不温启动**（R3 §1 在册理由：续训引入第二变量）。
- **宿主输入域=token 级注记（2026-09-30 口径纠错随行，判读引用必带）**：R2/R3 复证线 DeltaNet 输入域为 **Mistral 32k token 级**（`r2_spec.py:50-52` vocab_size 32000／tie_word_embeddings False；窗语义=corpus 按 4096B 切窗→utf-8 errors=replace 解码→tokenizer 加 BOS→截 2048 token，`r2_spec.py:59-62` 在案）。本案一切判词限定 **token 级输入域**；**字节级接口从未被复证臂检验**（回未排除混杂清单），本文禁写「字节级宿主」表述。
- **变量钉死**：唯一变量=**块粒度 C**（手术参数化）；手术其余维度逐项钉死（§2.0「同手术」构成定义）；tokenizer/窗/预算/调度/种子/仪器逐项照抄 R2/R3，「顺手优化」=体制混杂；效率工时硬上限照 E124 例（每档 2 天，超了先点火再优化）。
- **同卷纪律**：判决仪器与 R2/R3 收官**同款同种子**（500 窗×4 块+池化，选择链 424242／bootstrap 2000 次 424243，`probe_e122_deltanet_book.py`＋`pool_necessity_blocks.py` 零口径改动）；母列 **+0.1040 [+0.0951,+0.1125]** 与乙档六列（主列/加固/ctrl/去消融全表）**直接引用不重跑**（4090 同机同 env，权重与 items 在机）；每新列复核同卷构成性证据（n_sel=48,231/n_ctl=43,810 逐位一致）。
- **硬件口径（坑 9 实例④维度）**：全周期同机同 env（建议 4090，§10.3——乙档在册读数同指纹）；读数带硬件指纹，跨硬件只比方向；意外判死若发生于非 4090 承载，回 4090 重锚（丙臂预注册规则沿用）。
- **逃逸口原则沿用**：DeltaNet 纯线性、无注意力层可吸收需求，整模账直接打在状态通道上——手术毒性若存在，账上必显形（R2 §1/R3 §1 在册）。

## §2 臂定义（粒度阶梯：同手术换粒度；五档两免跑）

### §2.0 「同手术」的构成定义与连带共变注记

**同手术** = {summarizer 构造（DiT2+qpool 4 锚定查询 temp 16.0+双头 FFN，`r3_spec.py:465` `build_summarizer` 原类零重实现）、双头全接接头（值侧 `v_t←m_c`＋地址侧 `k_t←k_c`，side=both）、tap 点（v/k_conv1d 输出，`r3_spec.py:552/550`）、广播算子（`t//C` 逐位拷贝，`r3_spec.py:380-391`）、训练体制（§1）}；**换粒度=只动 C**。凡动其余任一维度即出本案单变量授权（查询数随粒度缩放／单头去消融／非替换写入等——登记为后续变体，本册不开列）。**连带共变注记（判读引用必带）**：①qpool 查询密度随 C 共变（4 锚/span：C=8→0.5 查询/token vs C=64→0.0625）——「同手术」定义的构成部分，「纯粒度」（查询数同步缩放）属另一手术参数化；②DiT span 内注意跨度随 C 共变；③块数/窗随 C 变（描述量落盘，不作必要性账分母）。

### §2.1 档 M=母列（无手术）——在册免跑

R2 母列 20K：池化 **+0.1040 [+0.0951,+0.1125]** 直接引用（阶梯上端锚=无压缩极限）。

### §2.2 档 G8（细档，C=8 token/块）——新跑，**承重列**

≈256 块/窗（训练窗 2047 token，尾块 valid mask 处理在册）。**选值理由**：①我们架构运行点 ≈24B/块 × 0.3982 tok/B ≈ **9.6 token/块**（E124 门②在册口径），另丙回执 S0'' token 空间段长 mean ~10.7 token 同窗族佐证——C=8 是该运行点的最近 2 幂下档；②2026-09-14 晚用户终审点名「8 token 块同手术」。**身份=判别承重列**（结局格归属机械依赖其判档，§5）**＋改造第一候选运行点**（格 1 兑现时）。

### §2.3 档 G16（中档偏细，C=16）——新跑

≈128 块/窗。我们架构运行点的最近 2 幂上档——G8/G16 把 ≈9.6–10.7 token/段 夹在中央；若阈值落此间，改造运行点与我们架构原生粒度的相对位置直接可读。

### §2.4 档 G32（中档偏粗，C=32）——新跑

≈64 块/窗。C=8 与 C=64 的几何中点；阈值定位与单调性核验的第三手术点——三点（加乙档四点）是判「单调/阈值/仍死」三形态的最小充分档数。

### §2.5 档 G64=乙档（原粒度，C=64）——在册免跑复用

R3 乙臂六列全表（`R3_SUMM_RECEIPT §9.5`）：主列 **+0.00019 [−0.00023,+0.00059] 死档**／s1 +0.00013／s2 +0.00030（加固 2/2 同格复现）／ctrl −0.00075（参数匹配对照同死）／value −0.00044／addr −0.00122（单头皆死）。阶梯下端锚=原粒度死档，零成本复用。

### §2.6 阶梯设计一句话

**×2 几何阶梯 {8,16,32} 三新列＋两端在册锚（母列=无手术／乙档=C=64 死档）=四点手术剂量曲线，总预算 ≈1.5 GPU·h**——理由：2 幂阶梯与宿主原生铺瓦粒度族（16/32/64）同族、把我们架构运行点（≈9.6–10.7 token/段）夹在 G8/G16 之间、三新列是单调/阈值判别与加固预算（封顶 ≈4 GPU·h）平衡下的最小充分点数。

### §2.7 对照结构（本案不设新训练对照列）
