## §0 定位

Q19 证明闭式解存在（0.33）而 Q17 证明 SGD 在 2K/单种子下找不到（0.10）。Q18 v2 做两件事：**可学习性墙的定量终审**（A：给足预算 SGD 能否摸到闭式天花板）与**全赛季第一发修复路径实测**（A′：闭式温启动 + 微调）。

## §1 双臂（冻结）

**A 臂（预算终审）**：Q17 形态原样复刻延长——同一从零读出链（**链范围 = Q17 修订 v1 足迹：readout_query×2+realign×2+align_k/align_v+backbone+decoder_in+decoder**，Q15 d 格基座冻结面不变），oracle 态全程（不退火——审的是"读人造健康态"本身的可学习性），**40K 步 + warmup 200 + cosine→0（E103 承重墙条款），3 种子（42/1/2）**。LR 沿用 Q17 的 1e-3（同任务同链，终审要的是预算变量不是配方变量）。B 参照列（降级形态）：每种子收官时加测一列"从零链读明文 memory 行"的同预算读数（不独立成臂——Q19 明文列 0.793 已预答冻结端口一侧，本列答从零侧）。

**A′ 臂（闭式温启动，双列）**：读出链各模块以 Q19 闭式三段件的等价权重初始化（ridge 段1/段2 映射到 readout_query+realign 对应层，生产 donor 端口权重灌 decoder_in_mem 对应位置/decoder 保持基座值——映射规格见 §3 施工注记；**零变化律检查预注册：温启动后首步 eval 必须显著高于随机初始化链（否则初始化没接通，臂作废重查，不许判负）**），随后微调：
- **oracle 态列**：验"温启动能否摸过 0.33 天花板"（目标线 >0.4）；
- **自然态列（生产判词）**：温启动后自然态上逐条目 Δ（源段完好−置乱，Q15 六臂探针同口径）张开 = 修复路径为真。
- 预算 20K/列（微调非从零——与 A 的 40K 不直接比步数，比的是"摸到天花板没有"；审稿 parity 注记入册）。种子 42 单种子先行（A′ 是方向性实测，种子加固等方向成立后再补）。

## §2 判读表（预注册）

**A 臂**（40K×3 种子，oracle 态 echo byte_acc 终点 + trailing 20% 斜率 CI + 逐种子）：
- 三种子均值 ≥0.30 且 CI 不含 0.25 → **Q17 = 预算伪影**，可学习性墙降级为"预算/配方问题"，E109 判词修订；
- 三种子均值 <0.15 且 trailing 斜率 CI 含 0 或为负 → **墙坐实为损失面/动力学性质**（预算排除），终审成立；
- 中间带（0.15–0.30）→ 如实登记"预算部分有效"，判词写"可学习性墙软化但未倒"，Q20/Q21 的优先级上调。

**A′ 臂**：
- oracle 列 >0.4 → 温启动破天花板，修复路径第一块砖落地；
- 自然列 Δ>0（CI 不含 0）且置乱地板列贴先验 → **修复路径为真**（生产判词）；
- 双列皆未过（oracle 卡 ~0.33、自然 Δ 平）→ 第一层墙（0.33 接口上限）临门实锤 → **Q20 顺势点火**（多槽读出）；
- oracle 列直接破 0.4 且自然列 Δ 张开 → Q20 紧迫性降级重排（用户裁定条款）。

**通用纪律**：一切过程读数涨了不算赢，终点 Δ/终点 acc 才算；每臂每列带置乱地板列与盲猜先验门（不过门的列作废不发判词）；codec 护栏 >2pp 回调线照旧（A′ 微调期的 codec 双指标随行）。

## §5 施工修订 v1（2026-08-27 点火前，主会话裁定——两项均非架构级）

1. **D7 验收（零变化律自检的考场修正）**：预注册的 echo byte_acc 自检考场在冒烟窗上不可分辨（基座生产链自身同点读数 0.0）——自检考场移至 Q19 同款 fine 细格（全槽 as-encoded，无 burst，backbone 腿判官）。**门槛标定修正**：绝对线 0.15 改为**比率线——温启动首步读数 ≥ 从零链同点读数的 3 倍**（原条款+理由+时刻：绝对线按从零链 0.00–0.04 标定，但基座生产链读 oracle 态本身只有 0.127–0.137，绝对线对 oracle 列系统性过严；比率的判别力不变——从零 3–10 倍以上即证明接通。冒烟实测：自然列 0.3105 vs 从零 0.021（15×）PASS；oracle 列同态挂载 0.137 vs 0.013（10.5×）PASS）。
2. **`--q18-xstate-target`（翻译挂载）默认关**：它把 oracle 列的挂载目标换成自然态生产行，能过旧绝对线但改变了"oracle 列测什么"——未评审旋钮，本季不使用，作为停放选项登记。oracle 列用同态忠实挂载点火。
