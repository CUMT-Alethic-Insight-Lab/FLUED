## §0 点火前检查（用户裁定：不做完不点火）

**检查 1（评测侧运气——已排除，证据在案）**：induction 探针的评测文档由 `torch.Generator(manual_seed(DOC_SEED+d))` 逐篇构造（probe_induction_score.py:208），与 checkpoint 无关；实证：2x sweep 七个里程碑 JSON 的 init 块逐位相同（max 0.2931/mean 0.2838 ×7）——init 模型同种子新建，读数逐位一致 ⟺ 评测管束跨里程碑逐比特固定。**评测集固定性 PASS**。

**检查 2（训练侧运气——数据突发性仪表）**：训练流是 `random.Random(seed=42)` 的随机偏移抽取（flued/data.py:158-194，num_workers=0 单流，Mersenne twister 跨平台稳定）——任意步的训练窗可离线精确重放。仪表：重放 2x 臂（E110）的数据流，逐 1K 步带计算窗内突发性密度（窗内重复 ≥12B 子串的字节覆盖率），与 induction 轨迹（3K 五头破线 2.74×）叠读：
- **破线点对应数据热点 → 瞬态是数据喂养的**：规模轴叙事再降级，"回路催生"回到数据层——Q13 重放合法性反而上升（数据驱动催生有先例，缺的只是常驻剂量）；
- **不相关 → 数据运气排除**，2×2 矩阵原样有效。

## §2 判读矩阵（K3 设计，用户核准，四格冻结）

现有三格：1x@2e-4（无）、2x@2e-4（瞬态）、4x@1e-4（无）。新两发补齐后：

| 结局 | 判词 |
|---|---|
| 瞬态出现在两个 2x 格、两个 4x 格皆无 | **规模非单调为真**——2x 附近存在"甜点"，回路催生存在规模窗口，写入机制章 |
| 瞬态出现在两个 2e-4 格、两个 1e-4 格皆无 | **纯 LR 效应**——"规模推回路"降级为 LR 敏感性案例，规模轴回到**未判**（不是"规模证伪"——瞬态消失只能证"催生条件含 LR 档位"，不能证"规模无用"，用户注记口径） |
| 只有 2x@2e-4 有（交互格） | LR×规模交互——"回路催生需要规模与 LR 的联合窗口" |
| 2x@2e-4 复跑瞬态**不复现** | **可复现性警报**——原 2x 瞬态降级为单次观察，全部相关叙事加注 |

codec 侧同表分账：4x@2e-4 仍优于 1x/2x → 4x 的 codec 优势是规模；2x@1e-4 相对 2x@2e-4 明显改善 → 低 LR 是主因。

## §3 条件第三臂（数据运气检验双用，用户裁定）

若检查 2 的仪表显示突发性有热点：在 **2x@2e-4 复跑臂**上换数据顺序 seed（其他全同）——"复跑"同时变"数据运气检验"，一发改造成两用，不加预算。该臂同时喂判读矩阵第四格（复现性）与数据运气判词。无热点则不点火（复现性检验暂不单独立项）。
