# v3.7 招募臂预注册：自然检索任务（K 通道招募判决）

> 2026-08-21 用户裁定设计，本文冻结后点火。前置：E90（Q10 闸门判负，招募 Δ=0.0000 与几何并列第一级瓶颈）；magic number 档案馆形态退役（双重 OOD 混杂：逐字节精确 + 合成格式，Δ=0 分不清"K 不可招募"与"任务对 K 不可赢/模型没看懂任务形式"）。自然检索形态把两个混杂同时拆掉：留在语料分布内，答案粒度=一个词/小片段，K 侧从"不可赢"变回"可竞争"。

## 1. 任务管线（自然检索批次）

训练语料窗口内**现取** 32–64B 连续片段作为来源段，遮其中一个词/小片段，在来源段之后提问"前文'XXXX___XXXX'空格处是什么"；答案 echo 段的字节承担损失。

**结构保证（必修一裁定，两档报价的落定）**：要求"来源段对问题段之后的 query 只经 K→状态→读出可达"。接线事实（`flued/v36/model.py`）：direct 路径是 per-chunk 独立条件化（chunk i 的 decoder 只读 v_row[i]，GlobalSpanDecoder 无跨段读），天然无泄漏；**唯一旁路 = SLM backbone block1 因果 cross-attention 的 store 行**（v=memory 格下 memory 行直达 store）。

- **档 a（掩码级剔除）——采纳**：block1 的 `allowed` 掩码本就内联构造（`model.py` SLMBackbone.forward，`(~future) & chunk_mask | eye`）；对问题段及之后的 query 位置 q>j 剔除来源段 store 行 j，只需从任务构造器线程一个 (B, n_q, n_kv) bool 掩码 AND 进 `allowed`（模型侧 ~10 行，无新参数、不动 forward 结构、checkpoint 不受影响；对角保留，无全掩码行 NaN 风险）。fork 2 的 m-view 路径（`_forward_views`）若日后叠用需同步 AND，本臂 views=1 不涉及。
- 档 b（结构手术）不触发。**退回条款（预冻结）**：若档 a 实施中发现不可行，退回事后遮蔽 V 旁路方案，判读降级注明两条：(i) 训练期压力路由变弱（模型仍可经 backbone 注意力库绕开 K，r=1.0 的"强制"名不副实）；(ii) 判死条件措辞从"结构性不可招募"弱化为"训练期压力下未招募"，fork 2 重估触发词不变、证据等级降半档。

## 2. 双臂对照

- **A 臂（内容驱动写键）**：键走现行 to_k 内容路径；
- **B 臂（纯位置先验写键）**：写键 = 与内容无关的固定位置向量（强先验绝对位置编码诊断臂）。B 臂的存在就是为了"A Δ>0 且 B Δ≈A"这个结局——内容寻址被证伪为摆设、位置才是真索引。

## 3. 主仪表：逐条目 Δ（扣先验）

逐条目 Δ = acc（答案｜来源段在状态中完好） − acc（答案｜来源段置乱）。逐条目测、留全量记录、再聚合报均值+CI——混合物稀释由逐条目记录兜底；不设"完全不可猜"过滤器。Δ 天然扣先验：纯猜条目置乱前后准确率不变，Δ≈0。

**答案计分口径**：答案为一个词，按归一化后精确匹配计（大小写/空白归一，全词匹配；多 token 词要求整词序列命中）。盲猜与基线共用同一计分器。（口径不冻结阈值于此——0.10 门会随计分松紧漂移，计分器变动须重锚。）

## 4. 招募压力施加

自然检索批次按 V 旁路剔除（档 a 掩码）比例 r 强制走 K→状态→读出路径，r 爬坡预注册 **{0 → 0.5 → 1.0}**，每档 ≥5K 步，饱和判定沿用"末 2K 逐位走平"。总预算 20K 步，与历史臂可比。

## 5. 有效性门（开跑即冻结）

> **V 旁路完好基线准确率 − 盲猜先验 ≥ 0.10，且在评测 n 上二项检验 p<0.01。**

盲猜先验定义（必修二裁定）：**同模型、来源段全程遮蔽条件下裸答的准确率**——它就是 Δ 的减数，零额外成本、口径自洽。不满足 → 任务理解层失败，Δ 不可解读，**臂作废重跑，不许判负**。

**OOD 判定标准（可操作化，并入）**：若日后确需分布外形式——4–8 条 in-context 示例后，答案格式合规率 ≥90% 且内容准确率超盲猜先验一个预注册边际；过不了这门，任何"模型没学会"的读数不许归因于记忆机制。

## 6. 判读矩阵（预注册）

| A Δ | B Δ | 判词 |
|---|---|---|
| >0 | =0 | 内容寻址为真机制 |
| >0 | ≈A | 内容寻址证伪为摆设，位置才是真索引 |
| >0 | >A | 位置主导，内容寻址辅助 |
| =0 | =0 | 见判死条件 |

**判死条件（预注册）**：r=1.0 拉满、饱和后双臂 Δ 仍 =0（CI 含 0）→ K 通道当前接线下结构性不可招募，fork 2 全线重估。（档 a 退回条款触发时措辞按 §1 降级。）
