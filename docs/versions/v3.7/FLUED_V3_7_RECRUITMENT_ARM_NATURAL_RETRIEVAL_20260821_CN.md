# v3.7 招募臂预注册：自然检索任务（K 通道招募判决）

> 2026-08-21 用户裁定设计，本文冻结后点火。前置：E90（Q10 闸门判负，招募 Δ=0.0000 与几何并列第一级瓶颈）；magic number 档案馆形态退役（双重 OOD 混杂：逐字节精确 + 合成格式，Δ=0 分不清"K 不可招募"与"任务对 K 不可赢/模型没看懂任务形式"）。自然检索形态把两个混杂同时拆掉：留在语料分布内，答案粒度=一个词/小片段，K 侧从"不可赢"变回"可竞争"。

## 1. 任务管线（自然检索批次）

训练语料窗口内**现取** 32–64B 连续片段作为来源段，遮其中一个词/小片段，在来源段之后提问"前文'XXXX___XXXX'空格处是什么"；答案 echo 段的字节承担损失。

**结构保证（必修一裁定，两档报价的落定）**：要求"来源段对问题段之后的 query 只经 K→状态→读出可达"。接线事实（`flued/v36/model.py`）：direct 路径是 per-chunk 独立条件化（chunk i 的 decoder 只读 v_row[i]，GlobalSpanDecoder 无跨段读），天然无泄漏；**唯一旁路 = SLM backbone block1 因果 cross-attention 的 store 行**（v=memory 格下 memory 行直达 store）。

- **档 a（掩码级剔除）——采纳**：block1 的 `allowed` 掩码本就内联构造（`model.py` SLMBackbone.forward，`(~future) & chunk_mask | eye`）；对问题段及之后的 query 位置 q>j 剔除来源段 store 行 j，只需从任务构造器线程一个 (B, n_q, n_kv) bool 掩码 AND 进 `allowed`（模型侧 ~10 行，无新参数、不动 forward 结构、checkpoint 不受影响；对角保留，无全掩码行 NaN 风险）。fork 2 的 m-view 路径（`_forward_views`）若日后叠用需同步 AND，本臂 views=1 不涉及。
- 档 b（结构手术）不触发。**退回条款（预冻结）**：若档 a 实施中发现不可行，退回事后遮蔽 V 旁路方案，判读降级注明两条：(i) 训练期压力路由变弱（模型仍可经 backbone 注意力库绕开 K，r=1.0 的"强制"名不副实）；(ii) 判死条件措辞从"结构性不可招募"弱化为"训练期压力下未招募"，fork 2 重估触发词不变、证据等级降半档。

## 2. 双臂对照

- **A 臂（内容驱动写键）**：键走现行 to_k 内容路径；
- **B 臂（纯位置先验写键）**：写键 = 与内容无关的固定位置向量（强先验绝对位置编码诊断臂）。B 臂的存在就是为了"A Δ>0 且 B Δ≈A"这个结局——内容寻址被证伪为摆设、位置才是真索引。

## 3. 主仪表：逐条目 Δ（扣先验）

逐条目 Δ = acc（答案｜来源段在状态中完好） − acc（答案｜来源段置乱）。逐条目测、留全量记录、再聚合报均值+CI——混合物稀释由逐条目记录兜底；不设"完全不可猜"过滤器。Δ 天然扣先验：纯猜条目置乱前后准确率不变，Δ≈0。

**答案计分口径**：答案为一个词，按归一化后精确匹配计（大小写/空白归一，全词匹配；多 token 词要求整词序列命中）。盲猜与基线共用同一计分器。（口径不冻结阈值于此——0.10 门会随计分松紧漂移，计分器变动须重锚。）

## 4. 招募压力施加

自然检索批次按 V 旁路剔除（档 a 掩码）比例 r 强制走 K→状态→读出路径，r 爬坡预注册 **{0 → 0.5 → 1.0}**，每档 ≥5K 步，饱和判定沿用"末 2K 逐位走平"。总预算 20K 步，与历史臂可比。

## 5. 有效性门（开跑即冻结）

> **V 旁路完好基线准确率 − 盲猜先验 ≥ 0.10，且在评测 n 上二项检验 p<0.01。**

盲猜先验定义（必修二裁定）：**同模型、来源段全程遮蔽条件下裸答的准确率**——它就是 Δ 的减数，零额外成本、口径自洽。不满足 → 任务理解层失败，Δ 不可解读，**臂作废重跑，不许判负**。

**OOD 判定标准（可操作化，并入）**：若日后确需分布外形式——4–8 条 in-context 示例后，答案格式合规率 ≥90% 且内容准确率超盲猜先验一个预注册边际；过不了这门，任何"模型没学会"的读数不许归因于记忆机制。

## 6. 判读矩阵（预注册）

| A Δ | B Δ | 判词 |
|---|---|---|
| >0 | =0 | 内容寻址为真机制 |
| >0 | ≈A | 内容寻址证伪为摆设，位置才是真索引 |
| >0 | >A | 位置主导，内容寻址辅助 |
| =0 | =0 | 见判死条件 |

**判死条件（预注册）**：r=1.0 拉满、饱和后双臂 Δ 仍 =0（CI 含 0）→ K 通道当前接线下结构性不可招募，fork 2 全线重估。（档 a 退回条款触发时措辞按 §1 降级。）

## 7. 随行护栏

- codec 双指标报备（direct/backbone，>2pp 退步按部分失败登记）；
- 20K 步预算与历史臂可比；单 seed 初判，阳性补第二 seed；
- E 行入册纪律；终考按修订 3 后的协议（自然检索形态）执行。

## 8. 与锁 v2 V 形检验的联动

锁 v2 的 V 形检验主战场在 40K 平台格（见 `FLUED_V3_7_LOCK_V2_VTEST_20260821_CN.md`）；**招募臂中点为任务 Δ 版复测点**（须待本臂 Δ>0 存在后执行，平台格无任务 Δ 定义）。

## 修订记录

### 修订案 v2（2026-08-21 用户裁定）：答案粒度 CJK 小片段扶正，ASCII 降为对照臂

**动机（入册）**：原主臂（ASCII 词）双重病：(i) 语料中文为主，随机 32–64B 片段约半数抽不到 ASCII 词（实测激活率 train 0.5 / eval 0.25–0.5），梯度压力稀释——招募臂最贵的失败方式是压力不到达；(ii) 更隐蔽的偏差：中文语料里的 ASCII 词多为数字串/英文术语/专名——高特异性、逐字节精确类答案，正是 magic number 退役的理由（K 侧容量有限，天然不适合存高精度细节），ASCII 主臂有重建"不可赢游戏"的结构性偏差。故：CJK 小片段扶正为主臂，ASCII（重抽方案）降为对照/复测臂。

**§1 片段定义与边界规则（冻结）**：
- 答案 = 2–4 个连续字符的 CJK 小片段；
- 首尾不得为标点/空白/换行；不跨标点边界（边界集枚举见本文附录 A，实现前已冻结）；
- UTF-8 字符边界吸附沿用现有纪律；片段内允许夹带数字/字母（不禁止、不以此为目标）；
- **分词器裁定：不引入**——研究问题是通道招募而非词法切分，分词器引入依赖、失败模式与规格面三笔成本，换不到机制层面的任何东西。代价声明（入册原文）："答案从语言学词变为任意连续字串——本任务测的是'从状态中取回指定来源段的指定片段'这一寻址行为本身，不测词法知识；结论适用域相应限定为字串粒度检索。"

**§2 计分（不变）**：沿用 cloze 同 schema：逐字节 byte_acc + 整段归一化 exact，指标定义一字不改。

**§3 抽样（冻结）**：来源段定位后优先在片段内取合格 CJK 小片段；取不到时重抽片段，上限 **N=8** 次（预冻结）；仍取不到则该样本记为未激活、如实计入激活率。激活率预期 ~1.0，train/eval 实测值入册。eval 全程固定种子流，逐条目可复现。

**§4 Δ 仪表（不动 + 一列描述性统计）**：逐条目 Δ = 来源段完好 acc − 来源段置乱 acc，逐条目测再聚合；不设可猜性过滤器。新增一列描述性统计：裸猜先验分布（来源段全程遮蔽下的裸答准确率，逐条目）——仅作描述，不进任何判据。**口径警告（入册）**：CJK 小片段的 LM 先验可猜性显著高于 ASCII 数字串，盲猜先验将抬高减数、压缩 Δ 动态范围——判读时效应量与 CI 并报，Δ 绝对值不得与 magic number 时代的 hit@1 跨任务比较。

**§5 判死链条（改写）**：c 主臂（CJK）遮蔽比例拉满（r=1.0）且饱和（末 2K 逐位走平）后 Δ=0（CI 含 0）→ 以 ASCII 臂复测对照：
- 两臂皆零 → "K 通道当前接线下结构性不可招募"判词生效，fork 2 全线重估；
- c 零而 ASCII 非零 → 粒度/答案形态问题而非结构性不可招募，另立判词（不得引用结构性判词）；
- c 非零 → 招募点燃，ASCII 臂转为复测确认（可选）。

**§6 其余全部不变**：档 a 构造、有效性门（基线−盲猜 ≥0.10 且 p<0.01，同一计分器）、r 爬坡 {0,0.5,1.0} 每档 ≥5K、饱和判定、codec 护栏、A/B 双臂判读矩阵。

**时序**：修订案冻结即生效；窗口排序不动（F2 → 锁 v2 V 形检验两相 → 招募臂 Q11 v2 点火）。

## 修订案 v3：Q12 示例密集型招募臂（2026-08-22 用户裁定冻结）

> 前置：E98（A 臂有效性门未过、臂作废不许判负——任务形式层失败坐实，r=0 旁路全开档 byte_acc 全程贴地）+ E99（OOD 门未过但正斜率：K=0 0.097 → K=4 0.138 → K=8 0.177，50M 模型能被示例教会形式、只是 8 条不够）。裁定：把斜率变成训练目标。选项 2（机械格式）否决留作后手（与 magic number 退役裁定方向相反，启用前须重新裁定，不得自动激活）。

### Q12.1 样本结构（冻结）

每条训练样本 = **2–4 条完整示例（答案可见）+ 1 条查询（答案遮蔽）**；示例与查询内容独立、示例/查询角色随机化、遮蔽位置随机化。

### Q12.2 反捷径条款（逐样本断言，机械执行）

- 查询答案字符串不得出现在任何示例中；
- 示例来源段 ≠ 查询来源段。

### Q12.3 主终点（关键）

**0 示例 eval 的逐条目 Δ**——脚手架拆除后检索仍在才算点燃；带示例 eval 只作诊断列。若 Δ 只在有示例时非零，如实登记"脚手架依赖"，不申领招募成功。

### Q12.4 沿用条款（原文不变）

有效性门与判死链条原文沿用（基线−盲猜 ≥0.10 且 p<0.01；门过后判死链条重新生效）；codec 双指标 >2pp 护栏；r 爬坡 {0,0.5,1.0}；Δ 仪表与 CJK 粒度规格。B 臂（位置先验键）与 Q12 同炉——新任务形态下双臂对照一次做完，判读矩阵不变。

### Q12.5 窗口

F3 池化臂上 GPU ∥ 示例密集型构造器编写（不占卡）→ 构造器冻结后 Q12 双臂排队；锁 v2 任务 Δ 版 V 检验挂 Q12 中点（Δ>0 存在后）。

## 附录 A（审计补充并入，2026-08-22 冻结）

### A1. 有效性门的挂点（门测理解，终点测留存）

- 有效性门挂在**带示例形态**上：基线（旁路完好、带示例）− 盲猜 ≥0.10 且 p<0.01——门测的是"模型懂不懂这个任务形式"，训练形态是什么就用什么验收理解度；
- 主终点 = **0 示例 eval 的逐条目 Δ**，测脚手架拆除后的检索留存；
- 门与终点禁止混用：门不过 → 臂作废重跑（不触发判死）；门过 + 0 示例 Δ=0（遮蔽拉满、饱和、CI 含 0）→ 判死链条生效。A 臂的作废即门/终点混用之鉴。

### A2. 两条描述性列（只描述，不进判据）

1. 命中条目的片段类型分布（实词片段 vs 虚词片段，沿用终考修订 1 记录条款）；
