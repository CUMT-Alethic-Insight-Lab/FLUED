## 第一部分：第六脸需求规格 v0

### §1 教义修订（相对上一季五张脸）

上一季需求五张脸（先验猜不中 / 零格式门 / 只经状态通道可达 / 密度高于维护成本 / 检索必须比背先验便宜）全部是**「把检索解抬便宜」**。E121 花 36.6 倍剂量抬检索解，E122 证明那批位点根本没有人需要黑板——**五张脸没有一张是「把先验解弄不可用」**。

**第六张脸（入册）：先验解要被结构性剥夺，不只被相对抬价。**

- 锚：posterior collapse 治疗线（free bits / word dropout 族）、REALM 的 ICT 相位分离（结构类比，作处方来源，不作判据——诚实边界见 §7）。
- 连带教义（外部构思审计后收编）：**结果级监督选不出接口**。拿回同一内容存在「读路径」与「写侧捷径（前向复制）」两条等价路径，任务指标不可区分，但梯度密度差数量级，训练必然收敛到模型已擅长的写侧。故需求除五+一张脸外，还须满足第七性质：**监督必须逐位置稠密地作用于读出件本身，不许只监督最终答案**。
- 登记在案的待验假说：前向复制捷径签名（needle 准确率升 + 固定查询方向余弦持平 0.07–0.10）——待遥测核验后销案或翻案。

### §3 点火前置门（全部零训练，缺一不许点火）

1. **密度账（改造版）**：合体臂的辅助监督逐位置稠密，密度天然过账；但仍需落一行算术：每窗遮蔽位点数 × 每位置监督字节 = 等效监督字节/窗，对照维护成本线落盘。
1b. **两门一预算方程（教义入册）**：密度账数的是梯度**供给量**（多少位点的读出能降 NLL），必要性账测的是梯度**质量**（这些位点的梯度是否内容特异）。必要性门若普遍测出 ΔNLL≈0，含义是这批位点的预测根本不依赖远处内容——此时稠密辅助损失也是稠密的噪声，读出件学会的是读无用的痕迹。**两门任一不及格，改的是语料/位点池，不是剂量。**
2. **必要性账 v2（E122 仪器改造，口径按外审攻击③修正）**：测量手段是**模型自身的 NLL**（摧毁是物理性的注意力遮蔽，不是闭式线性探针），故不受「线性可测性」假阴性攻击——但须换一处更狠的修正：E122 已证本基座对任何远处内容的消费都近零，若用「基座当前是否依赖该区」当门，门将自动否决一切位点、永久锁死所有臂。**正确测法是测「内容信息量」而非「基座现状」**：同一位点，内容置于**可读近区**（窗内可见、基座会用）vs 完全缺席，两条件 NLL 之差即该区内容对目标的互信息下界。差值显著为正 = 这段内容值得读，需求可造；差值为零 = 先验/局部可推，该位点淘汰出遮蔽候选池。措辞纪律（入册）：门的一切输出表述为「**相对于此基座与此探测手段，无可测需求**」，永不表述为「需求不存在」——两句话在论文里差一个假设，在被审稿时差一条命。口径钉死：遮蔽粒度、位点抽样 n、CI 口径与 E122 冻结 §4 同源。此账过，脸③才算第一次被实测而非假设。
3. **余弦-距离曲线（新仪器）**：固定查询方向余弦沿写入-读取距离的衰减测量。用途：病因分型——距离平滑衰减 = 干涉挤压（修法：结构化写入）；全程平坦近盲 = 查询压根没学（修法：梯度压力，即本臂）；兼作论文机制章供数。（原拟兼任 k 课程规格，已随 K_max 固定时间表定案而解除；v1.2 起课程改挂源-汇距离分布，见 §4。）
4. **门②多距离正册结论（v1.3：门过）**：单距离（k=1）口径曾落「无可测需求」（ΔNLL=−0.00053 含 0）；多距离分解翻案——**真依赖集中带在 k=2**（均值 ΔNLL=+0.03655，占依赖位 70%），k=1 占 30%，k≥3 无携带。教训入册：必要性门必须多距离扫描，单距离口径会把集中在邻距的需求判死。三份回执全部齐回：
   - **回执一·阈值灵敏度表 ✅**：0.02 档 170.5 字节/窗（113.6×Q13）/ **0.05 档 81.7（54.5×）/ 0.10 档 65.6（43.8×）**——三档全过线，0.05 档照准成立并冻结为选择器阈值。
   - **回执二·源-汇距离分布 ✅**：0.05 档选中块的依赖位 k=1 占 30%、k=2 占 70%、k≥4 ≈ 0——自然依赖全在 1–2 chunk（≈64–128 字节）。K_max 时间表据此倾斜（§4）。
   - **回执三·密度账定向池重算 ✅（口径勘误在册）**：v1.2 的「29 字节/窗 = 19×」误把块字节当监督字节；正确口径按依赖位计——**82 字节/窗 = 54×Q13**。供给线四倍冗余，非擦边。剂量逻辑仍标「质量置换」：每个遮蔽块都是门②实测真依赖，质量近满分。

## 第二部分：E123 合体臂预注册任务书（遮蔽 + 延迟自读出）

### §4 臂定义（单变量 = 合体需求有无）

- **基座**：canonical v37 线 a 格锚 50M 形态（`configs/canonical_v37.json`，施工时核实参数量与口径注记）；种子 42 先行。
- **合体列（v1.3 定向剥夺形态）**：两器件同开——
  - **遮蔽器件（定向·训练形态 = 注意力遮蔽单通道）**：每窗只遮蔽门②实测信息量 >0.05 nat（阈值已冻结）的高信息块（粒度 = **模型 chunk ≈64B**，以模型口径为准，16B 旧文作废），将其从窗内注意力视野中**结构性抹除**（注意力遮蔽，字节流不动，位置编号不动）。**训练形态禁止状态写入遮蔽**——内容必须活着进状态，需求才是「只经状态通道可达」；双遮蔽（注意力+写入）只存在于必要性账的测量/选择模式，搬进训练形态等于造无解需求（v1.3 冻结前拦截，设计评审活例入册）。与必要性账 v2 同码同源、仅模式之差：测量/选择 = 双遮蔽，训练 = 注意力单遮蔽。
  - **选择器（离线静态预计算，v1.3 改）**：冻结基座一次性扫训练窗流，产出每窗遮蔽块 + 依赖位决策日志逐窗落盘（满足槽五），训练时零额外前向。不用在线模式——训练步内每窗重测双遮蔽多花 2 次前向/块，且模型在学读，冻结基座测量随训练漂移、不再代表当前模型。
  - **延迟自读出器件**：对每个高信息块的**下游依赖位**，用**部署形态的同一个查询投影**去读状态里对应源块的内容，读出结果**汇入主流失的预测通路**（不是独立头——独立头会修私有旁路，部署查询纹丝不动，此教训在册）。监督位 = 门②实测的依赖位，不再随机取位。
- **对照列一（纯续训）**：同基座同预算，无遮蔽无辅助损失。wd 0.1 各列同开（保镖手段照旧例）。
- **对照列二（乱序目标列，外审攻击②收编）**：同遮蔽、同辅助损失，但自读出的**目标内容替换为乱序版本**。此列必须学不会——它学不会，才证明主列学的是「读那段内容」而不是「读状态这个习惯」。此列是三仪表之一，不是可选件。
- **预算**：10K 步 @4096B，**三列**串行，本地 5080（估 2–3 天；乱序对照列为攻击②的代价，+1 天换主判词免死）。远端 4090 同期任务以用户调度为准，不撞车。
- **k 课程（v1.3 按直方图倾斜，定案）**：定向形态下每个监督位的 k 由**真实源-汇依赖距离**决定，不人工采样。回执二直方图显示自然依赖 100% 在 k=1–2（30:70），故时间表倾斜：
  - **K_max=1**：0–2K 步（20%）
  - **K_max=2**：2K–6K 步（40%，自然需求最重的主档）
  - **K_max=4**：6K–8K 步（20%，泛化探针档——无自然需求，测已建成接口能否泛化到未训练距离）
  - **K_max=16**：8K–10K 步（20%，同上当远距前兆）
  时间表内只遮蔽距离 ≤ 当前 K_max 的高信息块（超程块本档不遮蔽不监督，后续档自动纳入）。k=4+ 两档本质是释放臂问题的前兆版，不指望贡献阳性判据。调度记忆风险由「依赖结构天然多样 + 时间表只调纳入范围」吸收（攻击①精神保留）。

### §5 判读表（双仪表即判据 + 两路副仪表）

| 仪表 | 口径 | 阳性 |

### §6b 释放臂（预注册的下一臂，合体臂阳性即启动；外审收编，定级为终局实验）

合体臂点燃只证明**被迫的需求**能造出读接口。奖牌测试：**撤掉遮蔽、撤掉辅助损失，回自然分布续训/评测，测固定查询余弦与跨段消费是否自持。** 三结局预注册：

| 释放结局 | 判词 | 论文形态 |
|---|---|---|
| 余弦保持 + 自然分布跨段消费恢复 | 需求工程成功，接口一旦建成可自持 | 机制论文升格：需求锻造配方 |
| 撤压即退化 | 器官需持续需求维持 | 有价值的负结果，指向「预训练分布里此器官无生态位」的更强版本 |
| 回混合架构重训后 3:1 配比移动 | **配比是训练分布的函数，不是架构常数** | 领域级主张，闭合 L2 原始问题——优先级高于一切单点架构改进 |

> **依赖排序注记（施工评审收编）**：第三结局的领域级主张挂在 GDN2「3:1 跨代纹丝不动」锚上，而该锚尚在「未过侦察」状态。**GDN2 撞车侦察 + 原文核对（附.4 队列）必须在释放臂收官判读前完成**；否则第三结局只能落「观测到移动」，不能落「配比是分布函数」。

**有效性门**：codec 绝对回调线照 d 格自锚老规矩（换锚不降格先例）；盲猜先验地板按种子窗流逐种子自锚（坑 9 实例③教训，不跨种子借用）。

### §7 施工与纪律

- **冒烟 500 步四条款**（坑 9「条款换臂必换锚」在场）：① 遮蔽接通——被遮蔽区对窗内注意力的注意力权重**逐位审计恰为零**（不是近似小，是零）；② 辅助损失汇入确认——梯度路径审计，部署查询投影确实收到来自遮蔽位的回传梯度；③ 逐键 diff（仅新增遮蔽器件 + 自读出器件 + 接线）；④ codec 回落判读线按本臂形态（遮蔽合体）自锚，不引 E120/E121 旧线。
- **坑 8 纪律**：点火显式旗标全带（基座架构漂移自查）；q15_* 等历史旗标的保留/弃用清单照 E120 先例逐枚枚举；duplicate process/CUDA context 照旧。

- **权重图/遮蔽图不进反向图**，遮蔽图随样本生成；遮蔽随机种子与数据流种子分离落盘。
- **施工口径槽四条（冻结文本预留，施工时逐条钉死回执）**：
  - **槽一·必要性账 v2 的「完全缺席」实现**：用 **(b) 注意力 + 状态写入双遮蔽**——字节流与位置编号全不动，窗内注意力与状态写入两通道都看不见该区，ΔNLL 纯净测「携带信息」。不用中性填充替换（surprisal 位移需诱饵对照吸收，E122 v1.0 腐蚀口径的教训在册）。且与臂内遮蔽器件的 measurement-mode **同码同源**（禁两套口径）。
  - **槽二·乱序列的乱序口径（v1.3 改跨窗）**：**块间置换·跨窗版**——乱序目标 = **另一窗**同形态高信息块的真实内容。定向形态每窗仅 ~1.4 遮蔽块，同窗置换多数窗无料，故跨窗取材。状态里全是真内容、真可读，唯独对应关系错；读出件若只学会「从状态抠任意块」，此列 loss 不降、对真内容的 acc 不升，正好隔离「读习惯」vs「读那段内容」。不用块内字节置换（保留 unigram 结构，隔离力弱一档）。指标钉死：对**真内容**的 byte-acc 贴盲猜地板。

  - **槽四·遥测分层**：仪表①的 byte-acc 按 k 分层落盘（已写入 §5 仪表①口径）。
  - **槽五·选择器离线决策日志（v1.3 定稿）**：选择器离线静态预计算（§4），与门②正册仪器同码同源、仅模式之差（测量 = 双遮蔽，选择产出 = 遮蔽块 + 依赖位清单）；决策日志逐窗落盘（遮蔽了哪块、信息量读数、源-汇距离），供收官审计与密度账复算。训练时零额外前向。
