# K 线寻址能力终考 · 预注册（ex-ante）

> 裁定纪律（2026-08-18，用户）：预注册的全部价值在于 ex-ante——阈值、样本量、验收标准在看到任何新实验结果之前落笔。
> 本文写于 to_k 手术两格（E75-E78）、oracle 判决（E73）、复训首跑（E80）之后、μ 课程版复训与解耦手术格**之前**。
> 已有基线（E-c/各格探针首跑，n=12/档）仅用于设定参照系，不用于调整阈值方向。

## 1. 考试对象与装置

- 装置：`tools/analysis/v3_6/probe_archive_addressing_v37.py`（档案馆寻址探针 v37 版），`--per-item-log` 开。
- 被测格：K 线最终形态格（手术+复训+cloze 三件套满配格）为主考对象；对照格 = 无 cloze 无手术同形态格（已有基线）。
- 档案馆：4 页 × 4096B，needle 模板 + 同模板干扰，档位 D ∈ {4, 16, 64}。

## 2. 样本量与种子

- 每档 n ≥ 48 docs（现有 n=12 的四倍；探针参数 `--eval-docs` 调 48）。
- 主种子 1042（与全部历史口径一致）；另跑 2 个轮换种子（1043、1044）做稳健性，报三种子均值±离散。

## 3. 报告指标（全部强制）

1. **hit@k 全曲线**（k=1,3,5）× D 三档 × 三种子——hit@1 单点禁止单独引用。
2. **几何三件套**：μ_mean、μ_max、Gram 有效秩 PR/n + 逐条目相干直方图（E78 审计裁定）。
3. V 侧 needle 回读 exact/byte_acc（direct 与 backbone 臂分列，监控 E78 裂口）。
4. per-item 记录（μ_i × 命中）全开——但 E79 已证伪该谓词在当前 regime 的解释力，仅作描述性材料。
5. 训练侧伴随量：μ 轨迹终值、state_norm 平台性（末段增长率）。

## 4. 预注册验收判据（ex-ante 阈值，不得事后调整）

- **主判据（寻址形成）**：D=64 档 hit@1 三种子均值 > 0.10 且对随机基线（≈0.0015）二项检验 p < 0.01。
  - 达成 → "压缩状态内部索引通道可训出寻址几何"成立，K 线生。
- **次判据（标度吻合）**：hit@1(D) 衰减曲线与平均情形 Tropp 预测（基于实测 μ_max）方向一致为佐证，不作生死判据。
- **阴性判定（寻址未形成）**：D=4 档 hit@1 ≤ 0.15，或 D=64 不显著超随机——达成则按已立预案诚实收束（负结果 + 核心 claim 收束到字节级语言接口本体）。
- **平台义务**：任何指标若在训练/复训中饱和，报告平台位置（对照 Tropp/平均情形预测值），不只报"过没过"（超预期判据裁定）。

## 5. 混杂控制清单

- 冷 buffer 陷阱：to_k_center 格的探针/测量必须先暖批（EMA buffer 升温），否则测到的是假几何（persistent=False 裁定口径，见 E75/E76 注记）。
- 探针检索器收敛性：W_q 训练损失须显著低于 ln(N_keys)（随机）才允许判读 hit 数；不收敛则当次考试作废重训探针，不解读为模型无能。
- 单 seed 训练风险：本考为单训练 seed 多 eval seed 口径；若主判据落在边界（0.05–0.15 区间），加训第二 seed 再判。
