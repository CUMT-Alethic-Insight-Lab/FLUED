# FLUED v3.7 — 规模轴双臂（2x 本地 ∥ 4x 4090）预注册任务书（冻结）

> 冻结时刻：2026-08-26，点火前。方案来源：用户裁定（本地 2x ∥ 4090 4x，两点同时出、把 150M 探针点夹在中间）。
> 上游：E109（Q17 点火失败 → venue 转 TMLR、规模轴扶正）、E104（induction 仪器）、E103（健康配方）。

## §0 定位

K 线/回路线收束后，"分配跟随需求"假说只剩规模轴活口；Q17 阴性把读出容量墙钉死在本规模。本双臂是规模轴的第一对正式数据点：**同一配方、两个规模、两台机器并行**，答两个问题——codec scaling 曲线的形状（白捡资产），以及**回路（induction）在哪个规模先涌现**（第一指标，决定 Q13 重放排到哪张卡）。

## §1 配置（冻结，单一变量=规模）

配方完全同源（用户纪律 1）：v37.3 canonical（qpool、slm、k=index/v=memory/seed=k 默认格）、E103 健康配方（LR 2e-4 + warmup 200 + cosine→0）、同一 corpus_v3、同一 eval 种子 1042、20K 步 @4096B（batch=1、max_chunks 1024、stride 2048）、seed 42、零任务旗标（纯 codec——burst/cloze/retrieval/Q15 全关）。

**从零口径（入册，含一处主动差异声明）**：canonical init（s0pp 快照）是 57M 形状，对 2x/4x 结构性不兼容；双臂 `init_checkpoint="" + freeze_prefixes=""` **全端到端从零**（含 segmentor——前端不再冻结预训练，同训同梯度）。两臂同待遇、互相可比；**与 1x 历史锚点存在"前端处理"口径差**（1x 用冻结预训练前端）——为此 1x 从零复跑排队为第三对照点（等 GPU 空档），三点从零口径成图，历史 1x 锚仅作参照列。

**预算口径入册（用户纪律 3）**：同 20K 步 = 同 token 量，4x 相对更欠训——读数按"等预算规模效应"解读，禁止按"等收敛"解读；若 4x 出现回路瞬态/涌现迹象，其延长档（token 预算加长）优先于其他排队臂；健康门（零 NaN、状态范数不报警）是点火延长档的前置。

## §2 仪表与判读键（用户纪律 2 + 四格表）

- **induction 常驻仪表**：双臂收官后对逐里程碑 checkpoint（3K/6K/9K/12K/15K/18K/20K）跑 `probe_induction_score.py`（同 Q13/Q14/E107 协议，细粒度为主粗粒度互证，2× 基线为破线判据）——"瞬态 vs 常驻 vs 缺席"三分 readout。
- **codec scaling**：direct/backbone acc+ppl 收官 eval（eval seed 1042 同窗），三点成图（1x 参照列 + 2x + 4x）。
- **收官 Δ**：无剔除形态逐条目 Δ（`probe_burst_route_q15` 加 `--no-excision` 形态——canonical 臂无剔除训练史，剔除会结构性压死直通格的内容路径；该开关施工入册后再用）。
- **判读键（四格，用户裁定）**：
  | 回路 | Δ | 后续 |
  |---|---|---|
  | 涌现（常驻破线） | 张开 | 胜者规模接 Q13 重放 |
  | 涌现 | 平 | 接 Q12 重放（任务形式层） |
  | 瞬态（破线但消退） | — | 加剂量：4x 延长档优先点火（健康门前置） |
  | 全程无 | — | 规模轴上移（更大点/重估） |
