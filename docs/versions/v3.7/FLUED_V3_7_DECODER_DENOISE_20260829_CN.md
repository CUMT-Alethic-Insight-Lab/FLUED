# FLUED v3.7 — decoder 去噪臂（段 3 端口练钝）预注册任务书（草案，未冻结）

> 状态：**草案**——主智能体审、用户终审冻结后才可点火。本文件不含任何代码改动。
> 上游：E114（Q19 闭式三段臂收官，墙址段 2/3）、E115/Q18 §8（2026-08-29 用户裁定：Q18 全线暂停，GPU 新排产 = 1x@1e-4（在跑）→ **decoder 去噪** → Q20 多槽读出）。
> 格式模板：Q18 v2 任务书（`FLUED_V3_7_Q18_V2_READOUT_WALL_20260827_CN.md` §0–§4）。

## §0 定位

Q19 收官台账（E114，`outputs/q19_closed_form_20260827/`）：段 1 ridge 解混近无损（oracle cos 0.967）；段 2（v̂→m̂ 桥）掉到 cos 0.63；**段 3（decoder direct 口 = decoder_in_mem(m̂)+pos→decoder）端到端只剩明文水位的 ~42%（0.3293 / 0.7925）**；而明文正对照列 0.7925 逐位级复现 E68 水位（0.7917）——段 3 对真 memory 行无虞，对「估计出来的模糊行」分布外（OOD）敏感。置乱地板 0.090 ≈ 先验 0.071，管线无泄漏。

**本臂靶子一句话**：decoder 端口只在真 memory 行上训过，对模糊 memory 行 OOD 敏感——用纯训练构造（往 direct 口的 memory 行里混扰动）把端口练钝，零架构改动。

依赖关系（文字版）：

```
1x@1e-4（远端在跑，规模轴）──┐
                            ├─▶ 本臂（decoder 去噪，练钝段 3 端口）
Q19 ridge 桥产物（闭式）───┘         │
                                     ├─▶ Q20 多槽读出：多槽读出改变 decoder 输入统计，
                                     │    端口不先练钝则 Q20 的增量测量会被端口娇气污染
                                     └─▶ A′-cached 温启动微调（Q18 §8 打捞路径）：
                                          donor 端口若对 m̂ 过敏，温启动判词无法归因
                                          「链没找到解」与「端口读不动解」
```

## §1 构造设计（扰动族预注册）

**对象**：decoder direct 口（`_slm_forward` 内 `decoder_in_mem(v_rows)+pos→decoder` 这一条腿）。冻结面：全模型除 `decoder_in_mem + chunk_pos + decoder`（端口链）；写入侧（summarizer/WriteHead/状态机）与 backbone 全程冻结（Q18 §4 写入侧冻结纪律沿用）。

**扰动族三列**（每 batch 在 direct 条件化上行级混入，backbone 腿与 predict 锚吃的 `v_rows` 一律不碰——扰动只发生在 decoder 输入副本上）：

1. **高斯噪声档**：对选中 chunk 行加 `ε ~ N(0, σ²·‖m_i‖²_rms · I)`，σ 扫 **{0.05, 0.10, 0.20}** 三档（σ 相对该行 RMS 范数）。逐里程碑递增课程：0–5K 只用 σ=0.05；5K–10K 加入 0.10；10K 起三档均匀抽。混入比例：每 batch 以 p=0.5 触发，触发时随机选 50% 的 chunk 行加噪（未触发 batch = 干净行，保水位）。
2. **岭回归估计行混入**：复用 Q19 段 1+段 2 ridge 管线（λ_unmix=0.01 / λ_stage2=1.0 同口径），在**训练窗**上重拟合桥（Q19 产物未落盘缓存，只有 JSON 台账——重拟合为闭式几分钟级），产出 m̂ 行（模糊度 ≈ cos 0.63–0.74 档）；每 batch 以 p=0.25 触发，触发时把选中行**整行替换**为同窗 m̂（非加性）。10K 里程碑前不启用，10K 起启用（先让高斯族把端口垫钝再上真实模糊分布）。
3. **对照列 = 干净行**：始终保留（见上 p 的补集 + 未触发 batch），既是训练信号也是水位护栏的在训仪表。

**种子**：42 单种子先行（方向性实测；方向成立后种子加固同 Q18 A′ 条款）。

**预算**：**10K–20K 步档，建议 20K 封顶 + 5K/10K 里程碑判读**。理由：v37.1 同管线 20K@4096B 实测 2.7–3.0 step/s ≈ 110–124 min（E60–E68 工程口径），20K ≈ 2 GPU·h 单晚可出；本臂是微调非从零，端口链参数量小（decoder_in_mem 0.2M + decoder ~10M 级），10K 里程碑大概率已见方向，20K 封顶防过拟合扰动族；若 5K 处主判据已过线且干净水位不降，可按里程碑判读提前收官。

## §2 判读表（预注册）

考场：eval 窗（seed 1042、16 批，E60–E68 同口径）fine 细格 echo byte_acc，四列同测：**干净行 / 高斯扰动行（三档各测）/ 岭估计行 m̂ / 置乱行**。

| 结局 | 判词 |
|---|---|
| **主判据过线**：岭估计行 acc ≥ **0.55**（=明文水位 0.79 的 ~70%，从现值 ~42%×0.79≈0.33 提升）且高斯 σ=0.10 档 acc ≥ 0.65 | **端口练钝成功**——段 3 损耗基本拆除，墙址收拢到段 2 单段；Q20 点火条件之一满足 |
| 卓越档：岭估计行 ≥ 0.65（~82% 水位） | 段 3 损耗可忽略，A′-cached 温启动的端口归因障碍清除 |
| 中间带：岭估计行 0.40–0.55 | 如实登记「端口部分练钝」，判词写「段 3 软化未拆除」，σ 上限/混入比例复诊后决定是否加档 |
| 未动：岭估计行仍 ~0.33 档 | 端口对分布外输入的敏感是结构性（decoder 内部表征纠缠）而非训练分布缺失——判词升级，Q20 设计须自带端口鲁棒性 |

**有效性门（护栏）**：干净行水位相对基座收官值（0.7917，E68 口径）回落 **>2pp 即触发 codec 回调线**（沿用 s1 训练器既有 Q15 自锚回调设施，`train_v36_s1.py:1423-1427` 的 direct_acc/backbone_acc 自锚 >0.02 → λ×0.5 机制）。

**地板门**：置乱行 acc 必须贴先验（≤0.10，先验 0.071 同档）——扰动训练若让 decoder 学会「无视条件行猜字节」，置乱列会漏；地板不过门的读数作废不发判词。

**判负格（预注册）**：扰动行/岭行 acc 提升但干净行回落 >2pp 且回调线压不住 → **端口容量不足判词**——decoder_in_mem+decoder 的容量不足以同时承载真行分布与模糊行分布，Q20 须先扩端口容量而非直接多槽。

**通用纪律**：一切过程读数（σ 档曲线、训练 loss）涨了不算赢，终点判读表落格才算；每列带 majority 基线与先验门。
