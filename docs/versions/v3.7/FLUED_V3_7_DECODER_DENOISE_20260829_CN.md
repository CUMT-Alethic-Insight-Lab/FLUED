## §0 定位

Q19 收官台账（E114，`outputs/q19_closed_form_20260827/`）：段 1 ridge 解混近无损（oracle cos 0.967）；段 2（v̂→m̂ 桥）掉到 cos 0.63；**段 3（decoder direct 口 = decoder_in_mem(m̂)+pos→decoder）端到端只剩明文水位的 ~42%（0.3293 / 0.7925）**；而明文正对照列 0.7925 逐位级复现 E68 水位（0.7917）——段 3 对真 memory 行无虞，对「估计出来的模糊行」分布外（OOD）敏感。置乱地板 0.090 ≈ 先验 0.071，管线无泄漏。

**本臂靶子一句话**：decoder 端口只在真 memory 行上训过，对模糊 memory 行 OOD 敏感——用纯训练构造（往 direct 口的 memory 行里混**与部署同分布的**扰动）把端口练钝，零架构改动。

依赖关系（文字版）：

```
Q19 ridge 管线（闭式，m̂ 统计）──▶ 本臂（decoder 去噪，练钝段 3 端口）
                                       │
                                       ├─▶ Q20 多槽读出：多槽读出改变 decoder 输入统计，
                                       │    端口不先练钝则 Q20 的增量测量会被端口娇气污染
                                       └─▶ A′-cached 温启动微调（Q18 §8 打捞路径）：
                                            donor 端口若对 m̂ 过敏，温启动判词无法归因
                                            「链没找到解」与「端口读不动解」
```

**裁定锚（2026-08-29）**：修复路径的终点产物是「估计的 memory 行」（m̂），它喂的端口就是生产环境的 decoder_in_mem（b 格 canonical 的 direct 直读口）——去噪训练的对象是「decoder 消费 memory 类向量的端口」，不是状态通道口。

## §1 构造设计（扰动族预注册，修订 v2）

**对象**：decoder direct 口（`_slm_forward` 内 `decoder_in_mem(v_rows)+pos→decoder` 这一条腿）。**可训练范围（终审钉死）= 仅 decoder**——decoder_in_mem/chunk_pos/backbone/写入侧（summarizer/WriteHead/状态机）全冻：端口练钝功劳归属单变量，若 decoder_in_mem 跟着动则钝化功劳归属说不清；判负时判词=「decoder 单件练钝不足」，decoder_in_mem 解冻臂作 escalation 另行裁定。

**前置测量（点火前必做，eval-only 分钟级）**：在 b 格基座上重拟合「K 状态 → memory 行」ridge 桥（Q19 §1 段 2 同口径 λ，b 格内自产自销——裁定开口项 2 选 (b)，生产语境是 b 格自产模糊；Q19 跨格桥 d→b 带域移，生产永远见不到），产出训练窗 m̂ 并测三件事落盘入册（本臂的「模糊分布身份证」）：① m̂ 相对真行的**范数收缩率**；② 残差 ε=m−m̂ 的**协方差结构**（逐维方差谱 + 有效秩）；③ m̂–m 余弦分布。**扰动族的所有参数由这三项实测决定，不许拍脑袋。**

**扰动族三列**（每 batch 在 direct 条件化上行级混入；backbone 腿与 predict 锚吃的 `v_rows` 一律不碰——扰动只发生在 decoder 输入副本上）：

1. **统计匹配噪声列（修订 v2，2026-08-29 用户裁定）**：以实测残差协方差结构采样扰动 + 行范数按实测收缩率缩放（合成式 ṽ=ρ·m+ε_a，F5 申报在案）。**强度三档 = 部署桥（λopt=1.0）残差采样器的标量倍率 s∈{0.5, 1.0, 2.0}（轻/中/重）**——λ 梯档作废：前置测量实测 λ{1.0/0.1/10.0} 三档 cos 极差 0.008 ≪ 档内 std 0.08（统计上同一档，档间不可分的课程是假课程；实测表见 §6）。s=1 恰是部署分布本身（同分布裁定不变）。逐里程碑递增课程：0–5K 只用轻档（s=0.5）；5K–10K 加中档（s=1.0）；10K 起三档均匀抽。**监控注记（裁定随行）：s=2.0 重档在课程后段才上线，冒烟只覆盖轻档——codec 回调线的首次真考验在中/重档上线时，监控别松。** 混入比例：每 batch 以 p=0.5 触发，触发时随机选 50% chunk 行（未触发 batch = 干净行，保水位）。
2. **m̂ 整行替换列**：前置测量的同一条 ridge 桥产出 m̂，每 batch 以 p=0.25 触发，触发时把选中行**整行替换**为同窗 m̂（非加性）。10K 里程碑前不启用（先让统计匹配噪声把端口垫钝再上真实模糊分布）。
3. **对照列 = 干净行**：始终保留（p 的补集 + 未触发 batch），既是训练信号也是水位护栏的在训仪表。

**冒烟条款（点火前）**：500 步冒烟验收旋钮接通（扰动确实进了 direct 腿损失）+ 干净水位不崩（回落 <2pp），冒烟不改档值；冒烟不过不点火。

**种子**：42 单种子先行（方向性实测；方向成立后种子加固同 Q18 A′ 条款）。

**预算**：**20K 封顶 + 5K/10K/15K 里程碑判读**，约 2 GPU·h（v37.1 同管线 20K@4096B 实测 2.7–3.0 step/s ≈ 110–124 min，E60–E68 工程口径）。本臂是微调非从零，端口链参数量小（decoder_in_mem 0.2M + decoder ~10M 级）；**早停门槛 = 10K**（修订：本赛季六次瞬态教训，5K 过线可能只是又一次「出现然后被吃」——10K 处主判据过线且干净水位不降才允许提前收官）。

## §2 判读表（预注册，冻结 v1.1）

**作用域限定（终审确认项 2）**：本表一切判词行文带「**适用于 slm 系 decoder 端口**」限定语——现役 canonical 为 attn 模式结构性无此端口，本臂判词不得被读成 canonical 端口结论。

考场：eval 窗（seed 1042、16 批，E60–E68 同口径）fine 细格 echo byte_acc，四列同测：**干净行 / 统计匹配噪声行（三档各测）/ m̂ 岭估计行 / 置乱行**。

| 结局 | 判词 |
|---|---|
| **主判据过线（及格线 = 段 3 损耗减半）**：m̂ 岭估计行 acc ≥ **0.56**（= 明文水位 0.7917 的 ~71%，即从现值 42% 水位 0.33 起把段 3 损耗砍掉一半）且噪声中档 acc ≥ 0.65 | **端口练钝成功**——段 3 损耗基本拆除，墙址收拢到段 2 单段；Q20 点火条件之一满足 |
| 卓越档：m̂ 行 ≥ 0.65（~82% 水位） | 段 3 损耗可忽略，A′-cached 温启动的端口归因障碍清除 |
| 中间带：m̂ 行 0.40–0.56 | 如实登记「端口部分练钝」，判词写「段 3 软化未拆除」，噪声档/混入比例复诊后决定是否加档 |
| 未动：m̂ 行仍 ~0.33 档 | 端口对分布外输入的敏感是结构性（decoder 内部表征纠缠）而非训练分布缺失——判词升级，Q20 设计须自带端口鲁棒性 |

**唯一硬指标（老纪律）**：端到端逐条目 Δ（burst_tail 源段完好−置乱）。作用域写明：本臂是端口练钝**工具臂**，不承诺 Δ 张开（需求缺席判词 E106/E113 在案）；Δ 列作为监护列随测（去噪不得进一步压 Δ），本臂+下游 Q20 串联后的最终价值判定才以 Δ 为唯一硬通货。

**有效性门（护栏）**：干净行水位相对基座收官值（0.7917，E68 口径）回落 **>2pp 即触发 codec 回调线**（沿用 s1 训练器既有自锚回调设施，`train_v36_s1.py:1423-1427` 的 direct_acc/backbone_acc 自锚 >0.02 → λ×0.5 机制）。

**地板门**：置乱行 acc 必须贴先验（≤0.10，先验 0.071 同档）——扰动训练若让 decoder 学会「无视条件行猜字节」，置乱列会漏；地板不过门的读数作废不发判词。

**判负格（预注册）**：扰动行/m̂ 行 acc 提升但干净行回落 >2pp 且回调线压不住 → **decoder 单件练钝不足判词**（终审钉死可训练范围=仅 decoder，decoder_in_mem 冻结在案）——decoder 容量/可塑性不足以同时承载真行分布与模糊行分布；escalation=decoder_in_mem 解冻臂另行裁定，Q20 须先扩端口容量而非直接多槽。

**通用纪律**：一切过程读数（噪声档曲线、训练 loss）涨了不算赢，终点判读表落格才算；每列带 majority 基线与先验门。
