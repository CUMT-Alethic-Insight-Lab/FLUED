## §1 相一：三站探针链（零训练，分钟级）

**对象**（三件套，同管线同任务形态）：
1. **主测件**：Q15 正臂收官 checkpoint（`v37ks_d_sm_q15_circuit_20k_ctx4096_20260825b`，d 格，奖励掰弯过）；
2. **对照件甲**：E103（Q12-40K，`v37ks_b_sm_retrieval_cjk_ex3_A_20k_ctx4096_20260822`）——训练过、无奖励，但 b 格 retrieval 对象：与主测件差两变量（格+奖励），只作松约束参照，**跨格混杂标注入册**；
3. **对照件乙（零训练本底）**【施工修订 2】：Q15 同配置同种子新建模型 + canonical 底座前端（E104 口径）——"从未形成"地板线，把"奖励掰弯的断"与"本底就有的断"干净分开（E103 跨格，本分离开不干净）。

**任务形态**：测量管束统一用 Q15 burst 形态（R=3 + 压缩区剔除，n=96【施工修订 3：48→96，分层后每带 ~32 条，CI 可读】）——含 E103 对照件也套同一管束（测的是"该对象在此结构条件下信息路径是否存在"，不是其训练任务表现）。

**三站探法**（复用岭回归 real−garbage 口径，2-fold，majority 基线，逐条目；目标 = 答案字节串，按答案字节索引对齐、≤12 截断）：
- **探 A（取件站）双列**【施工修订 1】：**A1** = echo 位置实际注意力 top-1 行的原始 V~（E88 同口径——"聚中的行里有没有货"）；**A2** = 注意力加权值混合 ov_i = Σ_j A_ij·v_j（pre-o_proj——"实际流下去的货"）。A1 有货而 A2 缺货 = 混合稀释断；A1 缺货 = 写入断。
- **探 B（传送带）**：block-1 cross-attention 块输出后的隐藏态（post o_proj+residual+FFN1），同目标。
- **探 C（出口闸）**：decoder 入口隐藏态（backbone_out+pos 的 echo chunk 行），同目标。

**分层（机械规则）**【施工修订 4】：按答案**首字节**在其 chunk 内的绝对 slot 分带——head=[0,8)、mid=[8,18)、tail=[18,∞)（对齐 E88 死亡区起点 slot18）；逐带报 real−garbage 增量。**段尾组在探 A 的死亡是先验已知（E95），信息量判读落在段首/段中组**——不分层的三站读数会被段尾组稀释成全灭假象（设计稿原文）。

**判死口径（预注册）**：站间落差 = 相邻两站 real−garbage 增量之比；落差 >50% 且后站增量 <0.02（噪声带）→ 断点定位于该两站之间。**防双零假落差**【施工修订 5】：上游站增量须 ≥0.05 才允许"站间断"判定；两端皆零按"断在该站或上游"处理，禁止算近零分母的比值。第四行 = 逐条目 Δ（存在性地图，Q15 收官已测）；与路由消融（kstate_zero/vstate_zero/early_masked，因果地图，已测）叠读——**有存在无因果 = 断点在该站下游；无存在 = 断点在该站或上游**。

**施工事实**：探 B/A2 需 `SLMBackbone` 加两个捕获槽（`last_block1_ov`/`last_block1_h`，沿用 need_attn 开关模式，关态逐位不动零侵入）——相一唯一模型代码改动，配套单测（关态 None、开态形状/数值断言）。

**回报格式**：三对象 ×（A1/A2/B/C）×（head/mid/tail 带）的 real−garbage 增量全矩阵 + 逐条目落盘 JSON；只报数与断点定位，判词由协作链会合后落。

## §2 相二：修复臂变体预登记（相一读数激活其一，禁止现场设计第四变体）

| 断点 | 变体 | 要点 |
|---|---|---|
| 站 1（取件站） | **不点火** | 等于读出容量墙终审，修复归写入侧/接口形态，入册为规模轴问题，奖励线正式关闭 |
| 站 2（传送带） | **反先验对比损失臂** | 每条样本配"无源条件"对照前向（store 行置零，复用 zero_V 基建），铰链惩罚 with-source 与 no-source 答案区 logit 距离 <m；与 Q15 孪生项的区别写明：孪生罚"篡改无感"，本条罚"与先验一致"——把先验通道从输出路径挤下去 |
| 站 3（出口闸） | **decoder 置信校准臂** | 无源条件下答案区输出应为高熵/低置信，有源才允许尖锐——最便宜一档 |

**时序**：相一不占训练预算（分钟级）；相二 20K 约 2h。相一读数回报后按预登记表激活变体，相二点火前出冻结文本走终审。

**地板扣减（施工修订 2 的决定性作用）**：init 随机网络的被动输入残留精确解释了 Q15 全站的"弱存在"（回声态效应：可见副本在输入里，随机特征线性可解码）；扣地板后 Q15 四站超额 ≈ +0.002/+0.004/+0.006/−0.010，E103 全站在地板之下。

**判词**：判死口径全落差触发"上游 <0.05 禁算比值"护栏；按叠读规则"无存在（超地板）= 断点在该站或上游"一路推至首站——**断在站 1 或更上游（写入侧/状态累积）：注意力聚向的行从一开始就没装货**。与因果地图（E107：Δ=0、kstate_zero −0.048 只出通用语境）叠读自洽：无货可用，也确实没用上。§0 预期管理的那个结局实锤——**最后一环的断点接回第一环的墙**。

**相二激活**：按 §2 预登记表，断在站 1 = **不点火条款触发——读出容量墙终审成立，奖励线正式关闭**；修复归写入侧/接口形态，入册为规模轴问题。站 2/站 3 两变体未激活，预登记文本保留在册备未来规模轴复用。

**方法论入账**：零训练本底（init 对象）自此为一切"存在性"类探针的强制对照——不测地板的"存在"读数不可引用（本次若无 init 对照，"四站皆弱存在"会被误读为站间无断、断在 decoder）。
