## §0 立项逻辑（一句话）

E104 坐实窗内基础复制回路从未形成（init≈trained），Q13/Q14 证明数据层注入（突发性/先验筛需求）催不出常驻回路；Q15 换激励层：**把回路本身设为奖励靶点**——过程奖励直接监督"注意力落到状态通道行"，并用反作弊对偶把"学会"和"表演"在损失函数层面分开。两头都赢：养成则负结果论文升级为"判词+已验证修复路径"；影帝结局（注意力被监督成表演）则是对注意力监督文献的反例贡献，同为论文级发现。

## §1 接线事实与格裁定（d 格，用户裁定 2026-08-25）

**接线核实发现（实现前澄清程序产出，全部核到代码行）**：

1. store_block 按行号剔除（`flued/v36/model.py:1522-1524`；`train_v36_s1.py:750`），K/V 两侧同行号同剔除，对角线由 `allowed|eye` 永保。
2. **b 格（Q14 接线：`k_row_source=state, v_row_source=memory`）下 block-1 注意力的 V 侧是 memory 行**（`model.py:1495`）——逐 chunk 无跨段内容；注意力落到源后 K~ 行读出的是那些 chunk 自己的 memory，不是源段内容。b 格下状态内容只经 seed 进 hidden（`seed_source=k`：`h_i⁰=align_k(K~_i)+pos`），不经注意力 V 侧。
3. 结论：b 格下 L_attend 焊在"地址对但读不到内容"的路径上，条件挂钩会把结果损失锁死在结构性无答案的路径——**影帝结局将从测量发现退化为结构预定**。

**裁定：Q15 切 d 格**（`k_row_source=state, v_row_source=state, seed_source=k`）。V~_j 是状态机第 j 步的内容读出，注意力落到源后行即读到真源段内容；结果梯度经 V~→状态机→write_head→summarizer 回流进写入侧——"梯度层造需求"只有 v=state 才接通。

**三条裁定注记**：

- **口径边界**：Q15 任务读数与 Q14（b 格）不可比，登记为口径切换，禁止混排。codec 回调线改用**臂内自锚**（§5），E65–E68 的 d 格历史锚（direct_ppl 37.5–40.3，前前世代异象格）只作参照入册注，不当及格线。
- **白捡的仪器**：d 格是 E-a"内容过黑板 codec 崩盘"（困惑度 2.1→38–43）原始异象的事发地。direct_ppl 逐里程碑落盘（默认仪表）；若过程奖励顺手治好 d 格 codec 崩盘，E-a 异象获得复活判词——**不预写判词，只落数据**。
- **双状态机范数**：E103 健康配方（2e-4 + warmup 200 + cosine→0）+ 范数增长率黄灯沿用。

**方法论备案（用户裁定入册）**：奖励工程与普通损失工程不一样——**奖励焊错位置不是次优，是预定结论**。"奖励靶点与掩码剔除集的交集断言"自此为一切后续奖励臂的强制澄清项。

## §2 构造（Q14 全量沿用 + 压缩区激励改造）

沿用 Q14 已冻结全部件：突发性逐字重复 R=3（损失只打第 R 次出现的遮蔽段尾，前 R−1 次完整可见）；段尾末 2–4 个 CJK 字符遮蔽（UTF-8 边界吸附）；**先验筛保留**（裸猜 <0.05 才录用，筛子固定于开工 checkpoint——结果奖励回归后先验能蒙就会蒙，筛子比 Q14 更重要）；防背护栏（每窗现采随机段、严禁固定段库、epoch 内不重复断言）；产出率入册（<70% 报警，不静默放宽）；中点先验复测钩（漂移 >0.02 登记先验侵蚀）。

**新增（压缩区激励改造）**：对每条 splice 样本，将第 1..R−1 次出现所覆盖的 store 行按档 a 语义剔除——`block[b, qc:, src_chunks]=True`，其中 src_chunks = 第 1..R−1 次出现的并集 chunk，qc = 遮蔽段尾首字节的 chunk。**r 恒 1.0**（剔除是任务构造本体，不走概率爬坡、不消耗随机流）。已知边界（入册）：剔除只作用于 block-1 cross-attention，blocks 2..L 自注意力两跳 relay 路径结构上不可剔（中间位置对源行仍可读）；"只经状态机可达"因而不是绝对的，由 Δ 仪表（§6）与 L_couple（§3.3）双重兜住真实依赖性。

## §3 三件套损失（全部为损失工程，零新架构参数）

记：A = block-1 cross-attention 概率（B, H, C, C），经 `need_attn` 开关手工注意力取得（§7）；样本 b 的源后目标行集 T(b, q) = {j : c1_end(b) < j ≤ q, j ∉ src_chunks(b)}，c1_end = 第 1 次出现的末 chunk，q = query 位置所在 chunk。**机械断言：T ∩ src_chunks = ∅**（逐样本 assert，违反即响亮报错——本断言是§1 方法论备案的首次执行）。

### §3.1 注意力引导损失 L_attend

对每个 echo 字节位置 i（其 chunk 为 q_i）：

  mass_i = Σ_h Σ_{j∈T(b,q_i)} A[b, h, q_i, j]
  L_attend = mean_i( −log(mass_i + ε) )，ε = 1e-6（冻结）

**逐头求和而非全头均值**——允许单个头特化成回路（induction 在标准架构里也是特定头的事），不强迫所有头表演。

### §3.2 条件挂钩的结果损失 L_out·g(attend)

**【修订 v1（点火前校准，2026-08-25）】原条款**：g_i = σ((mass_i − τ)/s)，τ=0.25、s=0.05，mass_i 取逐头求和。**改写理由**：逐头求和的 mass 值域是 [0, H=8]，均匀注意力基线 ≈ H·|T|/|allowed|（CPU 冒烟实测初始 mass=4.163）——τ=0.25 在随机初始即饱和，门控形同虚设（"注意力没落上不计分"永不触发）；标定错误在冻结后、点火前发现，未消耗任何训练，ex-ante 修正。**改写时刻**：2026-08-25 点火前。

现行条款：

  g_i = σ((max_h mass_h(i) − chance_i − δ)/s)
  chance_i = |T(b,q_i)| / |allowed(b,q_i)|（该样本该位置的均匀基线，allowed = 因果 ≤q_i ∧ 有效 ∧ 非剔除，对角已在集内）
  δ = 0.15、s = 0.05（冻结）

门输入改为**单头超基线超出量**：某个头的 T 质量超出该位置均匀基线 0.15 才开门；随机初始 max-head mass ≈ chance+涨落 → 门基本关闭；单头特化（max→1）门全开。L_attend 公式不变（§3.1 逐头求和、−log(mass+ε)）。

  L_out = mean_i( sg(g_i) · CE_i )，λ_out 继承 task2_loss_weight（=1.0，不作新自由度）

**反捷径条款（实现层改写，带理由）**：门 g 取 **stop-gradient**。原文"注意力没落上，结果对了也不计分"的意图是信用门控；若 g 不 detach，模型可通过压小 g 把该项损失幅度趋零（不学习也"零损失"），与 L_attend 对拉形成退化路径。sg(g) 下注意力低时 echo CE 梯度按比例关断（不计分 ✓），且模型无法经本项把 g Game 下来。训练期 echo 槽位从常规 completion 网格中剔除（防双重计分），codec 覆盖由本项接续（g→1 时等价全覆盖；g→0 时遮蔽段尾暂不被任何项覆盖——这是设计本体：段尾是任务靶，条件覆盖即设计）。

### §3.3 反作弊对偶项 L_couple

对 **p = 0.25 的已 splice 样本**（用户裁定口径：不摊给非任务样本）构造孪生行：同窗同掩码，唯一差异 = 第 1..R−1 次出现的段尾 k 字符被篡改为**该段段首 k 字符**（head-tail swap；UTF-8 合法、机械确定性）。孪生**选择**消耗 `_BURST_GENERATOR` 每条 splice 样本一抽（固定顺序，同 retrieval block 抽取纪律）；篡改本身零随机流。

  d = mean over echo 位置 of ½·‖softmax(f_clean) − softmax(f_twin)‖₁  ∈ [0, 1]
  L_couple = max(0, m − d)，m = 0.1（冻结），λ_couple = 0.5（冻结）

铰链方向：对篡改敏感（d ≥ m）则零损失；**注意力高 + 篡改无感 = 演戏，直接产生惩罚**。消费剖面仪表就此搬进奖励端。孪生前向为带梯度全训练前向（铰链回灌共享参数），只取 logits_backbone 计算铰链，不参与 codec 各损失（防污染）。开销报价（已核准）：期望 +12.5% 行前向（burst_prob 0.5 × p 0.25），20K 步约 +15–30 min。

## §7 实现纪律与验收

1. **need_attn 开关**：`SLMBackbone` 加开关，开时 block-1 走手工注意力（q·k/√d → 掩码 softmax → ·v，n≈64 chunk 尺度成本可忽略）并把概率存 `last_block1_attn`；**关时 legacy SDPA 路径逐位不变**——验收单测：同权重同输入下关态输出与关态自身确定性逐比特相等、开关两态 allclose(1e-5@fp32)、关态 `last_block1_attn is None`。
2. **eval 形态纪律**：三件套损失 train-only；eval 时 echo 槽位留在常规 completion 网格（eval_loss 与历史形态一致）。store_block 剔除 train/eval 同开（任务定义的一部分）；收官另补一发 no-excision eval（分钟级）作 codec 头条口径对照。
3. **孪生不污染**：twin 行前向只取 logits_backbone 供铰链，不进任何 codec 损失与指标。
4. **随机流纪律**：孪生篡改用段内 head-tail swap（零随机流）；孪生选择每条 splice 样本消耗 `_BURST_GENERATOR` 一抽（固定顺序）；剔除无概率抽取（r 恒 1.0）；既有 burst/筛子随机流顺序不变。
5. **CLI**：`--q15-circuit-rearing` 主开关 + 响亮校验：要求 burst 开、先验筛开、slm、d 格（k=state ∧ v=state）、seed_source=k；与 cloze/retrieval 互斥沿用 burst 既有校验。
6. **单测**：交集断言（构造性样本 T∩src=∅）、孪生篡改字节级正确性（只动 1..R−1 次出现的段尾 k 字符）、门控 sg 行为（g 无梯度）、回调线触发/下限、开关逐比特、CLI 校验响亮报错。全量测试基线 477+4 不得回退。

## §8 预算与排程

- 20K 步 @ 4096B，batch=1（chunk 网格 1024×64），LR 2e-4 + warmup 200 + cosine→0（E103 健康配方，不许回 1e-3 恒定）；init = canonical segmentor 快照（`s0pp_pro_v4_sft_20260805`），其余从头；

## §9 备案

## §10 收官判读（2026-08-25 收官后补记，判词落格）

**判读矩阵落格：格二（影帝结局），弱形态**——三列会合：

| 列 | 读数 | 判定 |
|---|---|---|
| 注意力（修订 v1 口径） | maxmass−chance 全程区间 +0.09~+0.16（未达"持续 +0.15 贴顶"强形态；对比 pilot 的贴顶 1.0），mass/chance 比 ~1.5 全程稳定 | **温和响应**：监督接通（旋钮动了，非格三），但未特化 |
| 孪生敏感 d | 全程贴零（20K 均值 ~0.002，峰 0.005；pilot 同期 0.08–0.12 边际） | **不敏感** |
