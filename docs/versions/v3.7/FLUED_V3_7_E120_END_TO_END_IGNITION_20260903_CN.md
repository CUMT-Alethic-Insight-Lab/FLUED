## §0 定位

**一句话**：E119 证明了"温启动读出链能兑现状态内容"（仪器级 0.61），本臂测最后一环——**接进生产环境后，主干在真实检索任务里是否开始用状态通道**。这是 ICLR 重裁定的唯一硬通货。

**第一行假设（防乐观）**：读出链修好了 ≠ 主学会用它——消费断口（E107：状态通道只出通用语境、Δ=0）和招募失败（E98–E113）都在案，本臂完全可能阴性收场，阴性也是判词。

**作用域限定**：一切判词带「适用于 slm 系 d 格（K、V 双状态机）+ burst_tail 任务族」限定语。

## §1 构造设计

**基座**：Q15（E107）d 格收官 checkpoint（**修订 v2 钉死 = `v37ks_d_sm_q15_circuit_20k_ctx4096_20260825b`**——无 b 后缀的是 512B off-spec pilot，禁混排）。理由：burst 训练史在（Δ 仪器有意义）、任务链路完整、K/V 双状态机齐全。**注记入册**：该基座带"注意力几何被过程奖励掰弯过"的历史（影帝臂），本臂读数与无奖励史基座不可直接比，若阳性需在未来的干净基座上复测确认（或有条款，不在本臂预算内；**修订 v2 收紧：干净基座复测只在乙列阳性后触发——阴性时下一步由路由消融读数决定，不自动复测**）。

**唯一新件**：读出端换成 **k=1 温启动读出件**（E119 定型档）。温启动源 = 在 d 格基座**自产状态**上重拟合的闭式解（ridge 段 1 + 部署桥，eval-only 分钟级，fuzz_id 同款流程——不许跨格搬 E118 的 b 格桥，域移纪律）。

**插入点**：替换生产读出（readout_query），即温启动读出行进 **backbone seed 链 + block-1 交叉注意力的行集**——这是"内容进主干"的唯一通道。decoder 直读口不动（d 格结构性无 decoder_in_mem，在案）。

**两臂同测**：
- **甲列（纯插拔）**：只换读出件，全模型冻结，测 Δ——答"主干现成的消费路径能不能直接用新货"；
- **乙列（主格）**：换读出件后**全模型解冻**，burst_tail 任务续训 20K@4096B，测收官 Δ——答"给足适应期，端到端点不点得燃"。**修订 v2：乙列显式关 `q15_circuit_rearing`**（生产环境无过程奖励拐杖；E107 已证 L_attend 压制 prefix-match 几何，继续开着=继续压自然回路）；四枚 q15_* 旗标（`q15_circuit_rearing`/`q15_lambda_att`/`q15_lambda_out`/`q15_lambda_couple`）逐枚列清单写 keep/drop 进施工注记（枚举式裁定，坑 8 对偶敞口：老 config 会静默继承，不许靠默认值）。**风险缓解登记**：乙列阴性且前 2K 监控显示 maxmass 从状态行漂离 →「保持 L_attend」变体排队（分离"注意力没看"与"内容没用"）。

**对照列**：原读出件同预算续训（分离"多训了 20K"与"温启动读出"）、置乱地板列（≤0.10 先验门）。**修订 v2 条件臂**：若乙列阳性，「随机初始化读出件+全模型解冻」并入 {1,2} 种子加固批次当审稿护甲（"温启动是必要的吗"必问题；E115 已从另一侧供从零阴性先验）；阴性不烧。

## §2 判读表

**主判据**：收官逐条目 Δ（burst_tail 源段完好−置乱，q15 口径，n≥48，CI 自举）。

| 结局 | 判词 | 行动 |
|---|---|---|
| 乙列 Δ 张开（CI 不含 0 且 Δ≥0.05）| **端到端点燃**——修复路径全线闭环 | ICLR 定案；种子 {1,2} 加固即点（随机初始化对照列并入当审稿护甲，修订 v2）；写作线全速 |
| 乙列 Δ 平、甲列 Δ 平，但归因消融显示状态通道被消费 | "读出可修、消费路径未形成"——墙址移交消费层 | TMLR 轨道锁定；消费层成下一季开篇 |
| 乙列 Δ 平且状态通道零消费 | 修复未传导，如实判负 | 同上，判词写"读出端修复不足以点燃端到端" |
| 任一列地板门不过 / codec 回调线破 | 该列作废重查，不许判负 | loud fail |

**因果归因必做**（防"Δ 来自窗内复制"冤案）：收官时做路由消融（状态行置零 vs 完好），Δ 必须随状态行归零而坍塌才算"经状态通道"——E107 仪器原样。

**有效性门**：盲猜先验逐碑落盘；codec 回调线锚 = d 格自锚（崩盘区水位，口径注记在案），退步 >2pp 触发降权。
