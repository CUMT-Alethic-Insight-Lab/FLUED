## §2 臂定义（2×2 归因结构：门 × 需求，三列先行、第四格条件触发）

- **合体列**：三器件同开——
- **硬预算检索门**：V 行只能经 index 命中后取回。查询先打 K(index)，top-k 命中的 V 行进注意力，其余 V 行在前向里**结构性不可见**。预算 k 用**分位数预算退火**（E6 已验证件）从全量（=现状全读）退到目标值；可微路径用软 top-k + 温度退火衔接。
- **可学 α-entmax 锐度**（H-DEMAND-GATE 收编件）：门内命中分布用可学 α-entmax，不用可学温度 softmax（softmax 弥散定理管不着 α-entmax；低分行拿精确零）。**α 本身入仪表**：α 贴 1 学不上去 = 「回路不肯承诺」的直接读数。
- **定向剥夺需求器件（E123 v1.3 同件，生命维持）**：离线选择器（**τ=0.02 nat 档，遮 3 块/窗 = 71 监督字节/窗**，定稿见 §3.3）定向遮蔽高信息块（注意力单遮蔽训练形态 + **切点钉死**，见 §3.6；chunk 以模型口径 ≈24B 新体制实测），遮蔽位下游依赖位走延迟自读出辅助损失汇入主流失；**K_max 课程：1（0–2K 步）→ 2（2K–10K 步）**，按新直方图定稿（§3.2）。**无此件，硬预算必收敛「取最近 k 行」位置先验（fable 预言，E66/E122 推论同向）**。
- **对照列一（硬预算无需求列）**：同基座同预算，硬预算门 + α-entmax 同开，**无遮蔽无辅助损失**——直接测量 fable 预言的绕过形态（位置先验），是本臂的判决性对照。
- **对照列二（需求无硬预算列 = E123 主线复刻列，用户裁定增补）**：同基座同预算，定向遮蔽 + 延迟自读出同开，**无硬预算门**——即 E123 在冻结主线体制下的复刻。以列代臂，一举三得：洗掉 E123 阴性的体制混杂（无锚段界器注记）、补齐门×需求的 2×2 归因第三格、E123 不必单独重跑。
- **预算**：10K 步 @4096B，**三列**串行，本地 5080。施工评审实测估价：a 格冻结主线 50M 级按 ~2.7 步/s 估 10K≈62 分钟/列，**三列半天内**，降级预案大概率用不上。远端 4090 同期任务以用户调度为准。第四格（纯续训参照）与乱序确认列同为条件触发，见下。
- **阳性确认条件列（预注册、条件触发）**：合体列阳性才跑——乱序目标列（跨窗置换口径，槽二 v1.3）+ 纯续训参照列，半预算 5K。**阴性不跑，省钱；阳性不补跑，不发证。**

## §6b 用户四问裁定（2026-09-09，入册）

1. **E123 是否先重跑**：不单独重跑，**以列代臂**（对照列二，§2）。理由：单列重跑只洗体制混杂，并进 E124 后同时补齐归因格，一份预算两份收益。

3. **是否扩大 context window 让 index 真承重**：**本臂不扩**。必要性账实测自然依赖全部集中在 1–2 chunk（64–128B）——扩窗不扩需求，只是把沙漠扩大，索引在长窗里照样没有猎物。扩窗必须与「带真实长程依赖的语料」配对才有意义，注册为**阳性后的第二阶段确认臂**（真长程体制验证），本臂 §7 的规模保留声明照旧承重。
4. **显存/内存分配与训练效率**：属施工件非科学件，处理口径三条——① 施工报价须含**退火全行程的峰值显存表**（退火起点=**全量 173 段全读**（训练流实测 172.7，新体制数；旧文 166 为考场体制数，作废——此行是显存峰值表分母，工程报价直接引用），是显存峰值点；RD 扫描仪器另算）；② 效率优化准许但**不许改数值语义**：任何 kernel/融合/重排改动须过同机对拍（逐位或冻结容差），否则不许进训练列；③ 效率工时设硬上限 2 天，超了先点火再优化——两周窗优先于吞吐。

## §7 诚实边界与外推（行动 8 首次执行）
