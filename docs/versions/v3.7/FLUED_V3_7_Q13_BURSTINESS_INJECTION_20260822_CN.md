# Q13 预注册：突发性注入臂（burstiness injection arm）

> 2026-08-22 重建稿同日转正：原始冻结文本在会话压缩中丢失，本文按用户裁定口述重建并经用户确认数值后**正式冻结**（点火令 2026-08-22）。K3 索档即本文。
> 前置证据链：E98（A 臂任务形式层失败）→ E99（OOD 门正斜率）→ E101（示例密集边际翻倍未过门）→ E103（40K 分支②，边际不涨）→ **E104（induction 仪器：窗内基础复制回路从未形成——四代失败的归因改写为"回路缺席"，修复方向=数据层注突发性）**。

## 1. 机制定位（外部文献锚点）

DeepMind ICL 权衡文献（K3 对标，2026-08-22）：induction 回路（prefix-matching 复制回路）在 25–50 亿 token 相变窗口形成，依赖数据的**突发性（burstiness）+ 罕见类别**双属性。我方语料（corpus_v3）与训练量（~8 千万字节/世代）不满足前者——Q13 即在数据层人工注入突发性，把复制回路催出来。Q13 构造（逐字重复+段尾遮蔽）与文献独立收敛同形态（外部佐证）。剂量-权衡曲线（加量→ICL 先升后稳、先验续涨）的验证责任自 Q12 移交 Q13 系。

## 2. 任务构造（突发性注入）

- **重复段**：每训练窗内，从语料**现采**一个随机段（32–64B），在窗内**逐字重复**插入 **R=3** 次（成簇出现=突发性）；损失只打第 R 次出现的遮蔽段尾，前 R−1 次完整可见（它们是突发性本体，遮蔽即自毁需求）；
- **段尾遮蔽**：重复段第 R 次的**末 2–4 个 CJK 字符**遮蔽（UTF-8 边界吸附，与 Q11 v2 同规，不用比例制不用字节数）——模型要补全段尾，必须回看该段的前一次出现位置并抄后面内容——这正是 induction 回路的训练信号；
- **位置随机化**：重复段的插入位置在窗内随机（不固定窗首/窗尾）；
- 其余训练任务（direct/completion/predict）不变——注入只改数据分布，不改损失。

## 3. 防背护栏（2026-08-22 用户裁定，冻结）

- **重复段必须每窗现采随机段，严禁固定段库**——段集合有限可背 → 训练延长后答案被背进权重 → 需求臂退化成背诵臂而仪表看不出（E103 先验驱动收缩即此权衡的小号预演）；
- 构造器断言：任何段在同一 epoch 内不得重复用于重复构造（机械执行，违例响亮报错）。

## 4. 测量与判读

- **主仪表**：induction 分数仪器（`tools/analysis/v3_6/probe_induction_score.py`）逐里程碑复测——回路是否被催出来（无 head 超 2× 基线 → 出现超线 head）；
- **有效性门**（A1 纪律：门测理解）：注入形态下的段尾补全 acc 超盲猜先验一个预注册边际≥0.10 且 p<0.01（同 Q12 门）；
- **主终点**：回路形成后，转 Q12 形态复测有效性门与 0 示例 Δ（终点测留存）——回路在 + 任务形式在，K 线判决才重新可读；
- **判读矩阵**：
  - induction 分数起 → 回路催出 → Q12 系复测；
  - induction 分数不起（注入 R 次段仍无超线 head）→ 数据注入也不足以催回路，A3 形式上限与回路缺席的归因在"催不出"处合流——K 线在当前规模诚实收束。

## 5. 边界与纪律

- 注入只改数据、不改架构；codec 双指标 >2pp 护栏；预算 20K 步，饱和判定末 2K 逐位走平；配方 2e-4 + warmup 200 + cosine 到 0（E103 事故归因闭环后的健康配方，不许回 1e-3 恒定）；
- 判读金规不变（剖面/Δ 是判词，损失不作数）；E 行入册。

## 6. 判读矩阵四格（2026-08-22 点火令冻结全文）

- **格一**：任务成（Δ>0）+ induction 破 2× 线 + 剖面压平 → 全赢：回路催出、需求驱动分配，DeepMind 框架本系统复现；
- **格二**：任务成 + induction 平 → 状态通道走了非 induction 的私有路由，机制章立新节（比复现文献更有价值，如实按阳性登记）；
- **格三**：任务不成且双仪表不动 → 回 A1 门纪律查任务理解，假说判词不动；
- **格四（判死"分配跟随需求"的唯一合法格）**：任务成 + induction 破线 + 逐槽位剖面头尾比不动 → 两层判词顺序执行：
  - 第一层先查答案实际路由（路由归因仪表，§7）；
  - 路由在窗内 → 判词="分配跟随需求沿最便宜通道兑现"——假说修正而非死亡（需求被窗内复制满足，memory 行分配不动不是假说的反例）；
  - 路由在状态通道而剖面仍不动 → "需求挂上、回路形成、分配不跟"，假说死于 fork 3 侧，按预注册判死条款生效。
  - **禁止跳层：路由未归因前，第四格不许落任何判词（防冤案也防假胜利）。**

## 7. 路由归因仪表（第四格配套，随 Q13 同建）

1. **eval 双消融臂**（复用 store_block 机械）：(i) 状态读出行置零——答案死则路由在状态通道；(ii) 窗内早次出现遮蔽——答案死则路由在窗内复制；两臂分报，互不代报；
2. **逐条目"窗内副本存在"审计列**：构造器记录每条样本的各次出现位置，标记预测时刻是否存在窗内可见副本；Δ 与剖面按该标记分列聚合——让"便宜通道逃逸"在数据里直接可见，不靠事后推断；
3. **构造倾向**：早次出现优先落在压缩区（超窗），从源头压缩窗内逃逸的比例（不是硬约束——审计列就是为此准备的）。

## 8. 双主仪表与纪律（冻结重申）

- induction 分数逐里程碑（prefix matching，细粒度档为主、粗粒度互证，2× 基线为破线判据）；
- 逐槽位剖面头尾比（vs E88 的 5.15× 基线）+ 逐条目 Δ；
- 防背护栏原文冻结：每窗现采随机段、严禁固定段库、epoch 内不重复断言；
- A1 门纪律：门测理解（带形态基线−盲猜 ≥0.10 且 p<0.01）、终点测留存；
- 判读金规：剖面/Δ/仪器读数是判词，损失曲线永不作数；
- codec 双指标随行，退步 >2pp 按部分失败登记。
