## 1. 机制定位（外部文献锚点）

DeepMind ICL 权衡文献（K3 对标，2026-08-22）：induction 回路（prefix-matching 复制回路）在 25–50 亿 token 相变窗口形成，依赖数据的**突发性（burstiness）+ 罕见类别**双属性。我方语料（corpus_v3）与训练量（~8 千万字节/世代）不满足前者——Q13 即在数据层人工注入突发性，把复制回路催出来。Q13 构造（逐字重复+段尾遮蔽）与文献独立收敛同形态（外部佐证）。剂量-权衡曲线（加量→ICL 先升后稳、先验续涨）的验证责任自 Q12 移交 Q13 系。

## 2. 任务构造（突发性注入）

- **重复段**：每训练窗内，从语料**现采**一个随机段（32–64B），在窗内**逐字重复**插入 R 次【待确认：R=3】（成簇出现=突发性）；
- **段尾遮蔽**：重复段的**尾部字节遮蔽**【待确认：遮蔽尾部 25%，或末 4–8 字节】——模型要补全段尾，必须回看该段的前一次出现位置并抄后面内容——这正是 induction 回路的训练信号；
- **位置随机化**：重复段的插入位置在窗内随机（不固定窗首/窗尾）；
- 其余训练任务（direct/completion/predict）不变——注入只改数据分布，不改损失。

## 3. 防背护栏（2026-08-22 用户裁定，冻结）

- **重复段必须每窗现采随机段，严禁固定段库**——段集合有限可背 → 训练延长后答案被背进权重 → 需求臂退化成背诵臂而仪表看不出（E103 先验驱动收缩即此权衡的小号预演）；
- 构造器断言：任何段在同一 epoch 内不得重复用于重复构造（机械执行，违例响亮报错）。

## 4. 测量与判读

- **主仪表**：induction 分数仪器（`tools/analysis/v3_6/probe_induction_score.py`）逐里程碑复测——回路是否被催出来（无 head 超 2× 基线 → 出现超线 head）；
- **有效性门**（A1 纪律：门测理解）：注入形态下的段尾补全 acc 超盲猜先验一个预注册边际【待确认：≥0.10 且 p<0.01 同 Q12 门】；
- **主终点**：回路形成后，转 Q12 形态复测有效性门与 0 示例 Δ（终点测留存）——回路在 + 任务形式在，K 线判决才重新可读；
