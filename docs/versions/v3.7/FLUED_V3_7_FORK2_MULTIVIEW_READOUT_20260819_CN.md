# v3.7 fork 2 立项书：多视角读出 + 前向校验（接口形态改造）

> 2026-08-19 用户四题裁定落地。前置证据链：E73（oracle 判决）→ E74/E75（键塌缩定位）→ E76（手术必要非充分）→ E77（锁死 μ 平线）→ E80/E81/E82（复训平台 0.19，主干旋钮结构惰）→ E83（fork 1 被否，饱和 0.30 = 接口形态天花板）。护栏二：接口信息量充足（real−garbage +0.47@slot0）——**锁死不在信息含量，在每段单向量的接口形态**。fork 2 的任务就是把接口带宽打开。

## 0. 问题陈述

v37 形态下，状态读出后每段产生**一个** d_v 维条件向量，decoder 据它还原整段字节。实测：线性探针能从接口向量读出 62%（slot0 口径），而训练链只兑现 30%（E83 饱和）——缺口 = 接口形态容量缺口。fork 2 = 把"每段单向量"改为"每段 m 个测量向量 + 生成-校验闭环"。

## 1. 架构规格（四题裁定的落实）

### 1.1 多视角探针（Q1：免训练固定正交测量系）
- 每段配 m 个读出探针（默认 m=4），取自**播种随机正交帧**（按段索引旋转一次，固定种子，全训练/评测一致）——免训练、天然免疫塌缩与装饰律（E66 教训：无专项压力的学出组件会退化成装饰）。
- 读出：段 i 的读出 = 状态读出行经 m 个探针得到的 m 个测量向量（按需现算，见 §1.4）。
- **对照臂 2**：可学习内容条件探针（内容条件生成 q）。反超臂 1 → 内容自适应测量有真增益；退化 → 装饰律再坐实。
- **m 扫描预注册 {1,2,4,8}**：提取率-m 曲线斜率本身是诊断——m=4 后饱和 → 下一墙在 decoder 条件形态；持续上升 → 带宽确为瓶颈。
- 带宽账：m ≥ H(段|上下文)/(d_v·b_eff·η_提取)；以 25 字节/段自然熵代入，m=4 足以逼近接口探针天花板。

### 1.2 列表读出 = 生成-校验闭环（Q2）
- decoder 对每段出 top-L 候选（beam 即可）；
- **前向校验**：复用写入算子对每个候选重放写入 ŝ_ℓ = write(cand_ℓ)，在**测量空间**比对 ‖Q·ŝ_ℓ − Q·S‖（Q 为 §1.1 的测量系），取最近者——校验器零新学组件（写入算子已存在，oracle 实验已手工调它），不会被装饰律侵蚀；测量空间联合校验压伪峰（错误候选重嵌入也接近的风险），禁用全状态范数。
- 明确否决：LM 重打分（LM 看不见状态，评的是流畅度不是保真度）；段级码本吸附（候选空间指数级）。
- 首个兑换目标：E78 的 hit@5−hit@1 缺口（0.42 vs 0.17）。

### 1.3 最小侵入（Q3）
- **只改补全/回读路径**的条件形态（单向量→m 向量）；direct/predict 原样不动。
- 理由：三任务带宽需求不同；统一改则增益来源不可分（归因污染）且把 LM 稳定路径暴露给 V 回读回归（E78 裂口教训）。predict 是否跟进另行独立立案。

### 1.4 预算中性（Q4）
- m 个读出向量在回读时从持久状态**按需现算**，持久存储不变；逐段顺序解码时瞬时开销 O(m·d_v)。口径：不是压缩率让步，是把一部分容量预算换成读出时计算预算（与 DART SMA、test-time compute 同族权衡）。
- 若实现约束迫使 m 向量全量物化进 decoder 条件：给帕累托曲线（m × 提取率 × 压缩率），并配**等比特对照**（同接口比特预算的 KV cache 注意力基线）——等比特打赢才算证据。

## 2. 验收判据（预注册，ex-ante）

1. m=4 + 前向校验下，**状态行独存**回读指标 ≥ 0.45（贴着接口探针 +0.47 信息上限）；
2. m 扫描 {1,2,4,8} 单调（非严格单调须附解释）；
3. 档案馆终考（n≥48/档、三种子、hit@k 全曲线，见终考预注册文档）：D=64 档 hit@1 显著超 0.17（E78 基线）；
4. **codec 与 hit@k 并列报告**（fork 1 遗留裁定：K 线不开张则验收不通过）。

## 3. 失败分析（预注册）

- m 扫描平坦 → decoder 条件形态是下一墙（转向 decoder 侧立项）；
- 校验级不能把 hit@5 兑换成 hit@1 → 启动伪峰率测量（错误候选重嵌入接近率）；
- 臂 2（可学探针）反超臂 1 → 更新"免训练探针"先验；臂 2 退化 → 装饰律再添一例。

## 4. 最小实现路径

1. 探针帧模块：播种随机正交帧 + 段索引旋转（纯函数，单测锁定确定性）；
2. 读出接口改造：补全/回读路径的条件从单向量扩为 m 向量（realign/decoder_in 输入维度相应 ×m 或 m 路共享权重——实现时择侵入小者）；
3. 前向校验器：写入算子重放 + 测量空间比对（eval 期组件）；
4. 单测：探针帧确定性/正交性、校验器伪峰率合成测试、m 扫描接线、默认关逐比特不变；
5. 冒烟 → b 格形态 20K 正式臂 → 档案馆终考（预注册协议）。

## 5. 边界与纪律

- 本立项只动读出接口；写入侧（WriteHead/状态机/键几何）一律不动（手术线在原队列排队）。
- 全程 E 行入册纪律；终考按已冻结的预注册协议执行，判读只按预注册判据。
- codec 全覆盖律不动（任何内容任务仍覆盖 1..i 全前缀）。
