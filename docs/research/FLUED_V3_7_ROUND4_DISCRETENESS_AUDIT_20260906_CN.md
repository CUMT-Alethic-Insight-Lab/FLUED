## 0. 判词一句话

链条的前两环成立且已有工程化的现成件；第三环（「取消离散承诺 = 环境可微 = 消灭 RL」）在最接近的邻域里已被实证否掉。可微交互不消灭 RL，它只付清 RL 三件货物里的一件（信度分配），另外两件（探索、方差/偏置控制）在可微化之后反而更难诊断。

用户自埋的那颗雷（「离散性是监督的住处」）成立，且比原表述重一档：文献里离散性不只是监督的住处，还是**泛化的住处**。

## 1. 逐环评析

### 环 A「token 数=门控数，每次启用一个」——修正成立，且有定理级支持

原链的自我修正（LLM 内部早就是稠密软门控，attention 所有位置同时加权竞争）正确。但这一环真正的收获不是修辞修正：

**Veličković et al., ICML 2025，《Softmax is not Enough (for Sharp Size Generalisation)》（arXiv:2410.01104）** 证明 softmax 的输出系数在输入元素数足够多时**必然弥散**（熵→均匀），锐度无法随规模保持。作者同时提出自适应温度（熵→温度的四次多项式映射），但明确声明它是 ad-hoc、**逃不出自己的负结论**。

对 FLUED 的直接后果：读出注意力打在记忆行上，行数一多，「摊平」不是训练没到位，是 softmax 的性质。**E107 影帝结局在这条定理下不是意外，是预期。** 这给「软化=平均化」这句判词换了一个比经验更硬的底座。

### 环 B「读出端拆固定查询」（H-DEMAND-GATE 的状态依赖需求）——站得住

E120 的 cos=0.07（d 格 V 通道）/0.1044（b 格 K 通道）已把固定单查询近视测死，状态依赖查询是正面解法。本环无异议；撞车侦察义务另计。

### 环 C「交互连续 ⇒ 反馈可微 ⇒ RL 失去存在理由」——**塌了，且是被最接近的邻域实证塌的**

原链举的例子是机器人连续控制。恰恰这个领域已把该命题做成了实验：

1. **Suh et al., ICML 2022,《Do Differentiable Simulators Give Better Policy Gradients?》（arXiv:2202.00817）**——结论是「看情况，而且经常更差」。可微模拟器给的一阶梯度在**近似/严格不连续、刚性、混沌**地形上**有偏**，且论文明确指出：**该偏置无法从经验方差里诊断出来**。处方不是「梯度替代 RL」，而是 α-order 估计量——把零阶（RL 的 score function）与一阶（可微梯度）混用。2026 年复核论文（arXiv:2604.18161）把结论进一步收窄为「方差控制往往比估计量切换更重要」。
2. **可微就得截断**：SHAC / Adaptive-Horizon Actor-Critic（arXiv:2405.17784）、Analytic Policy Gradients（arXiv:2606.21525）——沿完整可微轨迹反传因雅可比连乘爆炸，故主动**切断计算图、用 critic 估终值**。即：路径可微之后，人们又把 RL 的 critic 请了回来。
3. **最贴题面的反例**：Butt, Kwiatkowski, Labiad, Kempe, Ollivier,《Soft Tokens, Hard Truths》（arXiv:2509.19170，2025-09）——要训连续 CoT，用的方法是 **RL，且额外往输入嵌入注入噪声以提供探索**。连续化没有消灭 RL；它消灭的是离散性，**探索必须手工再注射回去**。

对照第一轮自己给出的 RL 三件货物拆解，精确的账：

| RL 的货物 | 可微化付清了吗 |
|---|---|
| ② 延迟信度分配 | **付清**——NTM→DNC 的真实教训，本环原判正确 |
| ③ 探索压力 | **未付**——可微给梯度，不给「明知没用也试一次」；Soft Tokens 必须外挂噪声 |
| ① 优势减法 / 方差 | **未付，且可能更糟**——不连续地形上一阶估计量有偏，且偏置不可从方差诊断（Suh 2022） |

结论：「化有形于无形 = 消灭 RL」的准确版本是 **1/3 真**。

### 方法论注记：收敛不等于置信度

原链称「哲学链与上一轮定理独立收敛，收敛本身就是置信度」。此处不成立：两条链共享同一隐藏前提（**可微 ⇒ 梯度可用**）。前提错则两条一起错。收敛只在前提不共享时才构成独立证据。

## 2. 「离散性是监督的住处」——成立，但要升一档

原链的分类是二分：**内部固定点可拆 / 环境固定点（字节、损失位）是锚不可拆**。文献支持后半，但**否掉「内部固定点一律可拆」**——存在第三类：**承重的内部离散性**。三条独立证据：

1. **DreamerV2（Hafner et al., arXiv:2010.02193）**：在一个**完全可微、本可全程连续**的世界模型里，把潜变量从高斯换成**类别型**，55 个任务 **42 胜 8 负 5 平**。作者解释：类别先验能完美拟合聚合后验（类别的混合仍是类别），高斯先验拟合不了高斯混合。→ **内部离散性带来的是多模态承载力，不是监督接口。**
2. **离散瓶颈提升系统性泛化**：DVNC（arXiv:2107.02367，NeurIPS 2021）、Discrete Key-Value Bottleneck（arXiv:2207.11240，ICML 2023）——把组件间通信量化成离散码，跨 Transformer / 模块化架构 / GNN 一致提升 OOD 泛化。
3. **记忆领域走的是反方向**：Rae et al., Sparse Access Memory（arXiv:1610.09027，NeurIPS 2016）——软寻址「会跨槽泄漏、无法精确表示离散结构」，故把硬性（稀疏 top-k）加回来才让 DNC 规模化（1000× 快、3000× 省内存）。Kaiser & Bengio,《Learning to Remember Rare Events》（arXiv:1703.03129，ICLR 2017）同款：**除最近邻查询外全可微**——刻意保留一个硬点，且其靶正是**稀有事件记忆**，与 D1 稀有续尾同靶。

**修订后的公理**：离散性该放在「需要承诺」的那一层，不该放在「需要梯度流」的那一层；而记忆检索恰属前者。推论：**E119 那个能训到 0.596 的多槽读出件，其槽位硬度是资产不是负债。**

## 3. 处方修订：可学锐度的正确形态

原链处方为「门控温度可学、可达低温极限」。方向对，但有两档，且第二档更好：

- **可学/自适应温度**：存在（Veličković 2025 的熵→温度映射；CLIP 的可学温度），但作者自陈 ad-hoc，且**softmax 永远给不出精确零**。
- **更对的形态：α-entmax / sparsemax，且 α 可学**——Correia, Niculae, Martins,《Adaptively Sparse Transformers》（arXiv:1909.00015，EMNLP 2019）给出对 α 的雅可比，**每个头自学稀疏度**：α→1⁺ 退化为 softmax，α=2 为 sparsemax，中间连续可调，**低分行拿到精确 0 而非小值**。这正是「平时软着、需要选择时锐化、且真能到低温极限」，并**绕开 softmax 弥散定理**（该定理只管 softmax）。

**对 H-DEMAND-GATE 的具体建议**：需求叠加后的读出注意力用**可学 α-entmax**，而非可学温度 softmax。附带好处：α 本身即仪表——α 学不上去（贴 1）就是「回路不肯承诺」的直接读数，比熵轨迹歧义更少。

## 4. 判读表：熵格要加，但不能升格

原链提议「读出分布熵轨迹恒高 = 影帝前兆，当场拒发」。**加，但必须标前兆格不是判据格**，理由在册上：

**E107 已证「注意力锐 ≠ 承重」**——maxmass−chance 全程 +0.09~+0.16（注意力确被拉动，非均匀），而 twin_d ≈ 0.002、主终点 Δ=−0.0012±0.0083（CI 含 0，n=48）。**低熵与承重解耦。**

故熵格只能做**单向判据**：
- 熵恒高 → **拒发**（省钱，合法）；
- 熵降下来 → **什么都不能判**，承重仍只能靠逐条目 Δ / 消费消融。

旁证（同类先例）：Soft Thinking（arXiv:2505.15778）的 Cold Stop 即以输出熵做早停闸；而《LLMs are Single-threaded Reasoners》（arXiv:2508.03440）的探测发现朴素 soft thinking **塌成单线程贪心**（被最大分量支配）——方向与「摊平」**相反**。连续化的两个死法（摊平 / 塌成硬贪心）都真实存在，**熵这一个数分不清健康锐化与病态塌缩**，更说明它只能当前兆。

## 5. 文献带回的缺口：五张脸只覆盖了一半

**「消费路径未形成」在文献里有名字，且有一整条治疗线。**

1. **REALM 的冷启动恶性循环**（Guu et al., 2020）几乎是 E120 的逐字版本：*检索器初始随机 → 取回文档无关 → 知识编码器**学会忽略检索结果** → 检索器**再也收不到有意义的梯度** → 死锁*。即「鸡生蛋动力学」。REALM 的解不是损失重加权，是**给检索器单开一个逼迫检索的预训练目标（Inverse Cloze Task）**——即第一轮三分叉的 ②相位分离。
   **与 E119 的差别**：ICT 的任务**结构上保证答案只在被检索文档里**，且该压力在联合训练期**持续存在**；E119 温启动只给了盆地、未给持续压力，E120 遂判否。
2. **Posterior collapse / 强解码器问题**：强自回归解码器有足够容量在**不用潜变量**时拿到好似然，潜通道遂被弃用。与脸⑤（检索必须比背先验便宜）同构，但治疗线更全：KL annealing、**free bits（对信息项打铰链下界）**、**word dropout（生成时随机把上文替换为空向量，强迫依赖潜码）**、削弱解码器。

**关键观察**：需求五张脸全部是「**把检索解抬便宜**」（D1 即是）；**没有一条是「把先验解弄不可用」**。而 collapse 文献里最稳的两个处方（free bits、word dropout）都属于后者。E121 花 36.6× 剂量抬检索，先验解一根毫毛未动——而先验解正是「先冲线」的那个。

## 6. 由此得到的最便宜下一步（建议排在两个候选假设开臂之前）

E121 判「不确定」，但有一个更简单的解释尚未排除：

- 规格 §3 自陈：**「密度账答不了脸③⑤（只经状态通道可达 / 比背先验便宜），归 50M 短臂实测」**；
- D1 任务书对脸③的依据是一句**设计假设**——「源在上一段，窗内注意力够不到 chunk 内部细粒度」——**不是测量**；
- E121 消费消融 **Δ=0.0000±0.0000（n=64）**：置乱状态通道精度一点不掉。

这与「回路没形成」观测等价，但也与另一假设观测等价：**这批 D1 位点根本不需要黑板**——窗内/先验即可覆盖。稀有度只是「先验猜不中**这个字节**」的代理，不等于「**只有跨段检索**能拿到」；稀有 n-gram 续尾中有大量是**局部可推**的（形态、拼写、模板续写）。

### 建议：给脸③配一个与脸④（密度账 36.6×）同级别的零训练算术关

**跨段必要性账**：对 D1 选中位点，用冻结基座测两条件下的字节 NLL——

- (a) 完整窗；
- (b) 前一 chunk 置乱/删除。

**ΔNLL 即这批需求的「跨段互信息」下界。** 密度账算的是「有多少监督字节」，本账算的是**其中有多少字节真的只有黑板能给**。

- 成本：CPU / 单卡小时级；
- 复用件：`tools/analysis/v3_6/probe_burst_route_q15.py` 的 `--no-excision` 口径 + `tools/analysis/v3_6/demand_density_book.py` 的窗流；
- 判据后果：若有效跨段字节远低于 54.8 字节/窗，则 **E121 的「剂量够但消费未出」是误判，真相是剂量没打在黑板上**——H-DEMAND-GATE（修接口形式）与 H-EPOCH-AGG（改优化节奏）就都在修一个没坏的地方。

**理论对齐**：平均化在损失面上输，当且仅当**目标的条件熵低而先验熵高**；两者之差正是上述互信息。原链「损失要在选择真正承重的位置上惩罚平均化」，其可测形式就是它。

## 7. 建议的登记动作

1. **环 C 降级入册**：「可微交互消灭 RL」→ 改为「**可微交互付清信度分配，不付探索与方差**」。锚：Suh 2022（偏置不可从方差诊断）+ Soft Tokens 2025（连续 CoT 仍需 RL+噪声）。连带后果：第一轮三分叉中「③架构侧再软化」的期望上限低于原判。
2. **H-DEMAND-GATE 设计公理修订**：可学锐度 → **可学 α-entmax（非可学温度）**；α 本身入仪表。撞车侦察清单增补两条：Adaptively Sparse Transformers（1909.00015）、Sparse Access Memory（1610.09027）。
3. **熵格标前兆不标判据**，理由锚 E107（maxmass 抬起而 twin_d 贴零）。
4. **需求五张脸增补第六张**（或把脸⑤拆成对偶）：「**先验解要被结构性剥夺，不只被相对抬价**」。锚：posterior collapse 的 free bits / word dropout 线 + REALM ICT。
5. **下一臂排序**：跨段必要性账（零训练）优先于 H-DEMAND-GATE / H-EPOCH-AGG 开臂。
