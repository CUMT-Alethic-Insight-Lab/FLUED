# S38 臂 B（残差第二状态 S′）撞车侦察报告

> 2026-08-09，按 AGENTS.md 协作协议规则 5（架构级臂开 GPU 前必出撞车侦察报告）。
> 拟开臂：**残差第二状态 S′**——解码残差门控写入 + 独立内容条件化读出，
> 挂靠在 S36 主形态上，2048 尺度。本报告给出同名/同形核查、12 个月谱系扫描、
> 一句话差异点。结论：**可开臂**。

## 1. 同名/同形核查（same-name / same-shape check）

| 候选 | 同形点 | 关键差异 | 裁定 |
|---|---|---|---|
| **RDN / RLA**（arXiv:2509.25223，北大+港大+MiniMax，2025-09） | 残差累积进第二循环状态 R，输出叠加主/残差读出 | ① R 的写入是**逐 token 写入侧残差**（v_t−S_{t-1}k_t，无门控）；我方是**段级、解码 CE 门控**（下游失败决定写不写）；② RDN 的 R 与 S **共用读出 q**；我方给 S′ **独立内容条件化查询**；③ RDN 在 token 级 LM 语境，我方在 boundary/segment 压缩语境（段=最小语义单元） | 最接近撞车点，差异成立 |
| **HOLA**（arXiv:2607.02303，2026-07） | 残差驱动写入判据 | 残差只取标量 surprise 作精确 KV cache 准入；**不做二次压缩**（存原样行）。我方 S′ 是残差的二次压缩成定长状态 | 不撞 |
| **HAM**（arXiv:2603.22325，2026-03） | RNN 预测误差门控 KV cache 写入 | 同 HOLA——精确备份，不二次压缩；残差定义在 RNN 预测误差（与我方解码 CE 同族），但落点是逐 token KV cache | 不撞 |
| **Q-Delta**（arXiv:2606.08804，2026-06） | query 侧读出残差 | 读出残差**回写修正 state 演化**；我方残差状态有独立读出通道、服务于检索而非状态修正 | 不撞 |
| **CCQ**（arXiv:2606.01294，2026-05） | 条件化读出 query | 条件化用的是全局二阶统计（running key covariance），非逐内容生成；且只条件化主读出 | 不撞 |
| **Memory Caching**（arXiv:2602.24281，2026-02） | segment 级 state checkpoint + Gated Residual Memory 跨段读出 | checkpoint 是周期性整存，非残差门控；细节仅二手，已标注 | 大概率不撞，已标注未深读 |

## 2. 12 个月谱系扫描（2025-08 → 2026-08）

delta 规则线：DeltaNet → GDN → KDA（2510.26692）→ **GDN-2**（2605.22791，
erase/write 门控解耦）/ **EDA**（2606.26560，擦除地址解耦）；二阶化：MDN
（2605.05838 动量）、DeltaProduct（2502.10297 Householder 多步）、Mamba-3
（2603.15569 复特征值）；几何化：KATA（2607.17419）。残差线：RDN/RLA
（2509.25223）、Q-Delta（2606.08804）、HOLA/HAM（残差作缓存判据）。
**"残差同时驱动 是否写/写什么/如何读"的三位一体无任何工作占位**——
HOLA/HAM 只答"是否写"（写向精确缓存），RDN 只答"写什么"（无门控、共用
读出），Q-Delta/CCQ 只碰"如何读"。段级（boundary-conditioned）残差自报
无对应物。

## 3. 一句话差异点

**S′ = 段级残差状态，写入由下游解码失败门控（CUIB 谱系：下游显式效用反向
调度上游）、读出由内容条件化独立 query 承担——RDN 证明"残差→第二状态"
可行，我们占"boundary-conditioned 残差 + 独立读出通道 + 解码侧门控"，
三者在我方证据（写入残差与失败零相关 0.09-0.14 vs 解码 CE 0.97，双尺度）
下是唯一自洽组合。**
