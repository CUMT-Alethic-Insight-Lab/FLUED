## 可交给主代理的核心判断：均为待全文验证的初筛结论

1. **“预先层级摘要+来源方向指针+查询回访”已有多个非常近的组合，不能凭组合名称主张空白。**先读 MemWalker（034）、ReadAgent（033）、H-MEM（005）、HORMA（037）、CAM（004）、RAPTOR（001）、MemoRAG（048）。
2. **“来源”要拆开。**父节点到子记忆、摘要到原文片段、事实到支持证据、KV 到逻辑 token、逻辑 token 到物理页，是五种映射。H-MEM 的“下层索引”不能提前写成“原文指针”；PagedAttention 的物理页也不是语义来源。
3. **原文保留与摘要不冲突。**ReadAgent 明确回读原文；HORMA 摘要明示摘要实体连 raw trajectories；Eywa（029）先存不可变 evidence 再派生事实。完整原文在数据库/文件中，并不意味着全部进入当前上下文或常驻显存。
4. **反对照必须先于结构扩展。**ReFind（018）说明能干的原文词法搜索可能恢复被归功于结构的收益；051 表明其强重排器受控设置下层级摘要等无可靠额外增益。两者不证明所有层级无用，但会改变必要基线。
5. **动态一致性有不同对象。**002 是摘要树文档增删维护；012 是时间事实图；019 是取到证据后的版本策略执行；038 是编码器变化造成旧向量过期；046/047 是位置/前缀上下文变化造成 KV 失效。不能互相当作已经解决。
6. **首轮最大意外是版本收窄。**019 v1 旧题为 Don’t Ask the LLM to Track Freshness，v2 当前题为 Reliable Post-Retrieval Assembly…。最新摘要明确：主要收益来自证据抽取和策略执行分离，不是 freshness operator 本身；LongMemEval 小样本对比无显著总体优势。下轮必须读 v2 并核查 v1，不复制旧题的强结论。

## 全文证据卡的统一提取字段

1. **版本与定位**：题名、作者、年份、arXiv/DOI、版本日期；关键机制给节/页/公式/图/表和 URL；明确作者主张与本轮推断。
2. **训练与因果可见性**：压缩器/写入器/查询器谁训练、奖励/监督源；写记忆时是否见 query、答案、未来事件或完整历史；离线 oracle 不能混成在线策略。
3. **五种粒度**：输入、持久存储、索引/地址、单次读出、实际计算 token/状态；若论文只支持 token，不能替字节接口作证。
4. **来源关系**：原始内容是否不可变；稳定 ID/区间/时间戳；父子 DAG 或 tree；摘要丢词后可否绕过摘要直取源；链接断裂/遗漏检测。
5. **生命周期**：追加、改写、撤销、压缩、淘汰、外置、加载、重算、回滚各是谁的动作；内存对象是否只是从 prompt 移出，还是确实从持久存储删掉。
6. **一致性**：事件时间 vs 写入时间；旧/新冲突；事实、摘要、向量、KV 四类失效是否分开；并发/异步刷新窗口；模型/编码器更新引起的陈旧状态。
7. **完整资源账**：下节六栏，缺项如实写未报；不要从 token 节省反推 GPU 节省。
8. **反事实与失败条件**：同源原文检索、平层摘要、无压缩完整历史、结构但不回访、允许回访但不分层、oracle 路由/证据读取；任务全局性/时序性/证据稀疏性和负例。

## 必须分开的六张资源账

| 对象 | 应记录 | 常见口径错误 |
|---|---|---|
| 持久源文 | bytes、压缩、追加/删除、备份与访问延迟 | 原文在磁盘却算成常驻显存；或宣称“压缩后不必保留原文”但代码仍存全量 |
| 派生记忆/索引 | 摘要/图/embedding/KV bytes、索引元数据、构建与更新调用 | 只报摘要 token，不报索引/原文/向量副本 |
| 在线工作上下文 | 每请求可见 token、读出的层数、重复插入 | 把一次 prompt 限额当总记忆容量 |
| 活跃显存 | 参数、活跃 KV、加载页、索引/缓冲区峰值 | M+ 的相近 GPU 开销被误读成全系统存储相近 |
| 数据搬运与重算 | CPU↔GPU/磁盘带宽、预取、缓存命中、重算 FLOPs/耗时 | 外置容量变大却不报慢层访问；选择重算只报命中时速度 |
| 长期总成本 | 写/读/维护/重建/删除调用、token、延迟、查询次数摊销 | 只报在线成本，忽略 sleep-time 更新与首次索引构建 |

缩写说明：RAG 为“检索增强生成”，先检索外部证据再供模型作答；KV 为注意力“键—值”状态缓存；gist memory 为简短要点记忆；source pointer 为能定位原始记录或区间的来源指针。后两者不能仅凭语义相似检索就认定存在。

## 竞争假说与低成本判别建议（供后续综合，不在本轮执行）

| 候选假说 | 最便宜可证伪比较 | 结果怎样改变后续方向 |
