## 0. 审计结论

**建议定向扩展，不能按382篇或207篇候选宣布覆盖充分；也没有依据把现有目录整体判为不可信。** 当前最影响研究决策的不是再加多少新模型，而是：

1. **核心组合已有实质先例，且不止外部检索系统。** 本轮独立阅读原文的 MemWalker、ReadAgent、RAPTOR、HORMA、Landmark Attention 和 SSA/H-SSA，分别覆盖多级摘要、来源链接、问题驱动回访、退回父节点、学得的粗到细原始键值访问。不能只写“RAG不同于网络内部”就绕开最近邻，也不能据此否定草案所有可能贡献。
2. **有一个直接、可定位的漏项：草案§10点名的 HMT（2405.06067）不在当前 `01_search`、`02_catalog`。** 本轮独立取得其v1正文；它确为相关工作，但“回忆”主要访问历史摘要向量，不等于任意历史原始内容回访。应补录、锁最新版后精读，而非因其名称层级化就认定完全同构。
3. **来源偏差比总量不足更明确。** 384个作品实体中，358个以arXiv为原生键；八专题日志可识别的328个实际检索式均无中文字符。存在英语查询/英文公开预印本生态偏置，尤其缺中文及跨语种的来源定位与因果消费测试；这不等于作者地域偏置，也不等于非英语论文必然被排除。
4. **不是“没有经典”，而是经典谱系不均。** 信息论和部分自适应计算已有经典；早期学得文档导航、读写分离记忆、概率筛选后原库验证、数据库来源与增量维护等谱系明显不足。近期预印本在决定性机制和反例位置承重较大，不能把其新近性当可靠性或不可替代性。
5. **元数据错误已有跨文件传播。** 第一轮发现审计指出的 H-MEM 作者错名仍在 `CATALOG.md:127`；题名前缀、版本核销也未全部传回目录。应先做唯一作品级元数据补查，再将关键结论升级为科研判词。

**建议分类**：必须扩展见§4；优先精读/调序见§5；可暂缓见§6。所有建议以“能否改变竞争解释或架构选择”为排序依据，不设补足篇数的验收门。

### 1.3 草案匹配的最小分解

按用户草案§2—§7，而非按论文标题，分为：

- **保存**：至少粗细两种内容同时存活；最细来源的保存期限、物理位置、淘汰规则明确。
- **对应**：粗节点能定位细节点/原文/原始键值；父子编号、原文跨度、事实支持关系和物理页映射分别记录。
- **读取**：问题或当前查询改变访问对象/粒度；不是仅训练前固定一种压缩率。
- **纠错**：可回父节点、改路径、扩搜、直接取源；存在动作与能校准地发现遗漏、保证召回是不同层级。
- **加工**：未活跃状态可保留供读，但不执行昂贵变换；跨网络深度读取不等于文本粒度下钻。
- **学习**：边界、摘要、路由、停止分别由何信号形成；主任务损失、证据重合奖励、单步代理效用、闭环终局效用不等价。
- **价值**：相同来源保留权限与总资源预算下，最终预测确实特异依赖正确内容，而不只是能找到、能探测、会引用。

前四项是本轮最近邻主轴；选择性加工和效用头在草案中是可选增强，**不能要求先例同时含全部可选组件，才承认它撞到了最小原型。**

下列判断来自本轮通过Kimi Code内置浏览器重新读取公开原文DOM，不是复述专题摘要或首轮审计。仅核列明章节；未读到的实现细节写“未核”，不写“没有”。

### 2.1 MemWalker｜W0139｜2310.05029v1

原文：[HTML v1](https://arxiv.org/html/2310.05029v1)，§3、Figure 1、Table 1、§4.1/4.3、§5及§7。

- **正文直接确认**：构树不依赖查询；原文切段后逐级生成摘要；查询到达后在子节点和返回父节点之间选择；叶提示含原文段落；`-1`为退回、`-2`为作答。§3明确“Leaf prompt contains the content of the segment”。
- **不是仅有回退接口**：§5 Table 4报告走偏路径比例和回退后答对比例；说明已有实际纠错使用，不只是图示愿景。这仍不是未知遗漏的完备检测或最坏情况召回保证。
- **与草案匹配**：粗细共存、层级对应、查询下钻、细源回访、路径回退，已在同一系统出现。草案§7的固定粒度多级摘要+来源回访最小原型必须正面对照它；“增加回退”不能单独作差异句。
- **不能扩大的部分**：§3为零样本提示，不是学得字节边界或轻控制头；§7承认构树规模、强模型依赖和未微调的限制。§4.3所谓Full Context基线会左/右截断到4096 token，**不是草案的Flat Full Access全源访问基线**。§5只量阅读token占比不能代替持久源、构树、总调用与墙钟成本。

### 2.2 ReadAgent｜W0138｜2402.09727v3

原文：[HTML v3](https://arxiv.org/html/2402.09727v3)，§3.1—§3.3、§2及§4开头。

- **正文直接确认**：页边界由提示选择；每页要点前加页码；查询读完整要点集并选择原始页；原始页在对应位置替换要点。顺序版本看已展开页再选择下一页，并可输出STOP。
- **与草案匹配**：来源编号、粗/细双表示、按问题恢复原文、序贯追加读取和停止，均有实际流程。它不是只有摘要的不可逆压缩。
- **关键差别**：§3.1的要点集合主要是同层有序目录，不能当多级树；§2明确要点总体仍受上下文窗口限制。正文§3.3明确构建可在同一文档多次查询间摊销，报告的是处理词量；不能把多问摊销收益当单次请求或端到端时延收益。
- **应补的比较**：统一原始页、要点、问题和读取预算，比较一次并行、逐次追加、平层全要点与层级导航；否则模型能力、交互次数和粒度一起变。

### 2.3 RAPTOR｜W0082｜2401.18059v1

原文：[HTML v1](https://arxiv.org/html/2401.18059v1)，§3、Figure 2/3。

- **正文直接确认**：叶节点含原始短块及其向量，父节点为聚类摘要；软聚类允许同一节点属于多个簇。因此草案“不必严格树、可以重叠”的宽泛想法也不能直接作为未有先例的差异。
- **两种读取不能混写**：逐层遍历在所选父节点的孩子中继续top-k；折叠树则把所有层节点放在共同候选池按查询检索。Figure 3说明在20篇QASPER文档上的比较后，主结果采用2000-token预算的**折叠树**。
- **与草案匹配/不匹配**：多尺度内容保存和查询选取匹配；主结果不是“先摘要判断不足，再交互下钻”。既不能把RAPTOR全部收益归给下钻，也不能因为它常用折叠检索，就否认其多层表示先例。
- **限定**：正文指出折叠方式须搜索所有层节点，可由快速近邻库加速；作者的效率声称仍需补构建、索引和跨源维护成本。所读§3没有给出可靠遗漏触发回退的机制证据，不等于全论文或实现中绝不存在。

### 2.6 Landmark Attention｜W0197｜2305.16300v2

### 2.7 SSA/H-SSA｜W0162｜2604.20920v2

SSA中文说明：要点单元稀疏注意力，以学得要点给块打分并展开选中块；H-SSA是其多级要点扩展。原文：[HTML v2](https://arxiv.org/html/2604.20920v2)，§3.1—§3.6、公式(6)—(10)、Table 1/3。

- **最强的内部机制撞车之一**：§3.2用当前查询与要点键打分；§3.3公式(8)展开选中块的**完整原始键值**并保留该块要点；§3.5把多级要点、粗到细选择、原始token共同置于一个框架。它不只是“远端只能读压缩KV”。
- **学习信号明确**：§3.4先以受限因果掩码和后缀下一token损失训练要点；查询条件展开的额外微调可选。不能以“端到端学得摘要+查询回访”宽泛自称新机制；也不能把离散top-k每条未选路径都说成已可微训练。
- **与草案的未决差异**：固定块和固定分组不是学得语义边界；§3.3的adaptive top-k主要按长度、压缩率、分组结构调预算，不自动是按证据不足在线升级；所读段落未核到有校准保障的跨父节点扩搜。可调查这些轴，但不能因未核就宣布文献空白。
- **复杂度不能只摘理论表**：§3.5在选取预算等条件下给出单查询对数路由；§3.6同时明确实际实现有O(n)元数据数组和O(n)压紧扫描。优化服务模式还可能把预算向上取整、选默认top-k的超集。比较必须分默认集合与服务优化集合，不能用不同选择权限的最快数字证明同预算胜出。
- **别只摘正结论**：Table 3所读行中，持续预训练阶段H-SSA在16×与32×的平均成绩低于单级SSA，微调阶段部分设置才反超。多级不具有无条件优势；必须携带训练阶段和压缩率。这是作者表格内的限定，不是本轮复现。

### 2.8 HMT｜目录外必补｜2405.06067v1

HMT中文说明：层级记忆Transformer，用近期token、传递摘要和历史摘要缓存增强分段递归处理。原文：[HTML v1](https://arxiv.org/html/2405.06067v1)，作者栏、§3.1—§3.3、Figure 1、§4开头。

- **身份实核**：题名 *HMT: Hierarchical Memory Transformer for Long Context Language Processing*；Zifan He、Zongyue Qin、Neha Prakriya、Yizhou Sun、Jason Cong；v1为2024-05-09。本轮只读v1，不宣称它是目前最新版本。
- **草案与目录差异**：用户草案§10明确给出2405.06067，现有候选与目录对该ID、HMT和完整核心题名定向搜索无命中。这是明确的入口遗漏，不是“整个层级记忆领域未覆盖”。本轮不代目录所有者补W-ID。
- **正文不支持把所有回忆称源回访**：当前段前j个表示形成查询，与最近N个历史记忆摘要交叉注意力；近期精细路径仅保留上一段末k个token表示。§3.2承认历史摘要累积，较旧信息损失更大。它是查询相关历史摘要召回，不是任意远端原文定位读取。

### 2.9 新颖性的有限结论

**已有先例足以阻止的宽泛表述**：

- “首次同时保存粗细表示并按问题回访原文”；
- “首次多级摘要+来源指针+下钻+返回父节点”；
- “首次在语言模型内部以学得要点控制原始键值粗到细访问”；
- “首次把记忆组织和检索职责解耦，并训练导航器”。

**本轮仍不能裁定、也不应据摘要否定的研究空间**：

- 特定未知查询族、固定总位数/总时延下，多槽地址与载荷各自该保留什么；
- 非树、重叠且随时间更新的来源关系如何与低开销读写维护共同优化；
- 摘要没有线索时，能否不先读全库就识别漏召回、在风险约束下探索或回退；
- 有负担上限的真实动作反事实标签，能否提高部署的多步内容消费，而非只提高支持证据重合；
- 字节接口上的公平内容覆盖、实际因果消费与来源生命周期的共同证据。

这些是**待核假说和条件性差异候选**，不是已经证明空白或首创的模块清单。改进评价、成本核算、失败条件或训练信号可以构成研究贡献；不要求贡献必须是拼出一个从未出现的组合名称。

### 3.2 英语偏差要拆成三件事

1. **检索语言**：328个实际查询未见中文字符，且已有日志以英文机制词、英文题名及英语模型生态为主。应补中文机制词和中文原始来源索引；不以“查到中国团队英文稿”抵充中文检索。
2. **评价语言**：目录已经有ByT5、CANINE、多语公平和低资源入口，不能说完全没有多语言。问题是核心回访近邻实际考场仍多为英文长文/英文对话；ReadAgent/SSA等的个别结果也不能自动为中文数字、跨语种实体别名、混合编码给证。
3. **来源渠道**：以arXiv键为主不等于未发表，却会使不挂预印本的数据库、信息检索、文档分析、中文期刊和较早系统工作难进入种子链。需沿正式参考文献与反向引用扩展，而非仅换搜索引擎继续找2026模型。

本轮没有按作者姓名推断国家/母语，没有统计所谓“英语论文覆盖率”，也没有证据给出非英语文献的遗漏百分比。补中文后仍须用稳定ID去重；翻译题名、博客转述、同模型中文报告不能另算独立实证。

### 3.3 前沿与经典：不靠年份比例裁定

- **已有经典不能抹掉**：W0108（1991逐级细化）、W0063（信息瓶颈源头）、W0101/W0102（决策意义的通道比较）、W0248（自适应计算）、W0251（多时间尺度递归）、W0303（自适应次模）及早期离策略评价已在表中。不是“全是2026”。
- **经典不足集中在桥接处**：候选正文搜索对Bloom、Neural Turing Machine、Differentiable Neural Computer、Memory Networks、Hierarchical Attention Networks、BM25、materialized、Geva/Berant无命中。这里只能称**现有候选未显式覆盖这些入口**，不是已完成该领域文献穷举。它们分别帮助排除“经典筛选/导航/寻址改名”“更强平层检索”“维护成本被转移”等解释。
- **原文引用带出可追线索**：MemWalker参考列出Geva与Berant 2018的 *Learning to Search in Long Documents Using Document Structure*（1806.03529），并在相关工作说明早期LSTM已沿标题/小节搜索。本轮未单独打开该旧作，不计确认新作；但它比新增又一2026摘要树更直接补优先权。
- **前沿承重风险**：H-SSA、HISA、AttentionIndex、HORMA和新近效用/因果反例恰在决定性位置。应保留，但每条强结论必须和稳定历史基线、不同团队反例、正式版/代码版本配对；不能把近期相似主张数当独立证据权重。
- **经典补读不是怀旧配额**：不必每个年代同篇数。若某经典只能提供无关的生物类比，可暂缓；若改变“来源是否在、导航是否学得、回访费用是否已解决”的解释，则应前移。

### 7.2 每个唯一作品应补的身份字段

- **稳定对象**：主W-ID、原生ID、所有正式版/预印本/仓库别名；作品数、版本数、系统变体数、独立实验簇分列。
- **确切标题与作者**：原文/出版者作者栏或BibTeX，含变音符、顺序、团体作者；不从arXiv From/联系人填作者，不凭首作者缩写补全。
- **时间**：首发、每版提交、正式出版、检索访问时间分列。DeepSeek-V4、Bridge-RAG、Titans、Hopfield等编号与记录日期异常保留原值和异常状态；不得按编号悄悄改日期，亦不得因此直接判ID虚构。
- **版本实体**：所读HTML/PDF准确版本、题名变化、页码变化、报告/模型卡/代码是否同版；公共仓库锁commit或发布tag，而非永远引用main。
- **出版与状态**：正式会场/轨道、主会/发现/演示/工作坊、DOI、撤回/更正。arXiv comment和会场简介不是已独立核定录用轨道；QuickMerge++撤回未知不能写已撤回或有效性能已确认。
- **访问与阅读**：访问成功≠读完整；PDF入口≠已下载；返回全文≠全文精读。失败记实际URL、日期、网络错误/404/429/验证码/拒绝类别及重试次数；拒绝不绕过。
- **原始材料类型**：官方发布页、模型卡、技术报告、正式论文、作者代码分别记；K3/LongCat2不能用README或发布页直接占全文论文名额；bGPT官方介绍也不能当读过方法。

## 8. 内部证据边界对本审计的硬约束

依据 `../00_scope/INTERNAL_EVIDENCE_BOUNDARIES.md`，不新增内部实验裁定：

- R2/R3为token输入域，不能给字节接口免责。外部token模型回访成功也不能直接替字节因果消费作证。
- C64手术同时动粒度、替换和地址广播；同参数对照只排除参数量，不能借外部单槽理论直接把内部失败改判成纯粒度结论。F5必须要求地址、载荷与算子分离。
- H-sup正梯度是收官点局部观察，不代表训练全史。F8须查形成过程、持续干预和策略变化，而不是从终点余弦推断所有监督兼容。
- 存储存在、强探针可恢复、部署读取、最终预测特异依赖四层分开；外部负面探针也不直接证明信息从未保存。
- 权重共享、余弦归一化、输出尺度是不同轴；token共享文献不能替小字节词表单变量实验作结论。
- 源存活时的可交互回访与无源不可逆编码不同类。不能用后者不可能性否掉前者，也不能用前者原文仍在反驳内部压缩状态限制。

不以补满500篇或读完固定200篇为充分条件。至少应满足：

1. 草案每个必选机制能指向最接近先例和明确差异；HMT漏项、H-MEM作者、已可核销版本/标题等基础问题已处理。
2. 原型对照包括真实全源访问、强平层检索、层级不回访、平层回访、层级回访和oracle定位；不能把被截断的Full Context当全源上界。
3. 最近邻具有原文证据，回退接口、遗漏检测和召回保证不互换；无法核查的部分留可见缺口。
4. 至少能区分“多存信息”“路由更好”“值更保真”“加工更多”“教师更贵”“消费者更强”，并给出新结果会如何改变决策。

6. 新一轮定向扩展若只增加重复机制/同证据簇而不改变上述选择，可停止该族；若仍会改变原型安全边界或主张，即使数量够仍继续。
