## 3. 分项裁决与修订指令

### 3.1 W0108：区间印刷错误与细化定理必须分开

**独立原页核查。** 内置浏览器直接查看正式PDF印刷p.272，式(37)确为

\[
\tfrac12(1-p)+\sqrt{p^2-6p+1}<z_1<\frac{1-p}{1+p},
\]

根号前没有额外的1/2。取合法参数p=0.1，左右界分别1.0903124237和0.8181818182，区间为空。不是仅凭文字抽取/OCR判断。式(34)给出的三支撑条件含
`[z-(1-p)/2]^2 <= (p²-6p+1)/4`，其较大根为0.7701562119。故“根号项疑缺1/2”是有代数依据的候选修复，但**没有取得勘误或1989博士论文**，不得当作者已更正。

- **确定错误**：上述式(37)与所选参数/区间用途不相容；确定的是印刷表达式不可按字面执行，不是整篇反例被证伪。
- **独立支持的卡内容**：p.273式(40)右侧第二列各行均为p，左侧三支撑反向通道第二列不全相等；行随机混合不能产生该左侧。卡的混合矩阵论证准确，但它以这些通道确为对应失真点的最优解为前提。
- **无法确认**：详细KKT（约束优化最优性条件）及定理3另引[18]的完整证明、正式勘误。本轮未为此复制“未复证=错误”。
- **对主张的影响**：不影响定理2关于两个最优测试通道的马尔可夫兼容形式，也不影响“细增量从仍见源的编码端发送，粗码不能自生细节”。影响的是将p.272给定选点作为已逐式验证的反例证据。
- **修订指令**：卡中“疑点”分为“已确认的印刷区间不一致”与“候选修复/完整最优性未核”；综合引用定理2可保留条件，反例加局部脚注，不传播空区间。

### 3.2 W0091：不是仅有形式张力，字面假设可直接导出矛盾

核对[v2 B.2](https://arxiv.org/html/2009.12789v2)及正式补充印刷p.19：对任意p∈[0,1]设置某点预测概率，并要求对**所有标签、所有两点**严格保留`sign`。同节“每标签非空原像”要求存在一个f，使每个类别都可在某z取概率1。

取至少两个类别a,b以及其原像z_a,z_b。概率归一化给`f[z_a](a)=1`、`f[z_b](a)=0`。对标签a、目标点z_a取p=0，保序要求
`g[z_a](a)>g[z_b](a)`，即`0>g[z_b](a)`，违反概率非负。

- **确定错误**：多类下这组字面假设不存在满足者；“一般神经网络/逻辑回归只改softmax偏置即可满足”的适用性声称不成立。有限偏置的softmax也不能精确到0/1。即便删除端点，多类中同时保留其他各标签的跨z顺序也需要单独证明，不能自动由单个偏置推出。
- **确定的条件不相容**：B.2含0概率（从另一类概率1即得），C.5命题7却对所有f,z,y要求`|log f[z](y)| <= C < infinity`。两套结果不能对同一这样的族直接拼接。命题7可作为另一受限族上的估计陈述，不应因此笼统宣布估计界本身为假。
- **确定的证明推步错误，非命题反例**：C.1.1从Z不是Z′函数推出Z′是Z的非单射函数，一般不成立。令独立比特a,b,c、X=(a,b,c)、Y=b、Z=(a,b)、Z′=(b,c)：两者均为Y充分统计量，却彼此均非函数。这击中该证明中的一步；未推翻最小充分统计量等价命题的可修复版本。
- **独立核准**：命题7界含`β log|Y|`，不随样本数消失；称其现成界自动一致收敛是误读。现卡已正确保留此限制。
- **版本核对**：上述B.2与C.5问题在NeurIPS 2020正式补充材料仍在，不是ar5iv渲染新增；本轮未逐式差分整个正式版，也未取得作者修复。
- **对主张的影响**：阻止把“任意实际softmax分类器上的精确最小充分表示保证所有ERM最优”当已具适用实例的定理。可解码信息的定义、区分表示含有/族内可读/实际消费的概念，以及论文具体实验不随之自动无效。
- **修订指令**：将卡“张力”改为“按字面多类假设不相容”，同时清楚标注这是适用条件问题，不是已反证作者可能意图的修正版；引用理想定理必须带该限定，经验表不要包装为定理验证。

### 3.3 W0059：均方误差反例成立，但不能误杀对数损失定理

核对v5 B.5/B.6和正式补充pp.11–14。编号发生变化：v5定义8/定理17/命题18/式(64)，正式补充为定义7/定理15/命题16/式(55)。**相同投影问题及“0或B²”文字均存在于正式版**，不是只在含编辑残留的HTML里出现。

**独立反例，连上确界一起核。** 取X=M为等概率±1，等价关系为恒等关系，Z经独立概率ε=0.1翻转；任务族限`E[Y²] <= 1`，Y与Z给定X条件独立，符合论文随机编码与二阶矩限制。任何`f(M)=a+bM`满足`E[f²]=a²+b² <= 1`，而`E[M|Z]=0.8Z`，因此

\[
R_{\rm mse}(f(M)\mid Z)=0.36b^2,\qquad
\sup_{a^2+b^2\le1}R_{\rm mse}=0.36.
\]

随机任务Y的超额风险等于其条件均值`E[Y|M]`的上述风险，Jensen不等式保证该均值仍在单位二阶矩球；Y=M达到0.36，故并非只证明一个任务有正风险，而是确实得到整个族的最坏超额风险0.36。另一方面`E[a+bM|Z]=a+0.8bZ=0`要求a=b=0，所以`L²(M) ∩ L²(Z)^⊥`只有零函数。论文从投影残差跳到该交集的等式会给0，后续“不是0就是1”也不成立。残差`M-0.8Z`并非M可测，正是错误所在。

- **确定错误**：上述投影等式、随后二值失真结论；子空间交集还永远含零，原文所谓“交集为空”按字面亦不成立。
- **不应升级**：命题18展示的`sup_f Rmse(f(M)|Z)`等式（v5式59）本身在该例是正确的；本反例不把整个命题每句话全部推翻。更不推翻对数损失下`max(0,H(M)-δ)`的主定理。均方误差的“可直接作为标准单字母失真套率失真定理”论证需要重新建立，不能从有误证明直接验收后续扩展。
- **B.5确定的表述遗漏**：“any loss”定理文字没有明确加信息保持条件，前文却自举常数损失反例，证明下界也依赖该条件。v5式55/正式式46将lower-is-better评分规则的不等号反写；例如真分布p=(1/2,1/2)、q=(3/4,1/4)的对数损失，q的期望损失大于p，而非原式的≤。
- **对主张的影响**：禁止借均方误差二值论断声称“丢任何一点信息就必达最大损失”；预定任务不变性、对数损失率式与未知私有细节不受保护的论点仍可引用。
- **修订指令**：将B.6从“具体疑点”升级为“特定推步及二值结论有独立反例”，附上完整上确界计算；引用时把v5编号与正式版编号分列。不要自行宣布定理19全部错误，也不要给其现有证明颁发正确性背书。

### 3.4 W0311：上界、最优性、贪心闭式与文字次序四件事

独立读v3 PDF pp.25–26附录F，而非使用被截在附录A的网页提取。原文确实写了单块决策树、Bellman递归、多块context-first论证及贪心两类首动作推导，不能把这些材料描述成“尚未取得”。

- **确定的文字错误**：§4.4将“myopic and optimal”后两个数次序倒置：n=1的公式最优/贪心是2.25/2.4375，n=3是3.25/5.6875。现卡已正确识别。
- **独立支持的可行上界**：单块给定树平均`1+2/8+(5/8)(1+3/5)=2.25`；先读context再执行给n≥2时3.25的策略。**这不是全局最优下界**。
- **有根据的证明疑点**：Step 2称任何策略必须先确定活跃块，非活跃块读数0.5故其他查询只会增成本。探测某块非0.5时可以同时获得位置与类别信息，这一句没有排除所有自适应策略，不能单独推出最优性。这里尚无本轮完整策略反例或穷举最优值，不能宣称3.25已被证伪。
- **新增确定的内部不一致，不能偷换为正确闭式**：Step 3 Case B文字说第二阶段`i=2`的非0.5分支（概率2/5）“one additional query”解决余下两类，但其紧邻递归仅写`M(n)=q(2/5)+(3/5)C(n)`，没有`+(2/5)·1`。若照文字应给B(n)增`(5/8)(2/5)=1/4`，初始两类平均增1/8；但这只是指出两种写法不相容，**没有验证阶段假设，不能把最后成本擅改为原式+1/8**。应核原型、后验、候选动作，再判文字或式子谁错。
- **独立确认条件独立疑点的边界**：n=2，先读块1坐标7得0.5后有13个等权context×label状态（块1活跃时5类，块2活跃时8类），`I(Y;C|该观测) ≈ 0.192006 bit > 0`。只证明中途context不再零信息；尚未证明它超过所有其余动作的条件互信息。不能仅凭此反证贪心期望式或最坏值3n。

- **对主张的影响**：仍可用来构造“零初始标签信息的地址动作可有后续价值”的合成机制示例；不能引用精确最优/贪心差距、线性增长率或最坏值作已独立验证定理。实验比较与一般多步价值候选不因这个证明缺口自动失效。

### 3.5 W0169：同版本统计冲突确实存在，等效结论必须撤回

- **疑点而非确定的统计造假/算法错误**：corpus抽取式vs LLM Δ=−.0154，p=.040，95% CI=[−.0335,+.0016]跨零。§6.4只给配对bootstrap、10,000次、固定种子，未定义双侧/单侧、中心化、百分位/其他区间。若p为单侧或区间与检验非互为反演，这种组合可以发生；现有资料不足以断言所有bootstrap实现都不允许。原卡“不能当同一双侧检验自洽证据”的限定合理，批小结简写成“不相容”应恢复该限定。

### 3.6 Merlin（B06 W0210）：固定段长矩不等于部分段经验矩

§3.1式7按`1/|C_i|`平均，式8解释成已见段的均值/方差；PDF p.17文字和p.18算法1/2明确包含当前部分段，每token更新却固定除以m。核实不是读者漏掉“只读闭合段”。

设已见r<m个相似度`s_j=q'·k'_j`，令α=r/m，已见均值为a、方差为v。算法实际得到

\[
\tilde\mu=\alpha a,\qquad
\tilde v=\alpha(v+a^2)-\alpha^2a^2
=\alpha v+\alpha(1-\alpha)a^2.
\]

这是**把m−r个未写槽位当零值**所得的非中心二阶矩与方差，不等于r个已见样本的经验矩。例如m=256、r=1、s=1，已见方差0，算法值255/65536≈.0038909912。

- **确定差异**：部分段不满足“恰好恢复已见相似度的均值和方差”的无条件说法；闭合段r=m时恢复一致。
- **不成立的升级**：不能由此说会算出负方差（上述精确算术非负）、泄漏未来内容、或证实生产实现有错。它也可能是有意的零填充路由，但论文没有把这与经验方差的语义对齐。式10的全softmax分组对不等长可见段应保留`log r`长度项，不能把“所有段等长”用于每个中途前缀。
- **读者误解**：“无偏方差”不是适当主问题：这里是有限已见键的精确经验总体矩，不是从一个外部分布估计无偏样本方差。应改用“归一化/零填充语义”。
- **独立核准**：式9确为两个softmax门控混合；§3.3末已明确不是将二阶展开的两项直接放进单softmax，所以不能将这种不等价本身列作作者证明错误。表9给GDN 16K/m256/dr128为72.1倍单状态，卡的总内存口径正确。
- **影响/指令**：不否定实测均值收益或地址/载荷投影分离；影响路由统计“精确方差”和softmax近似的解释。卡应加入上述式子、去“无偏”措辞；实现未核，保持未核，不强制FULL降级。后续需静态核实际前缀归一化及是否只对旧段作理论解释。
