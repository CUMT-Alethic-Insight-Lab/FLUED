# W0459｜TRAQ: Trustworthy Retrieval Augmented Question Answering via Conformal Prediction

- **状态 FULL**：实读[NAACL 2024正式PDF](https://aclanthology.org/2024.naacl-long.210.pdf)印刷3799–3821页、§3–4、附录A/B/E的证明及附录C/D；图曲线未逐点数字化。Shuo Li、Sangdon Park、Insup Lee、Osbert Bastani；[arXiv 2307.04642](https://arxiv.org/abs/2307.04642) v2（2024-04-05），正式版差分未逐项核。证明阅读不等于独立认证。
- **机制与权限**：§3.1–3.3，校准需要标注问题对应的最相关段及正确答案；给定问题，对检索评分按阈值选段，再对每段采样M=30答案，以ROUGE>0.7或NLI聚成语义簇，最后取答案集合并集。误差预算α=αRet+αLLM，以另一个优化集做贝叶斯优化，独立校准集定阈值。答案集合是内容，段排名/阈值是地址；query推理可见、金标只参与校准/评测；非层深或多粒度源设计，持久源更新未讨论。
- **证明对象**：§3.1假定校准与测试同分布、相关段在top-K内、给定该段正确答复在M次样本内。§3.2引理2.1/2.2和定理3、附录B：以漏相关段事件A和漏正确答案事件B作并集界，总漏率≤αRet+αLLM；这是对问题/校准样本分布的边际答案**集合**覆盖，不是每题单答案正确、不保证多跳全部必要证据。附录B.1以两项δ/2获得校准集层面的PAC置信保证，但仍不是每个问题条件覆盖。任何前筛或预算截断若不再满足预候选包含正确项的假设，该界不能原样继承。
- **实验**：§4每个数据集先筛出同时满足两正确性假设的1000题，再按300/300/400分校准/优化/测试；top-20×每段30次生成，正确率以答案ROUGE-1>0.3代理；附录D.2 BioASQ原始top-20命中率测试75.7%，说明筛选范围重要。表1 BioASQ 90%设定，TRAQ平均语义簇8.9、无优化Bonf 10.3；各表及不同覆盖率非一致改善，作者汇报80/90%平均缩小16.2%。
- **疑点精确定位**：附录E印刷3820页定理6证明的最终不等号印成`≤(1−α)…=1−α`，与目标下界方向不同；其引理5.1在PDF文本中也未显式给概率下界。只指出该可见推导需澄清，不把它扩成正文定理3失败；未独立重建附录E。合并语义簇依赖自动近似，误合并与去重具体实现未核。
- **成本/FLUED**：生成调用随候选段数及采样数增长，答案集合可能过大；硬截断没有原保证。与W0471的近邻平均FNR不同，此文拟保证答案集合覆盖且要求候选/样本可包含正确项。可引用为将索引失误与生成失误分配风险的条件性框架，不能把标签匹配或集合存在视为自然内容消费。
