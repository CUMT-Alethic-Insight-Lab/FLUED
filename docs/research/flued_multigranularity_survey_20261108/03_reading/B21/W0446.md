# W0446｜Learning to Search in Long Documents Using Document Structure

- **状态 FULL**：实读[COLING正式PDF](https://aclanthology.org/C18-1014.pdf)印刷161–176页：方法、表5–8、补充A.1–A.3；图像导航轨迹未逐像素转录。Mor Geva、Jonathan Berant，2018；[arXiv 1806.03529](https://arxiv.org/abs/1806.03529) v1/v2，未逐版差分。阅读不等于复现实验或代码核验。
- **来源/学习**：QA三元组提供答案文本而非路径；§4.1印刷164–165页以停止处与最近答案字符串节点的线性序号距离及命中设计奖励，导航−0.02、调用阅读器−0.06；因此不是最终答案正确性直接监督。§4.2与算法1：DQN离策略训练中混合从根轨迹、均匀节点、从含答案段逆向随机1–3步采样；训练时使用金答案，部署不使用，部署从根出发，最长100步而训练30步（表8）。
- **对象与可见性**：固定文档结构树，标题/节/段/句为地址，观察包含当前节点及祖先标签前k个词元（表8单节点20、总120）；输入问题可见，不需要未来问题；预测答案及置信特征可见，状态不保存完整访问史。Down、左右和上移到父的相邻兄弟使其能换分支；ANSWER运行阅读器后可继续，STOP返回当前答案结束（§4.1）。并非学习边界、压缩状态或跨网络深度路由。
- **源与成本**：文档与HTML结构预构建并保留，段/句可再次访问；删除、更新和长期生命周期未报告。读到的6.2%词元及平均约160阅读器词元不是树构建、全部索引、训练、调用或完整I/O成本（§5.1、表7）。
- **对照/结果**：同一固定RaSoR阅读器，表5：DocQN定位30.4%、文内TF-IDF 32.4%、融合35.0%；跨文档聚合43.6%、43.5%、48.0%，后者定位指标需oracle选择最好文档。表6测试EM/F1：DocQN 21.0/25.5、TF-IDF 18.2/23.5、答案融合25.4/30.5，ReadTop首800词元28.1/32.4更强。融合同时运行全篇词法入口，未同总读量匹配；互补是观察而非免费增益。
