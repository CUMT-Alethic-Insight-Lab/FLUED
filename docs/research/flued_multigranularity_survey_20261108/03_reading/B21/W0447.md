# W0447｜Coarse-to-Fine Question Answering for Long Documents

- **状态 PARTIAL（补充材料核查后仍PARTIAL）**：实读[ACL正式PDF](https://aclanthology.org/P17-1020.pdf)印刷209–220页及方法、实验、图4–5。图4在印刷214页确实给出批大小1/8/32/128的柱状标注`7.5/30.8/54.0/92.0 (ex/sec)`以及REINFORCE(K=1/2)、SOFTATTEND相对BASE的曲线；正文214页仍写“Exact numbers are reported in the supplementary material”。合法核查[arXiv v1源码归档](https://arxiv.org/src/1611.01839v1)和[v2源码归档](https://arxiv.org/src/1611.01839v2)的压缩包成员：只有主文`.tex`、图、样式和可视化文件，没有supplementary/补充数据文件或独立速度表；ACL元数据页/PDF也未提供独立补充入口。本轮未找到可核的“速度明细补充”，故不把图中四个标注冒充完整明细，状态不升FULL。Eunsol Choi、Daniel Hewlett、Jakob Uszkoreit、Illia Polosukhin、Alexandre Lacoste、Jonathan Berant，2017；[arXiv 1611.01839](https://arxiv.org/abs/1611.01839) v1/v2，不假设结果跨版相同。未核代码/复现。
- **学习**：§4–5用问题与候选句词袋/卷积评分，训练硬选择时按概率采样，奖励为选句条件下金答案对数概率；REINFORCE样本梯度只直接评价选中句，softmax归一化使其他句获得间接竞争梯度，不等于对全部未选句逐句反事实打分。课程先用答案字符串首次匹配句远程监督，找不到则默认第一句；软注意为逐位置向量混合且端到端反传。问题/答案训练可见，推理只见问题和候选。
- **粒度/源**：七词元块评分可边缘化为句概率；硬选K句拼接再由GRU按词元生成答案，K=1和K=2均试，非仅允许一证据句；软混合不等于可逐字还原源。输入前35句、每句最多35词元，截断之外无法被选；这是句/词元访问层次而非网络深度跳层。原文在任务期间可重读，持久化/更新/删除未报。
- **分开定位与回答**：正式表3印刷214页，WikiReading Long Base 40.1、K=1 40.1、K=2 42.2、字符串oracle 43.9；WikiSuggest Base 46.7、K=2 45.8；WikiReading Base 75.6、K=2 **73.9**。arXiv HTML表显示74.5，不混用。表4开发集在oracle能找到字符串的条件下，Long的ChunkBoW REINFORCE 74.4%，并不是全样本必要证据召回；答题能力另由表3报告。印刷215页表5对50个错误：Long无证据29、生成错误13、选择错误8；WikiSuggest噪声24、生成错误15、无证据8、选择错误3。
- **成本/失败**：Base只顺序读前300词元，而选择器可扫描截断后的35×35，昂贵RNN处理35或70；额外给Base相同输入长度作者称效果差，并非同模型全源等预算。图4的3.5–6.7倍是Xeon、batch=1**文档编码**速度，不是完整训练、筛选索引或端到端质量/延迟。跨句互补在K过小时可能遗漏，K=2提高不证明任意多跳完备；字符串oracle并非真证据oracle，数据本身噪声明显。
