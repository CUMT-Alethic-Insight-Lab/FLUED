# W0473｜Towards Robustness: A Critique of Current Vector Database Assessments

- **状态：FULL**。Zikai Wang、Qianxi Zhang、Baotong Lu、Qi Chen、Cheng Tan，arXiv:2507.00379v2，2026-04-02；[v2原文HTML](https://arxiv.org/html/2507.00379v2)、[v2 PDF](https://arxiv.org/pdf/2507.00379v2)。补读PDF第6–12页§5–7、全部图注/表格，后为参考文献，无附录；图形曲线未逐点数字化。无作者自有关键外置证明被指定；未运行代码。
- **应用实验细节**：PDF第9–10页§5.3/Figure 10–12，MSMARCO 8.8M段、约6.9K问、Gemini-2.0-Flash和LLM-Embedder，K=10；HotpotQA约4.8K问、2100万Wikipedia段、E5、K=5，比较Search-R1/Qwen2.5-7B与Qwen3-30B-A3B；GPT-4o-mini判分并用Gemini复核排名。ScaNN平均召回0.90与DiskANN 0.96均得74.9%问答准确，作者报吞吐25054/14606 QPS；比较不是控制所有查询的因果干预。
- **成本与反例**：PDF第7–8页固定均值Recall@10约0.9时，图索引在高δ（如0.9）可优于分区索引，与低δ方向相反；§5.4 HNSW M=128、efSearch=4096时Robustness-0.3为0.9988，但只有451 QPS。HotpotQA作者报告超60%问题初检失败后重试，约三分之二重试仍失败；大模型内部知识可遮盖检索失败。精确近邻、金标文档、最终答案和因果消费须分开。
- **疑点交独立复核**：§5.1.2先称K从10增至100时低δ鲁棒性增加，又称所有索引更大K下鲁棒性通常更低；不同阈值/配置可能解释，文字尚未明确。§2.4给DiskANN Recall<0.2比例5.72%，§1零召回4.8%，事件不同，不构成矛盾。
- **定义与对象**：§2–3，向量精确K近邻为参照，逐题Recall@K的达标比例`(1/m) Σ 1[R_i ≥ δ]`，包括等号；是分布统计而非逐题保证，也不是语义证据覆盖。δ=0.1且K=10时对应至少1个精确向量邻居，不自动等于至少1份回答证据。
- **例证与对照**：§1 Figure 1，同MSMARCO平均Recall@10=0.9，DiskANN有4.8%零召回，ScaNN较少；§4给出的示例中ScaNN与DiskANN准确率0.758/0.740、Robustness-0.2@10为0.997/0.974。作者对平均和尾部的差异展示不是单凭相关性就能断定答案提升的因果机制。
- **训练、粒度与成本**：§5设四数据集、六类索引，MSMARCO使用LLM-Embedder向量；query到达后访问图节点或分区并可能重排。索引在内存，双CPU、1.5TB RAM、16线程；未见编码、建索引与源更新的完整成本及源文档生命周期账；向量近邻不是完整证据集。取回向量ID/段落不等于内容被答案消费。
- **决策影响**：评价增加逐题召回分布、最低覆盖比例、完全证据集与最终答案，分开固定正确证据时的消费者能力；两个RAG任务的具体模型与对照见上。平均相同而尾部不同即可改变索引选型，但不得提前断言所有阈值和任务排名反转。
