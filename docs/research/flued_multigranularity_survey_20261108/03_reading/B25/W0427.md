# W0427｜Language-Integrated Query for Temporal Data (Extended version)

- **状态：FULL**。Simon Fowler、Vashti Galpin、James Cheney，arXiv:2210.12077v1，2022-10-21，[原文HTML](https://arxiv.org/html/2210.12077v1)、[PDF](https://arxiv.org/pdf/2210.12077v1)。本轮按页读PDF pp.1–13及附录A–E pp.16–31，含作者自有证明D；未运行代码或独立证明。全文未指定另需作者外置证明。
- **翻译/区间**：§4.1–4.3和附录B，更新与删除分五种区间关系：全覆盖、两端部分交叠、严格内嵌、无交集；内嵌时更新分三段，删除留两段。§5/Figure 9连接先取各记录起点最大值与终点最小值，交集非空才输出，结果限平坦记录；§4.3要求良构区间，执行失败则整事务中止，形式化只讨论良构的成功执行。
- **证明与能力边界**：§3.3定理3.1对良构库及`max(Δ)≤当前时间`的事务时间翻译；§4.3定理4.1对良构库中成功执行的有效时间翻译；证明在附录D，不等于本轮独立认证。§8明确把同时结合有效时间与事务时间的双时间数据库列为未来工作；三个读取合同是我们的目标设计，非该文已实现。§7不宣称效率实测，案例§6为苏格兰COVID数据的修订历史。
- **疑点交独立复核**：§4正文示例写更新区间2023–2025，但说明和结果表使用2023–2028（PDF pp.7–8）；Figure 7更新case 2/4的条件与附录D相应不相交边界的处理似有张力，可能涉及缺少非空交集条件或排版问题，需原页逐式/作者澄清，不能武断判定实现或完整定理错误。
- **原文事实**：§3记事务时间为数据库中记录何时存在，更新非破坏性；版本记录为闭开区间`[start,end)`且`start < end`。§4语法列有效时间的sequenced/nonsequenced更新和删除；sequenced操作作用于给定时间区间。具体区间切分与连接见上；作者未处理一般区间合并、去重与聚合（§8）。
- **对象/学习/权限**：这是时间关系模型与查询重写，不是学得摘要或LLM记忆；记录/字段/区间是存储读取粒度。请求查询可见数据库版本，但未来事件和答案可见性须由具体应用合同另定。事务时间与事实有效时间不同；不能以时间戳顺序推出因果。
- **成本/对照**：目前读到的范围不支持给出性能、更新维护和外存预算的定量结果；不拿案例运行替代全成本。保留过往版本也不等于物理删除或派生文本同步。
- **决策影响**：拟为草案分开“当时有效”“当时已知”“以现在知识回看过去”的三个合同；§8明确双时间组合是未来工作，不能将这三个合同冒充作者已有实现。进一步需设计同源版本及派生摘要失效协议，不能把关系模型正确性外推为神经摘要正确性。
