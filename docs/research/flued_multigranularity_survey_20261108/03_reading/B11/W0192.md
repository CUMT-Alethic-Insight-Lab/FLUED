# W0192｜NoLiMa: Long-Context Evaluation Beyond Literal Matching

- Ali Modarressi、Hanieh Deilamsalehy、Franck Dernoncourt、Trung Bui、Ryan Rossi、Seunghyun Yoon、Hinrich Schütze，2025；[arXiv:2502.05167v3 PDF](https://arxiv.org/pdf/2502.05167v3)，2025-07-09。**FULL**：读§1–5、附录A–G与表1–12、图注；曲线未逐点数字化。作者代码、数据许可证及实验未独立核验。
- **考场构造**：§3/4.1、附录A，58问题—针组合，问题关键词Wq与针中Wn尽可能不字面重叠，借常识/已有知识桥接（如德累斯顿与歌剧院），另设一跳/二跳、事实正倒序。5个干草堆×26位置×58=每长度7540次；10本开放许可书截取拼接。Contriever近词与Llama3.3过滤潜在干扰和答案、人工复核（§3.1）。这不是学习压缩或地址系统；输入为长上下文原文，答案位置由模型读者隐式选择，query出现在上下文后，答案不提供。
- **核心结果**：表3 GPT-4o短窗基分99.3、32K 69.7；11/13模型32K低于各自短窗基分一半。基分是每个题目在250/500/1K上取最好结果再平均，非单一短窗；有效长度阈值为基分85%。表6 Llama3.3 32K一跳56.2、两跳25.9；加入含正确姓名的选项93.1/87.2，改变的是选项可见权限而不只是检索算法。图5加入词面诱饵显著恶化；附录D给诱饵位置限制。
- **归因条件**：短窗控制有助排除部分桥接知识不足，但不是每个长窗实例的独立短窗/oracle证据匹配，也不能证明长窗下降唯一由路由引起；位置、干扰、桥接难度和格式并非完全正交。§4.4.2作者推测注意力定位机制，明确更深机制待查；模型可能找到了针但无法使用。表4 CoT在32K两跳25.9→34.3，仍显著低于短窗；附录E 128K把位置数由26降为11，GPT-4.1 64.7。姓名字符串匹配不能证明内容特异消费。
- **成本与差异**：筛选阶段的LLM调用、人工审核及长上下文推理成本应算入；论文给设计而非完整美元/时间/训练账，书籍开放许可不自动确认所有派生数据使用授权。与草案不同，本篇是评测而不是层级回访架构；可借配对字面/隐含、短窗、同针oracle与内容替换对照定位失败，扩展至多针及中文需另核。
