# W0181｜Corrective Retrieval Augmented Generation

- Shi-Qi Yan、Jia-Chen Gu、Yun Zhu、Zhen-Hua Ling，2024；[arXiv:2401.15884v3 PDF](https://arxiv.org/pdf/2401.15884v3)，2024-10-07。**FULL**：读正文§1–6、附录A/B、表1–11；未执行作者代码。
- **训练与访问**：§4.2、附录B.3，以T5-large 0.77B从PopQA已有主题wiki标题构造近似相关正例、检索结果随机负例，余下非测试样本微调；迁移到其他数据。每个query分别评分约10篇已检索文档；至少一篇超过高阈值走Correct；全低于低阈值走Incorrect；其余Ambiguous。本文档级相关并非所有必要事实充分：一篇高相关就可能误接受不完整多跳证据，未知遗漏无金标时不可直接观测。
- **粒度与回访**：§4.4–4.5将已检文档拆成数句片段，同评价器筛选并按序重组；Incorrect丢原候选并由ChatGPT改写查询、Google Search找网页，Ambiguous同时保留两路；外源网页按段筛选。构造是外部文本检索/扩域，不是网络内层级KV摘要或对同一库增加预算；实际来源更新、撤销和持久保存未报告。评价器和生成部署只见问题与已取文本；训练有主题标题监督，不需推理时答案。
- **对照与失败**：表1 SelfRAG-LLaMA2-7b PopQA RAG 52.8、CRAG 59.8；Self-RAG 54.9、Self-CRAG 61.8，但ARC Self-RAG 67.3、Self-CRAG 67.2，不能声称全面改善。表4评价器准确率84.3%基于PopQA特定评测，不是漏召回误接受率。表5始终附web的RAG 53.8 vs CRAG 59.8，但同时改变分流与片段处理，并非同源同预算隔离扩域的干净因果对照。表2移除Ambiguous时59.8→59.0；附录B.5 LLaMA2-hf-7b在真假题指令跟随差。
- **成本与可用主张**：附录B.3各数据阈值经验设定、网页最多5；表6 0.363/0.512秒（RAG/CRAG）只粗估生成阶段，明确不含检索、网页、改写、预处理、训练及尾延迟。可用其作为相关性触发扩域的先例，不能宣称能无答案可靠检测缺失或给出完整经济性；需追查已相关但不充分的误接受率及与同索引扩k的预算匹配。
