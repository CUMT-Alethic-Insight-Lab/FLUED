## 1. 逐题回答

### 1.1 三轴：键特征、值目标、充分统计、查询函数

论文将因果关联记为 \((k_i,v_i)\)，在位置 t 用前缀样本拟合一个记忆函数，并用当前 query 读取：

\[
 m_t\approx\arg\min_{m\in\mathcal M}\frac12\sum_{i=1}^t\gamma_i^{(t)}\|v_i-m(k_i)\|_2^2,\qquad y_t=m_t(q_t).
\]

这是作者的“test-time regression / regression-memory correspondence”（§3，公式(8)–(9)）。其中：

| 轴 | 论文中的选择 | 键/值与充分统计 | 查询函数 |
|---|---|---|---|
| 回归权重 \(\gamma_i^{(t)}\) | 等权、时间衰减、或查询相似度加权 | 等权线性回归需 \(K_t^\top K_t\) 与 \(V_t\)；加权时需 \(K_t^\top\Gamma_tK_t\)、\(V_t^\top\Gamma_tK_t\)；在线 SGD 不显式保留全统计 | 线性：\(M_tq_t\)；加权线性同式但以加权统计解读；局部回归把 query 相似度放进权重 |
| 函数类 \(\mathcal M\) | 线性 \(m(k)=Mk\)；特征映射线性；局部常数/局部多项式 | 线性最小二乘的充分统计是值-键交叉项和键 Gram；特征映射后换成 \(\Phi_t^\top\Phi_t\) 与 \(V_t^\top\Phi_t\)；局部 p=0 需 query 到各键的相似度权重，p=1 还需加权局部设计矩阵 | 线性/特征线性：\(M_tq\) 或 \(M_t\phi(q)\)；局部常数：归一化核加权值（公式(50)）；p=1：局部线性回归截距 \(M^{[0]}\)（公式(52)–(54)） |
| 优化器 | 解析解/一次 Newton；全批梯度下降；单样本 SGD；带自适应步长、L2/weight decay | 解析解显式需要 Gram 逆；全批 GD 的一次零初始化步只使用 \(V_t^\top K_t\)；单样本 SGD 只保留当前矩阵状态；Longhorn 是带保守自适应步长的在线二次目标解 | 查询当前状态：\(M_tq_t\)。DeltaNet 是从上一步状态初始化、每个样本一步 SGD；线性注意力是零初始化一次全批 GD |

论文的关键对照在 §4 Vignette 1、公式(10)–(13)、(17)–(29)：理想线性最小二乘为
\[
M_t=V_t^\top K_t(K_t^\top K_t)^{-1},
\]
而线性注意力以 \(K_t^\top K_t\approx I\) 代替 Gram 逆，得到 \(M_t\approx V_t^\top K_t\)。因此它忽略了键维度/键之间的协方差，而非“只丢掉少量 token”。在线 SGD 的公式(26)–(29)说明 DeltaNet 是沿当前样本的残差更新，不是解析全前缀回归。

### 1.2 忽略 token 相关性的近似在哪里

最明确的位置是 §4 “Vignette 1: Linear attention is (suboptimal) linear least squares regression”，公式(11)–(12)：把 \(K_t^\top K_t\) 近似为单位阵；论文明确说当键零均值时，该矩阵与经验协方差成比例，所以这是忽略**键维度之间相关性**的近似。它不等于忽略所有 token 相关性，也不是对任意相关键的普遍不可能性。

公式(13)进一步给出条件数/最小特征值的输出范数上界：
\[
\|y_t\|_2\leq \frac{\|q_t\|_2\sum_i\|v_i\|_2\|k_i\|_2}{\lambda_{\min}(K_t^\top K_t)}.
\]
忽略 Gram 后分母消失，输出可能随序列长度增大，作者将输出归一化解释为近似恢复这种自归一化性质。这个推导的条件是讨论通常的满列秩、\(t\ge D_k\) 情形；欠定情形用最小范数伪逆，论文没有把同一结论无条件外推到所有序列。

### 1.3 局部与全局查询何时等价

本文没有提出“局部查询=全局查询”的一般定理；它给出的是可辨识条件：

- 等权全局线性回归需要前缀全部键值对的 Gram/交叉统计。若目标映射在键空间中只由一个局部子集决定、局部外样本对 query 的权重为零/可忽略，或其贡献被结构性正交化，则局部与全局预测才可能相同。
- 局部常数回归（公式(48)–(51)）的权重本来就是 query 到键的距离核；若远端键的权重为零（严格紧支撑）或数值上可忽略，才退化为局部查询。高斯/指数核在数学上仍对所有样本有非零权重，不能把它写成严格局部。
- 论文的 p=1 局部线性回归明确还要估计局部协方差，故“只取 top-k 键”一般不等价于完整加权回归。
- 因果可见性是前缀：§3 规定位置 t 的回归只使用 \(\{(k_i,v_i)\}_{i\le t}\)，query 在同一前向步读取；非因果任务可扩展为同时使用后缀，但那不是本文实验设置。

§5 的非平稳实验提供了一个相反例：在前 T/4 与后 3T/4 的动力学变化中，无遗忘的全局等权 RLS 不能快速适应，query-aware softmax/局部线性回归因相似键及局部适配而恢复得快。这个实验支持“权重/局部性改变有效统计”，但不证明任意局部窗口都优于全局。

### 1.4 路由统计能否独立于载荷

按这篇论文的抽象，权重 \(\gamma_i^{(t)}\) 可以只由时间或 query-key 相似度确定，因而**在形式上**可独立于值载荷；但最终记忆参数仍由加权的键-值统计共同决定。论文没有把“独立路由统计+载荷损坏”作为单独架构消融，也没有证明独立路由普遍安全。

可区分的层次是：

1. **地址/路由**：\(\gamma_i\)、键 Gram 或核相似度决定哪些关联被优先拟合。
2. **载荷拟合**：\(V^\top K\) 或残差更新决定值如何绑定到地址。
3. **读取**：\(m_t(q)\) 把选定/压缩的载荷变成输出。

若键统计被准确保存但值交叉统计丢失，路由仍可能选对关联而输出错误；反之，载荷统计保留但 Gram 相关性未校正，输出也会受干扰。作者的公式支持这种分解，但没有在自然语言任务中做“路由正确、载荷置乱”的实验。因此不能从该框架推出地址和载荷天然可解耦。

## 2. 机制与信息流

### 2.1 写入、保存、读取粒度

输入 token \(x_t\) 投影为 key/query/value（§2）。在因果设置中，每一步把此前缀的键值对纳入一个当前 test-time regressor；参数化回归器可用矩阵状态递归保存，非参数软注意力则保留全部前缀键值。最小粒度是 token-level key/value pair；没有文本块、层级来源指针或原始 token 回访机制。

- 线性注意力：以 rank-1 外积 \(v_tk_t^\top\) 写入矩阵状态（公式(2)）。
- Gated/SSM：给旧状态时间衰减，等价于时间加权回归（公式(14)–(16)）。
- DeltaNet：用当前键读出旧值，再以残差更新该键对应方向（公式(5)–(6)、(26)–(29)）。
- Softmax：保留全部 prefix KV，作为非参数核回归；论文明确其内存随长度增长。

### 2.2 策略学习来源/方式

论文不是训练一个独立路由策略。三轴是**架构设计选择**：研究者规定权重、函数类和优化算法；随后序列层的慢参数仍可通过常规训练学习，但回归状态是在每次前向中由上下文即时构建。权重可以是时间衰减或 query 相似度；论文未使用 RL、Bellman 目标、未来效用标签或显式内容价值学习。

§6 的 key/value 构造是一个重要限定：短卷积可把 \(k_t=x_{t-1}\)、\(q_t=v_t=x_t\)，从而在 MQAR 中直接记忆 bigram；这不是学习出来源指针，而是预先选择适合 next-token recall 的输入构造。公式(57)–(58)在正交 embedding 与 cue-response 一一映射时说明线性层可解 MQAR。

### 2.3 Query 可见性与来源回访

可见性是严格因果前缀。参数化状态只保留充分统计/迭代状态，不保留逐 token 来源，故旧载荷不能回访。软注意力可直接访问所有 prefix KV，但代价是线性 KV cache 和二次交互。论文没有摘要树、原始片段回访、地址到来源块的显式映射，也没有保存/更新/淘汰后的可恢复机制。

## 3. 实验、对照、成本与限制

### 3.1 实验与作者声称

- **§5 在线回归**：非平稳切换 AR 过程，\(D_k=64,T=256\)，键协方差非对角；值是下一键归一化，query 是下一键。对比线性注意力、无权 RLS、softmax、p=1 局部线性回归和朴素前一步预测。作者报告线性注意力最差；无权 RLS不能适应后段变化；非参数回归能利用 query-key 相似性适配；p=1 优于 p=0。
- **§6 MQAR**：构造 bigram key/value，正交 embedding 时一层回归器即可按 cue 检索；实验中 \(d_{model}=P=64\) 的线性注意力可独立于序列长度解决，\(P=128>d_{model}=64\) 时线性注意力受限，而 RLS因考虑键协方差改善。这是合成地址/值任务，不是自然语言来源回访证明。
- **理论/工程**：公式(11)–(13)和§4说明准确 Gram 逆要付出成本；p=1 直接实现不适合实际长序列。

### 3.2 成本进入方式

- 解析线性回归每步需 \(D_k\times D_k\) 逆；虽然可用 Woodbury 递归，硬件友好性和常数仍显著高于简单外积状态（§4，公式(11)及“Efficient computation”）。
- 全批并行解析解需对 T 个线性系统求解；p=1 局部线性回归还需 \(O(T^2D_k)\) 时间、\(O(T^2D_k)\) 前缀输入材料空间、\(O(TD_k^2)\) 统计材料空间和 \(O(TD_k^3)\) 线性系统求解时间（§4 Vignette 4，公式(52)后）。作者明确称其当前形式对实际序列任务不实用。
- 参数化状态的矩阵存储是固定大小；遗忘权重不改变矩阵大小，但丢失较旧关联。非参数 softmax 的 KV 存储随 T 增长。

### 3.3 未包含/未测量

- 没有端到端 GPU 延迟、显存、搬运、缓存更新、并发吞吐的实测表。
- 没有地址路由正确而值载荷置乱的控制，没有原始来源回访/下钻/恢复对照，没有学习型路由策略的未来效用实验。
- §5 是小规模合成动力系统；§6 是 MQAR 构造，不可升级为 FLUED 字节任务或一般自然文本结论。

### 3.4 失败条件

- 键 Gram 非单位且不被校正时，线性注意力会发生相关键干扰；序列长、非正交或高相关键会放大问题。
- 固定状态的遗忘机制适合非平稳数据但会牺牲旧关联；无权 RLS在切换任务中不能快速适配。
- MQAR 的“单短卷积足够”依赖键值构造、embedding 维度/正交性和一一 cue-response；若 key/value 不能形成所需 bigram，结论不成立。
- p=1 局部回归理论更强但其前缀统计和求解成本使其难以部署。

## 4. 与FLUED草案的最近部分和关键差异

**最近部分**：把“地址/载荷”拆成 key/value，强调压缩状态其实是对 prefix 关联的在线回归；说明路由权重、回归器函数类、优化器分别改变保存什么、如何更新和如何读取；以及指出键相关性是线性外积压缩的核心误差源。这可作为 FLUED 讨论“地址统计不等于载荷充分性”的理论近邻。

**关键差异**：本文是 token-level KV associative memory 的数学统一，不是可变粒度文本/字节边界学习；没有块状态间的来源映射、原始 token 保留或 query 下钻；没有以未来任务效用学习选择性写入；也不讨论 FLUED 的编码—解码重构、边界概率或 byte interface。其“局部”主要是 query 相似度核/局部多项式，不是文本块层级。

## 5. FLUED可引用的准确主张

### 可以引用

1. 在 test-time regression 视角下，线性注意力、门控/SSM、DeltaNet、softmax attention 可按“回归权重—函数类—优化算法”统一描述（§3–§4，公式(8)–(9)、(14)–(16)、(26)–(29)、(48)–(50)）。
2. 线性注意力的关键近似是以单位阵替代键 Gram/协方差矩阵，因此会忽略键维度相关性；准确线性最小二乘含 Gram 逆（§4，公式(11)–(13)）。
3. 参数化递归状态保存的是压缩统计/迭代状态，不能像非参数 softmax 那样逐 token 回访；softmax 的灵活性伴随随长度增长的 KV 成本（§2、§4）。
4. MQAR 中合适的短卷积可构造 bigram-like key/value，实验显示其难度受 memory capacity 而不只是序列长度限制（§6，公式(56)–(58)、Figure 3）。

### 不能推出

1. 不能推出 query 局部访问与全局回归一般等价；论文只给出核权重/条件性解释，未给普遍等价定理。
2. 不能推出独立路由统计必然保持载荷正确；作者没有做载荷置乱、块找对但值损坏的控制。
3. 不能把“test-time regression”当作 FLUED 的训练策略或自然来源追踪机制；它不含原始来源回访、地址粒度下钻、字节级证据。
4. 不能把 p=1 高阶软注意力当可部署方案；作者明确报告其当前时间/空间/求解成本不实用。
