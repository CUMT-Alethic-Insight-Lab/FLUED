# W0385｜HMT: Hierarchical Memory Transformer for Efficient Long Context Language Processing

**FULL（NAACL正文及关键附录的阅读范围；不是独立验证）**。Zifan He、Yingqi Cao、Zongyue Qin、Neha Prakriya、Yizhou Sun、Jason Cong，NAACL 2025，[正式版 pp.8068–8089](https://aclanthology.org/2025.naacl-long.410.pdf)；[arXiv v3](https://arxiv.org/html/2405.06067v3) 2025-02-06。逐段对照并未完成：本文结果定位以NAACL为准；[v1](https://arxiv.org/html/2405.06067v1)真实存在，五作者且题名不含Efficient，不是错误身份。v3与NAACL均为六作者、同题名和核心机制；尚未逐表逐字差分，图号不可混用。

## 机制与信息权限
- §3.1–3.3、式(1)–(5)：每段L个token，取当前段前j个嵌入经可学习提示及骨干总结成查询，查询经训练的Q/K投影对最近N个**历史记忆嵌入**做softmax加权，输出单向量Pn；前段末k个输入token嵌入和Pn与当前段一起处理，末尾产生一枚累积记忆。不是查询原段索引，也不是保留多层摘要树；输入粒度是token/段，寻址是记忆向量，返回是加权混合向量，而非可独立下钻的源位置。
- 查询由当前段前j项构成，并在整段处理前用于增强整段：若对前j内部位置报告严格逐token因果概率，要核掩码/评估实现，不能假定无未来可见性。对稍后用户问题能否进入搜索取决于问题所在段；编码早期文档时并不见未来问题。论文不证明注意力权重等于答案因果使用。
- §3.3、附录D/E：默认L=1024、j=512、k=32，N=300或400；旧记忆滑出搜索窗口，累积向量可能含旧信息但非原文可恢复保证。前段k个是token输入嵌入，不是全历史原token；文中无面向旧源重放的存档或版本接口。位置/精度及所有层的持久存储介质未完整分账；附录K描述**训练**中CPU/GPU中间数据offload与ZeRO-2，不能冒充推理缓存层级统计。

## 学习、对照与失败
- 附录D/F/K：RedPajamaV2及下游微调，两阶段BPTT：先无检索展开2段，再引入检索最多15段；部分大模型rank-8 LoRA，其余全参；附录D称各700步，表7分阶段配置另有200/500步，不能忽略口径。图12：OPT 2.7B两阶段902秒、单阶段1680秒，4×MI210，具体实验非全生命周期费用。
- §5表4：30k Wikitext，Yi-6B滑窗5.2K PPL 6.89、44.8 GB，HMT+Yi 512段PPL 6.75、33.9 GB；两者历史访问和计算路径不同。表5 CCM-concat 7.41与HMT+Llama 2 7B 7.40；LongMem对比附录B使用不同骨干且原文LongMem数字来自原论文，不能解读为同精度同权限同预算。
- 附录E图8–11：移除检索有损；更大N边际收益递减；短前缀提查询与全段效果相近是所测数据上的结果。附录H表8：感官记忆8/16/32/64/128项PPL 4.54/4.25/4.19/4.31/4.57，更多并非恒优。附录G的交替段/填充实验提供检索模式证据，非因果消费证明。
- 附录J式(7)–(9)给RMT链式乘积、HMT多分支的作者推导；有较短路径并不单独保证非零下界，也未给普遍有界雅可比或消去支路相消的证明。定位为作者启发式解释及表9有限展开深度经验，非独立证明或论文整体错误判定。

## 成本与FLUED可引用主张
参数与KV最低显存见§5表3，作者明言实际显存可更大；全源档案、重编码、长期存储、网络、冷热命中、每问摊销与更新撤销未报。受限缓存是活跃状态上界，并非源库总量上界。可引用的是「在段级递归上以当前段构造查询、软混合近期累积记忆，且在给定训练/任务上优于若干对照」；不能引用为源可逆、多分辨率原文访问或严格因果保证。最近邻RMT仅传递压缩状态；HMT额外搜索近期状态，仍不是分离的内容/地址层。
