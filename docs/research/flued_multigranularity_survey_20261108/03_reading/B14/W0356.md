# W0356｜Byte Language Models: Scaling, Emergent Abstractions, and Information Allocation

**FULL**｜Jie Wang、Shiwei Luo、Qi Zhang、Yuanbin Wu，2026-10-05，[arXiv 2610.05978v1 HTML](https://arxiv.org/html/2610.05978v1)、[PDF](https://arxiv.org/pdf/2610.05978v1)。读正文§1–6，HTML截于附录D，续用PDF定向读A–C、D结果、E.1–E.2、F.1–F.3、G；未逐项数字化所有大表/图。代码和实验未核，F.1证明仅阅读未独立复证。

- **学习/对象**：字节输入256词表，前30%训练步4个相邻byte嵌入均值、预测下一4-byte无序包，余70%逐字节；这是按连续byte固定四分组而非外部分词，但也引入固定局部组先验。散列嵌入以5–8元byte串作为额外输入，卷积宽16对词元模型4；非只改tokenizer（§2.1、附录A）。训练/预测均看因果前缀。
- **预算与反例**：§2.2图1同参数最优曲线Byte较好；**同训练FLOPs最优曲线Subword始终更好**。Byte/Subword训练序列8192/2048位置、批1,048,576/262,144；训练算式不含查表、散列、loss、优化器（附录B/C）。4次共享深度的Subword缩小BPB差且QA-RC高于常规Byte（§2.4）。无完整源生命周期、存储及端到端延迟。
- **拷贝与25%**：附录E.1在10条、每词5个ASCII字节的6词英文短语、真前缀拷贝上做源区域内归一化注意力，可观察局部聚集，不等于终端预测因果消费。E.2用额外200M同族模型的真实token负对数概率设前缀局部跨度、约4倍压缩；28层模型第21–27层先均值池化、计算块更新，再将已完成块更新残差广播回原有字节状态；prompt块固定、生成token单独成块。不改变权重，部分任务成绩近基线；额外模型与构块成本未闭合，也不是丢弃所有精细状态或无监督自发现证明。
- **理论和生成**：附录F.1命题1对完整有限、可逆确定编码，按双射重排概率得到总熵相同；不保证不同有限上下文、参数模型的BPB相同。§4.2/表3及附录G：真前缀oracle模拟、无提议长度上限，200M草拟器每次接受9.527字节对词元9.523字节，3.366倍的是位置数而非文本或实测速率，未运行真实推测解码。
- **区别与FLUED主张**：固定临时合并并恢复byte残差，不是按当前问题访问持久原源的层级索引。可主张同参数、同训练算力及同原文暴露须分别比较，并把注意力、保留性能与内容替换因果效应区分。
