# W0352｜MambaByte: Token-free Selective State Space Model

**FULL**｜Junxiong Wang、Tushaar Gangavarapu、Jing Nathan Yan、Alexander M. Rush，COLM 2024，[arXiv 2401.13660v3 HTML](https://arxiv.org/html/2401.13660v3)、[PDF](https://arxiv.org/pdf/2401.13660v3)。读正文§1–7，相关附录A–G、H样例定向；HTML与PDF表号不同，下文明确来源。实现未核、未复现。

- **学习/粒度**：下一字节损失训练Mamba选择性状态空间模型，当前字节决定写入/保持与读出参数，固定大小的每层递归状态（§2–3）。无块级源地址或原文回访；历史状态被覆盖并混合，不等同原文可恢复。推理严格前缀；子词草拟器建议未来候选，字节验证器扫描并修正，附录F给算法。
- **对照与真实成本**：HTML表2，8,192字节窗、相近每字节FLOPs，353M在PG19/Stories/Books/ArXiv/Code为0.930/0.908/0.966/0.663/0.396 BPB，MegaByte为1.000/0.978/1.007/0.678/0.411；前者训练30B、后者80B字节。训练字节按窗口计可重复，并非唯一原文量；表1 FLOPs近似省略嵌入等，不代表所有系统成本。
- **换算与限制**：PDF附录E式(5)为`word PPL = exp((bytes/words) ln 2 × BPB)`，PG19训练/验证/测试分别5.92/5.90/5.93字节每词，子词1.48/1.45/1.48；这些仅PG19，不能逐数据集沿用。HTML表3的有效字节量和有效窗口含换算与滑窗，不等于所有原文实测，其他四数据集逐项分母本文未提供。PG19 972M 150B训练字节PPL 33.0，子词Mamba 600B有效字节33.9，且评估上下文不同；不是相同预训练原文量或精确相同条件。
- **推理反例**：HTML表8在A100上生成8192字节、110M额外子词草拟器、每次3子词、验证top-3，2.6倍相对原MambaByte，log-odds比0.89；top-3接受不保证与贪心输出或目标采样分布精确一致。草拟器驻留、训练与验证成本不可忽略；表7速度另是MambaByte对MegaByte比较，不能混为同一2.6倍。原文未确认输入/输出权重共享实际配置，未列持久源、索引冷/热I/O及全部训练成本。
