# W0445 — Leases: An Efficient Fault-Tolerant Mechanism for Distributed File Cache Consistency

**FULL｜** Cary G. Gray、David R. Cheriton，SOSP 1989，印刷pp.202–210，DOI [10.1145/74850.74870](https://doi.org/10.1145/74850.74870)，[公开会议PDF](https://www.cs.cmu.edu/~15712/papers/gray89.pdf)，§1–7全文及模型推导已读；无独立实现或证明认证。

## 机制/条件

无训练；server按文件或目录授予有限时长租约（对缓存副本的期限性写入协调权），客户端持有效租约可直接读，写者必须等待持有者确认失效或期限结束（§2 pp.202–203）。名字→文件绑定与权限本身也需受租约保护；缓存文件内容和租约覆盖范围是不同对象，目录覆盖大粒度降低状态但增加假共享。当前读/写请求已知，无未来或答案标签；神经层深不适用。

§3.1模型单服务端，N客户端、读写泊松率R/W、共享度S、固定网络成本且忽略排队，客户端下载有效期因传播和时钟偏差缩短；读续约与写通知构成权衡，太短甚至客户端有效期为零时只伤写不惠读。§3.2的V系统单客户端构建文件服务器轨迹，其他共享度是模型估计：S=1、10秒租期一致性流量为零期限10%，全服务端流量降低27%；不是多客户端实测或普适10秒最优。§5假设非拜占庭失效、服务端写入跨崩溃持久、时钟偏差或漂移有界；快服务端时钟或慢客户端时钟可破一致性。分区使写等待未回应租约到期；服务端崩溃后等待最大租期或使用持久租约记录。

## 生命周期与FLUED
