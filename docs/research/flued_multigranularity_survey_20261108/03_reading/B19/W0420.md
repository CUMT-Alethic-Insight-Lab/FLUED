# W0420 — Provenance as Dependency Analysis

**FULL｜阅读范围**：[arXiv 0708.2173v2全文](https://arxiv.org/html/0708.2173v2)，James Cheney、Amal Ahmed、Umut A. Acar，扩展2007 DBPL论文；通读§1–7及正文中的证明，分页至文末。阅读不等于独立证明/代码核验。

## 方法和证明

无训练：将嵌套关系演算（NRC）输入每个子值染上可代表地址的颜色集合，值粒度可到字段、元组和容器（§2–3）；执行已给定query时动态传播，或不读数据仅对查询/类型做静态上界。对象为输出值/容器结构的可能依赖，**不是**为下游预测学习粒度、语言模型层深或源位置永久稳定保证。

§3定义3.3–3.4的依赖正确性是：只改变颜色c标示的输入部分，输出只能在带c部分变化。其保守集合可误报无关来源，不意味着每个被标注源均实际影响；条件成立时未标注的变更不会改变相应未标注输出，属于模型内无漏报而非任意实现全局无漏报。§3命题3.3给出关键归约：对等价性待判的`e,e′`构造 `(e≈e′)∨y`，由于y=true时为真，其是否常真等价于e和e′是否等价，故一般最小依赖不可判；该结论关于纯函数、有限多重集和NRC查询，不是任意神经系统/所有受限任务下界。

§4图5/6传播算子，差集与相等把两侧全部颜色纳入，`R−R` 等价空集仍得到颜色是明确假阳性（§4与§6）；定理4.12以语法归纳、引理4.10按算子保证依赖正确。§5类型规则合并分支，定理5.15以类型归纳使静态标注覆盖动态标注；静态通常更粗，代价是更多无谓失效。§6只报告小原型，无大规模性能对照。

## 生命周期和应用

源的细字段/容器 → 动态依赖集合或类型级上界 → 派生值 → 外部索引/缓存/副本（后两层未实现协议）。源更新若命中上界应失效/重算，但命中不证明真实改变；替代推导不是此集合直接记录的与或结构，物理删除、事务并发、失败恢复及副本确认未给。静态多粒度是schema/字段/集合，和模型深度不等同；query当前可见，未来/答案泄漏不是本文场景。相比W0419正查询保留推导多项式，此文支持差集/聚合的安全过近似但会多报。FLUED可引用：可达来源、实际依赖、依赖上界与最终消费各有不同证据；模型摘要若不能建立此语义不可继承其安全性。成本：每结果颜色集合及跟踪，§6明确大库扩展/压缩和生产可用性未验证。
