# W0136｜LongMemEval-V2: Evaluating Long-Term Agent Memory Toward Experienced Colleagues

- Di Wu、Zixiang Ji、Asmi Kawatkar、Bryan Kwan、Jia-Chen Gu、Nanyun Peng、Kai-Wei Chang，2026，arXiv:2605.12493v1，[全文](https://arxiv.org/html/2605.12493v1)。**FULL**：正文§1–6、表1–2及附录A–E、提示与工具调用统计实际阅读；截图图像未逐像素核；代码、实验未独立验证。

## 数据及查询可见信息

§3、附录A：451个人工问题涵盖静态页面、动态状态转变、工作流、陷阱、前提错误；Small各领域共享100轨迹约25M token，Medium每题约500轨迹约115M token，选定相同答案核心再加干扰。1,540轨迹由WebArena/WorkArena沙盒收集，问答由人工出题、Codex候选证据标注后人核；固定读者Qwen3.5-9B，返回记忆限200K token。动态题是界面动作前后变化，不自动等同现实世界长期更新或历史撤销基准。

§4/附录C.2：R写时把每个状态±1窗口、动作序列和截图放原始状态池，另由语言模型生成相邻状态事件、整轨迹两条流程/提示笔记；各池向量检索。查询时控制器生成至多5个原始状态查询及事件/笔记查询；附录C表9输入还包含问题ID、题型与原任务goals，属于具体权限，不能只说自然语言问题。C写时保存轨迹JSON和截图原件，读时用Codex/GPT-5.4-mini在文件系统逐轨迹/状态搜索，清单及工具辅助，最多返回20个状态；问题后访问原始轨迹，非从摘要恢复。两臂都保存原始信息但R通过已生成状态窗口/索引读取，C可对全轨迹编程搜索；控制模型、阅读能力、检索/工具调用和提示同时改变，不是单变量压缩消融。未知未来问答未用于写时，但评测元数据/query时可见；无训练或效用监督新路由。

## 对草案

R的原状态/事件/策略三粒度，以及C的查询后原轨迹回访均是强外部先例；不是同源总预算条件下验证FLUED内部可学习字节路由。可引用固定读者与同源消融来警惕“存有即能用”；追查限制C搜索权限、统一控制器及全源/索引/维护成本后，层级是否还有净值。
