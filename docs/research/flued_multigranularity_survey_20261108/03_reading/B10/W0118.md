# W0118｜Zep: A Temporal Knowledge Graph Architecture for Agent Memory

- Preston Rasmussen、Pavlo Paliychuk、Travis Beauvais、Jack Ryan、Daniel Chalef，2025，arXiv:2501.13956v1，[HTML](https://arxiv.org/html/2501.13956v1)、[PDF](https://arxiv.org/pdf/2501.13956v1)。**FULL**：正文§1–5、表1–3、附录§6提示实际阅读；表格由HTML补足，PDF/HTML均有§2.2.2起始句和部分提示残缺，未据此推造缺词。未核代码、未复现实验。

## 信息与时间

§2.1–2.3：消息、文本或JSON原始episode保留；语言模型以当前消息和前4条消息抽实体与关系，实体消歧、关系去重与矛盾检测另需调用；来源episode与派生语义边具双向索引，作者明确说此来源链接未在实验中直接考察。实体名嵌入1024维，社区由标签传播得到并生成摘要；增加新实体采用邻居多数社区、更新摘要，逐步偏离全量聚类，须周期刷新。未报告删除源时传播到所有摘要、索引、缓存的算法或陈旧窗口。

双时间：边上 `t_valid/t_invalid` 为事实有效区间，`t'_created/t'_expired` 为系统事务创建/失效；新旧边时段冲突时用新边的生效时间截断旧边，按写入先后优先新信息（§2.2.3）。旧边逻辑失效与原始episode、历史记录继续存储，不是物理擦除；历史范围可作为结果输出，但论文不提供完整历史查询可达率或审计级删除。查询后以向量、BM25、图广度搜索召回实体/关系/社区，重排后把事实及有效区间等放入上下文（§3）；读取对象与地址是图实体、关系和社区文本，不是模型内部字节节点。图构建不需未来问题，预训练模型抽取并非最终答案效用训练。

## 对照与成本

DMR表1：GPT-4-turbo Zep 94.8%、完整对话94.4%、MemGPT报告93.4%；gpt-4o-mini 98.2%对98.0%，差距小，原作者承认每例仅约60消息。§4先称检索20个边/实体，§4.2 DMR又写top10，保留此口径差异。LongMemEval表2：完整上下文/ Zep分别55.4/63.8%及31.3/3.20秒（mini），60.2/71.2%及28.9/2.58秒（4o）；摘要的15.2%、18.5%是相对增幅，不是百分点。表3单会话assistant 4o从94.6降80.4，mini 81.8降75；表内delta的分母计算口径与通常相对基线存在疑点，以原始两列为准。作者未成功复现MemGPT在该卷结果。建图及更新语言模型费用、源/索引总字节、维护延迟、冷启动及多问摊销未闭合，查询延迟不含完整生命周期。

## 草案差异

这是外部原始episode+事实图+社区摘要的强近邻；双时间和源链接真实存在，但不是字节模型端到端训练的多粒度索引或删除验证。可引用逻辑失效、历史保持与相对更新成本需要分账；不可将可追溯链接等同实际回访成功或派生物擦除。后续追社区在边失效、源撤销时的重算/失效与并发快照。
