# W0133｜Evaluating Memory in LLM Agents via Incremental Multi-Turn Interactions

- Yuanzhe Hu、Yu Wang、Julian McAuley，2025首发，所读arXiv:2507.05257v4（2026-06-28），[全文](https://arxiv.org/html/2507.05257v4)、[版本史](https://arxiv.org/abs/2507.05257)。**FULL**：正文§1–5及附录A–L、表3/5/8–10/12/17–19实际阅读；图按图注与正文，代码、原始数据和实验未独立运行。未逐版比较v1–v3；W0125使用v3，不能把v4新增设置归给v3。

## 测试对象和时序

§3.1、附录B.4/D.2：FactConsolidation以MQuAKE原始事实及反事实改写成对编入6K至262K上下文，每条有序号，旧事实序号更小；向所有被测系统明确给“较新事实序号更大，按最新解决冲突”的任务规则。先逐块注入记忆，再给问题，最终用子串精确匹配答案。该任务测的是在冲突背景中选当前答案，不检查旧文、向量、图、缓存、备份是否物理删除，也不测试任意历史值。其“选择性遗忘”是行为性代理指标而非擦除证明。训练信号是任务提示与标注事实，不是为目标宿主训练写策略；问题/答案不在历史注入中，但更新规则与序号是显式先验。

§3.2–4.1比较长上下文、原文片段检索、向量/图及工具式记忆。基础合成事实通常分512 token；为计算/API成本Mem0、Cognee、Zep、MIRIX统一4096 token，检索常top10，长期上下文会按窗口FIFO丢最旧内容。不同系统的可用原源、构建调用数、索引和窗口不一致，统一提示不等同总预算匹配。

## 对照和限制

表3 262K：GPT-5-mini单跳78%、多跳28%，GPT-4o 60/5，BM25 48/3，HippoRAG-v2 54/5；这些是作者这套系统/参数结果，不证明任何结构范式普遍无效。表5短6K：o4-mini单跳100、多跳80；32K多跳14，说明长上下文/多跳组合更难，不能断言唯一原因是物理忘记失败。附录K表19：GPT-4.1-mini原36/5%，强制覆盖40/4%，保守否定规则28/4%；W0125 v2的同证据结构化抽取仍可大幅改善，因此不能把这几个提示对照升级为“提示工程不可能解决”。

附录E表12把构建和查询分账：MH-QA Mem0块512/4096构建10804/1334秒，查询0.79/0.65秒；多系统和模型/硬件差异存在。附录I表17的每问金额假设共享上下文缓存、排除嵌入建索引；附录J“算力匹配”按处理token而不是严格同FLOPs/原文访问/前向次数，不能当完整同资源证据。作者的短上下文可解性、追加提示与语料代理标签不能排除语义抽取、检索或答案策略混杂。

## 与草案关系

这是跨记忆形式的评价，不实现草案的内部字节级多粒度路由。可用其事实更新问答、粒度与预算对照来区分行为胜负；不能把答对最新事实写成源删除或因果消费。优先补同源同问的历史值、逻辑遮蔽和所有派生副本删除检查。
