# W0152｜CacheBlend: Fast Large Language Model Serving for RAG with Cached Knowledge Fusion

- Jiayi Yao、Hanchen Li、Yuhan Liu、Siddhant Ray、Yihua Cheng、Qizheng Zhang、Kuntai Du、Shan Lu、Junchen Jiang，EuroSys 2025，arXiv:2405.16444v3，[HTML](https://arxiv.org/html/2405.16444v3)、[PDF](https://arxiv.org/pdf/2405.16444v3)。**FULL**：正文§1–10、§7图注及附录A实际阅读；图未逐点量化。另从公开PDF内存提取p.16交叉核附录公式；未核代码、复现性能，未完整重证理论。

## 分块复用、粒度与条件

§3–4：离线分别对可复用文本块预计算KV；查询时检索文本块、拼接作为当前问题前缀。不在同一前缀的缓存忽略前块跨块注意力；位置旋转可校正地址，但不能补回跨块交互。§4.1–4.3定义对完整预填KV和末端注意力的偏差，用完整结果选最高偏差仅作oracle诊断；实际逐层对当前重算KV与缓存KV作差，从早层起逐渐筛出高偏差token后在后续层仅更新它们，未选token仍复用。块是缓存键/复用对象，token是重算粒度，层是加工深度；查询和检索块到达后才选择，未来问题写缓存时不可见。模型参数及选择规则不因此由终局答案损失训练。

§5.1/6：对文本chunk散列查缓存、不同层加载，空间满按LRU淘汰；未找到时重算并异步写回。论文未明确完整模型权重/版本、token化、前缀内容变更、缓存投毒或删除的联合失效键。部分重算是近似恢复跨块依赖，不是原始文本丢失后无损恢复，也非逐值精确等价证明。

## 关键理论疑点：只限具体推步

附录A命题A.1（HTML标A.2）声称RoPE内积仅依赖相对位置，该相对位置性质可由旋转矩阵乘法得到；但PDF p.16式(1)展开仅有同坐标乘积的cos项，**漏掉交叉sin项**。以二维q=(1,0)、k=(0,1)、相对位置差l=1且θ₀=1为例，真实旋转内积为sin(1)而印刷式给0。正确式还含`(q₀k₁−q₁k₀)sin(lθ)`（取论文旋转方向）；这击中该展开式，不推翻相对位置不变性质或经验结果。仅检查此反例与旋转代数，未完整重证所有实现细节。

## 成本、对照和反例

§5：Llama-7B/4K在15%重算时每层计算3ms、NVMe读取16ms，重算可被慢读取遮盖；Llama-70B分别7ms/4ms则不能完全遮盖。§7.1/7.2：A40、128GB RAM、1TB NVMe 4.8GB/s，4数据集3模型；预热请求前1000个不纳统计，后续多请求TTFT较全重算降低2.2–3.3倍、吞吐增2.8–5倍；质量词重叠指标较全重算差通常≤.02，非逐字节输出一致或所有任务无损。前缀缓存对照甚至假设加载零延时。完整重用无跨块注意力时多跳质量显著差，但MapRerank可更快而质量较差（§7.2）。图16特定Yi-34B、5–18%重算差≤.002，不能升级为全模型保证。预计算、重复使用率、源/派生缓存容量、冷启动、并发、迁移和淘汰应同账；论文给单层存储及百万块哈希16MB（§6），没有完整源权限与全生命周期单问/多问成本。

## 对草案

模型内部选token重算与外存原块KV回访是强近邻，但目标是近似融合多块已计算KV，不是按摘要不确定性自动扩搜原文或学习语义边界。可引用跨块依赖与冷读取条件反例；不可声称位置校正或15%重算提供精确保证。建议追来源变动/模型版本失效和完全冷负载同预算对照。
