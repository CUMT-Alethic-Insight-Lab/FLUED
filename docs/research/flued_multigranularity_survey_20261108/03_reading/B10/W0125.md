# W0125｜Reliable Post-Retrieval Assembly for Agent Memory

- Vikas Reddy、Sumanth Reddy Challaram，2026；arXiv:2606.01435v2（2026-08-02），[全文 HTML](https://arxiv.org/html/2606.01435v2)、[版本记录](https://arxiv.org/abs/2606.01435)。**FULL**：正文§1–7、表1–5、附录A–E（含表6–8）实际阅读；Fetch正文缺表，内置浏览器文档续页补齐。v1未逐版对比；代码未核、实验未复现。

## 来源、对象与生命周期

§3式(1)：事实文本及版本序号为输入，BM25按问题检索top-10；语言模型依主体/谓词抽取所有匹配 `(serial, text, entity)`，外部算子取最大serial。多跳逐跳分解、检索、抽取并执行后再代入下一跳。无新的模型训练：调用预训练模型做查询条件抽取，已知最大序号规则是任务先验而非学得；写入时不见未来查询，查询时可见已检索文本、编号和问题，不见金标答案。事实级或4096字符窗口是索引粒度，候选事实与实体为读取/决策对象；不是字节级内生路由。

这是查询后组装器，不是来源库生命周期系统。论文未给源修改、派生索引失效、擦除或缓存协议，也未证实能回访检索外来源。最大编号只给当前值；§5.7/附录D的历史问题需次新算子，聚合及Yes/No需不同策略，不能声称现实现已解决历史查询。版本序号顺序不等于一般事件因果顺序。

## 关键对照、反例与成本

表1固定gpt-4o-mini、事实级BM25、相同top-10、n=100/格：直接回答6K/32K/64K/262K为63/70/75/61%，抽取+LLM执行70/75/77/82%，抽取+确定性执行71/78/81/82%。总体端到端差+10.8个百分点、262K +21；但直接臂T=.7、结构臂T=0且提示/格式/步骤同时改变，不是抽取单变量。两结构臂候选抽取各自重跑、一致率96–100%，执行器近似隔离差平均+2点、262K为0；不能把总收益归因于最大值算子。表3：4096字符结构臂平均80.8%，事实级78%，262K分别73/82%，粒度效应随长度翻转。

§5.7表5：LongMemEval更新子集直接29/45、结构26/45，配对精确McNemar p=.45，**未证明优势，也未证明等效**。§5.6：短6K时o4-mini多跳分解52%低于直接80%；第一跳提取错误可级联。附录D约30例错误的归类只是抽查；检索缺失、语义错配、空候选均存在。作者与MAB v3公开系统结果的跨系统表并非同实现同权限对照。

附录A报告4,400次语言模型评估、API约3美元、四进程约15分钟；未闭合语料建库、持久存储、top-10检索和生产端单问/多问、尾延迟及写维护账。该金额不可当全生命周期成本。

## 草案差异与可用主张

这是外部文本证据到答案的分工，不实现草案的多层潜状态、字节地址、按需下钻或选择性变换；可用于限定“找到证据不等于正确消费”。可引用固定检索集合下的整体管线差，以及历史/聚合反例；不能称已验证任意时间冲突或源删除，也不能把预测正确当内容替换因果证据。后续追查同温度同提示、同候选逐字共享，及实际事件时间与写入时间冲突下的策略选择。
