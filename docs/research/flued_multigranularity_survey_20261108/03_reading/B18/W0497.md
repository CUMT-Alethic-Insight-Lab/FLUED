# W0497｜Reinforcement and Imitation Learning via Interactive No-Regret Learning

**FULL**：Stéphane Ross、J. Andrew Bagnell，[arXiv:1406.5979v1](https://arxiv.org/pdf/1406.5979v1)，2014。已读方法、理论及附录证明（pp.10–14）；此版本是理论文，无新增实证结果，不借引用文献的实验充数。未独立证明或执行代码。

- **来源/标签**：§2算法1：每轮m次，从初始状态由当前学习者（可混专家）运行至均匀随机t，探索一个动作，然后**专家**执行至结束，得到`(s,t,a,Q)`；可以由专家提供代价或一次轨迹估计。全动作代价向量需逐动作估值，部分动作可回归/重要性加权；均匀探索有支持需求。§3算法2 NRPI则从外给状态分布取s，执行探索动作后用**当前学习者**滚动；两者不可混称同一标签。
- **粒度/权限**：单位是一个状态动作的未来累计代价，地址为状态/动作；正文注2允许对部分可观察状态使用特征，但并未研究来源保存/多粒度内容。专家可恢复到学习者到不了的路径时，其标签可能过于乐观；§2.5窄崖道路反例中专家能走短路而学生类不能，学生被引向必跌悬崖，尽管类内存在较慢安全路。
- **理论**：§2.4定理2.1及附录定理4.4：专家代价有界、混合概率几何衰减、无遗憾与类内分类遗憾条件下，均匀混合/最佳策略相对专家的成本差由`T(εclass+εregret)`及混合误差控制。证明用性能差望远镜、混合与自主状态分布L1界，再用在线遗憾。定理2.2/4.5的有限样本版本另需均匀动作探索、有界损失，平方损失归约引入动作数和根号项。§3定理3.1还包含探索分布与比较策略状态分布的距离项，最坏可按T²恶化。
- **比较和成本**：§2.5 SEARN理论上使用当前策略续行而非专家续行；DAgger逐访问状态取专家动作，每T步可得约T个标签，而本法单个cost-to-go估计可能耗整条续行轨迹（§4）。精确全动作反事实比单动作噪声估值更贵，文中无统一实测账。一步动作+固定后续不是联合替换互补动作，亦不等于重训最优差。
- **FLUED可引用**：学习者诱导状态上的后续价值标签与专家动作模仿是两种信号；标清续行者、支持和轨迹成本才能解释控制器。多粒度读取或可回访不由此文证明。
