# W0498｜Double Reinforcement Learning for Efficient Off-Policy Evaluation in Markov Decision Processes

**FULL**：Nathan Kallus、Masatoshi Uehara，JMLR 21(167):1–63，2020；[JMLR身份页](https://www.jmlr.org/papers/v21/19-827.html)、[正式PDF](https://www.jmlr.org/papers/volume21/19-827/19-827.pdf)。已分页阅读正文§1–6、实验表2/3及附录A–C/关键定理证明；未运行代码、未独立复证全部泛函分析。

- **对象/权限/粒度**：§1.1 pp.3–5定义目标策略πe在行为策略πb轨迹上的累计回报ρπe；NMDP状态可含完整历史，MDP只依当前(s,a)，q/v分别是目标策略未来回报。地址是状态—动作—时间，不是内容压缩或多粒度来源；支持要求目标策略动作在行为策略下可见，奖励有界。未来奖励只作为训练标签/估计对象，不能当在线读取可见。
- **核心理论**：定理1 pp.8–9给NMDP高效影响函数及界；定理3 pp.10–11给MDP的边缘密度比`μt`版本，区别于NMDP累计比`λt`。定理4 p.12用Jensen证明`EffBd(M2)≤EffBd(M1)`，严格性需状态条件下比率/未来回报非平凡；定理5给MDP界至多`C Rmax²(T+1)²`，NMDP可随T指数增长，前提是Assumption 1/2及额外下界条件。附录B pp.43–46实际给影响函数正交切空间证明；不是只读摘要搬运。
- **DRL与稳健性**：§3 pp.13–19，K折交叉拟合从不含当前折的数据估q与密度比，再代入影响函数。定理6(NMDP)与定理13(MDP)在两个干扰估计的L2误差乘积为`op(n^-1/2)`且各自一致时达效率；定理10/16分别给一方正确、一方达到相应速率时的√n一致性，Corollary 11/17给只要求一方一致的普通一致性。有限样本定理7/14的常数仍依T、比率界、奖励界和误差上界。
- **强对照/结果**：§5.1表1为T=30连续状态模拟、50000次Monte Carlo重复；三种错设/正确组合中DRL-MDP总体最好，MIS在µ模型错设时明显变差，DRL-NMDP因累计比率大而可有高RMSE。§5.2表2 Cliff Walking(T=400) n=1500：DRL-MDP RMSE .075、DRL-NMDP .098、DM 1.01、IS 7.64；表3 Mountain Car(T=200) n=1500：DRL-MDP 1.69、DRL-NMDP 1.82、DM 3.30、IS 3.41。代码地址在正文p.27，但未执行。
- **成本/失败条件**：需要行为策略支持、q函数与边缘比率建模、交叉拟合；长视界、策略分布差异、密度比大、状态空间连续或模型错设会放大方差/误差。作者明确MIS通常低效，且NMDP无结构时诅咒视界不可避免。未给检索/内容字节成本、标签人工成本或总墙钟，不能外推到FLUED token/byte。
