# W0500｜Why Adaptively Collected Data Have Negative Bias and How to Correct for It

**FULL（核心阅读）**：Xinkun Nie、Xiaoying Tian、Jonathan Taylor、James Zou，AISTATS 2018，PMLR 84:1261–1269，[正式正文](https://proceedings.mlr.press/v84/nie18a/nie18a.pdf)，[补充](https://proceedings.mlr.press/v84/nie18a/nie18a-supp.pdf)含正文重排及附录；读正文、补充B核心证明和C–E主要实验/优化。未独立核验理论或运行代码。

- **估计对象与假设**：§2定义1/2与定理1：固定终止轮数T、每次从选中臂取独立样本、每臂有有限均值；同样本数及其他历史固定下，臂均值增加不会令已选中的该臂失选（Exploit），且未选该臂时其他选项的条件选择不依赖该臂历史（IIO）。在这些条件下，**预先指定某臂**的样本均值期望不高于真均值；两臂命题2不需IIO。每臂先观测以保证均值有定义。不能泛说所有自适应过程、任意停止规则或选中的冠军均值均负偏。
- **关键证明**：补充B把每轮选择拆为选该臂与未选时其他臂选择，固定其他臂样本和随机性；再研究样本路径到该臂抽取次数的映射，以Exploit的单调性和条件均值回归比较最大期望。补充中定理2证明使用历史到统计量`U`可逆的表述，是否满足所有声称的情形尚未独立复核，不据此判错。
- **去偏/代价**：§4式(2)–(6)给定采样机制并条件化已选臂序列，用Gumbel随机化平滑选择、对条件似然进行近似优化；要求改变采集，不能事后普遍修复历史日志。独立留出每轮多抽一份，减偏但样本利用减半；重要性加权可高方差。表2/3中K=2、T=8时Greedy原偏−.29，条件似然剩2.8%；其均方误差为原来的78%，留出108%。模拟特定分布、超参数，不是普适改进。
- **粒度与FLUED**：臂及采样轮次是地址粒度，没有内容压缩、query多粒度、来源生命周期。与W0501在固定日志上选择策略引起的倾向过拟合不同：这里是自适应**采样**对固定臂均值的偏差；冠军选择可能有相反的乐观偏差，两者可并存。建议记录探索、逐臂样本数和独立评价，不能以此证明FLUED的粒度效用方向。
