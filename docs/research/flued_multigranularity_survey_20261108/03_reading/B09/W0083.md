# W0083｜MemTree

**FULL（v1）**｜Alireza Rezazadeh、Zichao Li、Wei Wei、Yujia Bao，[arXiv:2410.14052v1](https://arxiv.org/pdf/2410.14052v1)，2024-10-17；v1完整题名 *From Isolated Conversations to Hierarchical Schemas: Dynamic Tree Memory Representation for LLMs*，队列短题属同ID别名，未逐版比较v3。已读PDF 22页、方法、所有实验、附录A.1–A.7及理论推导；代码/实验未复现、定理未独立验证。

- **构建与检索**：§3.1/算法1，新输入向量与子节点比较、超过深度阈值沿最相近分支走，否则插新叶；叶扩展时保留旧叶内容并新增另一叶，沿路径LLM摘要重写父节点。故旧叶不因父重写自动覆盖，但原始采集是否等同逐字原对话、长期持久/撤销未证。构建不依赖后续查询；§3.2所有层节点折叠为同一检索池，与查询余弦相似后阈值/top-k，叶可不经父摘要独立召回，不是顺序下钻。§4.3附录A.1.4分别用top-3/top-10。
- **训练和理论**：固定预训练嵌入及LLM提示，无对回访/边界的端到端训练。§3.1、附录A.7宣称β良分离条件下继承在线自顶向下聚类的β/3收益近似；原推导把汇总向量阈值决策类比成原算法簇间/簇内均值比较，并额外假定w(A)≥θ(d−1)，未展示这些对LLM摘要必然成立。因此这是**作者主张与证明缺口**，不是本轮已反证定理；勿用作任意输入、任意摘要或检索正确率保证。O(log N)插入亦需平衡树、分支比较与调用成本条件。
- **结果/成本**：表1短对话全文95.6高于MemTree 84.8；表3 QuALITY全文65.1、GraphRAG 62.8、MemTree 59.8。表4 MultiHop整体RAPTOR 81.0、MemTree 80.5，时间问题68.4对66.0。图5称平均新增10秒，累计构建时间约RAPTOR 1.4倍；不是同预算无代价。表5节点3164，而§5.3文字3154，待核（同版冲突）；附录A.1.3阈值按当前最大树深归一化，与§3未归一化式需区分。源/摘要/向量持久字节、撤销及冷I/O未给全账。
- **草案差异/可用**：在线多层摘要、保留叶及全层平面检索已经存在；不含基于不足判别的查询下钻、可靠回退或内部字节机制。可作为强平层跨层候选及低成本顺序更新对照，不以理论近似替代真实来源读取和因果消费。
