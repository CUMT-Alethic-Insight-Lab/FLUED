# W0044 — TACO-RL: Task Aware Prompt Compression Optimization with Reinforcement Learning

**FULL**：Shivam Shandilya、Menglin Xia、Supriyo Ghosh、Huiqiang Jiang、Jue Zhang、Qianhui Wu、Victor Rühle、Saravan Rajmohan；[ACL Findings 2025，pp.1582–1597](https://aclanthology.org/2025.findings-acl.81.pdf)，DOI 10.18653/v1/2025.findings-acl.81。读正文§1–6及附录A–E；远端截断后以本机pdftotext续读完整PDF，包括主表和末页。来源[ACL目录](https://aclanthology.org/2025.findings-acl.81/)。

## 方法与观察
- §4.1：先用类似LLMLingua-2的GPT-4标注训练二元分类器，再以REINFORCE（策略梯度）做任务特定微调；各token训练中伯努利抽样，长度偏离目标超过容忍窗给负奖励，否则奖励与原文生成结果的相似度，附熵正则；测试按分数top-k确定准确比例。双向块编码；QA奖励模型见问题，但正文§4定义编码器输入为prompt，未明确判定部署压缩器是否单独接收问题，需核论文/实现；不擅自等同查询可见。
- §5.2/附录A：并非直接使用W0043原先MeetingBank训练好的同一权重。MeetingBank和SQuAD先在WikiText重建类似基础分类器，代码任务在Py150重建，再分别强化；W0043默认MeetingBank。需要避免把两工作比较称为唯一变量的RL消融。模型使用512-token块，逐块压缩再拼接；原文被剪掉，未提供回访地址。
- §4.2：摘要奖励BLEU(压缩输出,原文输出)，QA奖励F1(压缩答案,原文答案)，教师GPT-3.5；§5.3用GPT-3.5-Turbo-1103下游，摘要参考GPT-4（附录A），代码参考原文GPT输出，部分评价与奖励共享模型或指标，存在共同偏好而非独立正确性证明。SQuAD评估用数据原答案。
- PDF p.1589表2：2倍SQuAD，同任务LLMLingua-2 F1 62.70、EM 38.02，F1奖励69.62/46.32，词相似奖励56.67/35.14，混合68.03/44.64；原文71.40/47.49。表1的2倍MeetingBank BLEU 18.68→21.35，原文21.50；6倍9.80→14.25。§5.5报告代码摘要5倍相对+189%，是相对百分比不是百分点。附录C代码补全2倍EM 7.00→8.92仍弱，见表4。
- PDF p.1597表8是五次运行单样本t检验，所有p值印为1.0000；作者说支持提升但仅此不能判断比较基准、检验方向或对基线差异显著性。未见同率随机/词频廉价对照。表9熵正则2倍BLEU 21.35 vs 去掉17.62。
- 附录A每训练步需API调用，原文输出可缓存；8×V100、不同任务训练4或15轮。总调用次数、费用和完整固定总训练预算未见；单测相同推理延迟不含训练代价。
- **最近邻与可引**：在蒸馏的抽取分类器上用输出相似奖励做任务适配；奖励条件和参考来源强依赖，不能认为实现答案真值最优化。压缩器是否显式看测试问题仍待实现核对。
