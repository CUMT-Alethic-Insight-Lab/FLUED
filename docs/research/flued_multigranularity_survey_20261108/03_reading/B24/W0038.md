# W0038 — In-context Autoencoder for Context Compression in a Large Language Model

**FULL**：Tao Ge、Jing Hu、Lei Wang、Xun Wang、Si-Qing Chen、Furu Wei；[2307.06945v4](https://arxiv.org/html/2307.06945v4)，2024，ICLR 2024；读§1–5、图表和附录A–D。版本历史见[arXiv](https://arxiv.org/abs/2307.06945)，未逐版比较，全文阅读不等于代码复现。

## 学习、粒度与访问
- §2：冻结目标LLM，编码侧在同一底模上添加LoRA（低秩适配）和可学习记忆token；原上下文后附k个槽，取其隐状态作为连续内容供原LLM解码。Pile上的自编码重建与文本续写混合预训，再以PwC指令–回复做监督微调；微调的上下文编码不见随后问题，解码器见问题。它是子词token→定数向量槽，不是字节切分；槽本身不提供原段地址或细粒度下钻。原上下文是否另存是应用层选择。
- §3.2、表1：512 token压128槽时，原上下文续写PPL 9.01、压缩9.50；图4显示长文本重建的前缀精确匹配下降，表3普通文本BLEU 99.3，结构化随机3.5，完全随机0.2。重建可读不保证最终问答使用了特定内容。
- 表5，同128槽，完整预训对无预训GPT-4裁判胜60.4%、负9.5%；混合AE+LM对仅AE胜36.4负28.5、对仅LM胜35.1负24.9。又有指令微调，但未逐一分离第三阶段的有无、顺序互换以及等总预训算量的全部控制。§3.2.2表4 Llama-2-7b-chat同模型原文对照，128槽胜19.6负45.4平35.0，明显非无损；GPT-4既参与PwC数据生成又作为裁判，附录D指出可能长度偏置。
- 附录A：8×A100、预训200k步、微调30k；§3.3.2表7和附录B记录A100单卡、压缩加生成与缓存复用，8×512总4.3s对原9.3s，单次压缩0.6s。未计PwC教师生成总成本、长期缓存更新和多查询尾延迟。§3.3.3多段独立压缩拼接原本失败，须增加多段训练，故跨段组合不是自动成立。
- **最近邻/可引**：较W0023的时间FIFO，ICAE是可预计算、查询无关的连续摘要，并明确提供AE/续写/预训练消融；但重建与问答相关性不是粒度或计算预算被控制后的因果结论。
