# W0013 — A gated quantized VAE for learning variable length tokens

**FULL**：Theo Datta、Kayla Huang、Sham Kakade、David Brandfonbrener，2025，[2512.21913v1全文](https://arxiv.org/html/2512.21913v1)，§I–IV及全部正文图表标题与结果已读；[版本历史](https://arxiv.org/abs/2512.21913)仅v1，未见独立附录。全文阅读不等于实现核验。

## 证据卡
- §II-A/B、式(1)–(11)：编码器、向量量化码本、门控器与解码头共同学习；输入字符/字节经潜在码本量化，门决定保留位置，单码解码定长字符窗口及长度。重建目标是输入字符而非下游任务答案；重建掩码随前面门变化，压缩项惩罚门开率，另有长度、码本和承诺项，量化使用直通梯度。
- 编码器式(1)使用整个输入序列，非前缀因果分段，也不见下游查询；事先以正则把TinyStories切成最长16字符子串，最大解码长度10。所学习码是内容而非外部来源地址；解码字典不附带任意原文索引。
- §II-C/III-A：推理检查逐字符重建，不一致的码退化成多个单字符，以保证输出文本无损；此回退要访问待编码原文，不等于部署后从码无条件下钻。图3称回退后压缩相对BPE损失低于7%；固定长度VQ-VAE对照图4同时受回退错误率影响。
- §III-B 图5：18M模型、整个TinyStories，BPE使用词表10000、GQ-VAE实际10314、VQ-VAE 13201；GQ-VAE损失高1.07%，其低压缩使相同数据训练步数更多。图6等压缩3.85字节/token时，把BPE词表降至3250，GQ-VAE达到BPE最低损失提前600步（16.6%）。同词表和同压缩不能同时视为同一比较；这些不是等总训练算量的干净排序。
- 方法§II-C描述先训练独立编码/解码并生成字典、再训练下游模型，支持分阶段；没有报告与端到端联合、冻结/解冻以及总标注与总算力匹配的消融。Toy英文数据和初始化敏感是作者§III-C限制；未报告长文本、跨语言部署延迟及词表/回退总成本。
- **最近邻与可引**：不同于W0012因果字节模型，这是预训练独立离散字符 tokenizer；按相同词表还是相同文本压缩率比较，排序可改变。不能据此断言模型字节接口无损或分阶段普遍最优。
