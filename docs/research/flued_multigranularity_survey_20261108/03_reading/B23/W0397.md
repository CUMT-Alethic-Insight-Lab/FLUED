# W0397｜Efficient Vision Transformer via Token Merger

**状态：FULL**。Zhanzhou Feng、Shiliang Zhang，IEEE Transactions on Image Processing 32 (2023), pp.4156–4169，DOI 10.1109/TIP.2023.3293763，[作者公开正式PDF](https://www.jdl.link/doc/2011/20231127_t-ip2.pdf)。全文文字逐页读；关键表I–IX及图8–10为图像，另将PDF第8–12页渲染后实际查看。无需补充材料的理论关键证明；未运行代码或独立复现。

- **决策与学习**：式4–5，输入视觉token经网络生成图像相关的meta token，作为查询对原token键注意，原token值加权聚合；同一输出可聚合非相邻patch。式6–8以共享可学习Bernoulli门和Gumbel松弛学习每层保留数，§III-C末明确训练后微调/推理固定；所以内容匹配逐图像变化，但保留率不是逐图动态率。任务分类损失+重建+算力正则共同端到端训骨干（式9–12）。
- **重建/风险**：式11为每个输入找最近输出的均方距离并平均，并非可逆重建或保证少数异常保留；尾部重要token可能被平均稀释是读者推论，未见原文逐类证明。§IV-B分类为250轮学率再50轮固定率；分割将合并token乘转置注意图投回原位置；剪枝基线用浅层线性投影填缺口，源与旁路权限并非完全等同。不是问题条件检索或源库长期管理。
