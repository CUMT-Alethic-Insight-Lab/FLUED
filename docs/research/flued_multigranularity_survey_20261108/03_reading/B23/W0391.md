# W0391｜Do latent tree learning models identify meaningful structure in sentences?

**状态：FULL**。Adina Williams、Andrew Drozdov、Samuel R. Bowman，[arXiv:1709.01121v2](https://arxiv.org/pdf/1709.01121v2)，2018；该稿标题与后续正式发表题名不同，未逐稿比对。已读正文方法、实验及分析；未执行代码或独立复现。

- **来源/对象**：文本蕴含标签驱动树结构和句表示共同学习，不用人工树训练两个潜树模型。RL-SPINN用策略梯度选 SHIFT/REDUCE；ST-Gumbel 枚举相邻候选组合、直通近似梯度选一个，均以 TreeLSTM 聚合成句向量（§3）。有向序列词到句向量，非压缩率可调的检索器。
- **可见性/生命周期**：文本对各自句编码后分类，实验还用双向叶 GRU；非自回归边界。句内树结点是组合及加工深度，未展示长久保留原文或问题驱动下钻；可解析不等同实际任务依赖。
- **实验/公平性**：§3 各模型从超参范围随机抽样、不同初始化共5次并开发集早停，改变超参与种子并非纯种子实验；§4 表1只报五次中开发集最优一次，SNLI/MultiNLI ST-Gumbel 83.3/69.5，LSTM 82.6/69.1。表2 ST-Gumbel带叶GRU任务开发准确率69.1±0.7、自身树F1 49.9；RL-SPINN对应67.4±1.6、92.7；随机树自身F1 32.6、平衡树100。各行细节随叶编码器而变，未报完整等总搜索/计算预算，也无重启差异显著性检验。
- **强结构对照**：§§5–7、表3/4比较随机、平衡、左/右分支和 Stanford/PTB 树。ST-Gumbel的PTB F1 19.0±1.0，随机21.3；RL-SPINN 13.2，主要是左分支；低一致性与较高任务分数并存，不证明树完全任意或语义结构不存在。浅树减少路径的解释为作者假设；§7否定、句首/句尾和功能词均有质检例子。
- **边界与最近邻**：W0406是原始ST-Gumbel论文；W0411为原始强化学习法，而本论文为共享代码库复现、扩大维度及增加叶GRU，不能当相同实现。W0392以明确参考结构的合成任务补充反例。可引用“任务表现和树重启一致性要分报”，不能宣判所有学习分段无效或把结果外推为字节因果性质。
