# W0406｜Learning to Compose Task-Specific Tree Structures

**状态：FULL**。Jihun Choi、Kang Min Yoo、Sang-goo Lee，AAAI 2018，[arXiv:1707.02786v4 PDF](https://arxiv.org/pdf/1707.02786v4)，正文及PDF内附录S1–S11逐读；未验证作者代码、独立重做梯度证明。

- **来源/方式**：自然语言推断（SNLI）或情感分类标签通过任务损失联合学习树和 Tree-LSTM 聚合；对每一轮相邻节点均算候选父结点，用可训练向量q打分、抽一个合并，N词N−1次，最后句向量分类（Model Description、式1–3、10–12）。这是计算结构逐层缩减，不是多粒度来源长期存储或问题后到下钻。
- **估计器/可见性**：训练前向离散Gumbel-Max抽样，反向用相同噪声的连续softmax代理；作者明确直通估计有偏，附录式S8–S11说明detach。推理无噪声取最高分。SNLI τ=1且作者称退火无益；句子编码不是保证自回归因果，叶LSTM能含之前词；没有单独的用户查询，分类答案只作为训练监督。
- **比较与边界**：表1 SNLI 100维有/无叶LSTM 82.6/81.8；300维85.6/84.4，原表计时0.6/0.7小时和3.1/1.6小时，外部对照部分取原论文或估算且批量不同，不能当同硬件同预算定论。表2 SST-2/SST-5分别90.7/53.7；SST训练使用所有人工树子树及其标签，尽管模型不输入树，训练实例构造仍有结构监督痕迹。图4仅示少数同句跨任务的树，不足证明策略稳定或任务特异可识别。
- **缺失**：未见固定树深度/固定结构或等计算预算的系统消融；未以多随机种子报告树一致性，无法判断高分捷径是否让树任意。组合率最终必然合到单根，网络深度不同于同时持久存储不同粒度；资源无源库/回访费用。
- **最近邻/可引用**：W0391重新实现并测重启/平衡与分支基线，W0392提供结构明确的合成诊断，均不能视为本作者原训练运行。可引用“任务标签可经有偏直通梯度训练动态组合，取得所列任务成绩”，不可由选例推断稳定的语言学解析或适用于因果字节模型。
