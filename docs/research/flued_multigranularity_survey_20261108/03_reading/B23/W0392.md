# W0392｜ListOps: A Diagnostic Dataset for Latent Tree Learning

**状态：FULL**。Nikita Nangia、Samuel R. Bowman，NAACL 2018，[正式版 pp.92–99](https://aclanthology.org/N18-4013.pdf)，关联 arXiv:1804.06028；读完整方法、结果和分析。未运行生成器或模型。

- **设置**：前缀表达式含 MAX/MIN/MED/模10求和及嵌套括号，十类结果标签；默认90k训练/10k测试，训练树平均深9.6（§3、图3）。模型接受结果标签而非参考树，学习相邻词/中间结点组合及 TreeLSTM 表示；组合树深度不等于保留多个可查询信息粒度。
- **查询/源**：输入整条表达式，预测单结果，不是后到查询、因果在线预测或源库回访；模型用完组合后不提供细源再读。正确解析的可用性不证明所有计算路径必须实现参考树。
- **对照**：§4–5、表1：128维 LSTM 73.3%、1024维74.4%；已给参考树的48维 TreeLSTM 94.7%、128维98.7%；128维 RL-SPINN 64.8%、ST-Gumbel 61.0%。上界模型多了参考树权限；作者对基线搜索32–1024维，潜树仅32–256维，超参搜索广度及总算力未等同。表2固定最佳超参重复4次，准确率均值±标准差分别 LSTM 71.5±1.5、RL 60.7±2.6、ST 57.6±2.9，自身树F1 30.8/32.3，随机30.1。
- **关键失败/解释**：表3最佳128维 RL 与正确树 F1 71.1但准确率64.8，说明接近参考树亦不能保证每题成功；其四次参考F1范围18.5–71.1（§6）。图4扩训练至240k/540k/990k，保留同一测试集，潜树仍落后。未报告按输入长度训练外长度外推；改变训练规模不是长度外推。固定宽度递归所需状态随嵌套深增长是§3直觉，不是对无限精度实数网络的已证明下界。
- **机制限制/可引用**：作者推测结构漂移阻碍组合优化，未隔离梯度估计偏差、搜索探索、组合算子表达能力三者；模型、任务与参数/训练预算均不同。相比W0391的自然语言高分/不稳定，本例提供人工结构明确的负例；可引用“参考树有用但给终局标签不保证学到它”，不能归责单一机制或推广到全部潜结构模型。
