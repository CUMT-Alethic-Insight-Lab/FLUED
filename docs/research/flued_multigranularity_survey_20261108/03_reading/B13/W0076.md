# W0076｜黑盒语言模型提示压缩的率失真

- **作品与阅读：FULL**。Alliot Nagle、Adway Girish、Marco Bondaschi、Michael Gastpar、Ashok Vardhan Makkuva、Hyeji Kim，*Fundamental Limits of Prompt Compression: A Rate-Distortion Framework for Black-Box Language Models*，arXiv:2407.15504v2（2024-12-11），[PDF](https://arxiv.org/pdf/2407.15504v2)。读§1–5、附录A–D，pp.1–42；代码未核、实验未复现、证明未独立验证。HTML Fetch失败，公开PDF转换并续读至文末。
- **权限与动作**：§3.1–3.4给固定消费模型φ、联合分布P(X,Q,Y)；压缩器不知查询用P(M|X)，知查询用P(M|X,Q)，消费者均见Q。M是较X短的**任意硬token序列**，长度相同时只允许原X，不限原文子序列；率为期望长度比E[len(M)/len(X)]，不是系统bit率或硬预算。失真是相对答案Y的对数损失或0/1损失，不是必然相对原模型完整输入输出分布的差。理论要求知道分布和候选m对应固定模型代价；不代表部署压缩器看见答案。
- **证明/计算**：§3.3定理1、算法1和附录A由原线性规划对偶和各x的率—失真点下凸包求最优；知查询情况在§3.4扩为(x,q)，平均率可在难题上多花预算而非每题固定。固定解码器与Wyner–Ziv等可设计解码器的经典形式不同（附录B）。枚举全部短输出代价随词表指数增长；仅允许原序列删词形成2^n候选也是受限上界，长文本束搜索更只是候选集上界，不是精确全局下界。
- **实际学习/结果**：§4、附录C，合成4–10位二进制Markov源、七种查询、1400验证样本；Mistral 7B先在训练集微调后冻结；QuerySelect/Adaptive QuerySelect由带查询的RoBERTa逐token预测保留，合成标签由规则生成，自然语言标签由GPT-4基于查询删词（Dolly筛选4.35k）。图1/4平均率下可变率优于所比方法，但按单题差异大；图5仅在小合成例中删词近似全部候选，不能普遍断言。自然语言仅10短文×4题，NarrativeQA只对摘要做大样本近似；相同来源全权限与端到端强检索未对照。
- **成本/可回访**：§4.2.3，100 token的束搜索示例约百万次推理；NarrativeQA C=4000、束宽5；附录D表6平均压缩时间Adaptive .114s、LLMLingua .510s，未计训练/教师/完整服务账。模型中源用于产生单一压缩提示，后续交互回访原库不在动作集；未报告源/索引淘汰、冷IO及尾延迟。草案按问题先取粗后回源属于不同权限类；可引用对查询可见性、平均预算和答案泄漏的限定性比较。
