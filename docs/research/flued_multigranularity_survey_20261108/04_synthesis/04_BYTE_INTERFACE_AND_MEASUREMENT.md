# 字节接口与测量：独立综述的研究骨架

2026-11-08｜sol 专题综合。本文为后续独立字节综述建立比较坐标、证据边界和判别决策，不提前写成第二篇完整综述，也不裁定 FLUED 新架构。

## 1. 核心判断：先分清模型在什么单位上做什么

1. **字节输入、字节输出、内部字节级计算、字节监督是四件事。** ByT5、BLT、MrT5、MAGNET 都与字节有关，但分别涉及双向编码、潜在块、编码端删除和脚本条件切分；DTP 的原实验是字符而非 UTF-8 字节；UBE 最终仍是子词模型。把它们合称“byte 模型”后直接排总榜，会把可见性、先验和计算位置一起混入。〔机制事实：W0351、W0010、W0511、W0510、W0007、W0359；比较推论〕[^W0351][^W0010][^W0511][^W0510][^W0007][^W0359]
2. **取消词表覆盖障碍，不等于取消跨语言资源差异。** UTF-8 对相同语义内容仍产生不等长序列；同 token、同原文、同语义、同算力分别回答不同问题。已有支持和反例足以拒绝“byte 天然公平/天然更优”，却不足以推出字节路线普遍劣于子词。〔数据与综合：W0361、W0363、W0356、W0516〕[^W0361][^W0363][^W0356][^W0516]
3. **输入输出矩阵绑定、编解码输入嵌入共享、主干层共享、余弦输出是不同轴。** ByT5-Large 已核的公开配置支持“两个输入端共享、解码输入与输出头不共享”，不是“不共享任何权重”，也不是“全模型绑定”。外部 token 模型的梯度偏置不能直接裁定 257 类字节接口。〔限定静态核查与经验：W0351、W0366〕[^W0351][^W0366]
4. **UTF-8 合法、目标字符正确、来源召回、最终内容依赖不能相互替代。** 字节回退模型可能拥有较低损失而仍生成非法字符；探针或干预优化器也可能表现很好，却未证明自然预测经过所称内容通道。〔数据、反例及争论：W0509、W0372、W0530、W0534/W0535〕[^W0509][^W0372][^W0530][^W0534][^W0535]
5. **现有外部材料可支持一套待验证仪器，不能认证 FLUED 字节长程消费已成立。** 内部 R2/R3 是 token 域；C64 同时改变粒度、替换及地址广播；H-sup 只量收官点梯度。它们分别留下接口、算子和训练史的竞争解释，不能由外部近邻成功予以免责。内部事实以 [边界表§“必须随引用携带的边界”](../00_scope/INTERNAL_EVIDENCE_BOUNDARIES.md)及其 CURRENT_STATE/草案定位为准；仪器的外部依据见 W0050、W0374、W0530。[^W0050][^W0374][^W0530]

## 2. 四种单位与因果可见性：不按名称分类

这里 token 指分词器产生的模型符号；Unicode 码点是编码编号，字素是用户通常感知的一个字符单元，二者和 UTF-8 字节都不等价。下表中“监督”同时记录预测对象与额外训练信息，不把无人工标签等同于无先验。

| 路线及证据 | 输入／输出 | 内部计算或压缩单位 | 监督与可见性 | 对本题有用的区别 |
|---|---|---|---|---|
| ByT5，W0351 | UTF-8 字节／字节 | 主要仍为逐字节位置，编码器较深 | 遮蔽跨度恢复；编码端双向，解码端自回归 | 没有查询后原源回访；不能代证因果前缀字节记忆 |
| CANINE、DTP，W0360/W0007 | 前者码点输入；后者字符预测 | 下采样／连续字符段 | CANINE-S 仍借子词目标；DTP 有子词边界、熵或任务梯度方案 | “不先分子词”不代表训练目标或边界不借外部结构 |
| BLT，W0010 | 字节／字节 | 局部字节路径＋全局可变块 | 下一字节损失；另训因果熵模型选块 | 熵教师与主干非联合；局部细路径不等于任意历史源可寻址 |
| H-Net，W0011 | 字节／字节 | 选中位置的状态进入上层，可递归 | 主任务、比例损失及梯度近似；因果前缀 | 不是段内平均；上采样、残差和来源回访不同 |
| MrT5，W0511 | 字节／字节 | 第三编码层后软训、硬删位置 | 双向跨度恢复；问题可参与删门输入 | 下游存活状态不等于原字节仍可读取 |
| MAGNET，W0510 | 字节／字节 | 脚本专用预测器决定动态段 | 下一字节＋段数先验；单脚本身份可见 | 脚本标签及整句选择权限须计入；混写未解决 |
| Local Byte Fusion，W0514 | 源字节／译文字节 | 卷积融合或词跨度掩码，之后仍给完整字节序列 | 翻译交叉熵；编码器见完整源句，Moses 预分词 | 融合不是持久压缩；中文词界可能另需分词器 |
| UBE，W0359 | 路由编码后 BPE 子词／子词 | UTF-8/UTF-16 双字母表后再学合并 | 确定编码＋离线 BPE＋下一 token | 不是原生字节模型；编码可逆不保证任意生成流合法 |
| MambaByte，W0352 | 字节／字节 | 固定大小递归状态 | 下一字节；严格前缀，推测解码另含子词草拟器 | 选择性更新不是来源地址；加速器和验证目标需另记 |

各行的原文节表见对应定位。[^W0351][^W0360][^W0007][^W0010][^W0011][^W0511][^W0510][^W0514][^W0359][^W0352]

**比较结论。** 研究“字节接口”的独立作用时，应固定内部保存与读取机制，再变输入/输出接口；研究“字节压缩”的作用时，应固定接口，再变边界、聚合和读取。不能把一个双向问答编码器与一个因果生成器的差距称为接口效应。BLT 与 H-Net 的局部细路径和多尺度前向值得比较，但它们本身没有证明草案要求的查询后原源回访；因此“内部有粗细层”不是多粒度来源访问的完成标准。〔综合推论：W0010、W0011、W0511〕[^W0010][^W0011][^W0511]

**监督单位也必须拆开。** 平均每字节交叉熵、每 token 损失、每字符目标、每跨度恢复、每边界辅助损失不可直接共用相同数值权重：每批目标数、掩码跨度、语言编码长度和损失求和/均值都会改变优化压力。ByT5 的平均 20 字节遮蔽跨度不是 mT5 的三个子词；W0356 前 30% 步骤预测四字节无序包，不能描述成全程逐字节下一步训练。若后续比较梯度，必须同时记录目标数、约简方式、任务权重和训练时点。最后一项是本稿的测量建议，不是这些论文完成过的正交实验。[^W0351][^W0356]

## 3. 共享权重：以实际张量和公式说话

设输入嵌入行为 `e_i`，输出隐藏态为 `h`。点积绑定是 `logit_i = e_iᵀh + b_i`；余弦输出则是 `logit_i = α·cos(e_i,h) + b_i`。后者还引入归一化及尺度 α，不能当作前者只改一个共享开关。共享矩阵的梯度可按输入、输出路径相加，但路径梯度范数的占比不是优化器实际更新贡献的比例，也不决定下游收益。〔形式区分及经验边界：W0366；FLUED 对应项见内部边界〕[^W0366]

后续综述和实现核查应逐项填表，而非只填 `tied=True/False`：

- 编码输入与解码输入是否是同一张表；
- 解码输入表与输出分类矩阵是否同一参数，输出偏置是否独立；
- 编码器、解码器的注意力/前馈层是否共享；
- 输出是否归一化、尺度是否可学、输入与输出路径梯度是否额外缩放。

**已能纠正的历史说法。** W0351 所核 ByT5-Large 的 `Bitransformer.shared_embedding=True` 与 `decoder/...shared_embedding_and_softmax_weights=False` 分别回答前两问；配置为 XNLI 微调，所对照固定代码提交未被证明就是论文训练依赖，其他大小和转换版不能自动继承。这项限定核查又经阅读红队 R1 §3.7 支持。[^W0351]

**不能据此选边。** W0366 报告 token 绑定模型偏向输出空间，早期输出梯度范数较大；输入梯度乘五后，部分指标改善、部分变差，且含单次运行与底座/数据差异。它足以要求保留共享与训练动态的竞争解释，不足以支持“解绑必修复”或“共享已被洗清”。若要把接口归因推进一步，先静态核本地真实张量别名、归一化与损失路径；只有主张效果时才需要后续独立对照，本任务不启动该对照。[^W0366]

## 4. 原文跨度与预算：至少保留两条主比较线

### 4.1 不强迫一张表同时匹配互相冲突的资源

| 比较合同 | 固定什么 | 能回答什么 | 必须另报什么 |
|---|---|---|---|
| **同原文诊断** | 同文档版本、完全相同字节串/源跨度、问题与证据位置、源保留权限 | 换接口或读取机制后，同一内容哪里失效 | 实际位置数、算量、时间可能不同 |
| **同资源部署前沿** | 固定训练或推理资源上限，画质量—实际成本曲线 | 哪条路线在该负载下更实用 | 各自实际看到的原文及语种份额可能不同 |
| **平行语义补充** | 同义译文或原生等难任务，分列翻译/自然性审查 | 相似任务的跨语资源负担和成功率 | 不同语言字节数、语法和任务难度本来就不同 |

这一区分由证据直接迫出：ByT5 固定输入位置时约只见 mT5 四分之一原文；TokSuite 同 token 主实验的原文字节相差很大，补做同文仅覆盖四种分词器；W0363 用平行句无截断控制内容，但任务预知、单槽且模型参数不完全相同；W0356 同参数与同训练算力的排序也不同。不能选择最有利合同替换其余合同。[^W0351][^W0518][^W0363][^W0356]

**最少账本。** 每个配置记录原始采样量、去重内容量、过滤后量、打包/截断后实际监督字节及逐语言份额；另列输入位置、输出位置、潜向量数、重复遍数。W0516 的打包丢弃随 tokenizer 变化，说明“同语料混合＋同抽样”不代表实际看到同文。空间账区分原源、索引、原始键值、压缩状态和副本；时间账含预处理、边界/熵教师、标签生成、训练、路由、冷/热搬运及输出。BLT 的理论总式未单列熵模型；WiscKey 已读机制显示指针查找后仍要取值、回收还会搬迁值。后者只作系统参照，不把其未读后半实测作为字节系统性能证据。[^W0516][^W0010][^W0442]

### 4.2 损失单位与“精确字节概率”不能偷换

对原始文本字节串 `x`，给定 tokenizer 路径 `τ(x)=(t₁,…,tₘ)`，可报告

`路径 BPB = −Σᵢ log₂ p(tᵢ | t<i) / |x|bytes`。

直接字节自回归模型的对应量是逐字节概率链；子词模型上述量通常是指定切分路径的似然，不自动等于所有可解码为同一文本的 token 序列概率之和。有限上下文、结束符和非一一映射还需固定协议。W0011 明确保留贪心分词 BPB 近似的限制，TokSuite 的精确字节概率计算代价也显著不同。完整可逆编码的熵不变性不能推出有限模型、有限窗口的损失相同。〔作者限制与形式推论：W0011、W0518、W0356〕[^W0011][^W0518][^W0356]

因此：

- 不跨 tokenizer 直接比较每 token 困惑度；同一测试文本、同上下文权限的原字节归一化损失更可解释。
- 跨语言 BPB 不是“同语义单位难度”：同一句平行内容的字节数可差很多，补报每句总比特、逐任务准确率及资源负担。W0516 用原始 UTF-8 分母，平行句分析也显示此差别。[^W0516]
- 若规范化、忽略坏字节、过滤或插入空格改变原文，标明损失究竟对应哪个字符串。以原字节分母归一化不可逆转换后目标的损失，不是对原文的严格无损码长。ByT5 `errors='ignore'` 和 UBE 的处理后文本边界都不能省略。[^W0351][^W0359]

## 5. 多语公平：覆盖、负担、能力、来源四账分开

**公平至少有四个可测对象：符号能否覆盖、同内容用了多少位置/资源、最终任务质量、哪些语言/来源更易被漏掉。** W0361 中字节与码点也有同义内容长度差；W0513 中降低长度不均并未让所有理解指标最好；W0360 在不同任务、语言和基线训练时长下有排序反转。不能把更低长度基尼系数直接称为能力公平。[^W0361][^W0513][^W0360]

建议用下列互补考场，而非求一个多语平均分：

| 要隔离的变化 | 现有证据能提供什么 | 本课题仍须加什么 |
|---|---|---|
| 问题语言变、源与答案语言不变 | W0523 的 en-x 固定英语源和答案 | 精确证据替换；其有金标权限的离线归因不是部署检索器 |
| 同语源检索、不同脚本 | MIRACL：18语11文字系统、母语相关性标注 | 各库规模/训练量/未标相关不同；保留段ID和版本，召回后再测消费者 |
| 同脚本但不同语言 | mLongRR 五语均拉丁脚本 | 不称跨文字证据；逐针读取与数值比较分开，背景并非平行 |
| 原生日文跨度 | JGLUE/JSQuAD 的字符级评分与词边界问题 | 原字节偏移到统一字符跨度的映射；官方评分及规范化实现仍未审 |
| 中文长段、表格及格式 | CLongEval、LV-Eval 有段键、表行、诱饵与改名 | 正确证据是否被截断、输出格式与内容错误分账；未做等字节因果隔离 |
| 混合脚本与边界先验 | MAGNET 的脚本专用预测器，Local Byte Fusion 的外部词界 | 未见未来的脚本选择、代码切换、无空格文字与额外容量控制 |

定位：W0523 §2–3、W0524 §2–5、W0522 §3–4、W0528 §3.3、W0519 §3–4、W0520 §3–4、W0510 §2/附录D、W0514 §4.3/§9。[^W0523][^W0524][^W0522][^W0528][^W0519][^W0520][^W0510][^W0514]

**数据合同。** 分开记录问题语言、源语言、答案语言、脚本、混写和译文/原生来源；控制实体/数字类型、相对与绝对位置、证据跨度及词面重合。先固定源和输出语言改变问题语言，再改变源语言，比同时全换更易归因。日文最终用字符 F1，也不能消除训练时子词边界与答案跨度不匹配；字符、码点、字素、UTF-8 偏移映射须可追溯。〔设计推论：W0523、W0528、W0519〕[^W0523][^W0528][^W0519]

**拒答不等于自检。** OneRuler 同时包含真无目标和有目标允许答 none，显示误拒须独立统计；当前卡已视觉确认 Figure 14“无 None”标题与含 None 模板的展示冲突，但实际消融请求未取得。可用任务定义和误拒分类，暂不采用“去 none”量化消融来证明遗漏检测机制。旧审计的“尚未视觉核”已被后续卡补读更新，运行条件疑点却未解除。[^W0521]

## 6. UTF-8 分层：不要让编码冗余或输出清洗遮住任务

### 6.1 四个分开的结果

| 结果 | 它回答的问题 | 它不回答的问题 |
|---|---|---|
| 严格结构合法率 | 自由生成字节是否构成合法 UTF-8 | 是否为目标字符、是否使用来源 |
| 目标字符/原始字节精确率 | 是否生成了所需值 | 是先验猜中、局部补码，还是远程读取 |
| 来源定位/完整证据集召回 | 正确文档、跨度或所需多项是否进入部署读取 | 下游是否实际利用 |
| 内容特异行为 | 换掉目标内容时输出是否按预定反事实改变 | 干预是否无副损伤、该通道是否唯一 |

W0509 是带字节回退的 8k BPE 模型而非纯字节模型；其部分进度、严格合法和字符准确率不同。正文/附录报告常见字符严格合法 50.47%、罕见 30.24%，但 abs 摘要相反；当前卡复核 v1/v2 指定 PDF 页面，未见所查表翻转。故采用具体正文表、标明元数据冲突，不能讲成“新版证明稀有更容易”或整篇实验错误。局部补字符也不是字节长程来源消费。[^W0509]

### 6.2 最小分层与自锚地板

以下是建议仪器，不是已经验证的通用评分器：

- 分 ASCII、多字节首字节、续字节；续字节再按第二/第三/第四位置、已知前缀长度分组。严格合法检查还需处理过长编码、代理范围及最大码点，不能只检查 `10xxxxxx`。
- 每层单列脚本、字符频率、数字/实体、源距离和窗口切边；将合法文本中人为切断字符，与原始数据本就含坏字节区分。
- 至少比较前缀/位置/语言等廉价基线、等预算无源或错误源、正确源；每层原准确率 `a_s` 与同协议地板 `f_s` 同报，可补 `a_s−f_s`，但不把不同分层的地板混合成普适常数。
- 原始字节精确评分、合法解码后评分、任务允许的规范化评分分栏；NFC/NFD（组合/分解形式的 Unicode 规范化）、异体字、组合符、零宽连接符及数字原值分开。非法输出不能先静默忽略再算“成功”。

上述分层来自 W0509 的编码约束与前缀实验、W0518 的规范化/扰动结果，以及 W0528 的跨度障碍；本稿把它们组合为候选协议，没有证据表明某篇已完成全部控制。[^W0509][^W0518][^W0528]

内部既有续字节净超地板质量，只能排除那些指定读出成绩完全由首字节/字类地板解释；仍不是部署消费。R2 的 token 碎片分层也不转成原生字节模型证据。下一步要在**同一宿主、同一窗流、同一种子/硬件条件**中校准地板与干预，不能换卷后沿用旧阈值。此项为内部边界的继承，不是外部 W-ID 新结论。

## 7. 从离线探针到因果消费：哪些仪器能排除什么

### 7.1 四层证据，不把阴性解释过头

| 证据层 | 最少记录 | 何时不能升级 |
|---|---|---|
| 存储存在 | 存的究竟是原文、原始键值、压缩状态还是来源指针，保存期和位预算 | 指针不等内容；原文外置仍有访问成本 |
| 外接探针可恢复 | 冻结表示、读出器容量/标签、训练评测分割、地板及随机控制 | 成功只证该读出器能取；失败不证信息不存在 |
| 部署读取可用 | 实际查询、自然路由、返回内容及正确证据条件下表现 | 有答案权限的归因或另训强读者不等自然读者 |
| 最终特异依赖 | 目标内容替换、反事实答案变化、非目标保真及干预有效性 | 置零掉分不等内容收益；无下降也可能有冗余、旁路或无效手术 |

依据分别是 W0442 的地址/载荷、W0369 的探针控制、W0523 的归因权限、W0050 的依赖/效用/内容区别和 W0372 的恢复/副损伤反例；这是一张测量权限表，不是四级必须严格蕴含的定理。[^W0442][^W0369][^W0523][^W0050][^W0372]

**离线探针的最低控制。** 真实目标与按身份固定随机标签对照；身份重复与未见身份分报，按文档/来源族划分，多个标签随机表；线性与有限容量非线性读出分报。W0369 的随机任务按词型固定，不是每次出现重抽。高选择性仍不证部署消费；tuned lens（调谐透镜：用另训映射拟合后层输出分布）也只能说明拟合能力，不能把拟合早层预测当早层自然贡献。[^W0369][^W0366]

### 7.2 优先自然源替换，潜在状态手术作定位补充

| 对照或操作 | 主要区分 | 必须保留的约束 |
|---|---|---|
| 正确源／无源／同类型错误源 | 通道依赖与正确内容收益 | 错源需审答案泄漏、词面捷径；接口、长度、位置和合法编码尽量配平 |
| 将源中目标值 A 合法改为 B，问题不变 | 输出是否随内容按预期改变 | 修订相关共指/约束使反事实世界自洽；另留未改目标作为保真检查 |
| 同长度无关源替换、同强度随机损伤 | 通用激活破坏、格式/长度副作用 | 随机同秩不等范数或分布距离相同；至少把损伤量单列 |
| 强制正确来源，再比较自然路由 | 载荷/消费者问题与地址问题 | 报强制读取权限与代价，不把 oracle（已知正确来源的诊断器）当部署能力 |
| 固定路由只换载荷；完整重算允许重新路由 | 固定地址下内容效应与全系统反应 | 两种估计对象分报；换源后不能无说明地只冻结有利的后续路径 |
| 互补源联合替换、冗余源成组干预 | 单项删除无效的歧义 | 记全组合预算；非加性不能靠单项效应相加消除 |
| 完整组件替换与子空间替换并列 | 模块级与学得方向级解释的分歧 | 子空间成功后仍须身份/模板留出、自然输入替换及非目标检查 |

这是待实施的判别设计。直接依据是 W0050 的错源/常量比较、W0372/W0374 的选择性限制、W0534/W0535 的模块与子空间争议；不是上述作品已经共同完成的统一协议。[^W0050][^W0372][^W0374][^W0534][^W0535]

**负对照也要允许正结果。** W0050 已读主表中正确检索文档优于另一问题的供体文档，而供体又能提高某些 F1；不能据此说“任意向量一样”。该文另训常量/无记忆参考有价值，但比较的是改变训练后的系统，不能与同模型推理时替换的效应混称一类因果量。九系统训练预算与缺失数值补充未闭合，不在本稿作架构排名。[^W0050]

### 7.3 B26 改变了什么：可靠性不只检查“删干净没”

- **LEACE 对齐删除目标，不认证自然机制。** 它在指定分布、有限二阶矩和仿射映射内给线性/凸损失口径的消除与最小扰动结果；不是所有非线性信息消失。样本估计不自动保证测试分布，稳定化实现还不同于理想斜投影。可借其受控删除目标，但字节合法性、非目标语义和后续恢复仍须另测。〔作者理论条件与限制，W0532〕[^W0532]
- **CausalGym 迫使检查干预器自身能力。** DAS（分布式对齐搜索：冻结模型、用反事实标签学习激活替换方向）在任意目标标签和随机初始化上也可能有效；扣除控制后方法排序能变。原模型任务不高于机会时，成功干预不证明其原本拥有该能力。其控制选择性与 W0374 的非目标保真不是同一指标，二者应并列而非互代。〔反例，W0530；操作定义，W0374〕[^W0530][^W0374]
- **W0534/W0535 的争论不能单边收束。** 一方构造休眠/零空间方向与下游有效方向混合后产生成功 patch，另一方认为某些现象可解释为分布式因果抽象，并要求跨输入泛化。双方还争论模块边界和原计算忠实性，不只是命名。高概率差不等交换答案成功；单对拟合再同对评价尤其弱。保留二者的定义和实证边界，不引用尚待核的 W0534 附录推步作为普遍保证，也不把两篇当独立复现。〔构造、反例、作者回应与本稿决策〕[^W0534][^W0535]

据此，候选验收至少并报：基行为超过相应地板、目标干预有效性、非目标保真、留出身份/模板泛化、任意标签控制、随机方向/初始化、扰动范数、概率与精确反事实答案。自然源替换是对部署内容依赖的较直接检验；它仍需世界自洽与副作用控制，不是免审因果金标。〔综合推论：W0530、W0374、W0534/W0535〕[^W0530][^W0374][^W0534][^W0535]

## 8. 研究决策：结果应怎样改变下一步

下表是给后续研究的低成本顺序；当前只整理合同和公开证据，不训练，也不预先规定通过阈值。阈值须在目标窗流、语言、硬件及阶段中另行预注册。

| 竞争解释或缺口 | 最便宜的判别动作 | 结果怎样改变选择 |
|---|---|---|
| 差距来自原文暴露量，而非接口 | 先审公开配置、过滤/打包与同文表；在后续计划中分同文和同资源两线 | 同文追平而同预算差：优先改吞吐/覆盖，不归罪保存能力；两线均差才继续拆内部机制。依据 W0351/W0516/W0518 |
| 小字节词表共享或输出几何限制了优化 | 静态核参数别名、点积/余弦/尺度和损失约简；不先做多模块大改 | 若配置不符，先修实验身份；若配置相符仍无单变量证据，H-tie 保持候选。依据 W0351/W0366 |
| 高字节分数主要来自局部 UTF-8 冗余 | 按首/续位、前缀与脚本重算既有输出并自锚地板 | 净增益只在局部补码：不能升长程消费；续位也超地板仍须做源替换。依据 W0509/W0369 |
| 正确源已到达但消费者不会用 | 强制正确源与自然路由分开，再用合法内容替换检查预期答案 | 强制源也无效先查表示/消费/任务；强制有效而自然无效先修路由，不先加更深摘要。依据 W0523/W0050 |
| 干预方向在“写答案”而非揭示自然通道 | 留出身份/模板、任意标签/初始化、完整组件与自然输入配对 | 只训练目标概率变而精确反事实失败，降为干预可控性；自然替换和保真均过才增强内容证据。依据 W0530/W0534/W0535 |
| 多语差距来自指令、脚本标签或格式 | 固定源/答案只换问题；加入混写、字符跨度和格式检查 | 指令或格式解释主要差距时先修合同；不能把差距全部叫长程遗忘。依据 W0521/W0523/W0528/W0519 |
| 平均召回掩盖困难题；返回 ID 被误当消费 | 先用已读定义加逐题召回分布和完整证据集，不等大复现 | 若尾部集中失效，平均达标不足验收；W0473 的未读应用后半不能证明最终质量因果改善 |
| 指针、教师或回访成本吃掉收益 | 列完整调用/空间账；先从现有运行材料辨别缺项 | 只热缓存多问有益则限定负载；成本未报则不宣称净加速。依据 W0442/W0467/W0010 |

证据及范围见脚注。[^W0351][^W0516][^W0518][^W0366][^W0509][^W0369][^W0523][^W0050][^W0530][^W0534][^W0535][^W0521][^W0528][^W0519][^W0473][^W0442][^W0467][^W0010]

B25 的补证对本题的作用很具体：W0475 已读部分说明保持既定评分 top-k 与覆盖语义必要事实不是同一保证；W0467 的真实近邻标签、初始搜索要付费；W0473 的逐题阈值覆盖不是每题保证；W0442 的地址/载荷分离并未让取值和回收消失。四卡在本稿读取时均有明确 PARTIAL 范围，故只引用已读机制/定义，不引用未读表格、后半 RAG 应用或完整性能结论。它们约束评价与成本合同，不是字节接口的直接效果证据。[^W0475][^W0467][^W0473][^W0442]

### 9.2 必须定向扩大，而非继续堆模型名

1. **字节长程内容消费仍未闭合。** 需要同原文/同源权限下，正确源、同类型等长错源、无源及自洽值替换，与 UTF-8 分层、自然路由和最终预测组成同一协议。现卡各自解决其中局部，没有材料足以宣称整个协议已被公共实证验证。这是继续调查的具体理由，不是“已证文献空白”。优先追公开工件能否补齐，而非再加一张总平均榜。
2. **多语评分实现与偏移必须可核。** 定向审 JGLUE 的字符评分/规范化与字节—字符跨度映射；MIRACL 评分实现及其召回公式口径；OneRuler 实际无 none 请求。若要用准确语言排名，再核逐语言有效分母、截断与缺输出处理。W0524 的印刷式疑点不在本稿被判为实现错误。
3. **共享结论需跨配置验证。** 现有 ByT5 核查仅 Large 公开微调配置；FLUED 的小词表、余弦/尺度和路径梯度没有对应的干净长程单变量证据。先补身份和实现，不把 token 域经验或收官梯度当训练全史。
4. **干预表达力争议需工件级配对。** 追 W0534/W0535 的实际留出、零空间分解和完整组件控制，并把 W0530 任意标签控制与 W0374 非目标保真对齐。尚未核销的证明不承重；即使证明补齐，也仍需目标字节任务的实证。
5. **成本缺项有决策后果。** B25 后半表格/应用、BLT 熵教师和边界标签总调用、冷/热源回访以及真实自回归延迟应定向补。没有同质量实际执行证据时，只能说减少理论计算或某项存储，不能称净加速；Fast BLT 的加载量估算与 MambaByte 的草拟器代价也应按同口径处理。[^W0014][^W0352]

**阶段收束条件。** 先取得足以决定上述合同的原文/工件证据；若某决定性材料仍无，明确其限制并保留对应实验义务，而非用更多 FULL 抵消。独立综述可以据此展开接口谱系、共享训练和多语测量三条线，但不能提前收成“字节免责”或“字节必败”的第二篇结论。
