# 实验决策矩阵：H1–H5仍为候选

2026-11-08｜配套[总报告](REPORT.md)、[执行摘要](EXECUTIVE_SUMMARY.md)、[缺口账](EVIDENCE_GAPS.md)。本文件是后续研究设计，不是已冻结任务书：**不规定通过阈值、样本量、种子数、宿主规模或算力，不授权训练、执行或修改内部预注册。** 文献数与FULL状态不作为实验通过线。

## 1. 推荐顺序及进入条件

| 次序 | 要先回答的问题 | 最便宜动作；不预先要求训练 | 进入下一步的条件与停点 |
|---|---|---|---|
| 0 | 题目及测量是否可判读 | 钉原始源版本、保存权限、query时序、答案、偏移/编码、合法反事实；核原样回放和正确细源阳性锚 | 阳性锚不工作，先修任务/接口/仪器，不靠增层或增槽掩盖 |
| 1 | H2：更细来源在正确位置是否有用 | 自然/已知正确地址×压缩/原细载荷四格；正确、错源、无源和自洽值替换 | 定位、载荷、绑定、消费分叉可解释后，再谈结构净值 |
| 2 | H1：层级本身是否值得 | 草案四臂＋同源强平层回访，先固定块、固定读者和深度 | 平层追平就不强制层级；保留回访价值与粒度价值的区别 |
| 与1/2同步 | H3：路由省下的是否大于付出的 | 建构建/持有/查询/维护账，冷/热、多问/更新分开；所有失败探测计费 | 无同质量真实成本不宣布净省；只热负载有益就限定区域 |
| 3 | 边界/地址该怎样学 | 在基本回访有效后，同实际段长/额外更新预算比较固定、代理、任务学习 | 旧规则同适配追平则不归因新信号；一次只改一轴 |
| 4 | H4：效用头是否改善自主选择 | 小动作真实组合、受控后续与闭环分别量，再与廉价策略比 | 无实际决策差异不先训头；简单策略追平则暂缓复杂控制 |
| 5 | H5：可读内容不变时能否少算 | 固定掩码，稠密算后遮蔽vs真稀疏执行，再考虑学习/重入/循环 | 内核和刷新无净省则不进入更复杂门控；正常生成质量/缓存须同配 |

## 2. 所有比较共享的合同

### 2.1 两条比较线，不强凑一张完全等量表

- **同内容诊断**：同一原始字节串、源版本/权限、问题、证据位置、消费者、精度；逐项改变保存、地址或读取。实际FLOPs和时间可不同，分别记录。FLOPs指浮点运算次数，不是实际延迟。
- **同资源部署前沿**：给共同总存储、训练/推理资源和服务条件，各方案选合适配置，画质量随真实预算的前沿。原文覆盖和内容可不同，但必须公开；不能只匹配参数、活动状态或最终上下文长度。
- **已知正确来源定位**仅作诊断：可叫oracle，即事先知道目标位置的参照，不是可部署策略，也不是任何消费者的答案上界。
- 先固定深度和边界，不同时引入接口、层级、效用、循环和损失；保持不动项与新增权限逐臂列清。

### 2.2 最小来源与测量记录

每个源有稳定ID、版本、原字节跨度、有效/失效与访问权限；派生物有输入版本、模型/分词/生成规则版本和反向依赖。原文、原KV、提取事实、累计状态和指针分开；KV是模型的键值状态，不等原始字节。query为读取时问题，金标为训练/评估参考答案，二者可见时点分列。

每次请求保留允许范围内的源→候选→精排→最终载荷→答案路径。分别量：源合法可取、完整证据集召回、打包后覆盖、正确证据条件下答案、正确/错源特异差、反事实答案、非目标保真。探针能力、部署读取和最终内容依赖不合并。零化、随机同秩和常量通道各有副损伤，不是万能阴性/阳性证书。W0050仅采用已读定义/主表，缺失补充不承重；W0530/W0534/W0535要求干预器控制。

## 3. H1：固定总预算的多粒度访问净值

**候选预测**：在同时需要概括与稀有细节的查询族中，多粒度可改善质量—总成本前沿。**竞争解释**：更多原源/副本、候选、调用、强读者、训练或过滤干扰带来提升，不是粒度本身。

| 项目 | 最小设计 |
|---|---|
| 核心臂 | 真全源访问；均匀压缩；层级不回访；层级按query回访；**同源强平层回访**。另有全层平铺与树导航可作局部比较，不强制都进入首轮大规模训练 |
| 不可省的强对照 | 任务适合的词法搜索、强精排/重排；不能只用弱单向量top-k。top-k为按给定分数取前k项；各臂实际候选/调用要计费 |
| 归因控制 | 同源保存期限/精度；总位数含地址、摘要、原KV和副本；同消费者；边界/段长与更多训练分开 |
| 考场 | 同文档概括＋随机精确值；多实体归属；跨父互补；稀有例外；晚到问题；另加时间更新合同 |
| 必看结果 | 绝对质量与每任务类型前沿、错误/空返回全分母、内容特异效应、冷/热及构建摊销 |

**结果分叉**：

- 平层同源回访同前沿追平：削弱层级独立收益，保留来源回访，不强制树或多级。
- 仅增加总状态后提升：先归容量扩张，不宣称分槽或粒度结构被证明更好。
- 只概括题提升、稀有细节失利：限定用途或混合路径，不能平均掩盖题型交换。
- 层级在同总账改善且正确内容干预有效：支持该宿主、查询族和负载下H1，仍不是普遍层级定理。

**证据锚**：W0162表3在Qwen2-7B-Instruct所选LongBench平均、同32倍压缩（非同总成本）有续训/微调排序反转，不代表统计显著或跨宿主定律；W0082附录I表14多层负例；W0449表4全局分母与全体不同；W0124附录10和W0156表2–3要求强平层但其预算也须匹配。不能直接用这些跨论文均值替代本实验。

## 4. H2：来源回访改善精确细节——先定位，后谈训练

| 地址／载荷 | 压缩载荷 | 原细载荷 |
|---|---|---|
| 自然路由 | 当前实际路径 | 仅换回细值，仍可能漏地址 |
| 已知正确地址 | 读者在理想定位下能否用压缩内容 | 任务/消费者/仪器阳性锚；权限/代价单列 |

**竞争解释与结果分叉**：

| 观察 | 优先解释/行动 | 不允许的结论 |
|---|---|---|
| 正确地址＋压缩有效，自然无效 | 先查粗剪枝、索引、桥接和打包，固定载荷只换路由 | 压缩把所有信息丢了 |
| 正确地址＋压缩差，原细值好 | 先修载荷、实体值绑定或保留来源，固定地址换值 | 一定只能增加网络深度 |
| 两轴联合才救回 | 记录交互项，别争唯一主凶 | 地址/载荷单项效应可以相加 |
| 原细源也无特异收益 | 核编码、位置、任务难度、读者和干预有效性 | 全部来源回访无用 |
| 探针好、自然读者差 | 读者权限/训练与部署接口不同，核实际query绑定 | 已完成自然消费；或所有信息都没存 |
| 删除单源不变、联合删除改变 | 查冗余/互补源和逃逸通道 | 单项无效便是源无用 |

源内容干预优先用合法A→B值替换、配平错源及未改目标，保持反事实世界自洽；固定路由与允许闭环重新路由分报。精细键广播同一块均值与精细独立值不同，重复键、跨实体和时间版本必须进入考场。

**证据锚**：W0138表1/4只要点vs回页的正例；W0197 §3地标value为零的地址门；W0174 §4先粗索引后原值；W0229 §3–4键Gram/值统计；W0050 §3/5区分通道损伤、训练收益与内容收益。四格是本稿设计，不声称文献已经完整隔离。

## 5. H3：低成本路由是否真正回本

| 维度 | 必须测/比什么 | 结果如何改变选择 |
|---|---|---|
| 路由 | 固定k、廉价置信/统计规则、等费用随机扩搜、词法/向量独立入口、层级、学习触发 | 简单规则同前沿则暂缓复杂头；只换第二入口有效则优先入口，不把收益全给层级 |
| 遗漏 | 无摘要线索、隐含桥接、错父级、跨父互补；有遗漏未触发/触发未救/无遗漏误扩搜 | 自信漏证据集中则限制合同/拒答，平均准确率不足认证 |
| 系统 | 路由、排序、全局元数据、压紧聚散、I/O、原源加载/重算、生成、失败重复 | 理论少算但端到端不省：该实现/负载不支持H3 |
| 持有与维护 | 原文、索引、摘要、原KV、缓冲副本；构建、教师、更新、失效及回收 | 层级固定费高、每问费不低，则无多问自动回本理由 |
| 服务 | 冷单问/热多问，查询/更新率、并发、均值/尾部、超预算/拒答 | 仅高查询低更新有益就限定部署区间；不能用热结果代冷结果 |
| 风险合同 | 向量top-L平均漏率、完整证据遗漏、答案集合、单答案错误分开 | 校准后硬截断/漂移须重评；不把平均风险写每题保证 |

I/O指持久存储读取和设备间搬运。保证对象按W0471、W0459、W0324原假设，不自行相乘多级边际召回。共形风险控制W0324 v4 §2.1定理1/式6–9，须固定非增、右连续、有界损失族，联合可交换，且最保守端`L(λ_max)≤α`几乎必然。**先检查预算内是否存在合法可行端点**；没有则记录目标不可达/溢出，或另定义并校准拒答损失，不能默认加一个拒答就获得原保证。恒为1的损失族即使满足其余条件也无法达α=.1；硬截断/漂移后重核全部前提。ConANN具体score/停止实现未核，不用其精确加速作为保障支柱；W0467停止运算符方向亦未核，最好结果不迁为通用收益。

**证据锚**：W0162 §3.6实际线性元数据扫描；W0197附录G冷载；W0440 §8.7硬件/带宽交叉；W0442 §4.1小值扫描及回收反例；W0473 §2–3逐query召回达标比例与§5.3应用不等因果消费。

## 6. H4：效用排序、校准和闭环净值

**候选预测**：反事实统一动作效用（CBIU，项目现有动作后果监督机制）可帮助在资源受限下选择。**竞争解释**：只是支持重合/金标似然、模型容量、原策略状态适配或更多教师调用，未改真实闭环。

### 最小标签合同

| 估计对象 | 固定与重算 | 用途/限制 |
|---|---|---|
| 受控后续差 | 固定参数、源、外部评价及合法后续动作，使用可比较随机性 | 当前动作局部作用；后续路径因动作变非法时不能悄悄改成另一量 |
| 固定策略闭环差 | 固定策略函数，但动作后从新状态重新决策至终点 | 一次动作部署总后效，追加/减少调用全计 |
| 重训差 | 同起点与匹配训练预算重新训练有/无机制 | 适应与替代能力，不是某状态的一次标签 |

先用少量同历史状态量`∅、a、b、ab`和必要反序；覆盖冗余、互补、地址先行、摘要无提示。草案删除边际不等从空集加入边际。两臂随机耦合要保留正确边缘分布，不把不同路径第n个样本当同一事件。

**有效基线**：类均值/固定分配、廉价启发式、同预算随机、一步终局净收益、固定继续策略学习停止；确有迟发净益后再比多步。金标、全特征、候选完整叶、教师续行权限单列。训练、标签、部署三张预算；按来源/问题划分开发、校准、最终评价，不将同轨迹前缀拆到两侧。

**指标与分叉**：成对排序、正负收益校准、选中动作相对同历史最佳合法动作的后悔值、闭环质量—成本前沿；预算/任务/长度迁移分直接转移与重校准。AUC即排序曲线下面积，高AUC但昂贵误选仍多不算成功。旧策略有效新状态崩溃，先修支持覆盖/校准；简单策略追平，不保留复杂头；互补或先地址后值带来可重复净益，才支持非短视增强。

**证据锚**：W0483异或例2.2.2；W0487 §3–9一步价值的条件及有限期边界；W0507 §3/附录A金标代理、截零与新颖性；W0455 §4每前缀八次作答/固定续行；W0339 PARTIAL仅v2已读Method；W0496/W0497、W0498状态分布/支持与教师续行差异。W0483以R4修复符号为准，不使用R3错误解除；W0313极限/AFABench精确常数均不拿来冻结阈值。

## 7. H5：同实际延迟的Copy/Transform净值

先回答功能与执行，再回答学习。Copy是不更新指定状态，Transform是昂贵变换，二者不自动保证保持者仍可被任意层读取。

| 阶段 | 最小比较 | 排除什么混杂/何时停止 |
|---|---|---|
| 执行可行性 | 固定载荷、读取集和掩码，稠密算后遮蔽vs先选后稀疏执行；核数值相容与算子是否跳过 | 聚散、KV/同步吃尽节省，则先停复杂门控训练；不把零系数当零执行 |
| 活动分配 | 等距静态、随机同预算、学习集合；同源与可读缓存 | 静态追平就保简单；新增容量/训练单列 |
| 重入 | 不重入、保旧状态重入、重入时刷新/补必要KV | 状态年龄、版本、依赖传播与刷新成本；视觉旧特征成功不代证因果字节免刷新 |
| 循环 | 固定循环vs自适应退出，同参数/数据及各缓存方案分报 | 质量/速度不得跨缓存搭配；预录出口重放只证调度，不证正常生成 |
| 长窗生存 | 长窗、多页、延迟重激活、负载切换 | 不在短窗冗余上裁定组件普遍无用；长程收益也要真实延迟过账 |

**证据锚**：W0287跨深度混合并未跳子层；W0292回放/打乱只测输入特异性；W0298双向轻重路径实速正例；W0262部分任务无稳定生成加速；W0270吞吐排除KV更新时间；W0274缓存质量和预录出口错配；W0278具体引擎优化非普通Transformer同质量胜出。

## 8. 共同考场与字节迁移

| 考场 | 需要分开的失败 | 必要控制 |
|---|---|---|
| 精确数字/实体归属 | 值没留、地址错、绑定错、输出格式错 | 未见身份、同类数值错源、自洽改值、原细源阳性 |
| 概括＋稀有例外 | 摘要省略合理vs后到任务必须 | 同源概括与细节题，不能只平均 |
| 多跳/跨父 | 单项零收益vs联合有用、打包缺一项 | 完整证据集、两项/联合和反序，不只至少一段相关 |
| 时间更正/撤销 | 有效时间、获知时间、生成版本、旧缓存复活 | 反向依赖、替代支持、一致快照；物理全擦除可另立目标，不删除逻辑失效任务 |
| 字节/多脚本 | UTF-8合法、目标值正确、召回、消费不同 | 同原始字节，ASCII/首/续位自锚地板；原字节、码点/规范化评分和偏移并列 |
| 迁移/服务 | 换预算/任务、冷/热、硬件体制 | 同机同环境同卷判读；旧阈值不得搬用，补资源前沿 |

内部R2/R3仅token域，C64未分离粒度/替换/广播，H-sup仅收官局部梯度，详[内部边界](../00_scope/INTERNAL_EVIDENCE_BOUNDARIES.md)。不因本矩阵允许字节实验就视为已授权迁移。

### 8.1 关系阶次的独立判别，不以多跳取齐代替

信息粒度G、关系阶次r、加工深度L、外部时间四轴保持独立，地址另记。元数k是一个谓词接受多少对象，r在此按关系结果再作参数的嵌套定义；组合步骤s和对象数m也不等r。关系模式向量可再处理，与单个关系实例带身份/角色/来源可再引用分别考，不新增已验证假说编号。

| 设计变量 | 最小对照与控制 | 结果分叉/证据限制 |
|---|---|---|
| 任务r与推导步s | 同原子事实/读取预算，比二元链、组关系模式比较、关系实例再引用；匹配或分层报操作数、支持事实、标签熵/难度 | 多跳或更多规则获益不自动支持更高r；同事实池不等任务等难 |
