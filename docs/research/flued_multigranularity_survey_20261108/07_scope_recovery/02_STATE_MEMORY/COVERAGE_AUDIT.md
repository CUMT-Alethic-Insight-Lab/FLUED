## 1. 审计问题与范围

## 3. 覆盖了什么；哪里缺原始证据链

**已有足够局部证据可重综合**：有限状态/查询权限、键相关与值绑定、总状态与活动状态、多槽不等多粒度、压缩态和少量精确例外的区别。旧理论报告§3–4及G5已有有用对照，不应全部推倒重来。

**重心确实偏离**：旧02报告开头明定草案§2–4及H1–H3，其主体是来源、导航、回退和系统成本；这些内容本身有证据，但不是原始状态记忆轴的充分综述。旧01已讲回归和多槽，却尚未系统串起“原特征外积→残差修正→保持/擦除→长延迟干扰→可学读取”。因此应重综合已有材料，而不是把所有机制继续按“有没有回访”筛掉。

必须避免三种证据替换：

1. **容量措辞替代可学使用**：W0212是固定规则精确键余弦，W0245是特定随机键排序，W0061是有限状态复制；三者均不能独立支持“现实记忆失效主要是容量不足”。
2. **残差措辞替代未来效用**：W0207/W0237确有原始机制与消融，但它们支持当前拟合误差筛选，不支持未来未知查询的最优写入。原始特征/残差写入的基础W0199/W0201反而未读。
3. **时间措辞替代状态遗忘证据**：外部数据库版本/删除合同不回答递推状态怎样被后续写入覆盖。W0208快照、W0229非平稳回归有局部证据，但同键更新、应忘与应留冲突、长延迟多条目及未见查询的联合证据薄弱。

## 5. 不采用多粒度来源回访也值得研究的路线

1. **改写入而不是扩源**：比较直接外积、残差修正、协方差校正/预条件；目标是降低关联干扰，不保存原文。W0229已有统一框架，W0199/W0201待补原始对照。
2. **独立擦除与保持**：W0202、EDA分别改变门强度及擦除方向，MIRAS改变保持正则；重点是保住旧关联同时适应新事实，不是“忘得越少越好”。
3. **改善可学性**：距离课程、学习率、局部绑定构造、使相关性信号及时到达写门；W0088/W0213/Anatomy分别提供候选，不先假定应扩大容量。
4. **更有表达力的压缩状态**：W0242/W0234/W0217的线性/非线性在线学习记忆；必须计内更新与优化器状态，不借争议容量定理越级。
5. **同尺度分隔或稀疏更新**：W0204/W0214/W0211隔离互扰，未选状态不更新；仍需总位匹配和读写共址诊断，不要求层级。
6. **按时间尺度保存可读统计**：HiPPO式投影或带正则的递归回归；研究任务相关保持，而不是重建全部历史。
7. **有界精确键值例外**：W0237/W0207不需原文档案；但确实保留部分精细历史且有淘汰盲区，应与“只剩不可逆压缩态”的路线分开记账。
