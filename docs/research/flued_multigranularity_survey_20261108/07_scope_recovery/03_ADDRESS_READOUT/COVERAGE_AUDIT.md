## 1. 结论与审查边界

**本轴足以重写一份问题导向的机制综合，尚不足以裁定压缩表示为何没有成为实际可用记忆，也不足以把多粒度来源回访选为默认答案。** 现有资料对外积关联存储、段状态路由、粗索引与细载荷分离已有实质证据；不足处集中在查询携带的信息、原生多头独立读出、地址/内容的不同压缩规则、归一化造成的训练问题，以及跨层共享写入与跨层混合的差别。

## 4. R3：让粒度与替换/广播可判别

内部依据仅为边界表及现有综合：R2/R3是token域；C64同时改变写入值/地址与重复结构。已有离线解混或probe的监督、查询权限不等于原生读者。以下是建议，不改变预注册或任何阈值，不在本轮运行。

### 4.1 固定内容权限，先隔离算子

1. **真实恒等锚**：原K、原V、原更新时序、原query与尺度；验证接线回放。C=1但仍有新投影/归一化不算恒等。
2. **只换地址**：块内K用同一粗键，V保持逐项；再以原K、相同粗V反向对照。两者共同失败可能有交互，不能要求单边修复必活。
3. **只换载荷**：K保持原生，V块摘要广播；固定K后用同长度自然供体V和目标值自洽替换检验内容特异性。
4. **只变广播/计数**：同一块摘要用“每原位置重复”与“块内只写一次”比较，分别记录写入次数、delta覆盖、衰减、softmax分母及输出范数。递归重复更新不等于注意力中重复等键，不能直接套用合并恒等式。
5. **独立槽读取**：保持同一写入bank和总位数，用不同q逐槽读取、拼接后投影，与先平均/混状态再用共享q读取比较。若全路径线性且同q，前后混合可等价；真正差别可能来自q、非线性、归一化或门的位置。
6. **最后才扫粒度**：控制或分报查询密度、可见跨度、总槽数/总位、重复次数、训练算量；原方案C64→C8同时变这些量，阳性只能证明该手术有可用区间。

### 4.2 对应文献与判词

- **W0229**：Gram校正/岭回归为“读出器换了”的基尺；先报告原生q的表现，再报告额外监督或已知地址q。probe恢复而自然读为零时，优先查query与消费，不据此断定容量足够或训练可达。
- **W0197/W0174**：证明粗K可不替换V，是隔离地址与载荷的正面结构参照；但它们额外保有逐词元KV，必须记信息权限。
- **AsymKV（新增A03）**：§3.2是在已将两键替成同一键后，求和值并修正计数分母的等价；这给广播/合并的算子检查，不证明原始不同键的合并无损。
- **D-NTM（新增A02）**：§4.3直接报告只用固定地址部分、忽略内容部分的病态解，并提出读写一致性正则；是“不消费内容可能来自训练路径而非粒度”的实质反例线索。
- **W0214/W0204/W0219**：区分读写错址、共享q多态聚合、token块混合与真正独立头读出。不能把“多头”当已控制其他因子。
- **W0237**：小量精确例外+共享归一化是非全量替换的比较方案；它没有原文回访，但有限缓存也会漏。

至少并报原生读取结果、给定正确地址结果、离线读者结果、内容替换后预期答案变化和非目标损伤。强制地址仅用于定位错误，不是部署成功。新实验必须重新锚定同机同环境、同窗流，不从外文或旧种子搬成功阈值。

## 5. 不采用多粒度来源回访的替代路线

| 路线 | 改的是哪一处 | 现有依据与代价/未知 |
|---|---|---|
| Gram/岭回归或预条件化的原生关联记忆 | 在同一封闭状态中减少相关键解混误差 | W0229；须存统计/求解，正则化和训练可达另核；不是免费离线probe变部署 |
| 固定可学习地址与内容分区、读写一致性 | 避免把固定地址当额外参数旁路、改善写读共址 | D-NTM、RAM-Net；固定槽总量、冲突与离散优化仍受限 |
| 同尺度多记忆及真正独立读出 | 允许不同事实/头分离绑定，避免读前坍成同一向量 | MoM/RAM-Net，MHLA需精读；等总位下收益未知，不需要层级或原文指针 |
| 值侧重组织/擦写分离 | 改写入干扰，而不是加细检索树 | 已入未读W0203、W0202；本轮只核W0203摘要，不宣称已验证其内部作用 |
| 少量精确KV例外加压缩主体 | 对难保留关联不用统一有损替换 | W0237；是内部缓存非来源回访，依然有容量与淘汰错误 |
| 不对称K/V压缩及计数感知读取 | K和V用不同压缩规则，修正重复质量 | AsymKV；键替换本身近似，需保留分母和构建梯度成本 |
| 更明确的任务/位置/身份query | 让读者提出可执行的读取问题，不要求全部内容平均广播 | Perceiver IO；任务输入权限可能更强，非任意未来query保证 |
| 跨层复用同一KV、或跨层value/残差混合 | 在深度轴降低冗余或改善信息传递 | CLA、W0289、W0287；不是多个写者共享摘要的现成解，通信/陈旧状态和梯度耦合须单列 |

**首要补洞**：先补原生query与读写共址证据；把共享query聚合和真正独立槽读出分开；将重复广播的次数/归一化与内容压缩正交化。资料数量不能代替这些在原宿主上的辨别。
