## 1. How to use this matrix

Select the row whose possible outcomes could change the current explanation or decision. Do not run the whole matrix as a fixed program. “Priority” means dependency on a valid instrument and the intended claim, not an unconditional queue. An artifact review can reveal that a proposed experiment is unnecessary or presently uninterpretable. Existing checkpoints are not assumed to exist or contain the needed state. M13/M24/M29/M30 are **comparison families**, not single cheap experiments: begin with their stated first separable fork, and treat later fitting/training as separate conditional work.

### Action types and costs

- **AR — artifact/source review:** inspect specified source, configuration, tensor contract, or logs; no model learning. Cost is human/static verification work or permitted public-source acquisition, not a training budget.
- **EC — existing-checkpoint computation:** forward evaluation or interventions using an existing competent saved model. No weight updates; GPU/CPU inference, activation storage, and repeated draws still cost work.
- **EC-B — existing-checkpoint backward analysis:** fresh gradients, finite differences, or Hessian-vector products without updates. This is not forward-only and does not recover missing historical optimizer state.
- **FD — fitted diagnostic:** train a probe, q adapter, or connector while the main saved state/model is fixed. This adds labels, fitting, tuning, and selection. It is not native unmodified use and requires separate permission for fitting.
- **NT — new main-model training/continuation:** change formation history, objective, update operator, or adaptation. Explicit additional authorization is required. Existing-checkpoint diagnostics cannot establish these causal training effects.
- **WL — workload/lifecycle evaluation:** replay source updates or serving/action workloads with fixed artifacts where possible. New model learning, if introduced, must be reclassified as NT.

Costs below are relative dimensions, **not numerical estimates**: forward passes, retained activations, source calls, fitting/teacher work, main-model updates, storage, transfers, and construction. Equal raw bytes, token positions, FLOPs, latency, and retained physical state are different matching objectives. Record the actual quantities; do not claim all were matched when only one was.

### Shared interpretation prerequisites

A competent original, exact replay/sham, known-positive semantic content contrast, screened negative, and non-target integrity are prerequisites for interpreting a causal null. Keep analysis/selection data separate from final evaluation. Use the same underlying examination stream within a contrast; retain seed, task, stage, source/recipient version, hardware/environment, and scoring fingerprints. Numerical margins and sample sizes require task-specific calibration, not inheritance from another arm. A stopped/inconclusive arm is not a negative architectural result.
