## 4. Required full-reading return format and claim ceilings

For each accepted queue item, return one version-pinned card with:

1. Stable ID/title, source URL, exact revision/date, official venueid/status **at access**, anonymous-author handling, full/partial/blocked scope, and precise page/section/table locations actually read.
2. The **specific previous problem**; one-sentence proposed solution; each borrowed mechanism and its role; how slow parameters, state update, query/readout and any routing policy are learned.
3. Input/content/address/state/query granularity and visibility: query before/after context, finite protected queries, target-token oracle, teacher access, bidirectional vs causal, token vs byte, closed state vs growing source/KV. Retained memory includes metadata, covariance/optimizer state and example caches.
4. Author claim versus actual reported observation versus our inference, with negative results and failed transfers preserved. Separate approximate theorem, exact construction, empirical observation and mechanistic explanation.
5. Controls: state bits/precision, parameter and active/total memory, generic extra compute, same/self-host and random/constant source, matched budget vs tuned frontiers, original task vs diagnostic intervention, non-target damage, and training-history versus terminal ablation.
6. Cost and failure contract: full learning/adaptation/teacher/calibration expense, serving memory and bandwidth, update order, numerical stability, long-window/symbol/query shift boundaries, and missing artifacts. Do not assert all resources are matched because one budget is.
7. The specific hypothesis split it changes and what remains a **new experiment**. A successful probe/oracle/adapter is not natural deployment use, and literature cannot certify target-system causality.

A full card is not theorem/code certification. An abstract, extracted table fragment or inaccessible supplement must not receive FULL. If a table/figure is not readable, record exactly that and whether textual claims were available. Public reviews may locate contested assumptions but never stand in for the reported experiment or independent reproduction.
