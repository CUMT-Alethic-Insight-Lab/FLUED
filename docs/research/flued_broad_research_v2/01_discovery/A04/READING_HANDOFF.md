## 4. Minimum reading output contract

For each completed original reading, return:

1. Exact title, author list or retained official anonymity, immutable version/date, source URL and verified venue status. Metadata association is not word-for-word version identity.
2. Actual read range: body, appendices, proof text, figures, source code and numerical extraction separately. A downloaded PDF/abstract is not a full reading; proofs read are not proofs independently certified.
3. The **estimand**（估计目标：固定输入分布、干预分布与评分后要测的量）with explicit paired worlds, permissions, graph/interface, recomputed descendants and score direction.
4. Training/label/future-query access, granularity and all extra reader/adaptation capabilities. Separate original deployed model from a learned intervention, trained reference or edited model.
5. At least one primary counterexample/limitation to the paper's broadest takeaway; exact section/table/equation rather than generic warnings.
6. What would falsify the hypothesized interpretation, what would merely invalidate the instrument, and what survives a null intervention.
7. Costs: exact passes or retraining/search, annotation, model/donor access, all unreported cost quantities marked unknown. No experiments under this assignment.
