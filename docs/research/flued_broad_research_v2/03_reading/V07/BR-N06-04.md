**Problem / solution / role.** Can independently trained vision foundation models be combined despite different pretraining and representation coordinates? Train a small stitch module on the source intermediate tokens to match the target model's final features, optionally followed by downstream supervised task training (§§3–4). This borrows feature distillation as interface repair, not an unsupervised proof of semantic equivalence.

**Learning and access.** Source prefix and target suffix are frozen; stitch module alone is trainable in the declared experiments, and a downstream linear classifier or dense segmentation decoder is separately trained (§§3.1–3.2, Appendix A.2). Layer feature matching (LFM) minimizes same-image intermediate MSE; final feature matching (FFM) backpropagates final target-feature MSE through frozen suffix; task-loss training (TLT) sees downstream labels. Default stitch is tokenwise two-layer ReLU MLP; layers 2,6,10,14,18,22 of 24, same data and module. AdamW, up to 100 epochs, early stopping patience 5, LR in {0.001,0.005,0.01}, no augmentation (§3.2, App.A.2). Self-stitches insert the identical trainable module at the same source/target position, losses and data (§4.1); identical initialization seeds are **not specified in inspected text**. FFM has full target forward/feature extraction and frozen-suffix backward overhead, even though only stitch parameters update.

**Units.** Input is an image; content is per-image vision-patch feature sequence; output is class label, pixel classes or multimodal LM output. It does not implement temporal memory writing, long-range query addressing or source return; no causal-LM query visibility result follows.

**Observed versus interpreted.** §3.2: at layer 2, DINOv2→SigLIP2 TLT 25.1% vs DINOv2 linear probe 46.7, SigLIP2 53.5, LFM 49.4 and FFM 51.4. Local MSE may be small while final-feature mismatch is large. §5.1 reports classification self-stitch improvements 0.7–5.5 points and segmentation 0.5–0.7 mIoU in the tested setups. §5.2/Fig.6 explicitly excepts weaker CLIP as source: it can fail to match the stronger target. The authors hypothesize discarded task information; optimization and connector limits remain alternatives. §5.4 uses 1.1M generic images to train FFM and downstream linear probing, so inference is not task-zero-shot. §5.3 compares linear, MLP and LoRA source layer: capacity, inter-token mixing and initialization differ. VST §6/App.B.6 reports 45.5%/84.2% of the two-VFM incremental gain at 4.3%/39% extra *backbone* cost, not whole-system latency or training cost; separate latency measurement is on one A100, batch 1 (§6.2).

**Competing explanation and next contrast.** F.03–F.09/F.12/F.16/F.19 and D.01–D.02. Exact replay, identity/self-stitch and randomized matched-initialization cross-stitch, equal teacher passes/optimizer budgets, held-out tasks and weak-source tests would separate connector learning from coordinates/actual complementary information. Recovery is bounded compatibility, not proof of preserved shared semantics. The v3 PDF Table 1 also shows FFM+TLT at layer 2 yields 51.7 for DINOv2→SigLIP2 versus 25.1 for TLT alone and 33.1 for LFM+TLT; these strategies have different training stages, not equal total compute.
