# W0435 — Stateful Large Language Model Serving with Pensieve

**Status: FULL, arXiv:2312.05516v3, 7 October 2024**; v3 itself bears EuroSys 2025 publication metadata, DOI 10.1145/3689031.3696086; no separate proceedings/PDF equality asserted. [Original](https://arxiv.org/pdf/2312.05516v3); local `sources/W0435__2312.05516v3.pdf`, SHA-256 `75a18b92c99eb017288cdb01e7fee70162c5e8285b85b685214bea1c28811707`. Main text and evaluation read; no supplementary theorem required.

**Problem → solution.** Re-prefilling a growing multi-turn chat repeats work. Pensieve borrows hierarchical CPU/GPU caching, recency-based eviction, asynchronous prefetch and paged attention to reuse existing token K/V, recomputing dropped pieces from retained raw chat. It does not train a language model or predict semantic importance.

**Lifecycle and causal visibility (§3–4).** Retained content is layerwise KV for previous tokens; index is conversation and token/chunk location, not semantic retrieval. Chunk size 32, retention score profiled recomputation cost divided by time since conversation activity; leading chunks are cheaper to recompute and may be dropped from CPU. AOT copy begins below a free-slot threshold; layerwise restore overlaps compute, and persistent conversation raw tokens supply missing leading fragments. Kernel handles causal non-contiguous segments and mixed prefill/decode. Nominal 13B 40-layer/5120-width FP16 cost is ~0.78 MB per token (§3.2); model, CPU cache, transient buffers, raw source and PCIe all count. Safe reuse presumes identical preceding context and model parameters; source changes, model-version invalidation and deletion are not demonstrated protocols.

**Measured evidence (§6).** OPT-13B/66B and Llama-2-13B/70B; Azure A100-80GB, up to four GPUs and 220GB CPU memory per GPU; each system allocated 40GB/GPU cache. 13B Llama was changed to 10 KV heads. ShareGPT real conversations and synthetic UltraChat are replayed with simulated Poisson arrivals and think times, max context 16,384, with 0.57% of ShareGPT conversations dropped. At stated latency, OPT-13B ShareGPT throughput 1.36× vLLM/1.14× TensorRT; 70B 3.0×/2.47× at 400ms/token, versions and setup §6.1–6.3. GPU-only cache can lose to TensorRT at some OPT settings; CPU cache matters. Eviction policy vs LRU has similar performance until ~3 requests/s; above that up to 4.4pp higher CPU hits and 14.6% less recomputation (§6.6). Longer simulated think times diminish the advantage (§6.7). Latency metric has mean-versus-90th-percentile wording in §§6.1–6.2, so preserve ambiguity rather than infer an unreported p99. Evaluation is not an answer-quality or stale-replay test; full cost of persistent raw source, cold storage, network and failures is not itemized.

**Inference and alternatives.** Transparent exact-prefix reuse is a serving choice, not proof that a compact state learned to retain source semantics. Compare source-free recurrent state, full recompute, GPU-only, CPU tier and matched prefix cache under identical source/model/workload and answer checks, charging peak GPU+CPU+store, transfer and tail latency. Reversal: shorter sessions, cold misses, CPU/network contention or invalidation/recompute fanout erase the gain. Directions R.09–R.10, R.12, R.16; F.17–F.19.
