**Problem / one-sentence solution / technique.** Delta-rule correction preserves associations but cannot rapidly clear all state; adaptive global scalar decay and targeted delta correction are combined in one recurrent mixer (§§2–3). Borrowed fast-weight/online regression gives the corrective update; gated recurrence gives adaptive forgetting and WY matrix factorization provides chunk-parallel implementation, not additional memory supervision.

**Native operation and learning.** For a head `S∈R^(dv×dk)`, `S_t=α_t S_(t−1)(I−β_t k_t k_tᵀ)+β_t v_t k_tᵀ`, output `S_t q_t` (§3.1 eq.10). It first decays state, then writes a residual at the current key; global decay is not address-specific. q/k/v each use projection, causal short convolution and SiLU; q/k L2-normalized; α,β use projections; output normalization, SiLU output gate and projection (§3.4/Fig.1). Llama-style residual/MLP layers and optional sliding-window attention (SWA) are separate paths. Training is next-token prediction, with AdamW and no external retrieval labels; q at t sees only legal current/prefix representation. Hybrid H1 interleaves SWA; H2 adds Mamba2 and SWA, meaning recurrent-only and hybrid inference state are different.

**Theory and cost.** The delta component is one explicit gradient step for squared key→value regression, whereas Longhorn has a different implicit optimum (§3.1); the WY chunk derivation and Appendix A induction re-express the recurrence, not evidence that a trained model actually uses old facts. Per-head persistent main state is `dk×dv` plus convolution history; hybrid layers additionally retain window KV. No complete matched-byte/precision ledger or frozen/transplant experiment is provided in the extracted comparisons. Hardware throughput on H100 is measured with model-specific implementations; recurrent-only is ~2–3k tokens/s slower than Mamba2 (§4/Fig.3), not a universal decode measurement.

**Observations and controls.** §3.2 contrasts repeated-haystack S-NIAH-1, where pure DeltaNet nearly perfectly retains while Mamba2 degrades and GDN is intermediate, with essay distractors S-NIAH-2/3, where DeltaNet falls and gating helps. This is not a single controlled test of semantic filtering. §4 compares ~1.3B, 100B FineWeb-Edu tokens, 4K training, 2K hybrid SWA, with 400M additional models. PDF Table 2 shows at 8K passkey DeltaNet 98.8, Mamba2 30.4, GDN 91.8, while 4K essay-number is 18.6, 56.2 and 92.2 respectively; at 8K essay-number even GDN falls to 29.6. Real-world recall is input-truncated at 2K and recurrent/Transformer gap persists; repetition is the authors' hypothesis, not a demonstrated cause. Fig.2 reports mixed extrapolation up to 20K. At 400M/15B, Appendix B.2 Table S.1 shows full mixer 27.35 average PPL/47.26 average accuracy; naive delta 30.87/45.12, no short conv 28.95/46.16, no output gate 29.12/45.46, no output norm 27.55/47.07. L1+SiLU 30.18/46.09 versus L2+ReLU 27.67/46.94; head 256 gets better quality (27.13/47.38) than 128, so 128 is an efficiency tradeoff. Table S.2 (p.22, 500M/15B) compares four hybrid orders: Mamba2→GDN→SWA achieves average 48.73 versus 47.88, 47.54 and 47.92 for the other listed orders, with 23.54/24.11 Wiki/LAMBADA PPL. These are separate ablations, not full factorial crossings.
