**Problem / solution / borrowed techniques.** Sequence models hide different assumptions about what to memorize and forget; MIRAS frames model design as a choice of fast-memory architecture, associative inner loss, retention regularizer and online optimizer (§§3–5). It borrows robust regression, proximal and mirror/FTRL online optimization to generate alternatives—not an external fact retrieval scheme.

**Learning and state.** Project each current prefix token into key, value, query with short causal convolution; q/k are L2-normalized (§5.4). Inner gradients write model-produced key/value pairs into per-sequence fast weights; native read applies the fast model to q and downstream output/MLP predicts the next token. Outer learning is next-token prediction, not supervised old-fact labels. Moneta uses 2-layer width-4 MLP, Lp loss and Lq-style regularization/auxiliary A; authors instantiate p=3,q=4. Yaad uses a Huber-type L1/L2 mixture and L2 local/global retention. Memora uses squared regression and a simplex/KL-derived softmax update (§5.3, eqs.24–27). Input-dependent low-rank projections generate channel rates/gates. These are distinct changes in loss *and* state evolution, not necessarily a reparameterized scalar gate. A's extra storage is part of Moneta's fast-state ledger; per-sequence MLP weights, temporary chunk gradients and convolution buffers count; hybrid SWA additionally carries KV. Momentum or optimizer state is a possible framework configuration, not automatically used by every variant.

**Exact versus approximation / proof.** Proposition 3.2 and Appendix B give FTRL/Learning–Retaining equivalence with constant η, full unconstrained space and strictly convex differentiable cumulative regularizer, same initialization and minimizers. It is not a claim that nonlinear learned networks globally attain the exact history optimum. §5.4 computes all within-chunk gradients at the previous boundary state (chunk 16 or 64), smooths sign/absolute, and postpones certain nonlinear normalizations; Memora adds a boundary/lag operation. This approximates sequential updates; report its compute and temporary state separately. Appendix equations have some notation that warrants comparison with visual PDF before exact algebra is adopted (e.g. q exponent conventions and self-indexing in §5.2), not grounds to call the result wrong.

**Experimental scope and negatives.** §6 trains 120M/340M on 15B, 760M on 30B, 1.3B on 100B tokens; train context 4096, FineWeb-Edu and C4, with baseline results inherited from Titans rather than all necessarily rerun. Authors report useful LM/reasoning/needle outcomes; §6.4's p sweep is nonmonotone, p=3 best and p=4 worst; q changes length scaling. Table 4 (p.18) reports Yaad 53.98 versus without retention 50.63, input-dependent δ 52.19, L2 component 52.86, L1 component 53.04, and linear memory 51.57, under its listed average metric. Table 2 (p.17) supplies counterexamples to uniform wins: at 340M Wiki PPL GDN 27.01 beats Memora 27.16; at 1.3B GDN-H2 15.91 is below Memora 15.90 only narrowly, while several individual columns favor other models. Appendix C Table 5 gives 170M/780M, conflicting with §6's 120M/760M nomenclature; exact model-size alignment remains unresolved. FLOP-frontier plot does not match physical fast bits, optimizer/buffer bytes, context permissions, tuning and model training exposure simultaneously.
