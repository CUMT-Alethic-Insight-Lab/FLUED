**Problem / solution / borrowed AI technique.** Fixed recurrent hidden states compress growing context poorly; make the hidden state the weights of a linear model or two-layer MLP and update it via self-supervised test-time gradient learning (§2). It borrows denoising/multiview learning and meta-learning: inner learning stores sequence-specific associations; outer next-token learning designs projections, initialization and rates.

**Objective, timing, units.** Current token representation x produces training view `K=θK x`, learned label view `V=θV x`, test view `Q=θQ x`; inner loss `||f(K;W)−V||²`, output `f(Q;W_t)` after updates (§§2.1–2.3). The target is projected current input, not human/teacher answer, and q has causal current/prefix visibility, not a future-query oracle. Outer training differentiates through the inner gradient, and optimizes θK/Q/V, learned W0, input-dependent learning rate and normal model parameters (§2.2, 2.7). For b=16, each chunk's gradients are evaluated at previous chunk's boundary W, but causal cumulative updates still include the current position before readout; they are not identical to fully sequential online GD (§2.4). `TTT-Linear` is square W; `TTT-MLP` has two layers and 4× hidden width; both use residual and layer norm. Mamba-style temporal conv is another local path. Decoder state includes per-sequence W, conv history, and within-chunk gradient/buffer artifacts; W0 is learned slow initialization. Training saves chunk states and applies gradient checkpointing through time (Appendix C). Do not count only one matrix for the MLP.

**Theory and systems.** Theorem 1 (§2.6) proves simple *unnormalized* linear attention for linear f, zero W0, batch GD, η=1/2; learned initialization, mini-batches, residual and normalization move away from these assumptions. Theorem 2 uses a nonparametric Nadaraya–Watson estimator which retains the full growing input/history, so does not make full attention constant memory. Appendix A describes a masked dual computation algebraically equivalent to the *chosen mini-batch* update, not to tokenwise sequential GD; proof read is not verified. Online b=1 has better reported perplexity than larger b, but slower; train b=16. MLP has substantially worse practical wall time relative to its FLOPs (§3.3, §4.2).

**Controls and negative cases.** §3 uses Pile and Books3, four models 125M–1.3B (Mamba 130M–1.4B), Llama tokenizer, AdamW, with Mamba/Transformer and Mamba/Transformer backbones; transformer long-context fine-tuning receives 20% extra tokens. At 2K, TTT-MLP is slightly worse at large matched FLOPs; at longer context matched-FLOP TTT improves versus Mamba, while Transformer remains competitive. Appendix C/Fig.2 reports same training FLOPs as Mamba, but transformer inference 2.8× FLOPs; dimensions differ (TTT-Linear MLP 5808, TTT-MLP 5248). Appendix Fig.16 caption explicitly says from-scratch perplexity eventually worsens as context grows; finetuned Transformer mostly does not. Backbone convolution helps linear differently from MLP (§3.1). Figures do not establish equal physical fast bits, buffers, update steps and exposure; lower PPL by context length is not causal old-fact use.

**Rival / discrimination.** A nonlinear memory, more fast bits, learning-rate choice, local convolution, longer exposure or a better query may explain gains. Hold total live state/precision and q/read width fixed, cross linear/MLP with matched training+decode compute and inner steps, include b=1/b=16 and equal-context/adaptation controls; measure old/rare fact native answer flips, not only PPL.
