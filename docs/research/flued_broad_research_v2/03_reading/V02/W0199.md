**Problem / solution / borrowed technique.** Pure additive finite associative storage superposes conflicting mappings; learn a slow controller producing fast weights with a delta-rule residual write, alongside deterministic parameter-free feature projection (DPFP) to enlarge key feature dimension (§§2–5). Fast-weight programming supplies transient associative memory; the Widrow–Hoff delta rule supplies the correction, not a separately trained retrieval system.

**Write, read and optimization.** At step i, transform learned key/query with nonnegative φ and normalize each by its coordinate sum. Read old value `v_old=W_(i−1)φ(k_i)`; set `β=sigmoid(Wβ x_i)` and write `W_i=W_(i−1)+β(v_i−v_old)φ(k_i)^T`; query the updated `W_i φ(q_i)` (§4.2, eqs.20–25, 28). A separate growing normalizer `z` is an alternative attention-normalization scheme, not automatically part of that final sum-normalized write; attention-normalization accumulator growth and imbalance motivate the alternative. β is learned by outer training, not an externally supplied fact label. The model writes before reading at a token; higher-layer current representations may contain prior context.

**Tasks and evidence.** In §6.1, fixed one-hot value symbols and learned key embeddings generate `(k,v)` writes; the test query is revealed only after the writes. Adam optimizes squared error to the queried value. Capacity experiment samples without replacement with `L=S`, key dimension 64, values orthogonal, and sweeps S=20–600; additive linear attention errors begin around 60, DPFP-1/2/3 near 128/256/384, FAVOR+ fails to converge exactly, and softmax itself struggles past 500 (§6.1.1/Fig.2). Those thresholds are not arbitrary-query finite-bit bounds. Rebinding experiment samples with replacement, `L=40`, 20 symbols and latest binding is truth, compares sum and two earlier delta variants with/without DPFP (§6.1.2/Fig.3). DPFP and normalization differ between some arms: this is not an independently matched nonorthogonal-key causal control. v3 Appendix B's exact preservation example assumes two orthonormal keys and reuses the second key, whereas correlated keys can incur collateral effects. Appendix D.2/Fig.5 sweeps 20–200 symbols with replacement and excludes FAVOR+ because it produced NaNs with the update.

**Budgets and negative outcomes.** WMT14 En→De tests feature maps (§6.2); WikiText-103 small/medium 16-layer tests update rule with similar parameter counts, eight heads and contexts 256/384 (§6.3/Tables 1–4). Authors say no sum-normalization diverged, attention-normalized delta was worse, and carry-state additive baseline without attention normalization exceeded perplexity 1600; Transformer-XL with larger state outperformed delta on untruncated context. v3 Table 2 (p.8) gives medium linear-sum test 33.0 versus delta 31.5, while the standard Transformer is 29.6; Appendix D.3 Table 5 (p.15) gives small DPFP sum 38.8 versus delta 35.0 and Transformer 34.1. Increasing projected dimension again did not improve LM; FAVOR+ with delta produced NaNs in Appendix D.2. Appendix B's orthonormal-key proof does not establish interference-free nonorthogonal writes. WMT uses ~4 days/3 V100; the LM comparison uses up to two V100/<4 days and unequal gating parameters, so equality of total compute is not established.

**Theory versus use / follow-up.** §4.1 concerns linearly retrieved superposed associations and orthogonal key directions, not a general upper bound on every learned recurrent state, nor proof of native semantic use. Distinguish residual-write benefit from projection and training optimization: fix identical K/V and state precision, factorialize repeated vs novel keys, key overlap, first-vs-latest target, load, and report both old and new values with tuned baselines.
