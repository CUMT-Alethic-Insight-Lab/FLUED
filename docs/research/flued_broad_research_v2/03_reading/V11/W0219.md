## Problem and method

Authors attribute long-sequence linear-attention degradation to shared global-summary rank and diffuse attention. **Solution:** split tokens into M blocks, form a KV summary per block, and mix those summaries with a learned block-index coefficient matrix before applying the query (§4). Borrowed techniques: kernelized linear attention, blockwise grouping, mixture weighting, chunk-parallel execution. Language models train autoregressive next-token loss; visual tasks use their ordinary classification/generative objectives.

For block b, `S_b=sum_j k_j v_j^T`, with optional key normalizer; query position in block i uses `sum_b m[i,b] S_b` and then its own q. **The coefficient matrix is learned across training and indexed by query block and source block; the formula does not make it a per-example function of q or input.** Within each block the `q^T k_j` term is already query-dependent in ordinary linear attention. The source alternates between static block-specific formulas (§4.1–4.2) and App. G.1's claim of dynamic coefficients unique to every query; the latter is not established by the displayed equations. Treat increased positional mixtures, independent channel queries, and more retained block summaries as distinct interventions.

## Causality and accounting

Noncausal vision blocks may see the whole image/video. App. C proposes a lower-triangular block matrix, retains prior block summaries and incrementally updates the current block. However, the printed intra-block term `(Q_i K_i^T)V_i` shows no triangular token mask, and the block-boundary rule for extending the learned finite M×M matrix to arbitrarily long generation is unspecified. A strictly causal implementation would need a within-block triangular mask or equivalent prefix operation; do not treat the printed expression as a verified streaming implementation. Retaining M summaries costs `O(M d²)` and mixing `O(M² d²)` per sequence; the paper's `O(N d²)` requires M² ≤ N or another explicitly bounded-M regime. O(d²) incremental work within a block does not count computing a new row's weighted sum over all prior blocks. No fixed-total-memory equivalence follows.

For unmasked `QK^T`, rank ≤ d; its block-stacked bound is ≤ sum_b min(n_b,d), with equality conditional on full row ranks and independent row spaces (§4.3). This algebra is not a proof all linear queries return identical values or causal masked attention has rank ≤ d: lower-triangular masking itself can raise matrix rank. Concentration is observed empirically, not a universal uniformity theorem.

In video, Table 5 FA/MHLA/hybrid total 83.31/82.62/83.82 with 166/81/103 seconds; hybrid retains one-third full attention. Image DiT-XL with guidance reverses the positive adaptation comparison (FID 2.54 MHLA vs 2.27 self-attention, Table 3b). Visual results are not causal text-memory binding measurements.

Directions **C.02, C.06–C.08, C.14–C.15**. Independent no-revisit option: match **total physical state** while allocating more independent learned read queries over a single state, or repair native query/key geometry without adding token groups. Factor block count, read heads and state bytes in separate controls, and require prefix perturbation, long-generation coefficient extension, and downstream content swaps. The hypothesis that grouped summaries intrinsically improve native addressing changes if the benefit disappears at equal state or is matched by query-only repair; data conflict and code-level causal mask remain open.
