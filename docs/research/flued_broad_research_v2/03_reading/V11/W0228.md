[Original PDF](sources/W0228__2406.06484v6.pdf), [extraction](sources/W0228__2406.06484v6.txt), 25 pages. Main §§2–5, Apps. ## Problem and technique

Delta-rule fast weights improved association correction over additive linear attention, but sequential state updates made large-scale training inefficient. **Solution:** rewrite the exact input-conditioned delta recurrence as compact products of rank-one generalized Householder transformations, then perform chunkwise matrix operations and triangular solves without materializing each token's matrix state (§§2.2–3.2, App. B). Borrowed tools are least-mean-squares online regression, WY/UT factorizations, and hardware-aware chunked attention. The inner per-token regression target is the model-generated value, not a supervised external fact label; the outer model is trained on next-token language loss.

For token t, `S_t = S_(t-1) - beta_t (S_(t-1) k_t - v_t) k_t^T`, `o_t = S_t q_t`. The update reads the old value at the new key before correcting it; beta is input-derived. Expanding `S_(t-1)(I-beta kk^T)+beta vk^T` and inductively introducing pseudo-values gives the same real-arithmetic recurrence. Within each chunk, App. B derives the lower-triangular system `T=(I+tril(diag(beta) K K^T,-1))^-1 diag(beta)`, `W=TK`, `U=TV`; chunk state and causal output are then formed from `U-W S^T` and triangular intra-chunk scores. Factorization is a computation schedule, not an added read or capacity increase. Floating-point numerical identity was not independently checked.

## Units, comparators and findings

The content is projected values stored in a per-head matrix; writes are keyed by the input-derived k, reads by separate input-derived q. Causal token outputs use the current prefix. §3.3–3.4's full block has Q/K/V projections, SiLU and L2-normalized Q/K, output RMSNorm/projection, residual Transformer++ with RMSNorm/SwiGLU, and short Q/K/V depthwise convolutions where enabled. With unit k and beta in (0,1), transition eigenvalues are 1 in orthogonal directions and 1-beta along k; selective preservation is exact for that update, not a guarantee against correlated-key interference across a sequence.

On SlimPajama, 340M/15B tokens and 1.3B/100B tokens, same tokenizer and subset, App. A specifies 8 H100s, head dimension 128 and convolution kernel 4. Visually checked Table 1: 340M SWDE/SQuAD/FDA DeltaNet without conv 24.6/26.9/4.5, with conv 26.4/28.9/12.8; GLA with conv 24.0/24.7/7.3. At 1.3B DeltaNet with conv 49.5/37.4/17.2 versus GLA with conv 52.4/37.4/22.3; state expansion 128x versus 256x. Hence neither a convolution-free nor fixed-state-physical-byte controlled universal delta claim follows. The two-global-attention hybrid 71.0/43.0/29.8 accesses full source through two layers; alternating sliding attention has local-cache permissions, not closed recurrence. MQAR Fig.4 uses 2 heads and **no DeltaNet convolution**, whereas MAD Fig.3 has convolution and borrowed baseline results; MAD Memorize is weak for DeltaNet (52.8). The 3B/1T-token DeltaNet average 59.8 trails same-setting PowerLM 62.3 (§4.2/Fig.5); training throughput still trails GLA and length extrapolation is limited (§5.3). Equal tokens are not equal FLOPs; local buffers and hybrid caches must be counted.

## Relevance and options

Directions **B.01–B.03, F.09**, plus B.06–B.08: isolate corrected versus additive writes with matched Q/K normalization, convolution, state bytes, sequence exposure and optimizer search; measure duplicate/near-key overwrites separately from native output dependence. An independent no-revisit alternative is a matched-state additive/gated or residual-writing recurrence with native query repair rather than any source reread. Hypothesis changes if this control matches or exceeds delta across long delays and interfering values, or if delta's gains disappear when its companion convolution and state budget are controlled. Compare W0199/W0201 at their own existing FULL editions; this card is not another reading of them.
