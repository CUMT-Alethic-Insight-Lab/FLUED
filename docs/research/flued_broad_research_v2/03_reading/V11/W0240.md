## Problem and one-sentence solution

Classical associative memories have limited pattern storage and binary dynamics hard to use as differentiable layers. **Solution:** use continuous states with log-sum-exp energy and an attention-equivalent softmax update over the stored pattern bank. Borrowed methods include Hopfield energy minimization, convex–concave procedure, Banach contraction, kernel pooling and learned query/key mappings. The model-specific objective depends on the downstream task (e.g. classification cross-entropy); its update is not by itself an online training algorithm for an unknown future text query.

Let X contain N stored d-dimensional patterns, M=max norm and β>0. `E(xi)=-lse(beta,X^T xi)+0.5||xi||²+constants`, `f(xi)=X softmax(beta X^T xi)` (§2). The fixed points/minimization belong to this update in **pattern space**. App. A.1.7/A.4 explain learned query/key projections and a value projection applied after the final update. Arbitrary independent value vectors produce ordinary KV attention for one read, but generally do not imply the same energy-decreasing iterative dynamics if fed back as the next query without an appropriate mapping.

## Theorem conditions and proof steps

Global energy converges, but state convergence requires the extra stationary-point condition stated in Theorem 2; global does not mean correct pattern from every query. A pattern is 'stored' if its neighborhood contains a unique attracting fixed point and neighborhoods are disjoint, and 'retrieved' if the update is epsilon-close to that fixed point (§2, Def.1). For separation `Delta_i = x_i^T x_i - max_(j≠i) x_i^T x_j`, radius `1/(β N M)` and sufficient separation in App. A.1.5.3 Lemmas A5–A7, the authors bound softmax spillover, show the ball maps to itself, bound the Jacobian below 1, then invoke Banach. The one-step bound (Theorem 4/A8) includes N, M, beta and the distances of the query and fixed point to the pattern; large separation and an appropriately close query, not arbitrary query, make it small. Error is distance to the **pattern**, not identity with the fixed point. Authors' Theorem 3/A5 asserts exponentially many randomly selected equal-norm spherical patterns at a specified failure probability and parameter-dependent base; it does not apply automatically to arbitrary correlated patterns or fixed precision. Similar clustered patterns can yield metastable averaging; if global spread is sufficiently small (`β m_max² < 1` in Lemma A3), averaging near a global mean can result. Neither one-step attention nor concentration proves correct downstream use.

**Accounting:** X explicitly holds N patterns, costing O(Nd) numerical elements, plus any separate values/projections. Exponential N in associative dimension d is not exponential history at constant total bits. App. A.1.8's causal formulation retains the prefix bank and its forgetting equation 451 adds temporal bias while displayed updates 453–454 omit it; implementation/notation reconciliation is needed before claiming a specific decay algorithm.

## Findings and hypothesis choices

Table 1 reports multiple-instance AUC: Tiger 91.3 vs path encoding 91.0, but Fox 64.05 vs MILES 73.8; other baselines use literature-reported scores. Drug-design Table A.5 shows Hopfield 0.815 HIV versus GCN 0.834 and 0.910 BBBP versus RF 0.927, while BACE 0.902 and SIDER 0.672 lead reported comparators. App. A.5.2 manual validation search and 160 epochs, 10-fold nested CV repeated five times; the immune set has hundreds of thousands of instances per bag. These are full-bank classification results, not closed-stream memory tests.
