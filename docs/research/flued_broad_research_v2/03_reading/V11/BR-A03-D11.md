## Original problem and solution

Earlier Memory Networks required supervised supporting facts and hard, non-differentiable lookup. **Solution:** train soft content-based access over an explicit bank end-to-end from answer labels, updating an internal query for several memory hops before prediction. Borrowed techniques are neural attention, recurrent hidden state, word embeddings, layer tying and linear-start optimization. The supervised loss is answer/next-word cross entropy; supporting-fact labels exist for evaluation but are not provided to this model in training (§4).

For memory item i, input embedding `m_i=A x_i`, output embedding `c_i=C x_i`; each hop computes `p_i=softmax(u^T m_i)`, `o=sum_i p_i c_i`, then `u_next=u+o`. Adjacent tying uses `A_(k+1)=C_k`, B=A1 and final prediction tied to CK; layer-wise tying repeats A and C across hops with learned H in `u_next=H u+o` (§2.2). QA items are sentences represented as bag-of-words or position-encoded word sums plus learned relative time encodings. LM items are individual previous words, not sentence summaries; initial LM query is the same constant 0.1, after which hop queries are content-adaptive (§5). The model can repeatedly access the full retained bank, limited to most recent 50 QA sentences and up to 200 LM words, and cannot be described as source-free fixed state.

## Experiments, controls and caveats

bAbI has 20 synthetic tasks, 1k or 10k labeled problems/task, up to 320 sentences before truncation. Default QA 3 hops with adjacent tying, d=20 separately trained or d=50 jointly, and softmax answer loss. For linear start, remove intermediate softmax until validation stops improving then restore it; 10% random empty memories jitter time indices. Training has 10% validation, batch 32, QA up to 100 epochs. **Ten random initializations selected by lowest training error** (§4.2), not ten independent-run averages; PTB selects lowest validation cost among ten runs, Text8 only one run (§5.1).

Visually checked Table 1: mean 1k joint 1/2/3-hop errors 25.8/15.6/13.3%; 3-hop + random noise 12.4%, whereas layer-wise tied version 13.2%. Larger d, joint training, different recurrence and further model choices complicate across-column mechanism claims. Strongly supervised original MemNN mean 6.7%; e.g. path-finding remains 90.2% error for 3-hop joint, so more hops do not universally solve reasoning. Paper prose says task-16 PE-alone 53.6% vs 1.6% with linear start, but Table 1 visibly gives **52.1% vs 1.6%**; source inconsistency retained. Table 2 PTB 2/6/7 hops at 100-memory 121/115/114 perplexity, Text8 187/155/147; increased memory to 200 for PTB 7 hops reaches 111. More hops have more read and compute cost; size effects are not monotonic. Claimed causal importance of adaptive rereading is not isolated: no matched repeated-identical-read or equal-extra-nonread-compute control is reported.

## Relevance / independent alternatives

Directions **C.06–C.08, C.17, C.19–C.20**. This is a direct positive example of trainable adaptive query updates, but bank residence provides greater history permission than a fixed compressed state. Independently test iterative native queries against repeated frozen-query reads **and** equally deep nonread compute on the same retained state and matched budget, plus a one-read query-repair baseline. Hypothesis changes if identical-read/nonread depth yields the same gain or adaptive hops improve only with the larger revisit bank. Attention maps alone are not causal proof of correct evidence consumption; swap or contradict the particular content and measure output changes.
