## Problem and mechanism

Distributed scene features do not naturally expose interchangeable object representations. **Solution:** learn a symmetric set of slots that iteratively compete to explain input features and update by a shared recurrent rule. Borrowed ideas: dot-product attention, soft clustering, gated recurrent units (GRU), spatial-broadcast image decoding, Hungarian set matching. Training is end-to-end image reconstruction by mean squared error for unsupervised discovery or labeled object properties with matching/Huber loss for supervised prediction; no segmentation labels are used for training. Evaluation uses ground-truth segmentation, excluding background.

Given N input feature vectors and K slots, logits `k(input_i)·q(slot_j)/sqrt(D)` are **softmax-normalized over slots j for each input i**, forcing competition; then weighted mean renormalizes over input positions i separately per slot with epsilon. Shared GRU and residual MLP update each slot, normally T=3 iterations. Random slot initializations share learned Gaussian parameters. The whole static image is available simultaneously: neither a causal streaming writer nor separately query-addressed persistent text memories is demonstrated. The vectors are object/region-oriented content and routing weights, not proof of retained arbitrary original strings. Cost `O(T N K D)` for attention; more slots and refinement steps cost more. App. D's proof composes equivariant per-item projections/softmax, input-invariant summation and shared slot updates; this is set symmetry given fixed features, not translation invariance or learned correct segmentation.

## Controls, budgets and failures

Table 1 visual: CLEVR6 Slot Attention and IODINE both 98.8% adjusted Rand index (ARI); Multi-dSprites 91.3±0.3 versus IODINE 76.7±5.6 and MONet 90.4±0.8. Tetrominoes 99.5±0.2 **excludes one of five runs** stuck segmenting stripes; this failure is not erased by its exclusion. 70K CLEVR training images and 320 test examples; 500K training steps, batch 64; T=3, K=7 for CLEVR6. Increasing test K to 11 and refinement steps improves aggregate performance on CLEVR10, but costs extra and does not fix K bits (§4.1, Fig.2). The 8-V100 24-hour versus ~7-day IODINE comparison uses reported setups, not a uniform modern efficiency audit. Supervised AP falls sharply at strict localization threshold (supplement Table 3); crowded images and some coordinates worsen with extra steps (App. C.2).

App. B finds competition over slots outperforms input-axis softmax, weighted mean improves over sum, GRU helps, and training with >3 refinement rounds slows same-step convergence; more test iterations usually help. A soft-k-means-like simultaneous removal of projections, GRU and normalization yields 75.5±3.8 vs 98.8±0.3 CLEVR6 ARI, so this combined ablation cannot attribute the deficit to any one component. Position embeddings matter for spatial coordinates. Task loss determines whether clustering forms objects, colors or regions; complex backgrounds remain an anticipated limitation (App. A).

## Directions and independent options

Relevant **C.14, C.19, A.13–A.14**. No-revisit choices include single-state structured write with multiple native read queries, competitive partitioned state, or learned query repair, all at matched total bits and without source-bank access. Test separate slot count, slot width, softmax axis, read-query diversity, and added update compute on causally revealed text; compare correct-content intervention with address scrambling. A hypothesis that competitive slots solve native binding weakens if improvements vanish at fixed bits or after causalization, or if no-read extra compute matches iteration gains. Image reconstruction and object-mask alignment alone do not establish fixed-bit superiority or future-query recall.
