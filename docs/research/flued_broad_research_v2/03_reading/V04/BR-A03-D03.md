## Problem, technique and learning contract

**Problem:** generation caches grow with context, and deleting low-attention positions risks losing later-useful content. **One-sentence solution:** merge neighboring low-attention keys using a diagonal-Fisher approximation while summing values and tracking multiplicities in the attention denominator (§§3.1–3.3). Borrowed technique: second-order Taylor/Newton approximation and diagonal empirical Fisher, used for training-free inference-time merge selection, not training a compressor; one selective backward pass per compression chunk is still needed. The gradient is of language-model loss with respect to candidate key embeddings; squared gradient approximates the diagonal Fisher, and the potentially unstable first-gradient term is dropped (Eq. 2–6). Exact data/label and gradient visibility contract for each decoding chunk needs appendix/implementation clarification; do not call the procedure cost-free.

## Units, access, algebra

Autoregressive token positions have retained K addresses, V content vectors and count metadata; query is the current token representation and output is a weighted value sum. No source reread or new learned writer is introduced. For *already equalized* keys, a pair with value sums v1+v2 and cardinality c1+c2 gives exactly the same weighted output using the count-weighted denominator, including repeatedly merged groups (§3.2 Eq. 7–11). This exactness applies to the modified equal-key bank, not original unequal keys; the approximation and any content loss occur in forcing keys equal. At max_length 2048, chunk_size 512, 32 initial tokens preserved, adjacent low-attention pairs are periodically merged (§3.3 and §4.1). Fixed token count is not fixed total bits: counts, gradients, temporary activations and custom attention matter.
