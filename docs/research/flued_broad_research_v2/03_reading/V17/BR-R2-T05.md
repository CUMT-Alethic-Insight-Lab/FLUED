## Problem, method, units, visibility

Student and teacher token vocabularies and token boundary positions differ, breaking full-distribution imitation. The proposed byte-prefix marginalization (BPM) uses a byte trie and maps every teacher next-token probability to the longest student token whose bytes prefix that teacher token, summing mass per student token and placing unmatched outcomes in a residual cell (pp. 3–5, Fig. 2, eqs. 2–5). Student/teacher share rendered response **bytes**, not token IDs; student generations supply on-policy histories and teacher scores those responses re-rendered in its own chat template. Source provides no guarantee that distinct prompt templates create identical effective teacher/student histories. Teacher tokens, student tokens, raw bytes, specials and training objective rows are distinct units; this is distillation, not a learned compressor or native memory retrieval.

If a student token starts inside a teacher token, condition on previously observed bytes and normalize compatible teacher mass by prefix probability. For tokens spanning multiple teacher tokens, multiply realized teacher-token probabilities by final prefix mass, subtracting from the appropriate scatter cell to retain normalization; this is a **lower bound** on full byte mass because other teacher token paths may spell the same bytes (pp. 5, 17–18, Algorithm 1). Rows neither starting at nor reaching a sync point are excluded. For the executed code experiment, all-space/tab realized tokens are also masked; the normalization counts even excluded rows. Teacher stop mass is separately accumulated across tokenizer EOS, generation configuration and chat-template stops and mapped to the response's realized student stop; a forward-KL binary stopping bridge adds restoring gradient (pp. 5–6, 15–16, 27). Prefixes can be byte strings; no explicit partial-UTF8 correctness experiment was found. No marked end-of-text exactness equivalence with BIW-0103 follows.

## Proof conditions and qualification

Appendix C pp. 16–17 states (A1) lossless concatenative byte-level BPE decoding and (A2) greedy longest-prefix student segmentation. Lemma C.1 proves partition/conservation; Proposition C.2 claims exact scatter for aligned chunks where student tokens refine a teacher token. Interior conditional case and realized-path spanning lower bound are separately described in Table D.1. A2 idealizes actual BPE merge priority; paper claims position-level cross-checks found no difference but proves **no error bound**. Conservation across token cells plus residual does not by itself prove exact unrestricted byte-string continuation probability; an observed path's refinement is not a verified universal condition for every counterfactual. No independent proof checking or code execution.

## Controls, findings, counterexamples, costs

Fixed Qwen3.5-2B thinking student; separately Qwen3-32B, GLM-Z1-9B and MiniMax-M2.7 teachers (span Jaccard 0.92/0.87/0.81). Each teacher pair's on-policy arms share 20k math/code prompts, two epochs, batch 256, optimizer schedule, 27,648-token rollout cap; comparator losses SimCT, ULD, GOLD and separately trained offline SeqKD (pp. 6–8). Each arm selected by six-benchmark average; Table 1 reports best BPM divergence (forward KL), not the default Jensen–Shannon mixture. Six-benchmark avg@8 is 39.0/41.5/38.7 vs strongest baseline 35.3/34.9/32.8; margins +3.7/+6.6/+5.9 percentage points. Not every dataset improves: for the first teacher MATH-500 avg@8 is 82.1 vs baseline 83.4, and HumanEval+ 61.8 vs 62.1 (Table 1 p. 7). P3 Jensen–Shannon HumanEval+ falls sharply, and bootstrap P3 JSD–ULD aggregate is −0.2 [−2.2,+1.8] (Table H.5 p. 27). Bootstrap reflects problems/samples from one regenerated evaluation, **not multiple training seeds or checkpoint selection** (H.4).

Whitespace is a concrete causal ablation: GLM-pair masked vs unmasked differs by mask; mask-matched random non-whitespace removal does not recover code tail reward (0.11 vs 0.17). In the unmasked probe code pass 49%→9%, block indentation errors 84%, while math remains stable; mask excludes ~3.5% of aligned code rows (Fig. 3, pp. 8–9, H.2, case I). The proposed segmentation-noise mechanism is an interpretation of these controls, not proof of universal causation. Reverse-direction student likelihood on teacher text guards against falsely favorable teacher likelihood on repetitive collapsed student output (Table 4, H.2). Stop transfer also does not universally fix length: P3 still has 62–90% cap rates (Table H.4).

One-time trie compilation O(sum of teacher-token byte lengths); scatter linear in teacher vocabulary per aligned row, extra conditional/span work, teacher scoring forward pass of each student rollout; no separate numerical per-method teacher-call, FLOP, wall-time or energy ledger is given (Appendix F). Each run normally uses one 8×H200 SXM node, some use additional data-parallel nodes; SeqKD runs offline three epochs. 20k prompt training is task/domain specific; no equal FLOP or total teacher-generation-cost guarantee follows from matched updates. No language-balance or out-of-distribution long-context test establishes FLUED transfer.

## Relevance to original directions

A.16: changing prediction supervision through a byte-mediated target is not evidence for reconstruction/retrieval sufficiency. F.17–F.18 and I.01–I.03/I.10–I.11: explicit output/teacher/student unit and history alignment matters during cross-interface adaptation. I.24–I.28: account for teacher full-vocabulary passes, alignment, masking, stopping and wall time separately; segmentation preservation and partial byte/EOS edge cases need direct tests. The whitespace ablation warns that mechanically faithful local matching can degrade downstream program function; it does not show long-range native content consumption or a generally optimal interface.
