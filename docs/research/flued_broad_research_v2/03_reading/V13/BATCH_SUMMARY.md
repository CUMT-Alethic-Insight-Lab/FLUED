## Synthesis handoff: independent hypotheses

- Early supervision can improve classification with extra heads and backward work, while blur-deprivation deficits and recoverable image flips show **specific**, not universal, finite-horizon path dependence. Use matched history/clean exposure, time-reversed schedules and recovery controls.
- Single scalar metrics are insufficient: update norm and feature rank have explicit plasticity counterexamples; empirical-Fisher rank is sample-limited and a distributional regularizer changes more than curvature. Test outcomes under several interventions, not just proxy correlations.
- Behavioral mixtures can predict held-out synthetic Markov task trends while leaving circuit identity underdetermined. More training can preserve ID performance and damage some OOD contexts; at other diversities a context-sensitive algorithm persists within budget. No 'all memory is blind' verdict.
- Stitching measures task-specific adapted compatibility. It is directional and label/optimization dependent: random early representations can stitch well, and even stronger invariant-aware methods have an explicit failed identity case. A practical connector is not evidence of shared source computation, and added end-model hints/inverted images are privileged permissions.
- Viable non-retrieval options include objective timing, learning-rate/history adjustment, initialization balancing, distributional regularization, native reader or receiver adaptation, and relation-preserving input representation. Compare against genuine source retrieval rather than defining the broad report by one approach. No byte-interface exoneration is warranted.
