## Problem and solution

Continual supervised learners may struggle on equally difficult new tasks after repeated distribution changes. **One sentence:** use estimated effective curvature directions at each task switch to study this degradation, and penalize the layerwise distributional Wasserstein distance from the initialization distribution to preserve plasticity. Borrowed techniques: Hessian/empirical-Fisher geometry, sorted-weight optimal transport and initialization-centered regularization. The new regularizer matches sorted layer weights to sorted initial weights, unlike coordinate-by-coordinate regenerative regularization; it allows larger individual displacements but requires sorting, storing/reference construction and added backward work. Its runtime/memory are not quantified as a full ledger.

A task is an observation/target distribution held fixed for U minibatch updates; the metric is error at **end of each task**, rather than average online error, which also reflects the immediate surprise after each change (§2 and C.1). Units are image examples, labels, parameter and feature directions; no memory address, autoregressive causality, source-state write/read or arbitrary language transfer is evaluated.

## Evidence and qualifications

- §3/Figs. 1–2, A: on a linearly separable MNIST subset, ReLU and leaky ReLU both lose plasticity despite **increasing** average updates for the latter; tanh can show falling feature rank without loss of plasticity, while high-rank feature regularization can coexist with deterioration. Dormancy and weight-norm patterns similarly fail as universal one-number explanations. A deep linear network succeeds on this small subset, but the full-data appendix C.3 reports it has high, nearly constant error due to insufficient capacity; constant error is not success.
- §§4–6, Figs. 3–8: curvature-direction loss co-occurs with error increases in permuted MNIST, random-label MNIST/CIFAR-10 and 500 binary continual-ImageNet tasks. Wasserstein and regenerative baselines preserve plasticity in several settings; Wasserstein is reported better on the harder CIFAR/ImageNet cases. More depth/width delays but does not eliminate failure in tested runs; regularized ResNet18 incurs a slightly higher error than the best initial unregularized error. Appendix C.9 tests 25–400 epochs per task; even 400 only delays degradation in the reported experiment, not proof that any conceivable longer recovery is impossible.
- Effective rank counts enough singular values for 99% of their sum. The practical matrix is a Gram matrix of **M per-example gradients**, rank at most M, normalized by its maximum; it is an empirical-Fisher proxy, not the true Hessian or model Fisher. Validation against full Hessian is on a small projected-MNIST network (36 input dimensions, three 32-wide hidden layers); accuracy of relative trends worsens later (§4.2/C.2). A causal intervention simultaneously changes weights, task learning, update geometry and curvature; correlation plus a helpful regularizer cannot establish curvature as the exclusive cause.
- Appendix B: full random-label MNIST uses 51,200 examples, batch 256, 200 epochs = 40,000 updates/task and 30 seeds; CIFAR uses 38,400 examples; regularization strengths swept across values reported in B. Each algorithm adds training/tuning and per-layer sorting; matching number of examples/updates is not equal FLOPs.

## Non-retrieval discriminator

Test a target-host objective/optimizer-history intervention or distributional regularizer against weight decay, regenerative and compute-matched controls, keeping task order and target visibility fixed. At matched horizons measure end-task performance, online loss, nonstationary gradient alignment, proxy sensitivity to sample count and independent Hessian checks on a tractable submodel. If accuracy recovers without preserved rank, or rank remains high while native task recovery fails, weaken the curvature-exclusive hypothesis. Probe rank alone is neither retained content nor deployed use.
