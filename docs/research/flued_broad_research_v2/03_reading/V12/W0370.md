# W0370 — Information-Theoretic Probing with Minimum Description Length

**Status: FULL**, Voita and Titov, formal EMNLP 2020, pp.183–196, [PDF](https://aclanthology.org/2020.emnlp-main.14.pdf); local [PDF](sources/W0370.pdf), [text](sources/W0370.txt). Read main text and Apps.A–B; PDF p.6 Table 1/Fig.2 visually inspected. No formal/arXiv edition equality asserted.

**Problem → solution.** Equal endpoint probe accuracy can conceal very different amounts of probe capacity or label supervision. Encode labels conditional on frozen representations and measure the bits needed to transmit both a predictor and its labels. Borrowed AI/statistical techniques: information theory, Bayesian variational inference, prequential coding and controlled random labels; it is a supervised diagnostic, not a new language-model memory.

**Method/theory (§2).** For probabilistic probe `p`, label code is `−Σ log2 p(y_i|x_i)`. Variational two-part code adds `KL(q(theta)||prior(theta))` to expected negative label log-likelihood; the bits-back interpretation and agreed prior/coding setup matter. Bayesian compression sparsifies probe neurons. Online code gives the first block uniform `t1 log2 K` bits, trains on already transmitted labeled blocks, then scores the next block before updating; fractions are .1, .2, .4, .8, 1.6, 3.2, 6.25, 12.5, 25, 50, 100% (§2.2, footnote). Model/algorithm/seeds and representations are shared assumptions: labels are not free, and theoretical codelength is not measured runtime or storage. Under the true joint and a valid coding scheme expected label codelength is at least conditional entropy; compression relative to true H(Y) is bounded by I(X;Y). This is not direct measurement of the target host's total information or its native readout.

**Results and budgets (§§3–4, Apps.A–B).** ELMo frozen layers on Penn Treebank part-of-speech; random word-type labels as control. MLP-2 h=1000: layer-0 accuracy real/control 93.7/96.3%, yet online code 173/302 kbits and variational 163/267 kbits, respectively (Table 1). Layer-1 real/control online 96/515 kbits. Control requires a type-dependent label mapping, not a true natural linguistic target. Five seeds and ten tested MLP-1/MLP-2 width configurations support bounded stability, not universal invariance. Random contextual ELMo layers retain the pretrained lexical layer, and remain stronger than context-free embedding for several tasks (Table 4); they are not fully random-input controls. Standard probes use Adam .001 with dev loss stopping; variational 200 epochs, distinct computational budgets; edge-probing tasks use projection, attention pooling and different training (App.B). High-dimensional probes and known spans are extra permissions.

**Directions:** D.01/C.18/E.03. Probe curves, random-label/feature baselines and explicit supervision budgets can distinguish cheap extractability from costly decoding. In-state non-revisit alternatives include objective and query/readout reform, not only source retrieval. Hypothesis changes if an unmodified deployed reader on matched tasks accesses the same information causally, or if a carefully budgeted probe fails despite validated positive controls; probe success alone proves neither native access nor prediction dependence.
