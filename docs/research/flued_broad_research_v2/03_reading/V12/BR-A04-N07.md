# BR-A04-N07 — FaithEval

**Status: FULL**, [arXiv:2410.03727v3](https://arxiv.org/pdf/2410.03727v3), 2025-04-24; first page labels this a published ICLR 2025 conference paper, but this card is scoped to these preprint bytes and does not certify equality with an OpenReview edition. Local [PDF](sources/BR-A04-N07.pdf), [text](sources/BR-A04-N07.txt). Main text, Appendices A–G including full generation prompts, results and extended example read; PDF pp.6–7,9 visual checks.

**Problem → solution.** Contextual QA benchmarks often mix factual truth, conflicting documents and missing evidence. Construct 4.9K QA items in three controlled regimes and measure whether instructed models follow the supplied context. Borrowed techniques: LLM-generated counterfactual documents, independent LLM judgment, majority human annotation, keyword answer matching, and instruction/decoding comparisons; this evaluates models, not a learned memory mechanism.

**Three distinct tasks (§3; Apps.A,B,D,E).** Unanswerable (2.4K) edits ten contextual datasets to remove answer evidence, optionally adding coherent sentences; target `unknown`. Inconsistent (1.5K) adds a generated, fabricated alternate answer context to the original; instruction targets `conflict` for conflicting *or multiple* answers, not a unique chosen truth. Counterfactual (1K) selects a wrong ARC-Challenge option and generates multi-paragraph support plus distractors; request only the exact context-based answer, not a specific conflict instruction. This is an explicit task-local authoritative stipulation even when world-false, not evidence that a real misinformation source is trustworthy. Judge checks whether the generated answer is supported and unique; 3 workers majority-vote the two open-ended tasks, while counterfactual uses LLM judge plus string matching with reported pilot human agreement. App.B's stricter whole-answer-phrase subset passes 68.9%; it is not semantic entailment. GPT-4o is generator and GPT-4o-mini judge; full prompts are App.D Figs.17–19. Related contextual source questions are often context-specific, not all universal scientific facts.

**Scoring and controls (§§3.3–5).** Common prompt: “respond with the exact answer, using only the information provided in the context”; unknown/conflict task-specific clauses as above; deterministic temperature 0. Primary accuracy counts answer *mention*, with strict `unknown`/`conflict` versus broader non-strict keyword lists; unknown's list even includes `not` (App.A). A response that mentions a target but also contradicts it can pass: whole-response entailment, exclusive answers and source authority are not established by this score. Report blanks/neither/both and factual semantic correctness separately; the paper does not give this complete decomposition.

**Observations and budgets (Figs.4–6, Table 1; App.F).** Eighteen instruction-tuned proprietary/open models; original-context control and no-context control use different task conditions, not matched-compute architecture arms. Phi-3-medium original 75.8% vs unanswerable 7.4%; GPT-4o closed-book 96.3% vs counterfactual 47.5%, while 95% human accuracy is a held-out subset, not the identical evaluation population. In normal contexts conflict prompting changes Claude 3.5 Sonnet average .90→.85 and GPT-4o .85→.83 (visual Table 1); it can also harm clean behavior. Direct versus chain-of-thought improves representative noisy-context scores (Fig.9), with added response tokens, and stochastic decoding gives small improvements. These results do not establish that all systems ignore memory or that source compliance is intrinsically truthfulness.

**Directions:** D.03–D.05/D.17–D.19. No-revisit options: train native conflict/abstention behavior, refine readout, reform state retention, all without adding source reaccess. Hypothesis would change with same-evidence controlled swaps and independent full-response entailment/contradiction adjudication, including correct prior versus correct source, clean input regression and explicit token/compute budgets.
