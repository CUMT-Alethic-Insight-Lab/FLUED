# BR-A04-N08 — ClashEval

**Status: FULL**, [arXiv:2404.10198v3](https://arxiv.org/pdf/2404.10198v3), 2025-02-07, first page identifies NeurIPS 2024 Datasets and Benchmarks; read this exact v3 main body and Appendix A, not certified identical to formal proceedings. Local [PDF](sources/BR-A04-N08.pdf), [text](sources/BR-A04-N08.txt). The public paper itself provides the protocol; no licensed medical website was visited. Complete prompt strings are said to be in the code repository, not printed in this PDF, so exact prompt wording and answer matcher implementation remain unverified artifacts.

**Problem → solution.** Both blindly accepting incorrect source text and rejecting correct source text in favor of an incorrect prior are failures. Generate question/context pairs in six domains, perturb answers in source passages and examine both conflict directions. Borrowed methods: GPT-4o question generation/filtering, context substitutions, semantic similarity document retrieval, token-probability calibration and prompt strictness. Confidence intervals are reported, but their construction is not specified here. This is inference-time assessment, not an intervention on internal write/read state.

**Protocol (§3; App.A).** 1,294 questions: 249 drug, 238 news, 200 years, 191 records, 200 names and 200 locations. Questions/excerpts generated from licensed UpToDate drug pages, AP news and Wikipedia; generated question transformation is reported fair use while underlying sources have licensing restrictions. GPT-4o filters medical and news questions and checks criteria; Wikipedia excerpt must exactly occur, answer forms constrained. Numeric perturbation multipliers .1/.2/.4/.8/1.2/1.5/2/3/5/10; years ±20-year increments to ±100; names/locations slight, significant and comical replacements. GPT-4o rewrites affected drug/news excerpts. Plausibility and correctness can change along with substitution, so not an isolated source-reliability effect. Six models, standard RAG-style prompt plus stricter/looser variants (Fig.6); exact strings external. Table 2 explicitly has prior-correct/context-wrong AND prior-wrong/context-correct columns, with prior/context/neither response categories. Handling of blanks, both answers, partial semantic matches and exclusion/overlap rules is not fully specified in the paper; do not equate mention to exclusive endorsement or invent it.

**Reported comparison/negative cases (§4, Tables 2–7).** For GPT-4o under the *prior-correct* condition, Table 2 reports choosing wrong context .608 and neither .065; when context correct, choosing context .903, neither .056. These conditional response proportions differ from Table 4's context-bias .304 and prior-bias .021; §3.1 describes bias conditionally, but the table values do not match the displayed conditional proportions. The exact aggregation/denominator reconciliation is not specified in the paper; do not silently interchange them. Claude Opus Table 4 accuracy .743 vs GPT-4o .615. More documents lower measured context bias but may also lower accuracy and increase neither responses: GPT-4o correct-context aggregate .941 at k=1 vs .922 at k=5, Claude Opus .939→.843 (Table 6). Prior confidence and perturbation magnitude correlate negatively with context preference, not proof of calibrated truth recognition. Token-probability correction for GPT-4o Table 3: accuracy .615→.754, context bias .304→.107, but prior bias .021→.085; random replacement at same .085 bias gives .575 accuracy per text. Calibration requires extra prior and contextual generations, log probabilities and percentile reference; its fitting split/cost are not fully described. Six models and enriched artificial errors are not a prevalence sample; one-hop fact QA is not multi-document reasoning.

**Directions:** D.03–D.05/D.18–D.19. Reversing control: independently vary source correctness and prior correctness, include answerable/no-answer/conflict and explicit authority before evaluating semantic output, not merely target mention. Non-revisit paths include native uncertainty/readout calibration or state reform; test clean-task regression and prior-correct as well as context-correct arms. Results that would revise a hypothesis include full-response adjudication with balanced truth strata and independently tuned confidence calibration plus both extra-call and resident-state costs.
