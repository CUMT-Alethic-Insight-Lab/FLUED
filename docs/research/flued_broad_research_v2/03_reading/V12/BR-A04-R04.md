# BR-A04-R04 — ERASER

**Status: FULL**, original formal ACL 2020 paper, [PDF](https://aclanthology.org/2020.acl-main.408.pdf), proceedings pp. 4443–4458; local [PDF](sources/BR-A04-R04.pdf), [text](sources/BR-A04-R04.txt). Read main text and Appendices A–C; Tables 3–4 visually checked on PDF p.8. This is not independent replication or proof that the metrics are ungameable.

**Problem → solution.** Plausible human-highlighted explanations need not be the features a model actually used. ERASER standardizes seven human-rationale NLP datasets and evaluates task performance, annotation overlap and prediction changes under rationale deletion/retention. Borrowed techniques include input erasure, ranking perturbation curves, attention/gradient/LIME explanations, and supervised or REINFORCE hard-rationale extractors; it is an evaluation benchmark, not a universal memory intervention.

**Exact measurement (§4.2).** For original input x, extracted rationale r and original *predicted* class j, comprehensiveness is `m(x)_j − m(x \ r)_j` (higher suggests stronger removal effect); sufficiency is `m(x)_j − m(r)_j` (lower suggests the retained rationale supports the same prediction). Both evaluate the original class probability, not the gold class nor task accuracy. A negative removal score means confidence increased after removal. These are perturbation effects under that input and fixed model, not identification of semantically correct use. For soft rankings, select `k_d` equal to the dataset-average human rationale length; AOPC uses top 1%, 5%, 10%, 20%, 50% token bins and no retraining. Random ordering averaged over ten runs is an explicit baseline. Dataset/query formatting and surviving input permissions matter; the paper's shorthand `m(r)` is not a guarantee of a natural in-distribution prompt.

**Supervision, units and controls (§§3,5–6; App.C).** Inputs are documents/questions and rationale spans or sentences; output is a task label. Some selectors are rationale-supervised, one learns from instance labels alone; the two-model pipeline trains an extractor and separately parameterized classifier using positive human rationale spans (teacher forcing). This is not an unmodified model's free native readout. Soft score methods share a classifier and its task score; random, attention, gradients and LIME vary only the explanation score. In Table 4 on movies, LIME comprehensiveness .187 vs attention .129, but sufficiency .093 vs .097 and random .330; on BoolQ GloVe/LSTM LIME sufficiency is −.154 versus random .005, illustrating that negative sign and ranking depend on condition. Table 3 on Evidence Inference BERT-to-BERT has F1 .708 and token F1 .468, versus supervised Lei model .461 and .000; models differ in structure and rationale supervision, not a matched architecture ablation. Long BoolQ/Evidence Inference exceed BERT limits in soft baseline and use GloVe. App.C reports hard Lei models trained up to 20 epochs, early stopping patience 5; pipeline models use different budgets. BoolQ source-document overlap is an explicit split exception (§3); do not infer uniform leakage-free splitting.

**Interpretation and follow-through.** Human agreement is plausibility, not causal use; hard extractive pipeline's decoder-input guarantee assumes independent encoder/decoder and does not equate rationale quality with source truth. Removal can create unnatural strings, exploit shortcut evidence, or cause out-of-distribution changes; return false/true/unknown/contradictory evidence with semantic answer checking and matched-length random/irrelevant deletions. Relevant original IDs D.14–D.17, plus D.03–D.05 and D.18. Independent no-revisit options include improving native query/readout, in-state conflict-aware objectives, or trained content-use supervision; none is justified merely by an erasure score. A hypothesis changes if legal matched natural replacements flip the correct answer while controls stay stable, and if task performance survives genuinely sufficient evidence with all other channels restricted.
