## Problem, solution and distinction
Global feature importance can miss redundancy and complementarity when measured only by leave-one-out or univariate effects. **Solution:** SAGE allocates a loss-based feature-coalition game with Shapley values averaged over permutations (§§2–3). This borrows cooperative game theory and Monte Carlo sampling; it interprets a trained supervised predictor rather than learning a sequential action policy. For a coalition S, the theoretical restricted predictor averages model output over missing features conditional on observed features, and coalition value is loss reduction relative to empty input. In practice the experiments sample the missing features from their **marginal**, breaking dependencies and changing the game (Supp. A, D): correlated counterfactual inputs may be off distribution. Content units are dataset features; subset membership is an observational/missingness convention, not a retrieval address, memory intervention or causally authorized adaptive query.

Shapley allocations sum to the full-coalition benefit and average each feature's incremental contribution across coalitions. This allows attribution of nonadditive interactions, but an additive score vector cannot exactly represent every coalition's value, and does not supply additive rewards for sequences of future actions. In a Bayes-optimal classifier with cross-entropy and exact conditional restrictions, the coalition value is mutual information and increments are conditional mutual information; Supp. B–C shows the required optimality and loss conditions. Sampling convergence (Supp. E) assumes correct conditional distribution, increasing inner/outer samples and arbitrarily large data; the practical marginal-sampling estimator targets a different set function even with infinite samples. Variance reduction alone does not repair this mismatch.

## Results, cost and falsification
Five datasets with trained MLP/tree/linear models are compared with permutation, mean imputation, feature ablation and univariate predictors. Visually checked Table 2: SAGE vs univariate correlation for BRCA is **0.8611 vs 0.8718**, and vs permutation on credit **0.9565 vs 0.9571**; SAGE does not win every cell. On MNIST univariate selection is best for identifying least important features (Fig. 2), while SAGE is strong for the most important. Supp. H uses 512 background samples on bank/bike/credit, 128 MNIST and 334 BRCA, and 5,000 (1,500 MNIST) retrained subset comparisons; authors report 2–4 orders fewer model evaluations than their naive mean-loss-SHAP comparison, not zero-cost explanation or a serving benchmark. Gene features include manually selected known genes and randomly selected others (H.1). Explanatory allocation is not causal source dependence or an online retained-memory utility.

**Directions:** R.14–R.15, D.11. Independent no-revisit options include fixed closed state, joint update or robust native readout without adaptive retrieval. A policy hypothesis changes only if observed coalition-conditioned actual task outcomes, including paired complementary features and negative combinations, predict held-out sequential continuation value under matched access/cost; compare conditional and marginal replacement, recomputed downstream paths and explicitly report support. Shapley ranking alone cannot establish this.
