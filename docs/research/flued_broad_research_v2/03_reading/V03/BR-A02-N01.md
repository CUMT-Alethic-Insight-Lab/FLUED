# BR-A02-N01 — LeapQuant: Efficient Linear Attention with Accurate Recurrent State Quantization

**Status: FULL (paper-reading scope).** [arXiv:2609.38166v1 PDF](https://arxiv.org/pdf/2609.38166v1), 29 September 2026; §§1–5 and Apps.A–E pp.1–16 including Tables 1–6 and derivations read. **Problem → one-sentence solution.** Repeated quantization corrupts recurrent states and outliers widen the scale: hold a low-bit boundary matrix for a window, read recent higher-precision update records, and refit low-rank FP16 compensators plus smoothing at each boundary (§3). Borrowed techniques are mixed-precision quantization, rank-one decomposition/power iteration, and chunked recurrence; it is training-free inference, not a new retention objective or retrained writer.

**What is written/read.** Current token produces k,v,q, decay and error-correction vectors; their past accumulated matrix plus buffered `(decay,key,correction)` supplies each native causal output. Queries are current token features, not known future questions; no future-label oracle. The recent buffer is projected update history, not original source text, but is an extra retention channel. The hybrid models retain full/sparse-attention KV and local convolution paths, so task accuracy cannot be assigned solely to recurrence. No counterfactual content-specific use was measured.

**Derivation versus experiment.** App.B.1 p.14 fixes the same input/coefficient sequence in both FP32 and quantized recurrences; error obeys propagated decay/erase plus newly injected rounding. Windowing changes frequency, not just state bits; the real closed-loop full-model coefficients can change. §3.2–3.4, App.B.2–B.3 derive reads from quantized boundary, compensated records and exact within-window projected updates in real arithmetic, not a universal finite-precision worst-case guarantee. Separate erase directions require two records per token (App.A).

**Costs and findings.** Default p=16, r=4 FP16 vector-pair compensators (r=8 for 4-bit) and FP32 smoothing scales; §4.3 p.8: 1.19 bytes/state element includes boundary residual, scales and compensators versus 4-byte FP32, **excluding** ~8 KiB/head/layer active update buffer for 128×128 states, plus refits/workspace, caches and weights. 8-layer Qwen3.8/GLM models only benchmark speed, not accuracy. Three full hybrid models, three generation seeds (§4.1/Table 1). Qwen-9B AIME/LCB: FP32 87.9/64.1; INT8 per-step 7.1/9.2; INT8 window 82.4/60.6; plus compensators 86.6/61.5; plus smoothing 87.9/64.1 (Table 2)—ordered additions, not full factorial. At p32 kernel 2.20× vs p16 2.52×; r16 0.74× FP32 kernel (Table 3). 4-bit aggregate 60.4 vs FP32 75.5 (Table 1), so not uniformly lossless. Fig.3 author reports 64K PG-19 state error and 39× improvement for windowed INT8; Appendix D 96K/128K is throughput-only on truncated models. End-to-end speedups use declared workload, including simulated Qwen-length distribution for Kimi; not an exact delayed-binding assay.

**Rivals and follow-up.** Rounding accumulation vs rank/bits vs local-attention compensation: vary precision and rounding frequency independently at equal **complete** bytes and update cost; evaluate long-delay random bindings and native wrong-content interventions with attention path controlled, then compare quality, active buffers, cache, refit and physical traffic. Prior directions **B.11–B.12, B.14–B.18, D.02–D.06, I.26, R.16**. No architecture or host-level conclusion follows.
