# W0213 — Beyond State Capacity: Why Retrieval Breaks in Mamba

**Problem → solution and borrowed technique.** Query-first recall can fail despite the ability in principle to keep only the requested answer; diagnose depth-dependent relevance using local target flags, linear probes, forward/reverse activation patching and oracle gate scaling (§§3–6). No trained deployable repair is proposed.

**Flow and permissions.** In each prompt two demonstrations and a name query precede the phonebook, followed by a request to output its ten random digits; flagged variant prepends the word `target` to the correct entry (App.A.1/Fig.5). The model's own causal representation generates token-dependent Mamba-2 write, decay and read coefficients; the output is the native generated answer. Diagnostic flag gives privileged target location, and patch/scaling acts specifically on **all ten known answer digits** at selected layers: neither is a legal unknown-query writer. The state probe substitutes single-token professions from 20 classes, so it does not probe the same 10-digit task (§4.2, App.A.3). Representation/gate probes are trained supervised classifiers; recoverability is not native readout or final answer use.

**Models, metrics, controls.** Nvidia base Mamba-2 8B, 56 layers, and code-instruction Mamba-2 7.3B, 64 layers; both width4096, 128 heads and state dimension128; normal lengths 150 and 400 entries (§3, App.A.2). App.A.3 uses 500 samples per task/length, top-1 decode 20 tokens and regex 10 digits; state probe uses 15,000 samples, sample-level 80/20 split, 1,048,576×20 per-layer parameters, balanced reservoir, Adam, 16 updates per forward batch. Relevance probes use 500 samples, 80/20 split, 100 epochs; total ~1,000 L40S GPU-hours. The paper's Transformer comparison is motivated from earlier work, not a fresh fully matched Transformer arm here.

**Observed vs interpreted.** §4/Fig.2: flag improves native retrieval, but longer phonebooks still degrade. §5/Fig.3: replacing target-digit gates in both directions transfers flagged/unflagged outcomes; scaling specified target gates 0.8× vs 1.2/1.5/2/3× can break/rescue. §6/Fig.4: representation relevance is linearly separable earlier than gate signals and cumulative early/middle-layer patch effects; this is a powerful intervention on gates but changed-prompt hybrids may be off-distribution. Matching representation- and gate-patch curves does not uniquely exclude content/reader interactions or show a learned correct-target detector.

**Theory and discrimination.** Query-first reduces an information requirement, it does not prove that a specific finite state, precision or learned representation has excess capacity. Decay, target write and output read can still interact. Minimal proposed control: same frozen states and legal gate/q readers, shuffled/non-target position and scale-matched patches, verified natural donor pairing, and matched query-first vs query-last randomized bindings. Prior directions **B.04–B.06, B.09–B.10, B.14–B.17, C.06–C.08, D.01–D.02, D.07–D.10, E.01–E.03**. Exact curve values were not digitized, and target-host effects remain open.
