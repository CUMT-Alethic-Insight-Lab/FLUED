**Problem → solution.** Local attention precisely accesses only a recent window; train a nonlinear neural associative memory through online gradients and combine it with local attention or use memory alone. Borrowed techniques: fast weights, meta-learning, inner-loop regression, gradient momentum and weight decay, persistent learned prefix vectors and chunked parallel updates (§§3–4).

**Learning, writing, addressing, use.** Current token x maps to k=xWk, v=xWv; inner loss ||Mprev(k)−v||² updates the fast neural memory weights; gradient is a measure of present fit error, not a measured guarantee of future usefulness. Data-dependent step and momentum update the momentum state, and data-dependent forgetting shrinks fast weights (eqs.11–14). Query q=xWq performs a forward pass on the memory, not a database lookup. Outer training learns projections and other model parameters by task/LM objective, while the inner network and momentum change during test. Chunkwise gradients refer to a chunk boundary state (§3.2), so exact update/causal timing must be checked against complete source and implementation. Persistent memory is input-independent learned prefix, distinct from both fast weights and local-window KV. Account for fast network weights, momentum, gates, chunk buffers, persistent vectors, local KV and training history.

**Three interfaces.** §4.1 MAC reads the prior segment's fast memory using current segment-derived queries, concatenates returned memory and learned prefixes with current input to causal within-segment attention, then uses attention outputs to update memory for later segment. §4.2 MAG combines sliding-window attention with a neural-memory branch by a nonlinear gate; §4.3 MAL puts memory before local attention. LMM tests neural memory alone; output comparisons are not an intervention proving which path carried the answer. Future segment text and answer labels are not explicitly supplied at writing; local attention nevertheless retains recent tokens.

**Controls and results.** §5.1: 170M/340M/400M trained 15B FineWeb-Edu tokens, 760M 30B, Llama2 32K tokenizer, 4K training length, AdamW 4e-4 cosine, batch .5M tokens; some baselines' 400M results are imported (App.B). No clean factorial separates local attention, state width, optimizer state and total training compute.

**Theory and discrimination.** §4.4 Theorem4.1 claims greater state-tracking expressivity than specified model classes; no proof was recovered in this version, and no proof implies trained retention at bounded precision. §5's attributed benefits of surprise, forgetting and depth are not isolated by unrelated-baseline comparisons. Minimal proposal: same trained network and budget, independently remove local path/momentum/decay with proper retraining and matched fast-state bytes; use fresh random bindings, load × delay × interference, and correct-versus-wrong-content interventions.
