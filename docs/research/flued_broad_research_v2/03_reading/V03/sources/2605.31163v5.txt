arXiv:2605.31163v5 [stat.ML] 14 Oct 2026                                             ABSTRACT

                                                    To battle softmax attention’s linearly growing inference memory cost, current
                                                     recurrent architectures compress history into a fixed-dimensional state. Their
                                                     recurrence equations alone, however, leave the underlying assumptions about
                                                     memory implicit. We introduce design models: auxiliary probabilistic models
                                                     specified by an initial distribution and input-dependent factors encoding memory
                                                     dynamics and incoming evidence. Once these assumptions are specified, Bayesian
                                                     filtering determines the recurrent update under the model. Specifically, a linear-
                                                     Gaussian design model yields the Bayesian Layer, which maintains a memory
                                                     estimate and its covariance via a Kalman update. Resetting this covariance recovers
                                                     Delta-rule updates, while a different design model yields the additive recurrences
                                                     of linear attention, GLA, and Mamba-2. These connections make explicit the
                                                     assumptions underlying familiar memory updates. We illustrate how the geometry
                                                     of the Bayesian Layer’s uncertainty shapes subsequent updates and helps preserve
                                                     earlier associations. In associative recall tasks, the Bayesian Layer improves recall
                                                     on longer sequences and with greater overlap between keys than seen during
                                                     training. We further evaluate its performance on multi-query associative recall
                                                    (MQAR) and language modeling. Distilling Bayesian Layers into a pretrained
                                                     Gated DeltaNet improves retrieval accuracy on RULER over a continued-training
                                                     control.

                                          1 INTRODUCTION

                                          Efficient recurrent sequence layers compress a growing token sequence into a finite-dimensional
                                          state that is updated as new inputs arrive. Deciding how to update this state is a central problem
                                          in recurrent architecture design: each update must incorporate new information while preserving
                                          information from earlier inputs that remains relevant. Linear attention, GLA, Mamba, and Delta-rule
                                          layers address this problem through different recurrence equations (Katharopoulos et al., 2020; Yang
                                          et al., 2024a; Gu & Dao, 2024; Schlag et al., 2021; Sun et al., 2023; Qin et al., 2024; Liu et al.,
                                          2025; Yang et al., 2025; Siems et al., 2025; Peng et al., 2023; 2024; Behrouz et al., 2026; De et al.,
                                          2024; Beck et al., 2024), while other work derives such rules from online regression and Bayesian
                                          inference (von Oswald et al., 2026; Bonnet et al., 2026; Shaj et al., 2026). The recurrence equations
                                          alone, however, do not make explicit the assumptions about what is stored and how new evidence
                                          relates to it.

                                          We make these assumptions explicit through a design model: an auxiliary probabilistic model of
                                          a latent memory state. The model specifies an initial distribution and input-dependent factors that
                                          encode state dynamics and incoming evidence. Consequently, Bayesian filtering determines the
                                          recurrent update from these assumptions. The belief parameters needed for subsequent updates and
                                          readouts form the implemented recurrent state, while a separate query-dependent readout produces
                                          the layer output. This framework thus links a recurrent update to explicit assumptions about memory.

                                          The Bayesian Layer (BL) instantiates this framework with linear-Gaussian latent-memory dynamics
                                          and write likelihood. Its recurrent state contains the posterior mean of a latent memory and a dense

The framework also provides a way to relate existing recurrent architectures through the assumptions
underlying their memory updates (Table 1). Resetting the Bayesian Layer’s predicted covariance to an
isotropic matrix at each step recovers Delta-rule updates (Schlag et al., 2021; Yang et al., 2024b; 2025;
Kimi Team, 2025). Under a separate design model, exact filtering yields the additive recurrences of
linear attention (Katharopoulos et al., 2020), GLA (Yang et al., 2024a), and Mamba-2/SSD (Dao &
Gu, 2024). These connections distinguish approximations to the filtering recurrence from differences
in the underlying design model.

Our contributions are:

       1. We introduce the design-model framework, which derives memory updates for recurrent
           architectures through Bayesian filtering and makes explicit the assumptions behind Delta-
           rule and additive recurrences (§§2–3).

       2. We derive the Bayesian Layer and analyze how tracking uncertainty shapes the geometry
           of memory updates, helping preserve associations under interference (§2).

       3. We evaluate the layer on associative recall tasks, MQAR, and language modeling, includ-
           ing long-context retrieval after distillation into a pretrained Gated DeltaNet (§4).

2 THE DESIGN-MODEL FRAMEWORK

We write a recurrent sequence layer in terms of its update function f . At each step, the current input
xt and previous state ht−1 determine the updated state,

                                 ht = f (ht−1, xt).                  (1)

Choosing f determines how each new input modifies a finite-dimensional representation of the
past. Modern recurrent architectures typically specify the memory-update rule f directly through
computational structure that supports parallel training and mechanisms such as gating and error-
correcting updates (Dao & Gu, 2024; Yang et al., 2025). These choices shape how information
accumulates in memory, but their underlying assumptions can be difficult to identify and compare
from the recurrences alone.

We propose making these assumptions the starting point for architectural design, through a probabilis-
tic model of memory, which we call a design model. The model specifies an initial distribution and
input-dependent factors that encode memory dynamics and incoming evidence. Bayesian filtering
determines the optimal recurrent update under the model (Särkkä, 2013), providing a systematic way
to construct updates and interpret their behavior.

nonnegative, input-dependent pairwise potentials Ψt(St−1, St; xt). For each input sequence x1:t,

Thus the design model determines the filtering update, while the readout specifies what the layer
estimates.

With the model and readout specified, a recurrent implementation requires the belief parameters
needed for subsequent filtering updates and readouts to admit a closed, fixed-size recurrence. These
parameters form the recurrent state ht in (1), whose update is determined by filtering.

The architectural choices in this framework are therefore the initial distribution µ0, the form of the
input-dependent pairwise potentials Ψt, and the readout g (Figure 1). In the following sections,
we illustrate these choices with the Bayesian Layer design model, whose factors encode dynamics
and associative relationships, and a latent-input design model, whose factors encode evidence about
independent write coefficients.

2.1 THE BAYESIAN LAYER DESIGN MODEL

Matrix-memory architectures represent key–value associations through a shared linear map, k → St⊤k
(Amari, 1972; Yang et al., 2025; von Oswald et al., 2026). We use this representation to construct
the Bayesian Layer design model, in which each value vt is a noisy observation of St⊤kt and the
memory follows input-dependent dynamics between observations.

RD×D, and noise scales rt = r(xt) > 0 and ℓt = ℓ(xt) ≥ 0.

Each coordinate of St⊤qt has posterior variance qt⊤Ptqt. Subsequent memory updates use Pt, while
the readout uses only the mean. We call the recurrent layer defined by this design model and readout

the Bayesian Layer.

2.2 THE BAYESIAN LAYER RECURRENCE

Under this design model, Bayesian filtering (Särkkä, 2013) gives a closed-form recurrence for the
recurrent state ht = (Mt, Pt). Starting from M0 = 0 and P0 = σ02I as specified in Definition 1,
the same update applies from t = 1.

Proposition 1 (Bayesian Layer recurrence). Under the Bayesian Layer design model (Defini-
tion 1) with belief structure (7), the uncertainty-warped key ut gives the update direction, and
the recurrent state (Mt, Pt) satisfies

P¯ t = At Pt−1 At⊤ + ℓt2I,                                   predicted covariance    (9)

ut = P¯ t kt,                                                update direction        (10)

βt = rt2 + kt⊤ut −1,                                         innovation precision    (11)

Mt = I − βt ut k⊤t At Mt−1 + βt ut vt⊤,                      mean update             (12)

Pt = P¯ t − βt ut u⊤t .                                      covariance update       (13)

This recurrence is the exact Kalman filter for the design model (Kalman, 1960; Anderson & Moore,
1979; Kailath et al., 2000). It preserves the belief structure in (7), with full posterior covariance
Im ⊗ Pt. The layer therefore propagates one shared D × D covariance matrix alongside the mean.
Section B derives the recurrence and establishes this closure.

The predicted covariance maps the key kt to the update direction ut, while βt scales the correction.
These quantities follow from filtering once the learned functions A, ℓ, k, v, r are evaluated at xt and
the previous belief is given. Prediction adds process noise through ℓt2I and conditioning then reduces
covariance by the rank-one term in (13). Both steps preserve positive semidefiniteness.

For efficient computation, we restrict At to be diagonal or blocks of damped rotations; Section C gives
the full implementation details. Multiplication by At then uses row-wise scaling or transformations
within each block. Covariance prediction and conditioning cost O(D2), and the mean update costs
O(Dm). The per-step recurrent cost is therefore O(D2 + Dm).

3 RECURRENT ARCHITECTURE FAMILIES THROUGH DESIGN MODELS

The construction in §2 yields the Bayesian Layer by exact filtering under the Bayesian Layer design
model. Resetting predicted covariance in the Bayesian Layer filter gives the Delta-rule family. A
different model, the latent-input design model, treats observations as evidence about independent
write coefficients rather than stored associations. Exact filtering under this model gives the additive
family. Table 1 summarizes both families; derivations appear in Section A.

3.1 BAYESIAN LAYER DESIGN MODEL: COVARIANCE RESET ⇒ DELTA-RULE FAMILY

Proposition 2 (Isotropic-reset reduction). Under the Bayesian Layer design model (Definition 1), fix
a scalar sequence λt > 0 and replace the predicted covariance P¯ t in the filtering update by λtI at
every step. Then ut = λtkt and the Bayesian Layer update reduces to

            Mt = (I − ηtktkt⊤) At Mt−1 + ηtktvt⊤,                ηt := λt/(rt2 + λt∥kt∥2).                 (16)

Equation (16) has the canonical Delta-rule form: the update corrects the difference between the
observed value and the predicted memory readout at kt. Covariance reset retains Delta-rule correction
but discards the covariance accumulated from past observations. Choices of At along the scalar–
diagonal–dense hierarchy recover the variants in Table 1.

3.2 LATENT-INPUT DESIGN MODEL: EXACT FILTER ⇒ ADDITIVE FAMILY

We consider a design model that treats each observation as evidence for a new write, independent of
stored associations.

Definition 2 (Latent-input design model). Let the initial memory S0 have mean M0. Each obser-
vation vt provides noisy evidence about a latent write coefficient ϕt ∈ Rm. For input-dependent
λt, rt > 0, define

            ϕt ∼ N (0, λtIm),          vt | ϕt ∼ N (ϕt, rt2Im),  St = AtSt−1 + ktϕ⊤t .                     (17)

All write coefficients and observation noises are mutually independent and independent of S0.

Given St−1 and ϕt, the memory St is deterministic. Marginalizing the write coefficient gives a
design factor Ψt(St−1, St; xt) within the framework of §2. Taking the posterior expectation of the

state update in (17) yields an additive recurrence for the latent memory state’s mean (Section A.2).

4 EXPERIMENTS

We test whether propagating covariance helps preserve stored associations under subsequent memory
updates. We first use synthetic recall tasks with controlled key overlap (§4.1), then evaluate recall
on MQAR and WikiText-103 (§4.2) and retrieval after distilling Bayesian Layers into a pretrained
language model (§4.3). Appendix Table 2 summarizes the experimental settings.

4.1 ASSOCIATIVE RECALL WITH OVERLAPPING KEYS

The analysis in §2.3 predicts that covariance geometry helps preserve associations during writes
at nearby keys. We first compare memory recurrences with fixed keys and values, without learned
projections. The toy task stores six associations, labeled A–F , with overlap ρ = 0.98 between keys
A and B while all other keys are orthogonal. After initialization, we repeat (kB, vB) ten times,
followed by ten repetitions of (kA, vA). Figure 3a shows the squared readout error ∥vˆt(kB) − vB∥2,
averaged over initial write orderings (Section E.1).

Repeated writes at kB reduce all methods’ mean error below 10−4, with dense and diagonal covari-
ance requiring fewer writes. However, during subsequent writes at kA, their performance diverges
with dense covariance reaching the lowest error plateau, followed by diagonal covariance (Figure 3a).
Asymptotic behavior under repeated writes is analyzed in Sections D.3 and E.2.

We next test whether the covariance advantage persists in learned networks and how it depends on key
overlap. We separately train two-layer networks using the Bayesian Layer, its diagonal-covariance
variant, Delta-rule (Schlag et al., 2021), linear-attention (Katharopoulos et al., 2020), and GLA (Yang
et al., 2024a) updates. Each training sequence contains target–distractor pairs (Ti, Di) with within-
pair key overlap kT⊤i kDi = ρi. Keys from different pairs remain orthogonal. Sequences initialize all
associations, write repeatedly at each target followed by nd writes at each distractor, and finally query
the target keys. We use the supplied key vectors directly as keys and queries, so learned projections
cannot change their overlap. Evaluation uses more distractor writes and greater key overlap than
training (Sections E.3 and E.3.2).

4.2 ASSOCIATIVE RECALL ON MQAR AND WIKITEXT-103

The preceding experiment controls key overlap directly. We next ask how the Bayesian Layer performs
when the model must learn representations for storing and retrieving associations from tokens. We
begin with Multi-Query Associative Recall (MQAR) (Arora et al., 2024a), where sequences present
key–value associations and later query their values. We compare two-layer models across widths
under a common data and training protocol (Section F.1). The baselines are Gated DeltaNet (Yang
et al., 2025), Gated DeltaNet-2 (GDN-2) (Hatamizadeh et al., 2026), MesaNet (von Oswald et al.,
2026), RWKV-7 (Peng et al., 2025), Palimpsa-D (Bonnet et al., 2026), Mamba-2 (Dao & Gu, 2024),
and causal attention (Vaswani et al., 2017) with rotary position embeddings (Su et al., 2024).

Figure 4a reports recall at sequence length 1,024, beyond the training maximum of 256. BL, MesaNet
and RWKV-7 achieve similarly high recall at width 256, but BL has higher recall than those two
baselines at width 128. BL therefore remains competitive with the strongest recurrent baselines when

5 DISCUSSION

Related probabilistic sequence layers. Like Palimpsa (Bonnet et al., 2026) and Kalman Linear
Attention (Shaj et al., 2026), the BL treats recurrent computation as probabilistic inference. Its
dense key-space covariance retains correlations omitted by the diagonal representations used in their
implemented layers. Dense statistics also appear in MesaNet (von Oswald et al., 2026), where they
support a reweighted in-context regression solved by conjugate gradient at readout. The BL instead
propagates a posterior over an evolving state through structured dynamics and process noise, with
readout given by a linear projection of the posterior mean of the latent memory state.

Limitations. Our geometric analysis focuses on Gaussian beliefs. Extending it to the information
geometry of other exponential families, drawing on natural-gradient approaches to Bayesian learning,
remains future work (Khan & Rue, 2023). Dense covariance adds training computation quadratic in
the key dimension and additional activation storage, making low-rank, sparse, or other structured
approximations promising future directions. Finally, the readout uses only the posterior mean, leaving
the use of propagated uncertainty for downstream losses or calibration unexplored.

Conclusion. Design models connect recurrent sequence architectures to probabilistic assumptions.
They place a range of recurrent architectures within a common probabilistic framework, distinguishing
changes to the underlying model from approximations to inference. For the Bayesian Layer, our
geometric analysis shows how repeated evidence can reshape covariance to reduce confusion between
nearby keys. Motivated by this analysis, we examined recall across controlled key geometries, small
language models, and distillation into a pretrained GDN. These experiments show improved recall
under greater key overlap and more distractor writes than seen during training, higher WikiText-103
associative recall over corresponding GDN and RWKV-7 baselines, and improved RULER retrieval

over continued GDN after distillation while retaining similar overall perplexity. Together, the analysis
and experiments demonstrate how probabilistic modeling can guide the design of recurrent sequence
architectures that use uncertainty geometry to integrate new evidence with stored information.

C FILTERING IMPLEMENTATION

We implement the Bayesian Layer using chunks of length L. Each chunk receives the posterior
mean and covariance from the preceding chunk, computes its outputs, and returns the updated belief
parameters. The implementation reorganizes the recurrence from Section B around batched matrix
products, compact histories of update directions, and tiled GPU operations. Chunk-boundary state
propagation and tiled evaluation also underpin efficient GLA and DeltaNet implementations (Yang
et al., 2024a;b). The equations below describe our covariance and mean computations.

C.1 STRUCTURED DYNAMICS AND NOISE

We use diagonal transitions or blocks of damped rotations,

              A(tj) = ρt,j  cos θt,j  − sin θt,j      ,        0 < ρt,j ≤ 1.
                            sin θt,j   cos θt,j

Diagonal entries likewise have magnitude at most one. These structures allow multiplication by At
through coordinate-wise scaling or transformations within each pair. Throughout this section, D

counts real state coordinates, including both coordinates of each rotational block.

For rotational blocks, keys and queries address the real coordinate: their embedded forms are (kt,j, 0)
and (qt,j, 0). Below, kt, qt ∈ RD denote these embedded vectors. We inject process noise into the
same coordinates, giving the block covariance

                            Qt(j) = ℓ2t      1    0         .
                                             0    0

Rotations subsequently transport this uncertainty between both coordinates. For ordinary real diagonal

The implementation uses forward transition products throughout. For a rotational block,

                         Φt(← j) s = exp  t                t

where R(θ) is the rotation matrix above. Relative products are evaluated from differences of
cumulative log-radii and angles, without explicitly forming inverse transition products. Under the
stated parameterization, ∥Φt←s∥2 ≤ 1.

We implement the tiled computations in Triton (Tillet et al., 2019). Recurrent quantities and chunk-
boundary states are maintained in fp32. The chunk identities above are exact in real arithmetic;
floating-point execution additionally floors innovation denominators at 10−6.

A custom backward pass differentiates the entry-covariance products, gain computation, mean/readout
recurrence, and exit-covariance update. Training retains chunk-boundary states and compact inter-
mediate histories for backward. Optional checkpointing recomputes these histories and reconstructs
intermediate boundaries by replaying chunks from saved states.

For one head with m value coordinates, recurrent-state storage is O(Dm + D2). The entry and exit
covariance computations cost O(LD2) per chunk, the gain-history computation costs O(L2D), and
the mean updates and readouts cost O(LDm). Over a sequence of length T , total forward work is
therefore

                                           O T D2 + LD + Dm .

For fixed chunk length, this is linear in sequence length. Training activation storage additionally
depends on the saved chunk boundaries and histories, and can be reduced through checkpointing.

E.4 RANDOM-KEY RECALL

This experiment tests interference beyond the engineered pair structure. Raw addresses are inde-
pendently sampled from N (0, I) in R64 and normalized to unit norm; values are one-hot labels
from {1, . . . , 64}, re-sampled for each sequence. Each sequence contains n writes followed by

eight queries sampled uniformly without replacement from the written keys. Tokens use the same

type/address/value format, now with 64 address and 64 value coordinates.

GDN-like and RWKV-like BL variants. These names describe the components surrounding the
Bayesian recurrence. Both BL variants have four heads with key and value dimensions 128 and use
learned diagonal state decay together with input-dependent process and observation noise. Initial
decay half-lives span 32 to 4,096 tokens. The initial process and prior variances are calibrated on
training windows to give an observation gain of approximately 0.5, with initial observation variance
one; eight disjoint training windows check the calibration. The initial prior covariance is then fixed,
while the process and observation noise parameters remain trainable.

The GDN-like variant retains GDN’s query, key, and value projections, length-four causal convolu-
tions with SiLU, ℓ2 normalization of queries and keys, and gated RMS-normalized output. It uses
RMS normalization around the residual blocks and a SwiGLU MLP of hidden width 1,536. The
RWKV-like variant instead retains RWKV-7’s two-token mixing, per-head group normalization, local
output term, and output gate, with LayerNorm and a squared-ReLU MLP of hidden width 2,048.
Both the RWKV-like BL and the RWKV-7 baseline disable cross-layer value sharing. This gives each
BL a corresponding baseline with the same surrounding block structure.

Other model configurations. GDN, GDN-2, MesaNet, and Palimpsa-D use four heads of dimen-
sion 128 and SwiGLU MLPs of hidden width 1,536. GDN-2 uses independent erase, write, and
decay gates. MesaNet uses 30 conjugate-gradient iterations, with its regularizer initialized to one and
bounded below by 0.25. Palimpsa-D uses chunk size 16, a rank-32 parameterization of its update
control, and fixed prior precision one. Mamba-2 uses expansion factor two, 16 heads with value
dimension 64 and state dimension 128, one input/output state-projection group, a length-four causal
convolution, and a SwiGLU MLP of hidden width 1,536. Attention uses eight heads of dimension
64, rotary position embeddings, and the same MLP width. These choices retain the architectures’
surrounding components; recurrent-state sizes and parameter counts are not constrained to be equal.

context. The earlier occurrence must be within the same document; tracking resets at document
boundaries. Distance is measured to that most recent occurrence, with bins 1–64, 65–256, and
257–1,024 tokens. All models use the same evaluated token positions. The test evaluation contains
325,473 target positions, including 4,301 AR targets; the three distance bins contain 1,669, 1,432, and

mean and sample standard deviation. In particular, reported mean perplexities average the per-seed
perplexities. Table 5 gives the full results.
