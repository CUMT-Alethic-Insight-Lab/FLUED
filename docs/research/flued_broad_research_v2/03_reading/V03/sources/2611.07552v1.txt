                                                           B.5 Memory and Performance Accounting

                                                           The compact recurrent-state size in Eq. (15) mea-
                                                           sures only the persistent coefficient storage and
                                                           does not represent the complete GPU memory foot-
                                                           print. Actual inference memory additionally in-
                                                           cludes model parameters, shared projection bases,

convolution caches, temporary workspaces, inter-
mediate activations, and CUDA Graph allocations.
We distinguish recurrent-state storage from the
measured peak allocated and reserved GPU mem-
ory throughout our experiments. Similarly, reduced
state capacity does not by itself establish a pro-
portional reduction in physical GPU memory traf-
fic. We therefore measure recurrent-kernel DRAM
reads and writes using hardware profiling coun-
ters and evaluate decoding latency using complete-
model execution. The reported decoding measure-
ments include all model layers and maintain re-
current and convolution states across dependent
token steps. All reported speedups are obtained
from synchronized fixed-batch workloads with ap-
propriate same-device Dense baselines and do not
imply improvements in continuous-batching serv-
ing throughput.
