## Problem, mechanism and actual information contract

Problem: sparse permanent patches save trunk context but leave prefix predictions with stale global context. Solution in one sentence: add entropy-triggered, transient partial-patch computations that refresh byte predictions without adding permanent patch entries (§§2–3). Borrowed techniques are local cross-attention pooling, causal Transformer shared trunk, auxiliary next-byte entropy and adaptive computation; none is an external retrieval index. Next-byte cross-entropy trains the decoder and auxiliary head equally; gradients from the two-layer auxiliary branch stop at encoder output (B.3). AdamW and cosine schedule apply (C.2).

Input/output/supervision are UTF-8 bytes with 320-ID vocabulary. Mean-pooled observed local byte states query within-patch byte keys/values. A scratchpad receives only its current patch prefix and committed earlier patch states; masks block other scratchpads. It is *not* iterative recurrence through earlier scratchpads. Byte encoder residual bypasses trunk and is fused into the decoder. At a boundary, permanent patch write wins; temporary scratchpad results are overwritten, not retained in trunk KV (§3.1–3.2, Fig.4). Thus a short-lived computation/readout is not a persistent new memory write or proof that remote content drives the answer.

## New v2 coverage and retained counterexamples

- v2 C.2/Table 4: 50,000 steps; 100B bytes, batch 256, versus 400B bytes, batch 1,024. Every cell and main configuration is **one training run**, no seed variance. Prior audit's visually recovered validation BPB rows, columns 500M/100B, 2B/100B, 2B/400B: byte `0.7283/0.6933/0.6366`; tokenizer `0.7509/0.7063/0.6465`; fixed-p8 `0.7833/0.7295/0.6691`; fixed-p8+SP `0.7425/0.6920/0.6345`. In particular the 500M SP gain does **not** beat the flat byte baseline. Domain differences persist: 2B p8+SP natural text 0.8444 vs byte 0.8534; code 0.3482 vs 0.3454 (§4.2).
- Fixed-data SP/non-SP **training** FLOP multipliers, §4.3: fixed-p8 1.74×, SpaceByte 1.49×, entropy 1.47×, H-Net 1.41×. Estimated inference FLOP/byte ratios on code are respectively 1.57×, 1.40×, 1.38×, 1.23×, with H-Net using the distinct 1.5 checkpoint. These are different budgets; equal bytes and parameters are not equal training work.
- H-Net v2 B.3 main threshold 2.5; Fig.8 frequency test uses a **separately trained checkpoint** at 1.5. E.4/Fig.13 uses 1.5 for illustration. The old v1 already distinguished 2.5 main and 1.5 illustration; the separate-checkpoint specification is the update. Under matched training FLOPs H-Net regresses despite its fixed-data BPB improving 0.6422→0.6382 (§5.1/Fig.7). One-position trigger/router redundancy is the authors' hypothesis, not experimentally established cause.
- The purported 16× reduction counts **persistent trunk patch KV**, not model-wide serving memory; A estimates combined encoder/trunk/decoder KV about 44% and 33% of the byte model for p4 and p8 under stated equal-precision/full-width assumptions, excluding transient workspace. D explicitly says no serving latency/throughput measured. Efficiency is analytical, not measured runtime. Dense updates cost far more and can slightly worsen natural-text BPB (E.2). FLORES-200 byte baseline ranks best (5.3); prior v1 card retains NLU/tokenizer and code counterexamples.

## Interpretation, directions and discrimination

Relevant original coordinates **I.08–I.09, I.24–I.27, A.17–A.18, R.13/R.16**. The result distinguishes update frequency from committed state count, not boundary quality or general long-range semantic use. Rival explanations include extra training compute, changed realized learned-boundary rate, local residual bypass and entropy-trigger scheduling. Minimum prospective test: same fixed boundaries and committed states, equal total FLOPs/bytes and training opportunity, entropy vs fixed-stride/random triggers, plus local-residual controls; measure prefix correctness and remote-content dependence separately. Deployment needs real peak memory, prefill/decode latency and token/byte throughput at matched implementations. No experiment performed here.
