## Problem and intervention

Glitch tokens cause frozen language models to mis-handle some strings. **One sentence:** offline, search byte-preserving token-ID substitutions using behavioral probes; online, replace only rule-matched IDs in canonical tokenization, leaving model weights and tokenizer merge rules unchanged (§§2–4). Borrowed techniques: directed acyclic graph path search, probe-driven ranking/calibration, and frozen-model behavior testing; this is not learned recurrent state or retrieval. No model parameter optimization for this method; the behavioral evaluation itself is supervision and incurs model calls.

Detection tests each vocabulary item on repetition, spelling and length; failed items G0 are targets and all-three-pass items N0 are allowed graph edges (3, A.1). For a target's exact raw bytes, a graph node is a byte position and each normal token covering a substring is an edge (§4.1, C.3). A local additive proposal score combines estimated single-token and adjacent-pair probe failures and length; it is **not** a factorization of full contextual model probability. Select up to K=8 candidate paths, evaluate full-context utility on 12 probes, penalize broken previously passing probes and added tokens, require a positive threshold and pass checks, then accept only if four independent calibration probes pass. m+=0, no path, over-budget or calibration failure retains original; no retry of second-best on calibration (4.1, C.5, D.1–D.2). Defaults budget at most eight extra tokens *per matched span*, maximum 64-byte span. Rule lookup is nonrecursive and applies to canonical input IDs; generation and output IDs are not patched (§4.2, F.2). No claim of test-time knowledge acquisition or new task state follows.

**Byte and prefix contract.** C.1's local-equivalence proposition requires same emitted bytes *and decoder exit state* for the actual entry state, same special-token sequence, and non-overlapping replacements; joint validation or fallback for incompatible adjacent spans. C.4/Table C2 demands exact byte edges for byte BPE; SentencePiece normalizer/leading space/byte fallback/decoder state are included, not assumed away. Partial UTF-8 requires complete jointly validated spans, never replacement-character strings. Preservation is relative to the tokenizer's actual normalized output, not necessarily the original raw user string. A.2 uses decodable portion for partially decoded test targets or byte-level tasks when decoding fails; this is not a guarantee over every Unicode normalization or stream boundary.

## Findings, comparator budgets and limits

- §3/Figs.3–4: deleting merge rules *globally* at depth 1 fixes 36.82%/40.73% of detected targets but causes 9.73%/6.48% originally normal-token regressions for Llama/Qwen, increasing overall glitch rate. Different depths have non-monotone fix rates; global merge dependency changes normal longer tokens.
- Ten frozen models/six tokenizer families, BF16, greedy decoding (§5, A); Table 1 reports macro mean fix rate 85.10%, initial glitch rate 14.88% to 2.27%; Table 2 reports 70.73% for GlitchCleaner, 58.39% GlitchEdit, 24.63% GlitchProber. These are tested behavior categories, not all token meanings or safety. Table 3/F.2: Qwen has 1,473/29,451 targets (5%) with no feasible path; of remaining targets some fail utility, calibration or final tests. Coverage 89.2% versus final fix rate 87.5% (D.4) means a stored rule is not a guaranteed fix.
- **RR denominator:** among initially normal vocabulary entries, fraction that fails tests after repair (§3, Table 1). Zero RR arises in the isolated token-level protocol plus no rule for normal IDs. C.2 guarantees *the entire effective input* and conditional distribution only when no position triggers and all other model inputs match; keeping one normal token ID unchanged inside a mixed request does not protect its surrounding behavior. H.1 tests 500 generated contextual QA items on three models and reports changes −0.2 to +0.2 pp, not universal zero contextual damage. H.2 uniformly samples 500 glitches per model for entity QA, copy and code identifiers; the entity judge is a model with 94% agreement on 50 human-checked cases. The paper's H.1 text says unrepaired tokens have identical input; F.2 also identifies stored rules that fail final tests. These descriptions need reconciliation: a rule can be applied without final repair, so do not infer all final-unfixed targets were unmodified.
- Qwen K sweep Table 4 estimates ~47k candidate evaluations at K1, ~253k at K8, ~488k at K16; FR 71.83%, 87.50%, 87.93%. This is offline behavioral search plus classification, shared probes, and calibration, not free. D.6 reports 2.6% mean token growth at B8 for its specified evaluation; multiple matches can accumulate. E reports 0.36–2.08 h offline build and mean 0.065% measured online latency increase on the reported A100 workload; this workload-specific aggregate is not a universal p95 latency guarantee. Loss comparisons in G average per token across different tokenizations on target-containing generated passages; use caution when token denominators change. No artifact execution performed.

## Research use and minimal discrimination

Original directions **I.01, I.08–I.09, I.18–I.19, I.22–I.23, I.26–I.28, F.17**. Useful evidence is targeted interface repair under a fixed model, not architectural evidence for long-range memory. Rival explanations include search/selection overfit, special-token/normalizer mismatch, token inflation, generic frequent-subtoken regularity, and altered downstream context. A prospective minimal test fixes raw bytes and canonical IDs, compares selected path against length-matched random legal paths on held-out real contexts with target and adjacent facts, stratifies matched/unmatched spans, UTF-8 boundaries and tokenizer families, and reports full offline calls and per-request length/latency tails. This is a proposed test, not work performed.
