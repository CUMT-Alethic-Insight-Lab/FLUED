## Problem and solution

A finite recent-history window can alias histories with different futures, while hidden-state filtering normally assumes known model dynamics. **One-sentence solution:** represent the state by probabilities of a sufficiently rich finite set of action-conditioned future observation tests and update those probabilities recursively as actions and observations arrive (§1). Borrowed tools: probabilistic sufficient statistics, POMDP belief filtering, action-observation tests and linear algebra; this work builds on observable-operator and deterministic-test ideas cited in the introduction.

A test `t=a1 o1 ... al ol` asks for the probability of those observations conditional on taking the specified future actions; history is the earlier action–observation sequence. State `p(h)` is the vector of predictions for chosen core tests. A sufficient state means **every finite future action/observation test** has its probability determined by this vector; a linear PSR has a linear projection for each test. This is prediction sufficiency for that environment, not a decoder guaranteed to reconstruct all of history, answer arbitrary text questions, or handle a different process. Action sequences are interventions specified by the test, not automatically visible future queries from the environment.

## Construction, update and proof scope

For an n-hidden-state POMDP with known transition and observation matrices, associate each test with an n-vector of its probability from each hidden state, `u(aot)=T_a O_{a,o} u(t)`, `u(empty)=1`. The §2 depth-first search repeatedly adds linearly independent one-step extensions until closure. At most n tests are retained; lengths ≤n; finite sets and Gaussian-elimination independence checking give the stated polynomial construction. Matrix U has these core outcome vectors as columns. Lemma 1 argues each extension `T_a O_ao U` lies in span(U), and closure inductively covers every test. The pseudoinverse then expresses the required projected output and update matrices; composition yields the same future-test probabilities as the starting POMDP (Theorem 1 and full proof, §2). Thus q≤n for the **minimal POMDP** by applying the construction to it. The worked five-state float/reset construction returns five linear core tests; its two-test representation discussed in the introduction needs **nonlinear** updating, and must not be misreported as the five-state linear construction.

After observing `(a,o)`, each core prediction updates as `p_i(hao) = P(ao t_i|h)/P(ao|h)`; the linear projection applies to numerator and denominator, while the state update is a **normalized ratio**, not a globally linear state transition (§1). Only positive-probability conditioning events make the ratio defined. Small denominators, nearly dependent test vectors and pseudoinverse conditioning create potential numerical sensitivity; **the paper does not provide a finite-precision stability or error bound**. This is an analytical limitation, not a discovered proof error.

## Learning, native use, comparators and research boundary

The theorem constructs from known POMDP dynamics and a model-specified outcome family; it does not give a loss, gradient estimator, training schedule, state identification procedure from unknown data, or guarantee that a neural model learns/uses the state. Section 3 explicitly describes learnability, generalization and possible exponential compression as future work/speculation, not experiments or universal bounds. Comparators are k-order history (float/reset shows bounded k cannot represent all such histories exactly) and POMDP belief states (five-dimensional in example). A predictive-state sufficiency theorem does not imply all historical details retained; opposite histories can legitimately share state when their possible future test distributions agree.

**Prior directions:** **B.19, B.20, B.22, A.01–A.02, A.06–A.08, C.18**. The source licenses a bounded conceptual alternative to source revisiting, not a proof that finite learned language state works under arbitrary unknown queries. Rival hypotheses include inadequate state dimension, estimation/training failure, unstable normalized filtering, and a task distribution whose predictive rank is large. Minimum prospective discriminator: in a *known* controlled finite environment independently vary hidden-state count and rank of future-test matrix, compare exact known-dynamics filter with estimated and neural filters at matched state precision, and evaluate held-out future tests, rare events, long horizon and reconstruction separately. Success of an oracle filter does not establish native learned use; empirical language transfer requires a separate test.
