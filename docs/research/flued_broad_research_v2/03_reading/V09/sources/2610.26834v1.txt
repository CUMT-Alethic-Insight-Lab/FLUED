                                        Abstract

                                        We propose KronLSTM, a linear attention architecture based on the Kronecker Delta Rule, a novel update rule
                                        for associative matrix memories. KronLSTM extends the xLSTM family with a memory-revision mechanism
                                        that corrects targeted associations while modifying the memory only along a single direction in matrix space.
                                        This minimally invasive memory revision reduces interference with previously stored information compared with
                                        delta-rule updates, making it particularly well suited for long-context language modeling. The resulting memory
                                        dynamics can be mathematically described as a Markov chain that converges to a steady-state distribution, while
                                        the expected norm of the memory matrix remains uniformly bounded throughout the entire input sequence.
                                        Hence, KronLSTM ensures stable memory dynamics without requiring additional normalization and stabilization
                                        mechanisms for the memory state. Experiments show that KronLSTM is competitive with, and often outperforms,
                                        existing linear attention architectures, including models of the (Gated) DeltaNet family, with particularly strong
                                        performance on long context benchmarks. These results establish the Kronecker Delta Rule as an effective and
                                        analytically tractable foundation for stable associative memory in recurrent linear attention architectures. Our
                                        code and models are open-source.

                                        1 Introduction

                                        Large language models (LLMs) predominantly use the Transformer architecture ( Qwen Team, 2023; OpenAI,
                                        2025; Touvron et al., 2023a; Vaswani et al., 2017), whose softmax attention mechanism has computational costs
                                        that grow quadratically with context length, while its key–value cache grows linearly. Consequently, inference
                                        becomes increasingly costly as contexts grow. To reduce these costs, recent work has explored replacing softmax
                                        attention with linear attention mechanisms (Katharopoulos et al., 2020; Schlag et al., 2021), which can be traced

back to the idea of fast weight programmers (Schmidhuber, 1992). Linear attention compresses the context

into a fixed-size memory matrix that is updated as new tokens arrive, yielding linear computational complexity

and a constant memory footprint. Recently, recurrent architectures based on associative memories (Anderson,

1972; Kohonen, 1972), including xLSTM (Beck et al., 2024), as well as related state-space and memory-based

approaches such as Mamba (Dao and Gu, 2024; Gu and Dao, 2024; Lahoti et al., 2026), DeltaNet (Hatamizadeh
et al., 2026; Kimi Team et al., 2025; Yang et al., 2024, 2025), RWKV-5 and 6 (Peng et al., 2024), and other

alternatives to Transformers.

like (Gated) DeltaNet, provides bounded memory through a delta-style update, but uses the Kronecker Delta
Rule. The Kronecker Delta Rule is less invasive: it modifies the memory only along a single direction in matrix
space, reducing interference with previously stored associations. This targeted memory revision results in a less
noisy gradient flow over time.

Our contributions are:

• (i) Kronecker Delta Rule is introduced as a new update rule for associative matrix memories, which corrects
  the scalar associations while having minimal interference with previously stored values.

• (ii) KronLSTM is introduced as a novel linear attention architecture based on the Kronecker Delta Rule
  equipped with a vector forget gate, a β gate, and a target gate.

• (iii) Stability properties for the Kronecker Delta Rule are mathematically proved via bounds on the expected
  memory norm. These bounds ensure stable learning and proper gradient flow.

• (iv) Experiments empirically validate the strong performance of KronLSTM at long-context language
  modeling and retrieval tasks. KronLSTM performs strongly across language modeling, recall, and state
  tracking benchmarks.

2.1 Kronecker Delta Rule

Linear attention update rules for matrix memory. Linear attention (Katharopoulos et al., 2020) compresses
the context into a matrix memory S that is updated per token and read out per query,

with St ∈ Rdv×dk , keys kt and queries qt in Rdk , and values vt in Rdv . Therefore, S is an associative memory
(Anderson, 1972; Kohonen, 1972) with a Hebbian rule, i.e., an outer product update rule. Modern linear
attention architectures like xLSTM (Beck et al., 2024), Mamba (Dao and Gu, 2024; Gu and Dao, 2024; Lahoti
et al., 2026), RWKV-5 and 6 (Peng et al., 2024) rely on these associative memories equipped with gates and
transformations. The memory growth is controlled by a forget gate, which stabilizes the memory dynamics.

In contrast, the Delta Rule (Schlag et al., 2021; Widrow and Hoff, 1960) corrects the memory with the difference
of the retrieval to the current value when writing into the memory

Householder matrix, which admits chunkwise-parallel training (Yang et al., 2024).

The two rules differ in how an association, once stored, is changed. The Hebbian write of (1) is additive, so

the memory grows with the sequence and an earlier value can be buried by later writes but never revised. The

delta rule (2) revises: it removes the value currently stored at kt before writing vt. The correction, however,
proceeds along (Stkt − vt)kt⊤, a direction determined by the current memory content, so values stored at keys
that overlap with kt are affected as well. We aim at an error-correcting write that acts solely on the pair (kt, vt).

Kronecker Delta Rule. Let St ∈ Rdv×dk be the memory matrix, kt ∈ Rdk and vt ∈ Rdv the key and value at
step t, ct ∈ R a target and βt a step size. The scalar vt⊤Stkt measures how strongly the memory associates kt
with vt. The Kronecker Delta Rule corrects this scalar towards the target along the outer product of the pair as

follows

            St+1 = St − βt vt⊤Stkt − ct vtkt⊤ = St − βt vt⊤Stkt vtkt⊤ + βt ct vtkt⊤ .                                          (3)

                                                                                       erase               write

In place of the dv-dimensional residual Stkt − vt of the delta rule, a scalar is corrected, and the direction vtkt⊤
of the correction is determined by the input pair alone without utilizing the memory content. A target ct ≡ 1
stores each association with unit strength, while ct = 0 erases it. The target ct may depend on the input, i.e.,
serves as a gate, so that what is written becomes input-dependent. The right-hand side of (3) separates the

update into an erase and a write term, both scaled by βt. Choosing the target c˜t = ct/βt removes the step size
from the write, so that βt alone determines how much of the stored association is erased and ct alone how much
is written. KronLSTM uses this form, with both quantities computed from the input as gates (Section 2.2).

2.2 The KronLSTM architecture

In modern deep learning architectures for sequence modeling, the matrix update rules are stabilized and enhanced
with gating mechanisms. The mLSTM (Beck et al., 2024) places the Hebbian write (1) under a sigmoid forget
gate and an exponential input gate, and Gated DeltaNet (Yang et al., 2025) decays the memory of (2) by a scalar
before the correction,

             St+1 = ft St + it vtkt⊤ ,  St+1 = ft St I − βt ktkt⊤ + βt vtkt⊤ .  (9)

Kimi Delta Attention (Kimi Team et al., 2025) makes the decay (key) channel-wise, and Gated DeltaNet-2
(Hatamizadeh et al., 2026) replaces the single βt by separate channel-wise erase and write gates. KronLSTM
proceeds in the same way: the step size βt and the target ct of (3) become gates computed from the input; a
forget gate decays the memory, and the rule is embedded in the projections, short convolutions, normalizations,

and output gate of a standard sequence-mixer layer. All quantities below are per head, with key and value
dimensions dk and dv; we suppress the head index and write xt ∈ Rd for the layer input at step t.

KronLSTM update. The forget gate is a diagonal matrix Ft with diagonal entries in (0, 1). It acts on the key

dimension and hence decays the memory from the right, StFt, retaining each key direction separately. We use

target c˜t = ct/βt to decouple erase and write. The erase term of (3) is evaluated on the decayed memory StFt.

With ℓ2-normalized keys and values and a sigmoid βt, we have βt ∥kt∥2 ∥vt∥2 = βt < 1, so every update is
non-expansive and the memory operates in the regime of Theorem 2; the forget gate, with entries below one,

mLSTM and sLSTM in the xLSTM architecture.

3 Experimental Validation

We experimentally validate the KronLSTM architecture on different benchmarks with a focus on language
modeling tasks. We compare KronLSTM with the following recurrent linear attention architectures: Gated
DeltaNet (GDN) (Yang et al., 2025), Kimi Delta Attention (KDA) (Kimi Team et al., 2025), Mamba-3 (Lahoti
et al., 2026), and Gated DeltaNet-2 (GDN-2) (Hatamizadeh et al., 2026). Recent deployments of linear attention
in frontier models follow two hybrid-setting paradigms: either interleave the linear layers with a small number
of softmax attention layers (Kimi Team et al., 2025; Merrill et al., 2026; NVIDIA, 2025) or use sliding-window
attention (SWA) instead (Cabannes et al., 2026; Hatamizadeh et al., 2026). The advantage of the latter is keeping
the memory footprint constant with respect to the context length. Therefore, we evaluate every architecture
in two settings: as a pure linear attention model, and as a hybrid with SWA layers. For the hybrid setting, we
employ a window size of 2048 at a 5:1 ratio of linear attention to SWA layers. All models are pretrained on the
FineWeb-Edu dataset using the Llama2 tokenizer (Touvron et al., 2023b).

We train at a context of 8k, motivated by previous works (Beck et al., 2025a, 2026; Guo et al., 2026), where the
throughput advantage of linear attention compared to the softmax attention emerges from 8k context onward.
We evaluate the models within and extrapolating outside their context length (Section 3.2). The experiments in
the following sections show 1.5B parameter models trained on 100B tokens. In Appendix A6, we provide a set
of experiments at 400M model size.

3.2 Retrieval Capabilities

On long-context tasks, the Kronecker Delta Rule should improve the most over previous update rules, as
interference grows with context length. We assess the performance of KronLSTM on two benchmarks with
different context lengths.

The first benchmark is the real-world recall suite of Arora et al. (2024) (SWDE, SQuAD, FDA, TriviaQA, NQ,
DROP) for 2k context. Results are given in Table 2. KronLSTM has the best average accuracy, and it is the
best method in three out of six tasks in both pure linear attention models and hybrid models. In general, hybrid
models using SWA gain five to nine accuracy points.

The second benchmark is the RULER needle-in-a-haystack (NIAH) tasks (Hsieh et al., 2024) where models
are evaluated at 4k, 8k and 16k context length, with 16k assessing the extrapolation capabilities of the models.
Results are presented in Table 3. Among all linear attention models, KronLSTM is the best or second-best
method across all sequence lengths, except for task S1. KronLSTM has the highest accuracy on S3 and MQ tasks
across all sequence lengths. Among all hybrid models, KronLSTM achieves the highest accuracy (averaged
over all lengths) on all tasks and has the highest accuracy at 16k on each task, confirming its strong long context
capabilities. The improvement of KronLSTM over competitors like Gated DeltaNet is consistent with the
interference analysis of Property A9. On S2 and S3, whose needles are unique sentences embedded in natural
language text, KronLSTM outperforms GDN except for S2 at 16k. For hybrid models, KronLSTM outranks
GDN-2 and Mamba-3 by 15.2 accuracy points on S2 at 4k. KronLSTM’s margin increases on MQ and MV with
sequence length. On MQ, KronLSTM’s lead distance grows from 2.4 to 4.1 accuracy points when increasing the
context from 4k to 16k. On MV, KronLSTM is 3.5 accuracy points behind the best method, GDN, for 4k context,
while KronLSTM is the leading method for 8k and 16k, with a 1.1 and 3.8 accuracy point lead, respectively.

artificial task with frequently repeated noise sentences, which is unrealistic for real-world text. We attribute
the performance drop of the KronLSTM in this task to the residual accumulation for recurring keys. Hybrid
models with SWA have a considerably smaller S1 accuracy, except KronLSTM. The hybrid models containing
the baseline linear attention layers reach at most 51.8, 26.6, and 12.6 accuracy for 4k, 8k, and 16k context
length, respectively. These accuracies closely match the fraction of the context covered by the attention window,
indicating that the needle is primarily retrieved when it lies within the window, with Mamba-3 and mLSTM
dropping to zero at 16k. The results suggest limited reliance on the recurrent architecture’s memory. KronLSTM
exceeds these accuracies on average across all context lengths and achieves the best performance across all six
tasks at 16k. Section 3.3 examines how these methods perform after context extension.

3.3 Long Context Extension

In applications, language models do not extrapolate to longer context but are trained on them, typically by
continued pretraining at increased context length (Fu et al., 2024; Gao et al., 2024). This stage unlocks retrieval
far beyond the original pretraining length (Fu et al., 2024). Linear attention models have no positional encoding
to adapt; rather, they must learn to keep more associations over longer time spans. We therefore branch the
1.5B linear KronLSTM and GDN-2 runs at 75B tokens and train them for the remaining 25B tokens at a
sequence length of 32k on a long-document mixture derived from ProLong-64K (Gao et al., 2024), so that the
context-length-extended models are token-matched to the 100B models of the previous sections. GDN-2 serves
as a reference model in this experiment since it also decouples erase and write. Further details on training are
described in Appendix A7.1. Table 4 shows the commonsense reasoning, LAMBADA, and recall results of the
extended models. Both models benefit from length extension on the reasoning and recall tasks, and perplexity
improves by about 4 perplexity points. KronLSTM keeps its lead: it has the higher average accuracy and the
lower perplexity, and it is better on five of the six recall tasks.

4 Conclusion

We have introduced the Kronecker Delta Rule, an update rule for associative matrix memories that corrects a
scalar association along a single direction, and KronLSTM, which embeds this rule in a gated linear attention
mixer. We proved that the memory dynamics converge to a unique steady state and that the expected memory
norm is bounded at every step. KronLSTM has the best average accuracy on commonsense reasoning and
real-world recall, both as a linear model and as a hybrid. Averaged over the context lengths, it is the best
or second-best linear model on every natural-text RULER task, and on S1 it is the only one that retrieves
needles beyond the sliding attention window in hybrid models. After extending the context to 32k, KronLSTM
outperforms GDN-2 on all natural-text retrieval tasks from 16k onward. Future work includes scaling up
KronLSTM and training hybrid models containing full softmax attention layers.

A2 Related Work

To the best of our knowledge, no existing work uses exactly this update that is a scalar bilinear read-out v⊤Sk
regressed onto the constant target 1. The established delta-rule linear attention family uses the vector read-out
Sk → v. The rule studied here is therefore the bilinear-readout, scalar-target member of the delta-rule. The
constraints are vk⊤, S F = 1 rather than Sk = v.

A2.1 Long Short-Term Memory

KronLSTM belongs to the xLSTM (Beck et al., 2024) family that revisits LSTM (Hochreiter, 1991; Hochreiter
and Schmidhuber, 1997) for the era of large language models (LLMs) with two modifications: exponential
gating and a redesigned memory. mLSTM replaces the scalar cell state by a matrix memory and drops memory
mixing, making the recurrence fully parallelizable over the sequence. mLSTM enables recurrent LLMs with
fast, constant-memory inference at scale (Beck et al., 2025a), and Beck et al. (2026) establish scaling behavior
competitive with Transformers at linear time complexity. xLSTM has also been applied to language modeling
(Beck et al., 2025b), vision (Alkin et al., 2025), biological and chemical sequences (Schmidinger et al., 2025),
and robotics (Schmied et al., 2025).
The matrix memory of mLSTM can be viewed as a classical correlation-based associative memory (Anderson,
1972; Kohonen, 1972) embedded within LSTM-style gating. In addition to providing an efficient mechanism
for storing and retrieving associations, the exponential gates allow mLSTM to revise storage decisions. This
distinguishes mLSTM from purely accumulative linear attention mechanisms. KronLSTM follows this line of
research by retaining the matrix memory and the ability to revise storage decisions, while introducing a different
memory-update rule.
A central challenge of recurrent architectures with growing memory is maintaining stable memory dynamics
over long sequences. The original LSTM uses a bounded squashing function for the exposed cell state, while
xLSTM introduces a normalizer state and a stabilizer state to control the scale of its matrix memory and retrievals.
However, normalization based on ratios of large quantities can lead to numerical and optimization difficulties,
particularly in large networks (Beck et al., 2025b). MC-LSTM (Hoedt et al., 2021) instead redistributes its cell
state with column-stochastic matrices, which conserve mass and never amplify the state. These considerations
motivate alternative matrix-memory update rules that retain memory revision while providing stable memory
dynamics. The Kronecker Delta Rule addresses this issue and provides convergence to a steady-state distribution
with a norm-bounded memory in expectation. Furthermore, KronLSTM yields advantageous gradient flow over
time compared with mLSTM (Hochreiter et al., 2000).

A2.2 The delta-rule linear attention family

The direct ancestor is the fast weight programmer perspective of Schlag et al. (2021), who introduced the
delta-rule write St+1 = St − β (Stkt − vt) kt⊤ into linear attention (Katharopoulos et al., 2020), building on the
fast-weight programmers of the early 1990s (Schmidhuber, 1992). Yang et al. (2024) (DeltaNet) made this rule

hardware-efficient by exploiting the WY representation of the resulting products of generalized Householder
matrices. This is exactly the product structure the bilinear rule inherits, with the Kronecker product kt ⊗vt taking
the role of kt. Subsequent extensions include Gated DeltaNet (Yang et al., 2025), which adds a scalar forget
gate αtSt; RWKV-7 (Peng et al., 2025), which employs a generalized delta rule with a decoupled in-context
learning rate; and DeltaProduct (Siems et al., 2025), which applies multiple Householder factors per token
to improve state tracking. This is directly relevant to the negative-eigenvalue regime β ∥at∥2 ∈ (1, 2) of the
transition factors I − βatat⊤, which allows state-tracking.

Longhorn (Liu et al., 2025) derives state-space recurrences explicitly as closed-form solutions of per-token

online learning objectives;  the bilinear rule fits     this  template  with  the objective  1  (v⊤Sk  −  1)2.  Test-time

gradient descent at inference time. Most relevant as a unifying framework is the Miras taxonomy of Behrouz

et al. (2026), which classifies memory architectures by their attentional-bias objective, retention mechanism,

and optimizer. The new bilinear rule occupies a new place of that taxonomy: it is a bilinear attentional bias

A2.4 Classical update and learning rules

When vectorized, the rule is the Widrow–Hoff LMS / delta rule (Widrow and Hoff, 1960) applied to the
Kronecker product input at = kt ⊗ vt with target 1. The stability range β ∥at∥2 ∈ (0, 2) is the classical LMS
step-size condition. The projection interpretation is Kaczmarz’s method (Kaczmarz, 1937): with the Newton
step β⋆ = 1/(∥k∥2 ∥v∥2), the update is the orthogonal projection onto the hyperplane {S : vk⊤, S F = 1},
and general β gives relaxed projections. The modern convergence theory, including the linear rate under
random sampling of constraints, is due to Strohmer and Vershynin (2009). The connections between Kaczmarz
iterations, stochastic gradient descent, and learning are surveyed by Chen (2018). Fejér monotonicity and
relaxed projection methods are standard in the projection-methods literature (Cegielski, 2012).

A2.5 Relation to cognitive and neuroscience

Because S scores key–value pairs rather than retrieving values, the closest relative in the cognitive and
neuroscience literature is familiarity (recognition) memory: the anti-Hebbian model of familiarity discrimination
in perirhinal cortex of Bogacz and Brown (2003) shows that scoring memories attain a far higher capacity than
retrieval memories, which is the same d2-versus-d capacity separation derived for the bilinear rule. The classical
retrieval-side background is given by correlation matrix memories (Anderson, 1972; Kohonen, 1972) for the
Hebbian write, and by delta-rule / pseudoinverse associative memories for capacity under Widrow–Hoff learning
(Prados and Kak, 1989).

A3 Kronecker Delta Rule: Setting, Name, Properties

A3.1 Setup and notation.

We use the notation of the main paper (Section 2.1), specialized to dk = dv =: d as in our experiments (where
dqk = dv); the general dv × dk case is identical with d2 replaced by dkdv. Let St ∈ Rd×d be the memory
matrix, kt ∈ Rd the key and vt ∈ Rd the value at step t, ct ∈ R a scalar target, and βt a step size. The scalar
vt⊤Stkt measures how strongly the memory associates kt with vt; the Kronecker Delta Rule corrects it towards
the target ct along the outer product vtkt⊤,

                              St+1 = St − βt vt⊤Stkt − ct vtkt⊤ ,                                          (A1)

which is Eq. (3) of the main paper. For the analysis, we abbreviate the scalar read-out and its residual,

yt := vt⊤Stkt                                 (scalar read-out),                                           (A2)
ψt := yt − ct
                                              (residual),                                                  (A3)

so that the update reads compactly St+1 = St − βt rt vtkt⊤. The target sequence ct subsumes different variants:

A3.4.6 Greedy minimality is global minimality

Per-step optimality does not by itself imply that a sequence of such steps is optimal. We show that our does.

Proposition 1 (The limit is the minimum-norm memory). Let {(ki, vi, ci)}in=1 be a consistent system of
associations. Apply the rule from S0 = 0 with relaxation ω ∈ (0, 2), visiting each pair infinitely often either
cyclically or by random sampling. Then St converges to

        S♯ = argmin ∥S∥F : vi⊤Ski = ci for all i ,                                       (A43)

the minimum Frobenius-norm memory satisfying all the associations.

Proof. This is the classical convergence theorem for relaxed Kaczmarz iterations (Cegielski, 2012; Kaczmarz,
1937), applied to the vectorized system ai⊤s = ci with ai = ki⊗vi. Each iterate stays in s0+span{a1, . . . , an},
which for s0 = 0 is the row space of the system; the iterates converge to a solution, and the unique solution in

the row space is the minimum-norm one.

So the memory built by a stream of minimally invasive revisions is itself the least-norm memory compatible
with everything it was asked to store: locally and globally, the rule writes as little as the task permits.

A3.4.7 Less invasive than DeltaNet

Theorems A1–A4 hold given the requirement encoded in Et: make the scalar read-out of the addressed pair
equal to ct, and do nothing else. DeltaNet’s step has to solve the d constraints Skt = vt, therefore its correction
is necessarily larger. The claim here is therefore not that DeltaNet is suboptimal for its own task, but that the
two tasks differ: a recognition memory needs one scalar corrected, and the Kronecker Delta Rule corrects it
with provably minimal disturbance, whereas a retrieval memory must rewrite an entire value vector and pays for
it in footprint.

Memory for the overloaded setting. Beyond capacity, S is no longer a table but an online linear regressor:

Assumptions for the proofs. Independence of it from the past makes the mean recursion exact and factorizes

the covariance cross terms; the normal equations kill the driving term in the mean and the cross terms in station-

Conflicting targets on the same pair: averaging vs. overwriting. The canonical inconsistency is one

stationary mean read-out is the weighted average, v⊤Eπβ [S] k = j pjcj/ j pj (the LS solution for identical

decides about overwrite behavior.

A4 DeltaNet Steady-State Norm Bound

A4.1 Overview

The DeltaNet steady-state norm bound can be derived essentially verbatim to kronLSTM. DeltaNet’s update is
affine in St and acts on each row of the memory independently; each row obeys exactly the scalar delta-rule
recursion analyzed for KronLSTM, with the association direction at = kt ⊗ vt replaced by the key kt and the
scalar target ct replaced by the value coordinate vt,j. Every step of the argument — the energy identity, the

the running memory — therefore transfers, and yields Eπβ [∥S∥2F] ≤ 2 E[∥v∥2]/λmin(K¯ ) with K¯ = E[kk⊤].
The practical consequence is a scoping correction: a length-independent steady-state bound is a property of
the delta-rule mechanism, shared by KronLSTM and DeltaNet, which separates both from mLSTM and from
any stability argument resting on a forget gate. We also record where the two genuinely differ: in the step-size
condition, in what the bound is a bound on, and in the conditioning constant that sets its scale.

A4.4 Relation to the KronLSTM Bound

The bound is a consequence of the delta rule being a relaxed projection that is a correction proportional to a
residual that shrinks as the memory improves. Both models have that structure, therefore separates the delta-rule
family from mLSTM, whose Hebbian write is uncorrected and has no fixed point to contract toward. It separates
the steady-state argument from the non-expansiveness argument, whose forget-gate bound βCAmax/(1 − f) is
Ω(T ) once f → 1 as long contexts require.

The constants are not comparable. The two bounds read

                   E[c2]                   2 E[∥v∥2]               A¯ = E aa⊤ ∈ Rd2×d2 , K¯ ∈ Rd×d . (A129)
KronLSTM: λmin(A¯) ,          DeltaNet: λmin(K¯ ) ,

These are bounds on the same object, ∥S∥F, but they are not bounds for the same task: KronLSTM’s stream
carries one scalar ct per step, DeltaNet’s a d-vector vt, so E[c2] and E ∥v∥2 measure different amounts of
information being written. The denominators also differ structurally: K¯ ≻ 0 requires only that the keys
span Rd, whereas A¯ ≻ 0 requires the ai = ki ⊗ vi to span Rd2, and λmin(A¯) is typically the smaller
of the two. The reason is that for independent isotropic keys and values, A¯ = E[kk⊤] ⊗ E[vv⊤] gives
λmin(A¯) = λmin(K¯ ) λmin(E[vv⊤]), a product of two small numbers. On the other hand the constant 2 appears

in the bound of the DeltaNet. Which constant is smaller in a given setting is an empirical question, not a

structural one.

DeltaNet has a smaller bound. The step-size condition is milder. KronLSTM requires β ∥kt∥2 ∥vt∥2 ≤ 1,
so a large value norm eats directly into the admissible step size and hence into the contraction rate βλmin(A¯);
DeltaNet requires only βt ∥kt∥2 ≤ 1, in which vt does not appear at all. It enters the drive but never the stability
condition.

KronLSTM has advantages. d2 rather than d exactly satisfiable associations per scalar slot, interference
gated by the product of key and value overlap rather than key overlap alone, an update direction vtkt⊤ fixed
by the input pair rather than the state-dependent utkt⊤ so that a write’s footprint on unrelated memories does
not compound with context length, single-binding write/rewrite/erase, and linearity of the memory in the target
sequence. None of these follow from, or are affected by, the steady-state bound.

A7.1 Long-context extension

The context-extended models of Section 3.3 branch from the 1.5B pretraining runs at 75B tokens and are
trained for a further 25B tokens at a sequence length of 32,768, so that both extended models finish at exactly
100B tokens and are token-matched to the 8k-pretrained models. The architecture, tokenizer, and all model
hyperparameters are unchanged. The global batch is held at the same 1M tokens per step, now as 32 sequences
of 32,768 tokens instead of 128 sequences of 8,192.

Optimization. The optimizer state is re-initialized at the branch point for both models and the schedule
restarts: linear warmup over 5% to a peak learning rate of 8.4 × 10−5, which is the value the parent cosine
schedule had reached at the checkpoint, followed by cosine decay over 23,800 steps to 0.1× the peak. This
mirrors the warmup-and-decay shape used by Gao et al. (2024). AdamW hyperparameters, weight decay, and
gradient clipping are as in Appendix A7.

The KronLSTM update (10) revises the matrix memory by a rank-one term whose coefficient depends on the
memory only through a scalar. It therefore admits the chunkwise-parallel training scheme of DeltaNet (Yang
et al., 2024), Gated DeltaNet (Yang et al., 2025), Kimi Delta Attention (Kimi Team et al., 2025), and Gated
DeltaNet-2 (Hatamizadeh et al., 2026): the sequence is split into chunks of length C, all token interactions inside
a chunk are expressed as dense matrix products and one small triangular solve, and the memory is propagated
only between chunks. Three points differ from the delta rule. (i) The triangular solve is built on the Gram
matrix of the Kronecker features at = kt ⊗ vt, which by the mixed-product property is the Hadamard product
of a (decay-weighted) key Gram and the value Gram; the dkdv-dimensional features are never formed. (ii)
The pseudo-values are scalar multiples urvr of the values. (iii) The incoming memory of a chunk enters the
solve through C scalar scores vr⊤S0(γr ⊙ kr) instead of the dv-dimensional read-outs S0kr of the delta rule.
The vector forget gate is handled as in KDA and Gated DeltaNet-2 by absorbing the cumulative decay into an
asymmetric pair of keys.

A8.7 Algorithm, cost and implementation

Algorithm (forward pass, one head). Given Q, K ∈ RL×dk , V ∈ RL×dv , β, c ∈ RL, log f ∈ RL×dk , a
chunk length C and an initial memory S[0]:
1. Chunk-local, in parallel over chunks. For every chunk: ℓ ← cumsum(log f ) within the chunk, γ ← exp(ℓ),

    and K, K¯ , K˘ , Q as in (A151); Gkk, Gvv, Gqk as in (A152), the entries of Gkk and Gqk via exp(ℓr − ℓs)
    for s ≤ r; N ← diag(β)(Gkk ⊙ Gvv) and Λ ← (I + N )−1 by forward substitution; u◦ ← Λc and
   Λβ ← Λ diag(β).
2. Scan, sequential over chunks. S ← S[0]; for n = 0, 1, . . . : p ← (V S) ⊙ K 1; u ← u◦ − Λβ p;
    V ← diag(u)V ; H[n] ← QS⊤ + GqkV ; S ← S diag(γC ) + V ⊤K˘ .
3. Return H ∈ RL×dv and the final memory S.

Cost. Per chunk and head the algorithm performs the two C × C key Grams (2C2dk multiply–adds), the
value Gram (C2dv), one unit lower triangular solve applied to two right-hand sides (O(C3), in practice on
16 × 16 blocks as in the delta-rule kernels), three products with the memory, V S, QS⊤ and V ⊤K˘ (3Cdkdv),
and the intra-chunk product GqkV (C2dv). Over a sequence of length L this is O LC(dk + dv) + Ldkdv
multiply–adds and O(LC2) for the solves, the same order as Gated DeltaNet and KDA; relative to KDA the
additional cost is the value Gram Gvv, and the coupling p replaces the product W S0 of the delta rule at equal
cost. The memory is materialized once per chunk, not per token.

Implementation notes. (i) The cumulative decays are kept in log space; the Gram entries use exp(ℓr − ℓs)
for s ≤ r only, so all decay factors lie in (0, 1] and no quotient 1/γ is ever formed (the kernels use base-2
logarithms and exp2). (ii) The triangular solve is the precision-sensitive step and is carried out in IEEE fp32;
the remaining products run on tensor cores. (iii) In the fused kernel the solve is not materialized as u◦ and
Λβ but applied inside the scan as u = Λ(c − β ⊙ p). (iv) Because p contracts over the full value dimension,
programs that tile the memory over dv exchange their partial row sums of (V S) ⊙ K once per chunk; this
is a synchronization, not a bandwidth cost (C floats per program against a dk × dv memory). (v) Padding a
sequence to a multiple of C with zero q, k, v, β = c = 0 and log f = 0 neither writes nor decays. (vi) Queries

A8.9 Verification

We verified Theorem A11 and (A162)–(A165) numerically in double precision against the token-by-token
recurrence (A149): outputs and final memory agree to machine precision (≤ 10−15 relative) for chunk lengths
C ∈ {1, 8, 16, L}, sequence lengths that are and are not multiples of C, dk ≠ dv, nonzero initial memory, strong
and weak decay, and βr ∈ (0, 1) as well as βr ∈ (0, 2); the operator identity (A161) holds against the explicitly
formed product of dkdv × dkdv factors; the no-decay reduction of N to the Gram of ar = kr ⊗ vr holds; and
the gradients with respect to Q, K, V , β, c, log f and S0 agree with central finite differences of the recurrence
to 10−9. The reference implementations in the supplementary material are checked against the same recurrence.
