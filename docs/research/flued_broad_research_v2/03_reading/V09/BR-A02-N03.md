**Problem → solution.** Fixed matrix state constrains recall, while growing standard projections may be parameter-expensive. Bind each value to two keys and contract the third-order state with two queries, increasing state by factor E with two small projections (§2). Borrowed tensor-product associative memory, fast weights, gated DeltaNet and causal chunking. Models learn the keys, queries and gates through next-token training; the second key has no stipulated semantic interpretation.

**Address vs content.** For state d×E×d, the write is k⊗k′⊗v and output contracts both key axes; interactions factor into (q·k)(q′·k′). Flattening joint key k⊗k′ gives a dE×d matrix recurrence, so higher tensor order is not evidence a relation was objectified. Orthonormal role calculations support idealized binding capacity only, not arbitrary learned or finite-precision retention. The E-fold state bytes are real even when parameter overhead is small. Chunk algorithm factors causal within-chunk scores into two Gram matrices, has separate slice decay, solves a shared lower-triangular system and tiles value columns; Appendix A computes log-gate differences without positive-exponent overflow. The reported reference checks compare outputs/gradients with FP64 (<1% relative), not a proof of all workloads.

**Experiments and negative cases.** At 400M pretrain 20B tokens, 1.3B 65B, then 64k extension at five tokens/parameter, versus 4k pretraining (§3.1). Table 1 matches 2×/4× state and approximate total parameters, compensating larger projections by reducing MLP width; thus this is not fixed-MLP or equal FLOPs. Three seeds at 400M, one at 1.3B for Table 2. Visual Table 1 GDN base recall 26.2, E=2 28.4 and E=4 31.1; 4× larger heads 28.5. sGLA E=2 28.4 slightly *below* grouped values 28.5. Triadic E=4 improves long PG19 but not every task; the hybrid E=4 has recall 44.5 vs larger-KV hybrid 45.3, despite better NIAH 56.3 vs 53.0 (Table 3). At 1.3B, upcycling E=8 recall 42.0 vs scratch 44.4 vs base 36.1 (Table 2). Reference scores match observed response containing the answer, not free-form proof of factual reasoning.

**Budgets and conditions.** Table state MB assumes two bytes/entry, while kernel example uses FP32 head state; actual precision and cache companions must be counted. Single-H100 block forward/backward E=8 adds 28–30% versus GDN, not full-serving speed (§3.5). Synthetic MQAR uses paired single-token bindings, read-only queries, 12.5B training tokens, 25 seeds (App. C); it is not ordinary autoregressive writes on query positions.

**Directions:** B.13/C.14–C.15/R.11. Independent alternatives: structured state pruning, improved update/address learning, targeted query adaptation or an explicit retrieval channel. Change hypothesis if complete memory/precision/MLP- and compute-matched comparisons erase the E advantage, or same-state alternative wins on long unseen bindings; task-conditioned evidence is needed before assuming learned semantic roles.
