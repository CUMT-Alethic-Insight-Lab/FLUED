# BR-A02-N05 — Kronecker Delta Rule for Long Context Linear Attention

**Reading:** FULL public [arXiv 2610.26834v1](https://arxiv.org/pdf/2610.26834v1), 2026-10-19, §§1–4 and Apps. A1–A8 including proof and chunk algorithm; [PDF](sources/2610.26834v1.pdf), [text](sources/2610.26834v1.txt), Table 1 [page image](sources/2610.26834v1_table.png). Related anonymous [ICLR 2027 submission](https://openreview.net/forum?id=2XDUbuZOTH) was separately audited; no decision or PDF equality established. Full read is not mathematical verification or execution.

**Problem → solution.** Delta-rule associative updates modify values at overlapping keys. KronLSTM instead corrects a scalar association vᵀSk with an outer-product direction vkᵀ, making perturbation of an old scalar binding proportional to *both* value and key overlap (§2.1, A3.3). It borrows online least-squares/delta rule, Kaczmarz projections, and chunk-parallel triangular solves. At language-model scale the network learns gates and projections under next-token prediction; this is not a separately supervised content store.

**Object and permissions.** Scalar score is addressed by the key–value pair, unlike vector retrieval Sk=v; native layer output is S q, followed by gate and RMSNorm (§2.2). Algebraic dₖdᵥ scalar constraints require independent joint features and enough compatible constraints; this does not establish dₖdᵥ vector facts retrievable from a key alone. Orthogonality of either key or value protects a bilinear score; correlated real streams need not satisfy it. Gating and short causal convolution create additional computational/state paths.

**Theory, precise scope.** A3.4 derives minimum Frobenius-norm single-step correction with Cauchy–Schwarz and minimum *expected* interference only for independent isotropic probe pairs. A3.5 uses i.i.d. finite-support samples, fixed step with 0<β||k⊗v||²<2 and full-rank joint covariance: exact mean recursion converges to least squares; synchronous coupling contracts in Wasserstein-2 and yields a stationary law, not pointwise convergence on inconsistent targets. A3.6 bounds expected squared norm with extra nonexpansive bound κ≤1. A5's longer initial-mode retention needs independent keys/values and normalized values, and costs slower adaptation. Learned input-dependent gates, ordered correlated or nonstationary streams and finite precision are not covered simply by these theorems. Appendix A4 explicitly gives a related norm bound for ordinary DeltaNet, so norm stability is not unique to KronLSTM or proof of fact preservation.

**Empirical comparisons and cost.** Same-token 1.5B/100B, 8k pretraining, identical outside mixer; GDN, GDN-2, KDA, Mamba-3, mLSTM and 5:1 2048-window hybrid (§3, A7). Visually checked Table 1 linear Avg-6 59.72 vs KDA 58.12, but PIQA GDN 73.61 > 73.45; hybrid Avg 59.56 vs GDN-2 58.79. Table 3 at 16k pure S1 Kron 11.6 vs GDN 99.2; no universal recall win. Natural recall average 30.31 vs GDN 29.81 (Table 2), while individual tasks reverse. For 32k extension branch at 75B then 25B tokens with changed long-document mixture, token matched but not identical training distribution/compute. Appendix A6 Table A3 gate ablation shows 4k needle average base 59.5 vs no value norm 39.6, while real-world recall 30.3 vs 31.3; rate and tasks matter. One H100 training throughput 36.8–44.5k tokens/s, GDN faster (§3.5). A8 uses factored key/value Grams and FP32 triangular solve; authors report numerical checks, not independently replicated.

**Directions:** B.01–B.08/B.11–B.12. Independent options: selective rewrite, better native readout, representation/learning changes, or external memory rather than state-order expansion. Hypothesis changes if matched-state-and-all-companions update ablations on controlled key/value overlap show no interference advantage, or long-horizon finite-bit tests show stability without retrievable facts. No target-host performance inferred.
