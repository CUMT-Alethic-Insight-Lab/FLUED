# BR-A08-V17 — Uncovering Latent Reasoning Strategies in Language Models

**Reading:** FULL public [arXiv 2607.17674v1](https://arxiv.org/pdf/2607.17674v1), 2026-07-20, §§1–6 and Apps. A–F including objective and proof steps; [PDF](sources/2607.17674v1.pdf), [text](sources/2607.17674v1.txt). Title-associated [ICLR 2027 submission](https://openreview.net/forum?id=edyITivJJW) is separately audited; no acceptance or PDF-equivalence claim. No source code run.

**Problem → solution.** An adapted pretrained autoregressive generator can ignore a latent variable while retaining its original response distribution, defeating strategy discovery. Train a Gaussian router/generator with a training-only posterior that sees the complete response, using base-loss-normalized reconstruction weighted toward high-surprisal response tokens plus a KL penalty (§3, App. D). Borrowed conditional variational inference, posterior-collapse analysis, distillation from frozen base, and LoRA adaptation. Response traces y are sampled from the frozen base; ground-truth strategy labels are withheld from factorization training but the base is first fitted on constructed strategy-bearing traces. Inference router sees x only; posterior sees (x,y) during training and is unavailable at inference.

**Content and causal permissions.** The code z is inserted as a pseudo-token for the adapted autoregressive decoder, which still directly attends to input and previous output. This is not a bottleneck-only compressed state or evidence that an unmodified model natively consults one. Varying/reusing z tests control in the adapted model; cross-input analogical consistency compares generated strategy labels for the same z on two problems in a task family, not long-context fact recovery. A hidden-state linear probe establishes decodability only, not native causal use.

**Results and controls.** Six synthetic algorithmic task families with parseable traces; Qwen2.5 0.5B and 1.5B after task fitting, 64-dimensional z, pretrained and random-init grids. Conditional ELBO and β-ELBO baselines can preserve valid-solution fidelity while latent alignment remains low; inverse-surprisal weighting is a directional control and weakens alignment (Figs. 3, 6, 8). Global scaling, token weighting and combination are compared, best run per KL β; random-init grid 504 LoRA adaptation runs (App. E). Pure high-surprisal pressure can sacrifice non-high-surprisal positions (Fig. 11). Fidelity is operationalized as fraction of valid strategy-compatible traces (App. E.1), not a full distributional distance certificate; no exact equality of output laws follows. Latent semantics multiplex across task families, rather than one global codebook.

**Theory.** App. F decomposes population β-ELBO into conditional entropy minus (1−β) conditional mutual information plus decoder/router approximation gaps and a complexity proxy. For β<1, positive profiled-score separation of the true encoder from all bad encoders implies recovery; empirical result further requires uniform convergence, finite-class sample bound needs bounded support/log losses. Input-dependent relabelings can preserve conditional information and local separation yet defeat global alignment unless complexity favors shared labels. These are conditional existence/separation results for a theoretical proxy, not proofs that the proposed neural weighted objective learns semantic strategies or that optimization achieves its global minimum.

**Directions:** A.03–A.05/E.07–E.10. Independent alternatives: alter task loss or decoder visibility, train a reader/query interface, or maintain explicit state rather than adding multiple granularities. Change hypothesis if same-budget removal/shuffling/swap of z while retaining x and prefix, plus open-ended out-of-distribution strategy labels and genuine distributional comparison, eliminate the inferred latent effect; preserve the decoder-bypass and strategy-alignment controls separately.
