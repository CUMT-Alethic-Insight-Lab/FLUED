# W0086 — On State Reduction in Linear Attention

**Reading:** FULL public [arXiv 2602.04852v3](https://arxiv.org/pdf/2602.04852v3), 2026-09-29, main body and Appendices A–H including F proofs and long-context controls; existing audited [v3 PDF](../../05_review/source_staging/W0086__2602.04852v3.pdf), [derived text](sources/2602.04852v3.txt). The audit checked v3 history and previously titled v1; v1 findings must not be substituted for v3. Title-associated anonymous [forum](https://openreview.net/forum?id=3uKKt21Vry) is a separately audited submission; body equality and decision are unknown. Read is not replication.

**Problem → solution.** Learned recurrent matrices often have skewed singular spectra, but unstructured sparsity does not shrink the state. Jointly select query/key channels using strong rank-revealing QR on calibration activations and physically slice corresponding projection and depthwise convolution channels (§3, App. B); then optionally recover with LoRA/distillation. Borrowed linear-system basis invariance, structured pruning, and rank-revealing matrix factorization. Calibration uses 128 FineWeb sequences of 2048 and 2.5k sampled keys/queries; recovery uses 32k FineWeb samples, rank-32 LoRA, unfreezes convolutions and norms, and uses original model as teacher (App. A).

**Rank and theory.** Effective/stable rank is ||S||²_F/||S||²₂, a spectral concentration statistic of the *value-by-key recurrent state*, not the number of facts or bits. For the specified additive/delta family, state rank is bounded by key/value matrix ranks (App. F.2); effective-rank lower bound uses full-row-rank keys and projected value matrix (F.1). Worst-case relative readout amplification equals condition number only when state has full column rank, with query/noise at extreme singular vectors (F.3); it is not a guarantee of average task sensitivity. Orthogonal Q/K changes preserve the abstract recurrence but dense rotations do not generally commute with channel-specific convolution or SiLU; axis selection is approximate, not a lossless rotation.

**Results and failure.** GDN 1.3B 50%-reduced DRRQR after recovery has WikiText PPL 16.3 vs baseline 16.8, but LAMBADA PPL 12.0 vs 9.7 and six-task accuracy 58.0 vs 59.4 (Table 1). At 4k, RULER 38.8→27.5 and NIAH 81.3→61.9 despite recovery; hybrid Qwen3.5 9B recurrent-only pruning 93.9→93.6 and 100→100 (Table 4, C.4). Exact-attention compensation is an author hypothesis, not path intervention. 7B Mamba pre-recovery Grad outperforms DRRQR on Wiki 16.7 vs 17.6 and task average 59.9 vs 57.1. Calibration distribution transfer favors DRRQR over gradient selection in tested 370M settings (Table 2). H100 batch-64 decode reports 1.47× at 50% state reduction but batch-1 only 1.03× (App. G.1); state reduction is not whole-model size reduction.

**Directions:** B.11–B.12/B.17/C.09–C.11. Independent options: task-aware selective preservation, native query/key adaptation, altered write rule, or hybrid explicit attention. Hypothesis changes when a long-tail recall and arbitrary-binding evaluation at equal complete runtime bytes with matched adaptation shows performance robust despite pruning, or a query-only counterfactual rescues errors without restored capacity. Avoid inferring all stored information is unused from stable average perplexity.
