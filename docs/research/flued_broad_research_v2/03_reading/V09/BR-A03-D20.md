# BR-A03-D20 — How Linear Attention Remembers

**Reading:** FULL for the public [arXiv 2609.33093v1](https://arxiv.org/pdf/2609.33093v1), 2026-09-27, main text and Appendices A–F; local [PDF](sources/2609.33093v1.pdf), [text](sources/2609.33093v1.txt). Public preprint is independently readable; the title-associated ICLR 2027 submission [forum](https://openreview.net/forum?id=b3lZofUyGC) was audited separately, note v2, not accepted by implication; manuscript equivalence unknown. Extraction has normalized surrogate pairs and visible escapes for any isolated surrogates. Figures interpreted via captions and reported text, not independently digitized. No replication.

**Problem → solution.** Fixed recurrent state superposes a long history without token-addressable KV entries, leaving write, retention, and query-time use hard to distinguish. Authors combine an exact fixed-trajectory state decomposition with donor-write, state-swap and output-patching interventions in frozen pretrained GLA and GDN.

**Technique and method.** Activation patching/causal mediation: at fact spans block or substitute a donor update; at the pre-query boundary substitute a donor state; at query replace or restore the selected head output. A development screen of 96/96/192 heads on 16 sources selects heads, fixed for confirmation (§§2–3, App. B–C). The decomposition is exact conditional on realized transition operators, not a claim that interventions leave future transitions fixed. No new model learning is performed; separate trained correction features in App. F are diagnostic.

**Units, causality and controls.** Tokenized, source-disjoint WikiText-103 filler and key–value facts, typically four balanced answer candidates scored by conditional likelihood; source-cluster bootstrap. Donor pairs differ in target value. Equal-norm random and control-head updates, held-out component landscape and donor/recipient restoration check alternative explanations. Four facts can transfer target answers 61–89% while non-target breaks are 0.4–1.4%, yet state-direction projections create opposing non-target margin shifts (§3.3). A joint head block is non-additive. This is not independently addressable KV storage. Output patch/restore implicates output mediation, **not** a direct intervention on query formation.

**Load, delay and competing results.** At fixed length, 1→16 facts costs roughly 30–40 points in 340M models; at four facts, 128→1024 filler tokens has a modest effect (§4.2). A later key aligned with target direction lowers margin ~0.27–0.44 logits; orthogonal/control interventions provide contrast. K=32 uses another layout; causality is local to the intervention distribution. Pure GDN and near-matched hybrid checkpoints are separately trained and differ in parameter count (399.5M vs 382.6M; App. A). Pre-query donor replacement places >99% of normalized effect in hybrid KV for this task, but recurrent layers may still shape writes and queries; it is not evidence all recurrent memory is blind. Other checkpoints exhibit varied top-head concentration (App. E).

**Negative and cost boundaries.** GLA state-feature correction recovers some failures but disrupts others; GDN improvement is small and Qwen deteriorates (App. F.1). Prose pilot at 512/128 filler yields recipient 56.3/71.9%, donor 53.1/68.8%, below the prespecified 80% full-vocabulary competence gate; no causal prose analysis is claimed (App. F.2). Precision BF16 weights/FP32 recurrent caches, two RTX 4080 SUPERs; exact four-choice recall is not general semantic use.

**Directions:** B.14–B.17, C.06–C.08, D.01–D.13. Independent options: change write gating or state partition, improve native query generation, adapt downstream reader, or retain separate external source; each is distinct from merely adding granularities. Change hypothesis if same-competence controlled donor-state and donor-query/reader interventions separate written information from inaccessible native reads, or load-matched delay sweeps reverse the observed ordering. Hybrid test must also intervene on KV construction/query formation, not just boundary storage.
