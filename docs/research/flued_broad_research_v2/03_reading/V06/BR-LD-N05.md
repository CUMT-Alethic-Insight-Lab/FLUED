## Problem, solution, supervision and units

**Problem:** a context-dependent skill can emerge transiently and be displaced even when both routes solve the training task. **Solution:** separate context-only, weight-only and hybrid evaluators and use causal formation and checkpoint interventions to expose competitive and shared computations. Borrowed mechanisms: synthetic in-context classification, causal attention/weight clamping, checkpoint swapping and a tensor-product toy learning-dynamics model. It is primarily a scientific explanation, not a proposed memory architecture.

§2 pp.2–3: an ImageNet-pretrained ResNet18 embeds Omniglot images, augmented to 12,800 training classes, 20 exemplars/class; each sequence has two exemplar–label pairs followed by the query image. A causal two-layer attention-only transformer (64 width, eight heads/layer) predicts the query label with cross-entropy, trained by Adam. Fixed class-label mappings and a context exemplar of the query class both support training; neither an arbitrary source store nor a query-last natural-document memory is measured. Layer 1 transforms prior tokens and Layer 2 attends to and copies labels; its ephemeral context and long-lived learned weights are different information stores.

The evaluators matter (§2.3/Fig.1): novel contextual labels force in-context mapping (ICL); absent matching example and label tests pure in-weight learning (IWL); absent matching example but **present correct label** tests context-constrained IWL (CIWL); flipped labels pit mapping-based ICL against CIWL. Main in-context accuracies restrict outputs to the two context labels; pure IWL must use full-label accuracy (Appendix B/C). A final CIWL result is **not** evidence that context is unnecessary.

## Findings, controls and limits

- §§3–5/Figs.1–4 pp.3–6: exemplar-label ICL emerges, then CIWL dominates; Layer 2 copying circuitry is reused while Layer 1 changes previous-token versus self-attention. Ablating L1→output with patterns preserved changes CIWL accuracy 98.7→98.5%; preserving everything except L2 values or keys produces 59.3% or 57.5%, respectively (§4.2). These interventions identify effects under specified hybrid networks, not unique contributions in all systems.
- Formation intervention, not endpoint ablation: on randomized-mapping ICL-only training, clamping L2+unembedding from a standard run enables faster learning. CIWL-only pretraining removes the confound that prior ICL created those weights: intermediate checkpoints 9.8M–31.5M sequences help, early and late do not (Fig.4). Continuing a fully formed CIWL-only checkpoint on bursty data did not yield ICL within the run. These comparisons change histories and add pretraining; they are not equal-compute from-scratch dominance proofs. Appendix E/Fig.18 blocks previous-token attention during formation and still learns CIWL; ablating initially important heads delays but does not prevent ICL.
- §6 and Appendix D pp.7,18–19: phenomenological tensor model shares factors b,c but adds a competition penalty and assumes relative speed/bias; 12 seeds include plateau-censored cases. This is not a derivation that all transformer circuits are shared. §7 exact matching of query and context exemplars preserves ICL in the observed small setting; the 12-layer result has a longer horizon and the ordinary comparison has not fully faded (Fig.6).
- Appendix B pp.12–14: several data/initialization seeds, positional-embedding dependence, class/exemplar sweeps; MLP model can show **resurgence** (12,800 classes, five exemplars), weakening any universal irreversible-replacement claim. Appendix C says small pure IWL remains and treats head superposition as preliminary, not established mechanism.

## Mapping and rival causes

Prior directions **D.20, E.05–E.08, E.15–E.22, F.13–F.16**. Rival explanations include loss-driven competition with independent circuits, useful shared subcircuits, or changed input distribution. Minimum discrimination: fixed held-out examples throughout training, record content sensitivity and native output; compare timed competitor suppression, restoration, matched random suppression, and shared-component-only pretraining with equal cumulative compute and data. A final-checkpoint ablation alone cannot adjudicate formation history. No target-host conclusion follows.
