## Problem and method

**Problem:** auxiliary learning may worsen the primary task, and local gradient cosine is not an adequate proxy for validation transfer. **One-sentence solution:** train branches with different auxiliary weights, regularly choose their parameter interpolation on a target validation set, merge, and repeat. Borrowed techniques are multi-task learning, validation-based hyperparameter selection, parameter averaging and stochastic gradient training; no teacher is required. §4.1/Algorithm 1: a target-only branch and a target-plus-auxiliary branch run Δt updates, after which a convex interpolation is selected on target validation and both branches synchronized; §4.2 extends to K+1 branches and optional pruning/greedy search.

Inputs/outputs depend on task: image→segmentation, depth or normal maps; image→domain class; impressions→click/conversion; semisupervised image classification uses rotation and exemplar self-supervision. Shared network parameters are written by gradient updates; validation selects a merge; native task-specific heads read the shared features at inference. There is no persistent example-addressed store or future query stream. The held-out validation labels are an explicit extra permission, not test-time retrieval. §C.6 specifies whether branches share inputs or omit absent-task examples.

## What is actually established

- Fig. 2 p.4 and Appendix B.1 pp.17–18 start from the **same** target-trained 25k-step ResNet-18 checkpoint. One sampled multitask step at several auxiliary weights is compared with one target-only step using target validation gain. An L2 auxiliary supplies a useful conflicting-gradient control. This is a local association, not evidence that aligned gradients yield a harmful shortcut throughout history, nor evidence of state-content use. The separate 25k-step distribution-shift analysis Fig. 3/B.2 is correlational; confidence discrepancy is not a definitive distance or causal identification of shift.
- The one-step interpolation algebra in Appendix A.1–A.2 assumes common parameters and simple gradient descent; the Δt-step branch interpolation is a **method extension**, not algebraic equivalence to training a single model with an intermediate weight for Δt steps. It can overfit the repeatedly accessed validation set or interpolate poorly. Neither the text nor the algebra proves global no-negative-transfer.
- Fig. 5 p.8 reports 23/30 equally weighted DomainNet task pairs negative and its ForkMerge results nonnegative on that tested matrix. Table 1 p.9 reports NYUv2 Δm 4.03% versus 0.30% equal weight and 1.49% post-train; Table 2 reports DomainNet 2.00% versus post-train 1.07% and equal weight −9.62%. For Quickdraw both target-only and ForkMerge report 73.0, not a strict improvement. Table 6 includes stronger standalone semi-supervised controls: method is not a claim of universal state of the art.
- Table 3–4 and Appendix C: equal branch iteration counts do not equal FLOPs. NYUv2 trains 200 epochs, merges every 10; DomainNet 50k iterations, merges every 12.5k. DomainNet's official test data are split into validation and test halves; repeated target-validation use and tuning must be counted. Two branches, multiple forward evaluations of candidate merges, optimizer states, pruning/search and hyperparameter sweeps cost resources. Appendix D.2 Fig.10 gives measured NYUv2 timing and multi-GPU asynchronous wall time; neither removes aggregate compute. Appendix D.4 compares 27 fixed weight combinations, not all possible dynamic policies; D.5 tests larger equal-weight batch; D.3 reports five NYU seeds.

## Implications / discriminator

Prior directions **E.09–E.14, E.21–E.22**, and **F.08–F.11**. Report local target-training descent, held-out validation transfer, full-history test performance, and content-specific natural use separately. Rival explanations: data distribution, optimizer scale/momentum, regularization or asymmetric tuning rather than cosine itself. A minimal target-system contrast holds checkpoint, data, optimizer and validation access fixed, logging gradient norms and preconditioned updates plus held-out target accuracy; compare target-only, fixed weights, dynamic weights, and matched-compute branching with independent final test data. This is a proposed experiment, not an architectural recommendation.
