## Problem, solution and technique

A powerful autoregressive decoder can ignore a stochastic continuous latent; discrete representation training also encounters high-variance estimators. **Solution:** nearest-neighbor vector quantization learns discrete codes with a straight-through gradient, followed by a separately learned autoregressive prior. This borrows vector quantization/k-means dictionary learning and straight-through estimation, not supervised token labels (§§2–3). Encoder produces continuous vectors, each chooses one of K embeddings; a decoder consumes the chosen embedding. With a deterministic categorical posterior and fixed uniform prior, the training KL is constant log K per position. Reconstruction gradient is copied to the encoder; the stopped-encoder dictionary term moves selected codes, and a stopped-code commitment term moves encoder outputs toward codes (β=.25; authors report .1–2 robust). Appendix A.1 gives an EMA alternative; the experiments use the loss update, not EMA. The printed Eq. 3 has a log-likelihood sign convention inconsistent with calling all three additions a minimization loss; use negative log-likelihood for the minimized reconstruction term rather than silently copying the sign.

The PixelCNN image prior/WaveNet speech prior is fitted **after** the encoder–decoder; joint prior training was future work (§3.3). Thus constant nominal KL and actual decoder sensitivity are distinct from codebook usage, entropy, and task-sufficient content. N positions with K symbols have nominal N log2 K bits, not automatically measured entropy, achieved compressed bytes, matched precision, or equivalent continuous-latent capacity. Code-index position is a spatial/temporal content slot, not a query-addressing experiment; neither arbitrary identifiers nor native long-delay memory are tested.

## Comparators and results

- CIFAR10 same architectural family: continuous VAE **4.51**, VQ-VAE **4.67**, VIMCO **5.14 bits/dimension**; likelihood figures reported as bounds (§4.1). 250,000 updates, batch 128, VIMCO 50 samples; latent configurations vary and nominal dimensions are not equal-bit controls. Discrete improves over the discrete comparator but not continuous VAE.
- ImageNet 128×128 RGB to 32×32 codes with K=512: author nominal 42.6× bit ratio, excluding model/prior/decoder and entropy coding overhead (§4.2). A second-stage 3×9-bit code with PixelCNN provides approximate scene reconstruction while synthesizing local texture; no exact pixel recovery. The author's strong-decoder noncollapse claim is experimental and qualitative, not a universal guarantee that every code is used.
- VCTK speech speaker-conditioned decoder and downsampled codes: author reports same words with altered waveform/prosody and speaker conversion; 128-code-to-41-phoneme fitted mapping yields **49.3% versus 7.2%** most-common-phoneme baseline (§4.3). This is a supervised post-hoc mapping, not fully unsupervised phoneme recognition or proof of speaker invariance. The non-action-conditioned video model generated similar results (§4.4), so shown action-conditional generation does not isolate action use.

## Implications and discriminators

**Directions:** A.03–A.05, A.15. Independent options include task-weighted or denoising objectives with continuous latents, constrained decoder context, and altered writer/reader training—none requires hierarchical retrieval. At fixed total payload, measure used-code histogram/entropy, dead entries, reconstruction and exact identifier/binding endpoint, then intervene on the native code under controlled local context. A benefit restricted to perceptual reconstruction while exact task content or native output dependence fails would reverse a generalized discrete-code hypothesis. This source does not diagnose the project host or exonerate byte interfaces.
