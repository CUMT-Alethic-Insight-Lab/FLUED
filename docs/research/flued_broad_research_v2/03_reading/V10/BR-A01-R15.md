## Prior problem and one-sentence solution

A flexible decoder can explain observations without encoding their interesting features, while generative likelihood alone does not identify a useful representation. **Solution:** deliberately restrict an autoregressive decoder's conditioning field to place hard-to-model information in a lossy global latent, and use an autoregressive flow prior to improve density modeling (§§2–3). Techniques borrowed from bits-back coding, Gaussian VAEs, PixelCNN and invertible flows; objective is the ELBO, with free-bits/soft-free-bits optimization aids.

## Argument and conditions

Bits-back expected code length is negative ELBO = cross-entropy of data under p(x) plus expected KL(q(z|x)||p(z|x)), at least data entropy plus that inference gap (§2.2, Eqs. 6–11). If a decoder represents the data distribution while ignoring z and the prior can be matched by the encoder, this construction avoids inference gap; the authors argue for an information preference, not that all expressive decoders inevitably ignore every latent. A local decoder may model local texture while long-range dependencies require z; this is a data/factorization and successful-optimization condition, not a semantic preservation theorem. Their Eq. 12–14 change of variables relates an autoregressive-flow prior to an inverse-flow encoder path, but generation paths differ; train cost claim is conditional on their construction (§3.2).

The source computes expected KL **13.3 nats ≈19.2 bits/image**, versus **37.3 bits** for a factorized-decoder variant (MNIST §4.1); it labels this a code rate, but expected KL includes aggregate-prior mismatch and is not measured physical storage or mutual information. Different local reconstruction may look plausible while losing required rare symbols: Fig. 2 OMNIGLOT examples sometimes fail to preserve semantics. Whole-image encoder has future visibility, and no address/native query reader or exact-identifier assay appears.

## Comparators and cost

- Static binary MNIST test NLL: IAF VAE **79.88**, AF VAE **79.30**, VLAE **79.03**; PixelRNN **79.20** (Table 1). Importance estimate uses 4096 samples; binary model latent dimension 64, local six-layer 3×3 masked decoder; 0.01 nat/data-dimension free bits (App. A). More costly ancestral decoding is acknowledged.
- Dynamically binarized MNIST: VLAE **78.53** vs unconditional decoder **87.55** (Table 2). Appendix D's related ablation: unconditional **87.55**, Gaussian prior **79.48**, AF prior **78.94**; retain differing VLAE values rather than assume identical runs or specifications.
- CIFAR10 Table 5: DenseNet VLAE **2.95 bits/dim**, PixelCNN++ **2.92**; 512 importance samples. Figure 3 shows larger receptive fields shift reconstruction toward coarser shape, and grayscale conditioning encourages color preservation. These are qualitative image observations; local decoder complexity/latent rate/optimization and sampling costs are not equalized across every comparison.

## Synthesis and reversal tests

**Directions:** A.03–A.10, E.09. Separate options from retrieval are task-weighted reconstruction, explicitly preserved rare strings, restricted local context and training schedule changes. Compare equal causal visibility and total payload plus decoder/training/serving compute; test exact identifiers and bindings as well as likelihood. If task-important short-range exceptions are lost or downstream native access does not improve, good image-style lossy compression is not a valid substitute for the promised content. Conversely, an expressive decoder using demonstrably task-relevant latent content is a direct negative to any blanket information-preference claim.
