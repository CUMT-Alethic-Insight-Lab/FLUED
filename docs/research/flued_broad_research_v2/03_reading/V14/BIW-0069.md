# BIW-0069 — MoCE: Adaptive Mixture of Contextualization Experts

**Reading: FULL**, specifically [arXiv 2411.01474v1](https://arxiv.org/pdf/2411.01474v1), 3 November 2024, 18 pages, title exactly as above. [PDF](sources/BIW-0069.pdf), [text](sources/BIW-0069.txt), SHA-256 `88f09dadd261e71fb47ebc0c84daebf53393ed1727b28c95c8e8087260d70232`. **Problem → solution.** One fixed set of local byte-context scales may fit multilingual text poorly; route each projected attention head's local contextualization through a sparse mixture of identity and convolution experts of several radii. This borrows top-k mixture-of-experts and convolution. Default top-2 router operates per token/head for Q, K and V, with optional input language ID, then global encoder attention; default replacement is only the first encoder layer (§3, F). Task supervision is parallel translation cross-entropy with label smoothing, not unsupervised boundaries.

**Four separate units.** Byte-model inputs are UTF-8 byte symbols plus language tokens; internal representations are byte-position attention heads contextually convolved with radius 0..Δ, not explicit compressed segments; the **byte-model decoder outputs bytes** (with shared encoder/decoder embeddings, App. B); target supervision is target-language translated text encoded as byte sequence. The separate subword baseline uses 32k/64k SentencePiece for its input/output. Thus this work does **not** establish byte-input/non-byte-output mixed supervision. The sentence encoder is bidirectional and its convolutions are not demonstrated causal for a streaming decoder (§7 limitations). UTF-8 codepoint length (1–4 bytes), relative translated sentence bytes, and semantic correspondence are distinct; no byte-offset or lead/continuation/ASCII analysis here.

**Observed comparisons and costs.** Ted-59 xx→en BLEU (Table 3): byte transformer 25.21, fixed-scale MSC 25.61, Ada-MSHA Δ5 26.30, Δ5+lid 26.52; subword 24.79 with 60.6M vs 44.4M parameters. OPUS-100 subword 30.72 (77M) exceeds Δ6+lid 26.10 (44.5M), so the Ted conclusion is not universal (Table 4). Top-2 vs top-1 Δ5+lid 26.52 vs 26.03; changing the number of active experts changes compute as well as mixing (Table 5). PC-6 language ID reduces Δ5 22.03→21.65 (Table 11); App. H says wrong IDs barely hurt ro→en vs correct, questioning a strong language-identification story. App. G low-resource baseline byte transformer 1.05 BLEU vs subword 18.56 and Δ5+lid 19.45; model/data regime specific. Batch 65,536 for Ted/PC-6, 131,072 OPUS, early stopping, 5 checkpoint average, beam 4 (App. B); no equal raw byte context or total training FLOP ledger established. Table 6 reports speeds ~0.95–0.99× training and ~0.96–0.97× inference relative to byte baseline, values below 1 slower; measured Ted-59 only, not general serving cost. Byte-nCF omitted on OPUS because the authors report >300GB host-memory failure.

**Inference and alternatives.** Routing-frequency correlations with language length are observational, not proof that a router understands semantic characters or that selected bytes are causally used. Directions I.01–I.04/I.12/I.26–I.28. Independent no-revisit options include fixed causal local convolutions, byte-to-nonbyte output transduction, and decoder-head/optimizer changes. Same raw documents/context/compute, explicit non-byte target labels, causal kernels and source content-swap controls could change the mixed-interface or usefulness hypothesis.
