# W0387 = BIW-0041 — Masked Segmental Language Model

**Reading: FULL**, formal [SIGMORPHON 2022 proceedings](https://aclanthology.org/2022.sigmorphon-1.5.pdf), pp. 39–50. [PDF](sources/W0387.pdf), [text](sources/W0387.txt), SHA-256 `a9ea10fd9e153c624660a012fc67d23c0fff1eee074ad4820bcc9a85169361ff`. Main §§3–7 and Appendix A read; Table 2 visually inspected. Code and dataset repository URLs in the PDF are redacted; no code or separate artifact checked.

**Problem → solution.** Recurrent segmental models discover boundaries through LM training but limit parallelizable contextual encoding; use an attention-based masked segmental encoder with an LSTM segment decoder and dynamic-programming marginalization. Borrowed span masking, self-attention and Viterbi/forward dynamic programming; training signal is character sequence likelihood without gold boundaries, while model selection can use gold (§§3–4).

**Visibility and units.** The masked encoder predicts candidate spans using left and right context. A special attention mask excludes the next maximum-k symbols, while later layers use keys/values derived directly from original embeddings to avoid multi-layer leakage (§3.2). Because the same k-wide mask covers all segment lengths, shorter spans also lose nearby context up to k; this is not standard next-character causal LM likelihood. Directional MSLM uses a causal mask and is an explicit ablation; recurrent SLM also causal. Segment generation is over characters with end-of-segment, not byte tokens and not pooling. Bidirectional segmentation of complete sequences cannot be called streaming causal generation.

**Experiment and observations.** Single-layer encoders/decoders, hidden 256, four attention heads, near-matched encoder parameters 592,381 vs 592,640, 8,192 steps, ~8,192 characters/batch; six learning rates swept at one seed, then five total seeds; max length 5 Chinese/10 English. CBOW character embeddings pretrained for 32 epochs (App. A). Gold-tuned model chooses configuration by validation segmentation, versus unsupervised BPC validation selection; both report gold test segmentation. Table 2: Chinese PKU median F1 gold-tuned RSLM 60.2, directional 72.7, masked 72.6; unsupervised 58.7, 63.4, 64.1. English PTB unsupervised RSLM 76.2 vs masked 71.5 and directional 73.8; BPC 1.96 vs 2.27. Therefore attention and visibility contributions are not interchangeable and English gives a genuine reversal. Pilot lexicon/length regularization provided no gain (§7), not a general impossibility. Training time per batch on M10 8GB ~2.94–2.99 s PKU, ~2.18–2.20 s PTB; shallow scale and unequal effective information visibility limit FLOP/quality interpretation.

**Evidence boundary / hypotheses.** More readable boundaries are not necessarily task-sufficient compressed content, and bidirectional language scoring is not a native causal retrieval test. Directions I.05–I.09/I.22–I.23. Independent non-revisit alternatives: causal fixed boundaries, input-local convolutions without boundary decisions, and loss/optimizer redesign. Compare same character/byte exposure, causal vs right-context matching and separate boundary/pooling interventions; sustained long-context answer reversals would change the relevance of segmentation quality.
