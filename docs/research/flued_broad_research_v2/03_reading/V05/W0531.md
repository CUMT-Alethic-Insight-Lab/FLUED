**Problem:** a representation intervention can change one entity attribute yet inadvertently change others, and interpretability methods need comparable generalization tests. **One-sentence solution:** benchmark targeted attribute-change and non-target preservation on entity/context splits and train a multitask distributed subspace intervention that explicitly optimizes both (§§2–4). Borrowed techniques are interchange intervention, linear subspace rotation, cross-entropy training, PCA/sparse autoencoders and adversarial probes; their role is to assess and steer a *fixed* language model, not produce a naturally occurring memory read.

## Data, intervention and learning

Five entity types, each at least 500 original entities and 50 templates; attributes include city country/continent/language and verb tense (§2/Table 1). Entity split has disjoint entities but shared templates, Context split disjoint templates but shared entities, each 50/25/25 train/dev/test (§2.1). They are **not simultaneously held out on both axes**. The filtered Llama2-7B evaluation contains 2,800 selected entities, top-performing entities and templates, with 94.3–97.1% initial accuracy by entity type (App. A.2/Table 4 in the locked PDF), so not a representative measure on all hard factual inputs.

The base prompt asks for a particular entity attribute; a separate donor prompt provides another entity's residual activation. Intervention at the last entity-token position/layer replaces the learned feature projection. The desired **Cause** output changes to donor's targeted attribute; **Iso** preserves the base's other tested attributes; their equal average is Disentangle (§2.2). Outputs are predicted tokens; attributes can have first-token approximations, and non-target preservation covers only the enumerated dataset attributes, not full semantics. Target and donor activations are visible to the supervised intervention learner; this is not the unmodified model spontaneously accessing external memory. The main LM is frozen while the intervention parameters are trained.

DAS learns `k` orthogonal directions through counterfactual cross-entropy; MDAS adds averaged cross-entropy on non-target attributes (§3.5–3.6). App. B.4 uses `k∈{32,128,512,2048}` out of 4096, selected on dev; masked DBM uses annealed temperature, and multi-task masks additionally optimize isolation. PCA/SAE are unsupervised representations but use supervised feature selection; SAE learns 16,384 features on 100k Wikipedia sentences per entity type and is not perfectly invertible unless reconstruction error is zero (§3.2/App. B). Compare full-representation replacement baseline, PCA, SAE, supervised adversarial probe RLAP, DBM/DAS and multitask variants. App. B.5 reports A6000 times (e.g. reduced-rank DAS/MDAS 50 s per 1,000 intervention examples at rank 128; evaluation 20 s per 1,000), not total matched compute across all methods or LM pretraining cost.

## Results and limits

- Table 2 Entity/Context Disentangle: full representation 40.5/39.5; DAS 56.5/57.3; MDAS 60.1/65.6; MDBM 53.7/53.9. This aggregate favors MDAS within the tested family, not natural readout or deployment utility.
- Locked PDF Table 6, p.18, has negative cases: on verb Entity, MDAS 49.5 < DAS 51.8, with high average Iso 90.2 but Cause only 8.8; physical-object Entity 60.9 < DAS 61.1. Country–language and latitude–longitude remain difficult to isolate (§4.2). Single-run results with dev hyperparameter selection are explicitly noted (App. C).
- **Source tension:** §4.2 says highest test scores over layers are reported; App. C says layer 16 for city and layer 7 for remaining entity types with dev-selected hyperparameters. Do not assume which selection protocol produced each aggregate without checking the PDF/code; no claim that the paper is wrong. Model/site restriction, correlations among true attributes, limited host and unknown seed variation remain limitations.

**Theory versus use:** a learned intervention can be causally effective at controlled surgery but the training labels, donor input, selected subspace, filtered tasks, and artificial hybrid give it stronger permissions than ordinary native use. It does not prove the model would naturally read the same feature or that only this feature carries the fact.

**Prior directions:** D.01–D.02, D.07–D.10, D.14–D.15, D.19; C.06–C.08, C.18; F.12. **Minimal discriminator:** train on entities/templates disjoint from a joint held-out set; compare native unmodified answer, full-representation donor swap, random/equal-rank and target-specific trained intervention, preservation of independently sampled non-target facts and answer-sensitive controls. Match trainable dimensions and intervention opportunities; retain negative verbs. No architecture ranking or experiment is authorized.
