**Problem / solution / borrowed technique.** Extend finite-context pretrained LMs by adapting them to output summaries that can condition future segments. The method borrows recurrent memory tokens, soft prompting, and truncated backpropagation through time: all previous segment summaries are concatenated rather than overwriting one fixed recurrent state.

**Write–retain–read–use.** §3 appends κ learned summary tokens to each causal segment, whose output vectors write the segment summary; next segment receives all earlier vectors as a soft prefix. Summary at segment i cannot see future segment or eventual query; current text's causal prefix remains directly visible for prediction. At segment i the retained summary is (i−1)κ vectors, growing linearly; attention over accumulated summaries remains quadratic in segment count (Limitations). Separate retrieved-passage application (§6) precomputes summaries before a query, retrieves source passages with Contriever/BM25, then uses their vectors; external source index is retained and this is a different permission from pure closed state.

**Training.** §3.1 minimizes next-token cross-entropy throughout all segments, not AE or teacher distillation. Random segment boundaries improve variable-length use. Gradients through cached summaries stop after two compression steps, while summary values remain in forward context. OPT 1.3/2.7B adapted on 2B Pile tokens; Llama-2 7B freezes base and trains summary embeddings plus rank-16 LoRA attention on 15B RedPajama tokens (Appendix A). The resulting consumer is adapted, so improvements cannot be attributed to a frozen original LM alone.

**Comparators, observations and costs.** §4 uses 50 vectors per 2048-token segment, RMT, fine-tuned ordinary OPT and extended full attention. Extended attention wins with enough text; Llama-2 full context outperforms at longer contexts. Increasing κ to 70/100 does not monotonically help, with 50 best overall (§4.4). Stop-gradient/random-boundary/accumulation ablations differ; claims are specific to the measured setup. §5 reports 8/11 tasks improve vs 150-token demonstrations and some zero-shot Llama degradation vs initialization; seven sampling seeds. §6.1: top-10 fused summaries beat 50-token passage controls and top-2 REPLUG on 512-token passages, but REPLUG top-10 wins. 10B-token corpora cost ~5 TB/domain at half precision; 21M passage vectors require 2.1/5.4 TB for 20/50 vectors (§6.2); reported reranking throughput assumes negligible vector loading and unbatched query. Precomputation, adaptation, index storage, full host state and source access must be counted separately. Hand-picked token gains (Appendix D) are suggestive, not counterfactual content-dependence proof.

**Directions / rival causes.** A.01/A.06–A.08/A.16/A.19–A.20, B.09/B.22 and D.02–D.06. Compare no/true/wrong/constant summaries with identical adapted and unchanged-host opportunity and matched accumulating state; test source bindings and held-out shifted queries. This distinguishes generic adaptation or topical priors from document-specific consumption. The reported timing is not a universal deployment frontier; original/formal edition equality remains unverified.
