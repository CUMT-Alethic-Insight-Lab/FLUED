**Problem / solution / borrowed AI technique.** Standard gist-token aggregation may duplicate attention and discard intermediate-layer-accessible features. ComprExIT feeds frozen LLM layer states into a learned per-token depth gate and entropy-regularized optimal transport from token anchors to compressed slots. Borrowed cross-layer mixing and Sinkhorn transport are learned readout and allocation tools; not proof of true information transmission or binding preservation (§§3–5).

**Write, retain, read and use.** Each token's cross-layer hidden states are mixed using learned global priors, gated projections and layer embeddings (§5.1). §5.2 partitions token anchors into local fields, mean-pools receivers, computes projected cosine utilities and learned source capacities; receiver capacities are uniform. The transport is coupled, but Sinkhorn runs on *128-token windows*, 30 iterations, not unrestricted document-wide coordination. A projection/MLP outputs K continuous compression slots; the decoder consumes those along with the question. In the question-unaware setting the writer sees the context but not future question; SFT explicitly uses context–question–answer supervision (§6.1/A.3). This is not an unbounded fixed-state stream. NTP uses 1B SlimPajama tokens and SFT uses MRQA, default 512 context/128 generation, ×4 compression, Llama-3.2-1B/3B; base is described as frozen feature extractor. Appendix A.8.2/Tables 9–11: four A100, BF16, 1 epoch, 2048 effective batch, ComprExIT learning rate 1e−4 versus ICAE/500x 3e−5 and trainable LoRA rank 128; hyperparameters/training machinery differ, so same source tokens are not identical optimization or total compute. SFT-specific full resource ledger is not quantified here.

Appendix A.7 Proposition A.1 assumes finite first moments and applies the Wasserstein triangle inequality: final representation-to-decoder mismatch is *upper-bounded* by initial mismatch plus the sum of per-layer distances.
