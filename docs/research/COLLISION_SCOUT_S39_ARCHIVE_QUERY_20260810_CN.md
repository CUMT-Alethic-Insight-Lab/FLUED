# S39（档案馆内容寻址远程查询接口）撞车侦察报告

> 2026-08-10，按 AGENTS.md 协作协议规则 5（架构级臂开 GPU 前必出撞车侦察报告）。
> 拟开臂：**档案馆内容寻址远程查询接口**——多页流式形态（页=512B 窗口，KDA 状态
> 跨页携带，页级残差缓存行全局序号编址）下，每页除 gist 外多吐少量**远程查询
> token**（学习的内容寻址查询），与缓存行 key 点积、top-k 硬选择 + 直通估计（STE）
> 传梯度，选中行加入该页读出集；训练任务=跨页 needle 还原，损失只打针位字节。
> 侦察方式：三路并行 subagent（经典内容寻址线 / 近 12 个月谱系 / 压缩×byte 交叉域），
> 全部引用经 WebSearch/FetchURL 实时核实，二手核实项逐条标注于 §8。
> 结论：**绿（带条件）——组合格无占位，可开臂**；两条设计约束（§5）必须吸收进预注册。

## 1. 一句话结论

四条 claim 逐格核查后，**组合格**（语义段定界的自压缩内部库存 × 生成损失直训的学习
查询接口 × KDA 载体 × byte 级）在经典线与 2025-08→2026-08 谱系中均无人占据；最近邻
HMT / SDM / M+ / CLaRa / SSA 各有机制级分界（§2），不是叙事差异。但单腿拎出来条条
有近邻占位——**立项书与 related work 必须逐条显式区分最近邻，否则按单腿判撞**。

## 2. 同名/同形核查（最近邻深读）

### 2.1 HMT（arXiv:2405.06067，2024-05）——查询接口形态最近邻

段摘要 embedding 当查询（Q=S_n·W_q），对滑窗内 N 条缓存段记忆行做 softmax 交叉
注意力，W_q/W_k 与主干联合微调、LM 损失端到端。**"自压缩段库存+段级学习内容寻址
+联合训练"它占了一半格**。机制级硬差异四点：① 它是有界滑窗（N≈300）**软注意力**，
S39 是全局序号编址 + top-k 硬选择 + STE——"远程精确命中"正是软窗做不到的；② 它的
查询=段自摘要（"我自己是什么"），S39 是专用远程查询 token（"我需要什么"）——自查询
vs 需求查询的分工，恰与我方 harness 的 0.04 vs 0.68 自查询对照互为印证（HMT 形态
已知偏向自查询）；③ 它的读出作 prompt 拼接服务全段 PPL，S39 损失只打针位字节、
直接塑造寻址；④ token 级 vs byte 级。

### 2.2 SDM（arXiv:2607.07386，Meta FAIR，2026-07）——载体+稀疏寻址最近邻

GDN 稠密外积状态换成 N 槽显式记忆表，PKM 式劈半外积打分 → top-R 读/top-W 写，
选中槽做 gated delta 写入，isoFLOP 训到 8B/1T token，RULER 大幅超 GDN（34.2→50.2
@8B）。**"delta-rule 载体+学习稀疏寻址大显式记忆"已被它在 8B 规模占位**——若把
S39 新颖性挂在"KDA 载体+学习寻址"上必撞。机制级硬差异：① SDM 槽位是**覆写式定长
状态表**（delta 就地更新，无历史概念），S39 是**只增不改的全局编址档案**（行=某页
某段快照，跨页可远程点名）——状态 vs 档案馆的本体差异；② SDM 寻址发自当前 token
隐藏态（读写同源捎带），无"为远程预留查询"的专用发射点；③ 选择边界无梯度（与
PKM 同族），S39 用 STE 穿透。**附带资产**：其 PKM 打分（O(√N·d)）是档案行数涨大后
的现成工程方案；"选择无梯度"路线是 STE 的现成消融对照臂（便宜且必做）。

### 2.3 M+ / MemoryLLM++（arXiv:2502.00592，2025-02）——协同训练检索器最近邻

MemoryLLM 自压缩潜 memory tokens 挤出后进 CPU 长期档案（每行附 age≈全局序号退化
版），f_q/f_k 双 MLP 投影点积检索，每层一次。**"自压缩潜库存+协同训练检索器"半格
被占**。机制级分界：其检索器**不走生成损失**——用文档分块 provenance 构造 θ₊/θ₋
辅助对比损失训 f_q/f_k；准入是随机丢弃（无语义段边界）；token 级；无线性状态机
载体。S39 的"针位生成损失经 STE 直训查询接口"是与之的机制级分野。related work
必须单列一句区分。

### 2.4 CLaRa（Apple，arXiv:2511.18659，2025-11）——"压缩库存×检索×生成"端到端最近邻

压缩+检索+生成在共享连续潜空间联合训练，**单一 LM 损失 + Straight-Through 可微
top-k**——梯度拓扑（针位式功能损失→生成器→STE→打分/压缩器）与 S39 同构。**它证明
了"压缩库存+STE 硬选择+联合训练"可训稳**（对本臂是可行性背书），但：库存=外部语料
的离线压缩（非模型流式处理中自写的内部情景记忆）；查询=双编码器检索语义（问题-
文档匹配），非主干生成途中按需吐出的"我缺什么"型查询；无状态机、无跨页携带；
token 级 RAG 管道。**"库存=自己的过去"这一半它没碰**。

### 2.5 SSA / "Forget, Then Recall"（arXiv:2604.20920，2026-04）——gist 作寻址 key 最近邻

块尾插 gist token、mask 强制信息装箱，推理时当前 query 只对 gist 打分、top-k 块
选择性展开回原文。**"gist=寻址 key"被占**，但三点硬差异：① 它的 gist 是**索引不是
存储**（原始 KV 全程保留，省的是带宽不是存储）——我方缓存行**就是存储本体**
（E54/E55 已证 4096 起承重）；② 打分 query 是生成中的当前 query（捎带），非每页
专门吐出的学习查询 token；③ top-k 选择不可微不进梯度。**术语警示**：其"gist"与我
方 k=1 读出的 gist token 同名异物，论文/报告须区分表述（见 §8 写作义务）。

## 3. 12 个月谱系扫描（2025-08 → 2026-08）

**收敛方向四分，"查询接口"不是任何一条的主角**：

1. **代理记忆工程线**（产出最多）：MemOS/Memory-R1/Mem-α/MemGen/MemSearcher/
   MemEvolve/SimpleMem——全在模型外，RL/prompt 管外部数据库。
2. **测试时参数化线**（学术声量最大）：Titans→ATLAS(Behrouz)→Miras→Nested
   Learning/HOPE→TTT-E2E——库存=权重，读出=前向，无寻址。
3. **原生稀疏注意力训练线**（工程落点最实）：NSA/MoBA→DSA(DeepSeek-V3.2)→
   Superlinear→L2A→UNIQUE——选择器全部作用于**原始 KV**，逐 token/逐块。
4. **综述层**：2025-12→2026-07 五篇记忆综述的 taxonomy 里"model-native learned
   retrieval into self-built archive"**不是一个被命名的类目**——格子在综述层也空。

**训练式跨页/跨段检索无公开死刑判文**：免训练/蒸馏选择器有负面（Sparse Frontier
2504.17768；2607.21692 路由率跨种子 36-98% 不稳）；训练式硬选择有规模化正例
（NSA/MoBA/Superlinear + 2512.03494 训推一致性研究）。读写耦合惩罚存在但轻微
（Memoir 2607.20792：学习速度惩罚非能力惩罚）。

**重要增量逐条**：SDM（2607.07386，§2.2）、CLaRa（2511.18659，§2.4）、SSA
（2604.20920，§2.5）、LoLA（2604.05438）、Causal Evidence Sets（2607.21692，§3
下）、DSA（2512.02556）、Engram（2601.07372）、LTE（Idiap-RR-01-2026，GDN+可
学习逐出，二手核实）、SeKV（2606.31145，STE 用于 KV 层级展开决策——STE 先例）、
ElasticMem（2605.30690，retrieval-control token 触发检索，RAG 语境）、PRECOG
（2608.02560，SSM 状态压缩库存+外置检索）、Mixture of Chapters（2603.21096）、
Memoir（2607.20792）。

## 4. 病灶的外部独立证实（2607.21692，Causal Evidence Sets）

其核心发现与我方 harness smoke **逐字同构**：注意力≠因果依赖，蒸馏注意力的选择器
跨种子路由率 36–98% 不稳；"在计算开始前承诺单一 block 集合"是多跳失败的机制，逐
查询重选后 0.94→1.00；结尾判词 **"the readout fails rather than the weights"**——
库存无罪、接口有罪（我方：needle 在缓存 hit=1.0，末端状态查询 0.04 vs 自查询
0.68）。含义：① S39 的病灶判断获外部独立背书；② 其"用下游因果证据而非注意力
蒸馏监督选择器"正是 S39 针位生成损失的形态——损失设计获背书；③ 其失败象限直接
转化为设计约束（§5 第 1 条）。

## 5. 一句话差异点（终版）+ claim 逐条裁决

**S39 = 对"只增不改、语义段定界、残差门控准入"的自压缩内部档案，由主干学习吐出
的专用远程查询 token 经 STE 穿透 top-k 硬选择实施内容寻址，监督直接来自针位字节
的生成损失——库存身份（内部情景记忆 vs 外部语料/原始 KV）、查询来源（需求查询
vs 捎带/自摘要/双编码器）、选择梯度（STE vs 无梯度/软读出/边缘化）三轴无占位。**

| 原草案 claim | 裁决 | 修订 |
|---|---|---|
| 库存=模型自压缩语义段行 | 半占位（HMT/SDM/ICAE/M+ 占了"自压缩"） | 收窄为"**语义段定界**的自压缩库存"（学习边界决定行粒度+残差门控准入——无占位） |
| 查询接口端到端联合训练 | 单拎出来已被占（REALM/HMT/SDM/CLaRa/NSA） | 重心移到"对**内部自压缩情景库存**的学习寻址接口"；新意=三层叠加：专用潜查询 token + STE 穿透硬选择 + 针位字节损失 |
| KDA 线性状态机载体 | 实质同构被 SDM 占位（GDN 姐妹架构，8B） | 改为**分工形态**：线性状态机管顺态压缩（gist），只增不改档案管精确寻址——与 SDM 覆写式状态表有本体差异 |
| byte 级无 tokenizer | 无占位 | 真实但属载体级，必须与语义段粒度绑定陈述（byte 级+学习边界 ⇒ 语义段库存的来源） |

## 6. 设计约束（侦察带回，预注册必须吸收）

1. **远程查询 token 不得是"每页单组一次性 top-k 承诺"**（2607.21692 失败象限）——
   设计须含多查询/逐位置重选能力；"页级承诺 vs 逐查询重选"列为预注册消融。
2. **训推一致**（2512.03494 + NSA/MoBA 正例）：评测必须用学习选择器出数，禁止
   oracle 兜底；oracle 选择只作上限参照臂（LoLA 记账规则可借）。
3. **读写耦合惩罚监测**（Memoir 2607.20792）：训练指标里监测读写交织是否引入
   学习速度惩罚。
4. **STE vs 选择无梯度**（SDM/PKM 路线）列为必做消融对照臂——便宜且是直接回应
   最近邻的判别证据。
5. 档案行数涨大后的打分工程方案：SDM 的 PKM 劈半外积（O(√N·d)）现成可借。

## 7. 我方前置证据（开臂依据）

- 多页 harness smoke（`tools/eval/paging_harness.py`）：needle 在缓存 hit=1.0，
  末端状态查询读出 0.04 vs 自查询 0.68——瓶颈在查询接口（2607.21692 外部背书）。
- E50：固定单查询取址墙（512B 死因终定）；逐段查询是逃逸轴。
- E54/E55：存储冗余律 512B/2048 成立、4096B 拐点 +1.78pp——存储在多页/长窗
  才承重，查询接口是其配套缺口。
- E44/E43：混合架构教训（Kimi Linear 3:1/Jamba）独立复证——精确通道必要性。

## 8. 生存验证原则对齐 + 写作义务 + 存疑清单

查询无活可干）——开臂尺度=多页 harness（页数扫描），判读线对 oracle 上限臂与
无接口对照臂双侧标定。若学习选择器追不上 oracle 的半数水位，路线降级为论文素材。

2208.03299）；② M+ 单列区分（provenance 辅助损失/随机丢弃准入/token 级/每层一次
共享查询）；③ "gist"术语与 SSA 的块索引 gist 同名异物，须区分表述（TERMS.md 已有
我方 gist token 词条，投稿文本加限定）；④ related work 逐条区分 §2.1-2.5 五个
