## §1 需求必须长出的六张脸（每张对应一处坟场；2026-09-06 增第六张）

1. **答案先验猜不中**（Q14 的坟）：尾字节、稀有串、随机实体——先验能蒙的需求等于没有需求，溶剂会把检索解吃掉；
2. **形式零门槛**（E98/E101 的坟）：不能有任何"先要理解任务格式"的环节——50M 的格式理解力全部死在有效性门上。最好的需求是**根本不像任务的需求**（损失重加权路线：**本项目自提**（fable5 会话产出，非文献——2026-09-04 用户认账更正），文献空档经撞车侦察确认：模型甚至不知道自己在被考）。**【2026-09-09 格别注记（审计行动 4）**：本脸证据产 b 格 v37.2 冻结前端臂，「50M 格式理解力全死」为该体制口径；外推 from-scratch 臂带注记（E121「Δ=0 与骨干未熟不可分离」在案）】；
3. **答案只经状态通道可达**（窗口剪刀）：源内容要落在窗内注意力直读够不着、旁路绕不开、只有"状态行索引 → memory 行取货"这条路能到的地方——不满足这条，练出来的是窗内复制回路，不是状态消费。**【2026-09-09 格别注记（审计行动 4/9）**：本脸概念出自 d/b 格语境；**a 格无状态机时退化为「store 行可达」**——考场臂的「跨段消费」考的是 memory 行→字节解码头通道而非状态矩阵（TERMS「窗剪刀」独立词条交叉引用）】；
4. **剂量密度要摊得过回路维持费**（Q13/Q14 的坟 + 回路经济学）：每窗 ~1.5 字节的监督密度只够催生瞬态——需求要么高频（突发性注入加量），要么配保镖（权重衰减给记忆化计价——**Singh et al. 2023**（《The Transient Nature of Emergent In-Context Learning in Transformers》，arXiv:2311.08360，NeurIPS 2023：ICL 瞬态→IWL 接管 + L2 正则延续 ICL 实证）**等最常复证的常驻辅助手段之一**（2026-09-04 降格裁定：「唯一实证有效」过言，goldfish loss 等同样在案））。**【2026-09-09 格别注记（审计行动 4）**：回路维持费经济学产 b 格 50M 冻结前端臂，外推 from-scratch 臂未复验】；
5. **检索必须比背先验便宜**（五次瞬态被吃的坟）：这是最深的一条——损失面上"背分布"和"查黑板"两个解并存时，需求必须让**查黑板的解先冲线**：梯度下降只奖励先到的解。前四条造需求，这一条决定需求有没有用。**【2026-09-06 增注】**本脸与第六张脸构成对偶：⑤抬检索解、⑥压先验解，两件都要做。**【2026-09-09 格别注记（审计行动 4）**：瞬态计数为跨格聚合（E105 b / E107 d / E110 a / E115 d），各证据行自带格标签、聚合口径有注记】；
6. **【2026-09-06 增（第四轮审计裁定④）】先验解要被结构性剥夺，不只被相对抬价**（posterior collapse 的坟）：脸①–⑤全部是"把检索解抬便宜"（D1 即是），没有一条动先验解本身——E121 以 36.6× 剂量抬检索、先验解一根毫毛未动，而先验解正是先冲线的那个。文献治疗线：posterior collapse 的 **free bits**（信息项铰链下界）/**word dropout**（生成时随机把上文替换为空向量，强迫依赖潜码）/KL annealing；REALM 冷启动死锁（检索器随机→编码器学会忽略检索→梯度死锁）的解=给检索器单开逼迫检索的预训练目标（Inverse Cloze Task）=相位分离先例。锚：`docs/research/FLUED_V3_7_ROUND4_DISCRETENESS_AUDIT_20260906_CN.md` §5。

**第七性质（2026-09-07 增，与六张脸并列——不是脸，是监督形态的硬约束）**：**监督必须逐位置稠密地作用于读出件本身，不许只监督最终答案**——拿回同一内容存在「读路径」与「写侧捷径（前向复制）」两条任务指标不可区分的等价路径，梯度密度差数量级，训练必然收敛到模型已擅长的写侧（外部构思审计收编，E123 任务书 §1）。
