## 5. 术语与含义边界

| 原词 | 本译法 | 局部对象或易混边界 |
|---|---|---|
| byte | 字节 | 八位单位；不与 Unicode 字符等同 |
| code point / Unicode scalar | 码点／Unicode 标量 | 代理码点不是标量；合法 UTF-8 编码标量 |
| grapheme cluster | 字素簇 | 近似用户感知字符，可跨码点 |
| character | 字符 | 按来源实际字母表解释；历史受限字符不改为原始 UTF-8 |
| script | 文字系统／文字 | 不是程序脚本，也不等于语言 |
| subword / token / word | 子词／词元／词 | 三者分开；专名和单位依原文 |
| patch / segment / grouping | 块／段／分组 | 跟随来源操作，不假设词义、无损或某种池化 |
| frontier | 前沿／前沿位置 | 缩放语境是资源前沿；MANTa 语境是累积边界位置 |
| pooling / endpoint selection | 池化／端点选择 | 内容算子与边界策略不同 |
| rate / realized rate | 速率／实际速率 | 通常是更新或组数相对字节数，不是 bytes/s 吞吐 |
| trunk / local / head | 主干／局部模块／预测头 | 分列其容量和成本，不只报总参数 |
| prefill / serving | 预填充／服务 | 提示处理与部署请求；不把训练步时间译成服务延迟 |
| causal | 因果 | 时间可见性与统计因果识别分别注明 |
| tying / sharing / alias | 绑定／共享／别名 | 指定矩阵或路径；共同初始化不等于共享训练存储 |
| unembedding | 反嵌入／输出读出 | 分类读出，不暗示输入嵌入可逆 |
| readout geometry | 读出几何 | 点积、行归一化、完整余弦和尺度不同 |
| observed-target confidence / entropy | 已观察目标置信度／熵 | 训练标签信号与观察前预测不确定性不同 |
| utility / novelty | 效用／新颖性 | 计算增量价值与重复信号，不互称语义边界 |
| canonical path / marginal / prefix cover | 规范路径／边缘概率／前缀覆盖 | 概率事件不同，换分母不改变事件 |
| target law / proposal / residual / bonus | 目标概率律／提议／残差／奖励 | 拒绝后的概率校正不同于全部接受后的额外样本 |
| retained state / post-ingestion | 保留状态／摄入完成后 | 复制上界还要求计入全部输入相关通路 |
| scoped FULL / intentional PARTIAL | 约定范围内原文阅读完成／有意窄范围摘读 | 都不是实验复现；PARTIAL 不改成受阻或失败全文阅读 |
| CER / PER / word error rate | 字符错误率／音素错误率／词错误率 | G2P 的音素、词错误率是不同误差单位 |
| percentage / percentage points | 百分比／百分点 | 保留原始百分数，不把绝对差写成相对百分比增长 |
| position / length parity | 位置消耗／长度的均衡程度 | 资源分配诊断，不直接等于规范性的任务公平 |
| tokenization parity / information parity | 分词长度比（TP）／信息比（IP） | 方言研究分别定义为语言／英语长度比、英语／语言总 NLL 比，方向不变 |
| probability mass | 概率质量 | 概率分布中的量，不是预测质量或任务质量 |
| partial patch | 未完成块中已观察到的部分 | 不等同于架构的局部块或局部模块 |
| lemma / lemmatization | 词汇基本形／词形还原 | 不与表示 token 的“词元”混用 |
| multimodal target variation | 目标分布多峰性带来的变异 | 此处指多个可能目标，不是多种输入模态 |
| evaluated population（MYTE 语境） | 评估语言集合 | 按各表语言列、运行和聚合口径界定，不是人的受试群体 |
| abridgment | 删节稿 | 不译成缩写，完整翻译不能由删节稿代替 |

模型名、BIW／BIP／OQ、数据集、版本、文件名、URL 保持不变。已有英文方法名不另造中文专名；必要的语义说明直接写在相关句中。本说明是本次翻译用语表，不修改项目术语注册表。
