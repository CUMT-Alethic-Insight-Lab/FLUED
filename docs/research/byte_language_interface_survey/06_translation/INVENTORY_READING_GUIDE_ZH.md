# 字节语言接口清单阅读指南

英文定稿：[INVENTORY_READING_GUIDE_EN.md](../04_synthesis/INVENTORY_READING_GUIDE_EN.md)。本译文中的“AI技术工具”指原研究使用或借鉴的人工智能、统计学习方法，不是翻译助手调用的软件工具。

<a id="1-what-this-guide-is-for"></a>
## 1. 本指南的用途

应把清单读成设计决策的地图，而不是“是否使用分词”的竞赛。它的核心是：语言系统如何把书写符号与计算、学习信号和生成输出连接起来。接口可以接收所有UTF-8字节，却让昂贵网络在子词上运行；可以把字节组合成词表示，却只预测固定词表；也可以在每个位置预测字节，而不学习边界。这些都是针对不同问题的不同方案。

本指南说明如何从问题定位记录、如何在比较机制时保留实验条件，以及如何围绕这些比较组织长篇综述。配套的[分类文章](CLASSIFICATION_ZH.md)提供全部296条记录的紧凑路线索引、可重叠的问题层级和面向技术的解释。逐条规范清单见[DETAILED_INVENTORY.md](../02_inventory/DETAILED_INVENTORY.md)，中文工作见[DETAILED_INVENTORY_ZH.md](DETAILED_INVENTORY_ZH.md)。这两篇组织性文章都不能替代清单中的逐条“问题→一句话方案→研究者实际使用的技术”。

文献总体为**141个独立来源实体**：136篇学术论文（含一项经筛查的提案）、一份GPT-2技术报告、三项标准和一份官方模型介绍。其中140个实体贡献记录。清单有**296条可追溯记录**，并不意味着296个独立科学问题或实验。阅读深度账目包含**92个不同的限定范围FULL来源**、两项有意限定范围的PARTIAL摘录，以及其他仅读摘要或选定段落的储备文献。FULL表示已完成登记范围的来源阅读，PARTIAL表示部分阅读。这些分母来自[COUNTS](../02_inventory/COUNTS.md)，不能通过累加引文或卡片出现次数得到。

尤其要区分*上位问题*和*来源特定的子发现*。“模型应如何沿字节流分配计算？”是上位问题。固定分块构造、学习式路由器、熵指标的负面诊断、缓存测量和优化近似，是该问题下不同的记录。分开保留记录是为了保留机制和证据，不会使它们成为独立复证。

<a id="2-start-with-the-right-document-and-identifier"></a>
## 2. 从正确的文件与标识符开始

<a id="21-the-short-navigation-chain"></a>
### 2.1 简短的导航链

对于实质性论断，沿以下链条查证：

**上位问题→BIP记录→BIW来源身份→承载证据的阅读卡→固定来源位置→当前更正。**

- [TAXONOMY](../02_inventory/TAXONOMY.md)提供12个人工赋予、允许重叠的C01–C12问题族及其完整成员清单。
- [DETAILED_INVENTORY](../02_inventory/DETAILED_INVENTORY.md)提供稳定的**BIP**记录锚点、具体方案、实际技术、证据条件和来源映射。
- [WORK_CATALOG](../02_inventory/WORK_CATALOG.md)提供稳定的**BIW**来源身份、版本、四类接口单位和承载阅读卡链接。历史W标识符是别名，不是额外文献。
- [EVIDENCE_STATUS](../02_inventory/EVIDENCE_STATUS.md)说明来源与论断各自的证据上限。
- [AUTHOR_HANDOFF](../02_inventory/AUTHOR_HANDOFF.md)与[CLAIM_RULES](../05_review/CLAIM_RULES.md)说明已采纳的更正，以及影响综合论述的未决问题。

BIW回答“是哪一个来源”，BIP回答“摘出了哪一个问题、机制、对照或例外”。一篇文献含有实质不同的发现时，应同时引用两者。例如，[BIW-0008](../02_inventory/WORK_CATALOG.md#BIW-0008)标识MEGABYTE，[BIP-0014](../02_inventory/DETAILED_INVENTORY.md#BIP-0014)标识因果对齐，[BIP-0284](../02_inventory/DETAILED_INVENTORY.md#BIP-0284)标识局部输入/输出共享的论文规定。不能把它们写成同一架构收益的三项独立证明。

当前基于阅读卡的部分优先于折叠的历史发现摘录。如果阅读卡本身也含有过时解读，应采用后来明确命名的更正，尤其是MYTE的聚合列、Hourglass的移位残差、方言研究的指标指代、MtPC的优化采样器和TokSuite的Figure 6。历史文字解释来源沿革，不是一份可任意挑选的同等有效解释菜单。

<a id="22-reading-depth-is-a-permission-not-a-score"></a>
### 2.2 阅读深度界定可论述范围，不是评分

限定范围的FULL卡表示已读完其固定来源及相关承载章节；不代表查明实际软件路径、复现结果、证明每一个论证，或补齐未报告字段。因此，MtPC可以有FULL卡，其优化随机采样封装的正确性却仍未验证。反过来，有意限定范围的摘录也可以支持有价值的历史陈述，而不认证整篇论文。

两项指定PARTIAL说明了后一种情况。[ELMo，BIW-0140](../03_reading/FIELD_ADDENDUM/arxiv_1802.05365v2.md)覆盖v2 §§1–3.4和Table 1：词位置上的字符组合、上下文层混合、迁移和方向间共享；§§4–6及补充材料未全面审读。[GPT-2，BIW-0141](../03_reading/FIELD_ADDENDUM/gpt2_official_report_2019.md)覆盖官方报告p.4 §§2.2–2.3及相邻§3.1：256字节基底、合并后的BPE片段和类别约束；报告其余部分及基准结果不在该摘录范围。两者都不是未完成的FULL任务，也都不能支持全来源的成本或性能结论。

296条记录的支持类型为：233条由限定范围FULL支持、4条由窄范围PARTIAL支持、53条属于发现阶段A/P（摘要/选段阅读）、3条规范性记录、2条官方介绍记录，以及1条尚未解决的指标计算问题。这些是记录的支持类别，不是已验证效果的数量。EvaByte官方介绍与三项标准保留各自的文献类型；仅提案来源不贡献已实现的实验。

<a id="3-read-an-interface-as-four-units-not-one-model-name"></a>
## 3. 把接口读成四类单位，而不是一个模型名称

比较两个系统之前，写出**输入/内部/输出/监督**。内部单位应说明昂贵计算发生的位置或持久状态，而不只说“隐藏向量”。监督单位除最终目标字母表外，还应说明扰动选择、教师边界或辅助标签。

| 接口路线 | 输入 | 内部计算 | 输出与监督 | 推荐入口 |
|---|---|---|---|---|
| 原生字节链 | 单个字节 | 字节位置、循环状态，或字节加分块的层级 | 下一字节的类别事件；任何特殊符号均须明确 | [BIW-0071](../03_reading/R09/BIW-0071.md)，§2；[BIP-0142](../02_inventory/DETAILED_INVENTORY.md#BIP-0142) |
| 码点编码器 | Unicode码点 | 局部码点状态、步幅4的全局状态、恢复后的任务位置 | 任务标签；分桶码点或可移除的子词预训练目标 | [CANINE卡](../03_reading/R01/BIW-0004.md)，§§3.1–3.2 |
| 字节序列到序列去噪器 | 经扰动的源字节 | 完整源序列的编码器状态；因果目标解码器状态 | 重建的字节/哨兵符号片段 | [MANTa卡](../03_reading/R01/BIW-0006.md)，§§3.1–3.2 |
| 字符组合式词语言模型 | 外部分词所得词内的字符 | 每个词对应一个循环位置 | 固定词类别与下一词交叉熵 | [BIW-0055](../03_reading/R02/BIW-0055.md)，Model/Fig.1 |
| 字节完备的子词语言模型 | 合并后的byte-BPE符号 | 每个合并符号一个位置 | 下一个合并词表项 | [GPT-2窄范围卡](../03_reading/FIELD_ADDENDUM/gpt2_official_report_2019.md)，§§2.2–2.3 |
| 稀疏词汇混合接口 | 规则切分的类词单位和三元组特征 | 每个完整单位一个主干位置 | 候选词典中的单位；多标签特征训练 | [T-FREE卡](../03_reading/R10/BIW-0127.md)，§§3.1–3.2/Algorithms 1–5 |

条件允许时，必须进一步明确“字符”的含义。清洗语料中的受限字母表、Unicode码点、用户感知的字素簇和UTF-8字节，是不同单位。[RFC 3629，BIW-0090](../02_inventory/WORK_CATALOG.md#BIW-0090)定义字节序列合法性；[UAX #15，BIW-0115](../02_inventory/WORK_CATALOG.md#BIW-0115)区分规范化等价；[UAX #29，BIW-0116](../02_inventory/WORK_CATALOG.md#BIW-0116)提供有版本的字素切分规则。它们定义测量工具与概念区别，不是模型实证成功。

开放输入支持也不等于开放生成。Character-Aware Neural Language Models可以从拼写构造向量，但报告的输出仍是含UNK的固定词softmax。CharacterBERT同样结合局部字节组合、词位置理解和临时词预测词表；见[BIW-0066](../03_reading/R01/BIW-0066.md) §§2–3及[BIP-0136–0138](../02_inventory/DETAILED_INVENTORY.md#BIP-0136)。T-FREE能够哈希新输入词，但生成时对有限候选词典评分。它们是有用的混合设计，不是某个预设字节输出目标的缺陷实现。

<a id="4-six-reading-routes-through-the-field"></a>
## 4. 贯穿领域的六条阅读路线

<a id="route-a-why-change-the-lexical-interface"></a>
### 路线A：为什么改变词汇接口？

先读[C01](../02_inventory/TAXONOMY.md#C01)，再比较应对词汇僵化的三种办法：字节完备的子词构造、局部拼写组合和原生字节预测。关键是：在哪一层移除了词汇依赖，哪里仍保留了它。

Character-Aware LM与GPT-2的历史比较尤其有启发。前者以字符CNN/最大池化/highway门控组合取代输入词表，同时保留词时间步循环和词输出。后者保留大型学习式片段词表，却以全部256个字节值为基底。这几乎是结合底层覆盖与高层计算的两种相反方式。GPT-2摘录确认的是50,257片段词表和1,024模型词元上下文，不是1,024字节；Character-Aware卡确认的是固定词分类器，不是无约束拼写生成。

接着读[CANINE](../03_reading/R01/BIW-0004.md)。哈希嵌入处理Unicode码点查表的存储和覆盖问题；它允许碰撞，不证明模型对未见书写系统拥有有用知识。CANINE的局部注意力和步幅卷积另外处理长输入。CANINE-S还说明，子词监督可以只是训练阶段的资源。因此，部署时免分词的编码器，不一定没有来自子词的学习信号。

这条路线应引向多语言资源分配，而不是“普遍覆盖即足够”的结论。[BIP-0061](../02_inventory/DETAILED_INVENTORY.md#BIP-0061)问平行语义消耗多少位置；[BIP-0221](../02_inventory/DETAILED_INVENTORY.md#BIP-0221)研究形态派生编码。可表示性、有效文本上下文和语言效用应放在相邻段落中讨论，不应压成一个指标。

<a id="route-b-how-are-fine-symbols-composed-and-what-is-actually-shortened"></a>
### 路线B：细粒度符号如何组合，实际缩短的是什么？

先读[C02](../02_inventory/TAXONOMY.md#C02)，再读[C03](../02_inventory/TAXONOMY.md#C03)，避免以边界为先的叙述掩盖聚合算子。比较CNN/最大池化、均值池化、拼接、交叉注意力、上下文末状态选择、删除后存活位置和固定潜在数组。

Character-Aware LM给出了具体的早期优化经验：PTB大配置中，两层highway得到78.9困惑度，无highway为84.6，普通单层MLP则为92.6（Table 7）。这是该字符到词设置中门控特征变换的证据，不是字节语言模型结果。同一卡还报告字符输入约1,500词词元/s、词输入约3,000词词元/s；参数节省不意味着局部组合没有成本。

Charformer与MANTa进一步区分两类可微性。[Charformer](../03_reading/R01/BIW-0005.md) §2.1在每个字节位置混合候选块表示，再施加最终固定步幅；软宽度偏好不是一致的硬划分。[MANTa](../03_reading/R01/BIW-0006.md) §3.1用高斯近似累计边界数所决定的成员关系，执行对顺序敏感的逐通道卷积/最大池化，并把保留块数上限设为输入长度的四分之一。§6.1报告，没有瓶颈时会退化到每字节一块；它没有给出可据以虚构数值的匹配消融。

沿[BIP-0010](../02_inventory/DETAILED_INVENTORY.md#BIP-0010)读Dynamic Token Pooling，沿[BIP-0026](../02_inventory/DETAILED_INVENTORY.md#BIP-0026)读H-Net。DTP明确平均已完成的字符片段；H-Net直接选择已经上下文化的状态。两者都没有建立无损逆变换。[Local Byte Fusion，BIP-0070](../02_inventory/DETAILED_INVENTORY.md#BIP-0070)是有用对照：局部融合恢复字节分辨率，并不缩短持久序列。Perceiver IO，[BIP-0121](../02_inventory/DETAILED_INVENTORY.md#BIP-0121)，把深层计算压入固定潜在槽位，无需连续片段身份。

<a id="route-c-is-segmentation-necessary-for-efficient-byte-computation"></a>
### 路线C：高效字节计算必须依赖切分吗？

阅读[C04](../02_inventory/TAXONOMY.md#C04)时，应完整保留非层级反例。从循环字符模型到层级字节模型只是一条历史脉络，不是整个领域。

[BIW-0071](../03_reading/R09/BIW-0071.md)扩大普通40层因果字节Transformer，仍然每字节一个位置。其23.0的词归一化困惑度针对处理后的lm1b语料，语料已经过词级预处理并替换了UNK；这既不是未经处理的原始文本证据，也不是与每个词模型的匹配计算比较。尽管如此，它直接挑战“必须有学习式压缩器才能得到有竞争力的字节似然”这一说法。

[Sparse Transformer](../03_reading/R09/BIW-0118.md)与[Reformer](../03_reading/FIELD_ADDENDUM/arxiv_2001.04451v2.md)保留序列位置，改变连接和执行。Sparse Transformer的enwik8 Table 2报告：稠密/固定稀疏/跨步稀疏BPB（每字节比特数）为1.00/0.99/1.13，Time/Iter为1.31/0.55/0.35；表头没有时间单位。更快的跨步方案质量更差，这项负面结果很重要：减少交互没有保住语言质量。Reformer分别处理近似注意力、随深度增长的训练激活和前馈中间量；执行分块不是学习到的文本片段。

[ACT](../03_reading/FIELD_ADDENDUM/arxiv_1603.08983v6.md)增加另一维度：在每个字节**内部**重复循环转移。Wikipedia结果是训练集误差，使用与不使用ACT相当接近；标点和XML轨迹可以启发“计算投入与不确定性”的问题，但未建立留出集字节收益。应把[BIP-0287–0289](../02_inventory/DETAILED_INVENTORY.md#BIP-0287)与[BIP-0054](../02_inventory/DETAILED_INVENTORY.md#BIP-0054)配对，而不是把ACT当成早期边界检测器。

最后，[scratchpad patching（暂存区分块）](../03_reading/R05/BIW-0076.md) §3改变刷新频率，而不改变已提交分块数。它聚合已观察的部分块，调用主干并覆盖临时缓存项。因此，持久缓存、临时工作区和总计算须分别记账。这条路线为长篇报告提供的是压缩的替代方案，不只是压缩变体。

<a id="route-d-what-makes-a-grouped-predictor-causal-and-a-multi-byte-decoder-coherent"></a>
### 路线D：怎样保证分组预测器的因果性与多字节解码器的一致性？

把[C05](../02_inventory/TAXONOMY.md#C05)、[C06](../02_inventory/TAXONOMY.md#C06)和[C11](../02_inventory/TAXONOMY.md#C11)连起来读。除注意力掩码外，还要追踪卷积、池化、残差、恢复和预处理。

[MEGABYTE](../03_reading/R03/BIW-0008.md) §2.2/Eqs.2–6把全局输入移一块、局部输入移一字节。小型局部Transformer提供具有依赖关系的自回归块联合分布。教师强制下的并行评分不等于独立并行生成。[Hourglass，BIP-0103/0104](../02_inventory/DETAILED_INVENTORY.md#BIP-0103)在缩短之前还需要额外移位k−1。没有细分辨率Transformer层时，缩短分支缺少当前组历史，但直接的移位输入残差仍携带紧邻的前一个符号。Appendix A.1的复制限制有特定适用范围；笼统声称组内独立是错误的。

[Patching Leaks](../03_reading/R03/BIW-0074.md)把机制与失败配对得尤其清楚。在其100符号独立随机诊断中，机会水平为1%；朴素分组解码器通过访问未来，几乎完美地预测块前部位置。只去掉卷积前视，仍有n-gram重叠泄漏。更大填充可以去除泄漏，却可能使翻译失败：德→英、缩短因子2时，填充臂BLEU仅0.04，去重叠臂为25.49（Table 2）。正确信息流与有用预测跨度是两个要求。

输出方面，应比较局部自回归、独立未来分类器、规范化电路草稿、扩散和验证器解码。[MtPC](../03_reading/R05/BIW-0079.md) §3/Appendix B提供规范化、具有依赖的草稿；训练采用重叠窗口复合似然。其优化缓存Algorithm 2的**随机目标分布保持性尚未验证**：所述状态复用没有清楚区分全部接受后从目标分布抽取的额外词元样本与拒绝后的残差修正样本。普通Algorithm 3的拒绝恒等式不能证明这个封装。[当前规则](../05_review/CLAIM_RULES.md#3-mtpc-exact-source-level-qualification-not-a-software-verdict)是对来源文字的限定，不是复现出来的软件缺陷。

<a id="route-e-how-can-an-existing-model-be-reused-across-interfaces"></a>
### 路线E：怎样跨接口复用已有模型？

把[C09](../02_inventory/TAXONOMY.md#C09)与[C07](../02_inventory/TAXONOMY.md#C07)、[C08](../02_inventory/TAXONOMY.md#C08)一起读。区分静态向量模仿、上下文对齐、词元logit蒸馏、字节概率转换、任务训练和真正的字节输出转换。

[Char2Subword](../03_reading/R06/BIW-0122.md) §§2–3拟合方向、大小、邻域与词表身份，再通过冻结的上下文主体训练。[Bolmo](../03_reading/R06/BIW-0097.md) §3.2.1对齐的是四层冻结主体之后的表示，而不只是其输入。参数冻结仍需反向计算，以把梯度传入新接口。Bolmo保留子词后缀输入查表，学习字节加边界输出，因此不是纯字节参数化。只做第二阶段的对照并未灾难性失败：第一阶段有帮助，尤其在1B时，但增加全局计算后差距缩小（§6.2/Fig.6）。这比宣称对齐普遍必需更有信息量。

[BIW-0098](../03_reading/R06/BIW-0098.md)区分中间的字节输入/词元输出阶段与最终字节解码。[BIW-0099](../03_reading/R06/BIW-0099.md)用公共字节监督空间进行跨分词器蒸馏；公共字母表不会自动保留指令遵循。[Zero-Shot Tokenizer Transfer](../03_reading/R06/BIW-0126.md)通过超网络跨分词器预测嵌入，而不是把生成改成原始字节链。

共享必须注明轴。MEGABYTE规定局部字节输入/输出绑权；LCA规定预测头之间共享投影；Reformer规定Q/K投影共享；ELMo规定方向之间表示共享、方向之间softmax共享。[共享登记表](../02_inventory/TAXONOMY.md#version--and-axis-specific-sharing-register-current)保留证据层级。BLT或H-Net未知的输入/输出共享仍是未知；架构血缘不等于张量别名检查。

<a id="route-f-does-finer-access-improve-real-language-behavior"></a>
### 路线F：更细粒度的访问是否改善真实语言行为？

在提出鲁棒性、公平性或字符能力论断之前，先读[C10](../02_inventory/TAXONOMY.md#C10)。分开讨论可表示性、已学信息、任务中可用的访问和生成正确性。

[SpellingBee](../03_reading/R10/BIW-0110.md) §2/Table 1训练一个解码冻结词元嵌入的外部解码器。可恢复拼写反驳了“无透明语义的ID完全没有拼写信息”这种简单说法，却不等于主体的自然拼写能力。另一个拼写初始化实验在报告的运行中，1,000次更新后掩码语言模型损失差异小于0.01（§5/Fig.2）。这是有范围的零效应干预，不证明拼写永远无益。应配合[Strawberry](../03_reading/R10/BIW-0113.md)与[CharBench](../03_reading/R07/BIW-0114.md)阅读；后两者分别涉及任务监督的字符访问，以及计数与定位，问题不同。

噪声证据也必须说明实际过程。[Synthetic and Natural Noise](../03_reading/R07/BIW-0109.md) Tables 6–7对比顺序不变均值、字符CNN与混合噪声训练。不变性保护模型免受乱序，却丢失区分能力和干净文本质量；混合训练扩大覆盖，但达不到每个专门模型的表现。其“自然”噪声来自编辑词典重建，不是自然带噪的平行测试语料。这些字符/词实验是先驱证据，不是原生字节鲁棒性测量。

多语言工作须分开语言采样、编码长度、任务标签和适配权限。MYTE当前[BIP-0221](../02_inventory/DETAILED_INVENTORY.md#BIP-0221)必须采用Appendix Table 8的低资源/总体均值：MyT5为21.1/21.8，ByT5为21.9/23.1，均有利于ByT5；而正文Table 4的低资源20.4对20.1有利于MyT5。评价集合/聚合方式的关系尚未解决，不能制造统一排名。其英语字节分母使用平行英语的UTF-8长度，而不是每个目标语言的字节；其形态派生编码也不是原始UTF-8。

<a id="5-three-comparison-habits-that-prevent-false-synthesis"></a>
## 5. 防止错误综合的三项比较习惯

<a id="51-name-the-probability-event-before-its-denominator"></a>
### 5.1 先说明概率事件，再说明分母

对相匹配的被评分事件，把nat转换为每原始字节比特数：

`score = summed_negative_log_probability_nats / (matching_original_bytes × ln 2)`。

即：分数等于以nat计的负对数概率总和，除以对应原始字节数与ln 2的乘积。如果只有平均交叉熵，须乘以实际计入评分的标签数，按损失定义排除忽略/填充标签。应注明提示、终止事件、规范化以及重复或重叠评分。换分母不会边缘化其他词元路径，也不会把辅助目标变成规范化联合分布。

区分五个对象：原生字节链、按字节归一化的规范词元路径、对分词求和的完整字符串概率、原始字节前缀覆盖事件，以及带标记的字节加边界过程。规范路径的字节归一化，在清楚标注时可以有用且合法。[BIW-0080](../03_reading/R04/BIW-0080.md)研究完整文本边缘化；[Exact Byte Probabilities](../03_reading/R04/BIW-0088.md) §4/Appendix A研究相容前缀覆盖。后者的规范路径支持集假设重要：压掉非规范softmax概率质量，会改变原来的神经分布。几乎必然终止也强于每个有限前缀处EOS概率为正。

TokSuite v2 C.2印出的CE/log₂|V|不是通用BPB转换。实际的运行→日志→Figure 6变换仍未知。不能用Figure 6认证跨分词器BPB相等或训练同样充分，但应保留另有支持的选项排序与四分词器文本流对照；见[BIP-0286](../02_inventory/DETAILED_INVENTORY.md#BIP-0286)与[CLAIM_RULES §4](../05_review/CLAIM_RULES.md#4-toksuite-exclude-an-unverified-figure-inference-not-the-whole-study)。

<a id="52-match-a-vector-of-resources-not-the-word-budget"></a>
### 5.2 匹配一组资源，而不只是说“预算”

记录原始/唯一/重复/实际保留文本，原始文本上下文，模型位置，总参数与主干参数，仅训练模块，训练FLOPs，教师/预处理成本，以及推理设备、精度、批量、预填充、输出大小、缓存和质量。等步数、等位置、等文本、等参数、等FLOPs回答的是不同问题。

MEGABYTE Table 6生成8,192字节耗时从132秒降至93秒，约减少29.5%时间，或速率约1.42×；模型大小与上下文不同，该比较没有说明计时设备/批量/缓存。其Table 8引用的最佳PG19分数用了基本评分工作量的四倍。MANTa的2.61对9.06秒是16张V100上的训练步比较，不是生成延迟。ByT5 Table 10的任务之一是**XNLI**，不是NER；长输入、个位数长度输出的任务仍可能很慢。这些条件界定结果告诉了我们什么，不是在取消发现。

MtPC具体展示了代理指标与成本的区别。其L40S、批量1、排除预填充的EvaByte采样比较中，因子分解/rank-32/rank-128草稿的接受量为5.19/5.88/6.02，吞吐为176.3/191.0/182.3字节/s（Table 1）。接受更多不一定更快。抑制EOS、大型电路头和转换成本界定了该测量。因此跨论文表应比较报告的前沿与机制，而不是用看似通用的速度数字给所有系统排序。

<a id="53-keep-a-findings-type-attached"></a>
### 5.3 让发现始终带着自己的类型

边界富集诊断、随机序列泄漏测试、受控消融、外部探针、统计相关、条件定理和软件复现，建立的是不同事实。实证负面结果须保留实际条件：DTP中英语空白规则可匹敌学习式路线而芬兰语不同；无泄漏填充翻译失败；MANTa无瓶颈退化；更大草稿秩使生成变慢；语言或主体特定的迁移反转。不能把未测结果变成失败。

同一纪律也解释了看似重复的记录。[BIP-0274/0275](../02_inventory/DETAILED_INVENTORY.md#BIP-0274)定义并修正前缀事件错配；[BIP-0111/0182/0278](../02_inventory/DETAILED_INVENTORY.md#BIP-0111)发展相容转换、增量成本与集成。它们是相连的子问题，不是“分词偏差”的五次独立确认。同理，[BIP-0284/0285/0294](../02_inventory/DETAILED_INVENTORY.md#BIP-0284)是共享规定，[BIP-0286](../02_inventory/DETAILED_INVENTORY.md#BIP-0286)是审查例外，不是四个已由作者解决的科学问题。

<a id="54-build-small-comparison-packets-rather-than-a-universal-leaderboard"></a>
### 5.4 组织小型比较单元，而不是通用排行榜

比较单元由上位问题、两三个承载来源、机制差异、最强相关对照和仍未解决的结果组成。它比一张各行列含义悄然变化的长表更利于综述整合。以下三个单元展示如何从清单组织比较。

**历史复用与重新计算。** 先读[Transformer-XL，BIW-0119/BIP-0238](../03_reading/R09/BIW-0119.md)正式版§§3.1–3.3与Table 9，再连接[BIP-0099](../02_inventory/DETAILED_INVENTORY.md#BIP-0099)及Sparse Transformer/Reformer路线。Transformer-XL拼接停止梯度的前段状态与当前状态，用相对位置避免位置重置歧义。隐藏状态持久不意味着权重随之更新；其记忆是存储序列，不是固定大小循环向量。注意力长度3,800时报告的1,874×评价比较，基线是从头重算整个窗口，不是现代匹配缓存的批量服务。贡献是有原则的复用机制；醒目比值描述的是选定基线。然后分别问：稀疏是否减少连接，可逆性是否减少训练激活，切分是否减少主干位置？这些是保留不同状态的节省方式，不是同一记忆量的三种测量。

**词汇发现与有用计算边界。** 将[Segmental Neural LM，BIW-0042/BIP-0149](../03_reading/R03/BIW-0042.md) §§2–4/Appendix F与DTP、H-Net配对。分段模型用动态规划对允许的字符切分求和，混合拼写生成与词汇记忆生成，并正则化预期片段长度。其最大后验（MAP）切分在看完整句后恢复；报告的边界评价使用训练/验证/测试的并集。DTP延后提供完整片段摘要，以便因果预测；H-Net选择上下文状态，减少昂贵更新。因此，较好的词汇F1、较低的下一字符损失和较好的质量/FLOP前沿，检验不同论断。共同兴趣是可变单位，差别则在潜在概率模型、部署决策时钟，以及显式监督或隐式效用标准。讨论结构发现时，应保留分段模型的封闭字符过滤与可选预训练图像特征条件。

**并行预测与精确生成。** 将MEGABYTE §2.4与[Blockwise Parallel Decoding，BIW-0082](../03_reading/R05/BIW-0082.md) §§2–4，以及推测采样原作[BIW-0083](../03_reading/R04/BIW-0083.md)、[BIW-0084](../03_reading/R04/BIW-0084.md)配对。局部自回归提供依赖块联合分布，却仍有串行局部决策。独立提议头可并行评价，并按最长贪心一致前缀接受；这保留指定验证器下某条贪心轨迹，不是任意采样。保持随机分布则需要实际提议/目标分布的接受率和拒绝残差修正。置信度或top-k放宽会改变策略。这个单元应分别报告接受量与实测吞吐，并说明保留的目标是原始主干、新训练的自回归路径，还是外部验证器。不能把它们都宣传成同一种精确加速。

组织更多单元时，应沿来源版本链，而不是悄悄混合修订。Transformer-XL正式主文与另行标明的arXiv-v3附录仍是一项工作，但须保留版本边界。GPT-2官方报告未固定修订。论文层面的共享属于指定公式，可变配置属于检查过的模型/移植版。这些区别使比较可复用：整合者能更新某条依赖工件的结论，而不必重写概念叙述或增加文献数。

<a id="6-from-inventory-to-a-long-report"></a>
## 6. 从清单到长篇报告

一种有用的报告顺序是：**单位与历史→词汇组合→全分辨率和状态式替代方案→分组及其学习信号→因果可用性→输出分布与解码→共享/优化→预训练适配→多语言性/鲁棒性/能力→资源与评价方法→开放问题**。这样各章可继承明确条件，而不必反复定义“字节模型”。概率记账应放在第一次似然比较附近，并在解码部分讨论其算法后果；预算条件应紧邻各结果，不应孤立到附录。

章内围绕一个上位问题组织小型比较，解释各技术的贡献，给出最强相关对照与负面结果，再指出剩余限制。例如，组合章可比较highway门控CNN特征、选定的上下文状态和交叉注意力池化，而不拿无关基准数字排名。计算章应把ACT、稀疏注意力放在层级方法旁，因为它们改变不同资源。适配章应先比较静态与上下文匹配，再讨论蒸馏字节目标。

最后的空白讨论应区分证据稀薄与已证实失败。目前证据较薄的方向包括通用混合书写系统因果路由、未见书写系统生成、保留字素的长串精确复制、非ASCII数值能力，以及在匹配质量下同时测量首个完整Unicode标量与尾延迟的批量服务。经典上下文混合/压缩历史是选择性覆盖。ACT报告的Wikipedia实验缺少留出集字节证据；Reformer最大运行缺少同样大的全注意力对照。这些是选定综述的具体边界，不是为了增加数量而重启发现工作的理由。

不必依赖某个本地架构或偏好的多粒度机制，才能把领域讲清楚。反复出现的问题是覆盖、有用表示、合法信息流、计算分配、可学习性、一致输出和可信评价。即使整合者希望加入本地项目启示，也应放在独立领域叙述之后。
