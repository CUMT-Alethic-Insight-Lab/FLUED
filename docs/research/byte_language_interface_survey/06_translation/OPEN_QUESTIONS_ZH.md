# 开放问题：已有证据与尚需怎样核销

## 1. 目的与证据类别

本议程配套 [SURVEY_ZH](SURVEY_ZH.md)，不是实施提案，也不是运行实验的授权。开放事项分三类：

- **研究比较：** 现有证据提出问题，但仍需受控或部署相关实验。
- **工件或规格核销：** 论文已经阅读，但指定算法分支、指标流水线、人群或预处理约定仍未知。再开大范围阅读批次或训练，不是默认恰当补救。
- **抽样薄弱的结果：** 语料含相关机制，却缺所需行为的直接评估。缺证据不是测得失败。

综述证据基础为 141 个实体、296 条可追溯记录、92 个不同的约定范围内 FULL 来源，另有两个有意窄范围历史摘读。这些计数不认证软件、独立效应或下述每项结果。稳定 BIW／BIP 标识符和来源版本不变；受影响主张遵循 [CLAIM_RULES](../05_review/CLAIM_RULES.md)。

## 2. 研究比较

<a id="oq01"></a>
### OQ-01. 廉价因果策略能否学习增量计算价值？

**已有认识。** BLT 用独立因果熵模型选块；SOMBRERO 学习已观察下一字节置信度目标；效用与新颖性研究用损失布局或未来重复信号。更早的 ACT 分配字节内计算，说明投入轨迹不必跟随即时不确定性。SOMBRERO 受控阶梯把多数收益归于平滑；效用策略改善选定强制前缀目标，却没有相当的自由生成成功（[综述 §§5–6](SURVEY_ZH.md#s06)；[BIP-0054](../02_inventory/DETAILED_INVENTORY.md#BIP-0054)、[0156–0157](../02_inventory/DETAILED_INVENTORY.md#BIP-0156)、[0162–0163](../02_inventory/DETAILED_INVENTORY.md#BIP-0162)、[0289](../02_inventory/DETAILED_INVENTORY.md#BIP-0289)）。

**尚未建立。** 这一选定语料没有建立一种通用、廉价、只看前缀的策略，能跨任务、语言和领域估计额外昂贵更新的边际收益。整个布局损失差不是干净的单边界效应，置信度富集也不是任务效用。

**所需实验。** 在实际速率、局部／主干容量、保留文本和调参预算匹配下，比较规则、自身／独立模型不确定性、已观察目标训练监督及直接价值标签。可行时使用单次新增更新干预，依据留出任务效用而非仅边界富集。分开测试强制前缀中间结果与自由生成；向新域迁移策略时，不默默改变训练边界分布。

**判定证据。** 价值策略应在完整成本匹配下提高留出质量，或在预声明质量下降低实测成本，且无不稳定速率或最差群体退化。某域失败会界定该策略，而非证明效用学习不可能。

<a id="oq02"></a>
### OQ-02. 收益来自边界、聚合还是上下文容量？

**已有认识。** DTP 平均完整字符跨度；H-Net 选择上下文状态；BLT 用注意力聚合；MEGABYTE 拼接固定块。H-Net XL 两阶段系统在 0.69 GFLOPs/byte 下把报告平均准确率从 BPE 的 55.5% 提至 58.2%，强空格对照为 57.1%／0.70，且参数不等。这一积极系统结果未隔离布局、聚合或容量（[综述 §6.4](SURVEY_ZH.md#s06)）。DTP 均值／端点比较与 H-Net 替代聚合器比较处于不同编码器／预算。MANTa 需容量瓶颈，才能避免接近逐字节速率分组（[BIP-0010](../02_inventory/DETAILED_INVENTORY.md#BIP-0010)、[0026](../02_inventory/DETAILED_INVENTORY.md#BIP-0026)、[0152–0154](../02_inventory/DETAILED_INVENTORY.md#BIP-0152)）。

**所需实验。** 在共享主干中，把固定／规则／学习布局与均值、上下文端点、拼接／投影、注意力算子交叉组合。匹配实际长度分布，不只目标平均速率；明确局部感受野与表示宽度。对重复拼写、精确标识符和组边位置进行边界变化测试。

**判定证据。** 边界质量效应需在同算子、同速率下保留布局优势；聚合效应需在同布局下仍有收益。精确重构或复制须独立于下一字节损失测量。这样可解释现有兼容发现，而不强行排出普遍池化排名。

<a id="oq03"></a>
### OQ-03. 位置、边、状态与深度之间怎样分配最好？

**已有认识。** 全分辨率稠密模型、稀疏注意力、Reformer、选择性循环、固定潜在阵列、分组及 ACT 改不同资源。Sparse Transformer 跨步模式按迭代量更便宜，却 BPB 更差；ACT 字节结果仅训练集且近持平；可逆激活应对训练内存，不是推理 KV（[综述 §5](SURVEY_ZH.md#s05)）。

**所需实验。** 建立互补的等保留文本与等完整计算比较，各家族在相同搜索预算内调参。分别变化存储状态、注意力连接、昂贵更新频率和位置内深度；测训练内存、原文上下文、任务质量和服务，不从渐近复杂度推断全部。

**判定证据。** 质量、训练时间／内存及匹配负载服务的帕累托前沿可确立适用区间，不能用单一标量压缩全部资源。ACT 自适应深度路线若要被记为现代字节质量收益，需先补留出字节证据。

<a id="oq04"></a>
### OQ-04. 临时刷新何时值得为新鲜度付费？

**已有认识。** Scratchpad Patching 刷新已观察的未完成块，不增加永久状态。p=16 时 NLU 从 48.0→54.2，验证 FLOP 节省倍数却由 5.7×→2.9×；部分分块器或密集刷新条件退步（[BIW-0076](../03_reading/R05/BIW-0076.md)，v1 §§3–5／Appendix E；[BIP-0105–0107](../02_inventory/DETAILED_INVENTORY.md#BIP-0105)）。

**所需实验。** 保持相同已提交布局，在匹配训练／推理成本下比较固定刷新日程和学习／熵触发。包含部分提示、不同输出长度、批量请求到达及缓存压力；既记录持久 KV，也记录临时工作区和触发模型工作。

**判定证据。** 计入调度开销后，新鲜度应改善质量匹配请求成本或指定延迟目标。持久状态更小本身不够。如果预先声明，某触发器即便不改善平均似然，只帮助长精确依赖，也仍可能有用。

<a id="oq05"></a>
### OQ-05. 依赖草稿能否足够便宜而有用？

**已有认识。** 局部 AR 保留块依赖，但局部采样串行；独立头便宜，却可能组合不兼容备选。MtPC 引入归一化电路依赖，但头大小和高秩采样会反转按接受量作的预期；LCA 也在一项条件中随候选增多而降吞吐（[综述 §8](SURVEY_ZH.md#s08)）。

**所需实验。** 固定目标模型和实际缓存实现，扫描头结构、秩、候选长度、共享／私有层及批量。区分贪心匹配、精确随机校正与近似置信策略。包含 EOS 和预填充，不只固定长度续写。

**判定证据。** 在目标律匹配或明确任务质量匹配下，比较请求级速度和驻留内存峰值。接受字节／周期须连同起草、验证、拒绝和缓存成本报告。在把 MtPC 优化随机分支标为精确前，须解决下文的封装概率律问题。

<a id="oq06"></a>
### OQ-06. 哪些共享与读出选择有益于小字母表？

**已有认识。** 大词表词／子词绑定提供背景，不是字节特定判词。字节文献在不同维度有绑定和不绑定规格。独热字节 NMT 揭示 dropout 交互；行归一化、余弦尺度及维度秩论证含义不同（[综述 §10](SURVEY_ZH.md#s10)；[BIP-0139](../02_inventory/DETAILED_INVENTORY.md#BIP-0139)、[0184–0199](../02_inventory/DETAILED_INVENTORY.md#BIP-0184)）。

**所需实验。** 在同一字节模型中，在上下文容量匹配及完整参数口径下，比较绑定、不绑定及变换读出，分别调学习率／尺度。匹配词元抹除语义，不只 dropout 概率。多次独立运行测路径特定梯度范数、校准、严格似然和下游行为。

**判定证据。** 收益须经得住调参与语义控制，并指明实际矩阵维度。存储主张依赖共享时，应核验静态规格是否对应训练后别名。归一化头代数提供实验动机，不能替代实验。

<a id="oq07"></a>
### OQ-07. 检查点转换必须保留什么，要付多少适配成本？

**已有认识。** Char2Subword 区分静态模仿与冻结宿主上下文训练。Bolmo 在四层后对齐，某阶段有帮助但去掉不灾难性；另一词元到字节配方却有严重直接蒸馏负对照。跨分词器字节监督可能损失指令行为；中间词元输出阶段不是完整字节转换（[综述 §11](SURVEY_ZH.md#s11)）。

**所需实验。** 同宿主内交叉静态／上下文／logit 对齐与冻结日程，把原预训练保留为继承资源。分视图匹配转换字节和全局工作。每次实际接口转变后都评估原通用任务、指令遵循、新表面任务及输出合法性，不只最终均值。

**判定证据。** 成功转换应以较低总适配成本保留预声明行为集，或在无不可接受损失下增加能力。向量距离下降或主干参数对应不足以成立。宿主特定负面结果有信息，但不能据此制定普遍分阶段规则。

## 3. 抽样薄弱的用户侧结果

<a id="oq08"></a>
### OQ-08. 混合文字路由能否真正保持在线？

**已有证据。** MAGNET 改各文字速率，但假设整序列一种文字。字符感知语码混合理解和广多语言字节任务，不确立只看前缀的混合文字生成。MYTE 压缩英语，却不压缩未见文字。

**所需评估。** 使用自然混合文字及受控插入，明确区分分词器归纳未见文字与模型训练未见文字。测停在 UTF-8 标量内部的前缀、快速文字切换、外来姓名、数字和标点。把每个预处理特征追溯到观察前缀，并在保留上下文匹配下比较最差群质量。

**核销标准。** 固定工件的流式论证，加直接生成任务证据和实测速率／成本分布。单文字选择器未测混合文字，不证明所有字节路由失败（[综述 §12](SURVEY_ZH.md#s12)）。

<a id="oq09"></a>
### OQ-09. 覆盖与局部损失能否转化为精确多语言字符串？

**已有证据。** 字节回退可消除未知符号，却不保证避免翻译崩溃。UTF-8 部分进展可远高于严格合法性。有限状态计数界针对均匀随机字符串完整摄入后才开始的确定性复制，且此后输出的全部输入相关影响都在计入的保留状态中。它排除源重读、未计外部缓存、摄入时已写出的输出及状态外任何旁路。自然语言冗余改变源分布，在线回显改变协议。注意力图和探针解码不是生成长复制测量。

**所需评估。** 生成长自然多语言跨度及随机对照，设置源替换／移除、读前／读后查询、干扰和边界偏移。声明回答是否摄入后才开始，计入每条保留源／缓存或输出通道；允许重读或外部访问的分支需自行列存储、访问和遍数预算，不能继承状态唯一通路上界。分别评分精确原字节、完整合法性、预期标量及额外由任务允许的规范／字素等价。记录修复前原输出，单列未完成终止。

**核销标准。** 以原文距离和持久状态成本为横轴的整串成功曲线，含清晰地板和多个种子。这样直接检验保真，不预设重读或外存为首选补救（[BIP-0063–0065](../02_inventory/DETAILED_INVENTORY.md#BIP-0063)、[0235](../02_inventory/DETAILED_INVENTORY.md#BIP-0235)）。

<a id="oq10"></a>
### OQ-10. 更细访问能否改善字符算法与数值能力？

**已有证据。** SpellingBee 显示可恢复信息及限定的初始化空结果；Strawberry 加快监督学习却未证明掌握；CharBench 区分计数和位置。非 ASCII 算术覆盖薄弱。

**所需评估。** 分解表示访问、显式字符训练、一般 LM 训练和输出字母表，加入相同任务且增强匹配的子词基线。区分转录与算术，变化进位链长和分组方向，加入非 ASCII 数字、地区分隔符、组合序列及明确索引单位。公布机会／多数类地板与解析失败。

**核销标准。** 匹配预算下生成任务准确率提高，不只是探针可读或更早越过极低起效阈值。报告收益能否迁移自然指令和未见形式（[综述 §12.7](SURVEY_ZH.md#s12)）。

<a id="oq11"></a>
### OQ-11. 批量字节服务下用户实际体验怎样？

**已有证据。** 现有研究混合训练步时间、FLOP 估计、定长 batch-one 续写、无缓存验证和权重流量代理。现代质量匹配并发、首个完整标量及尾延迟证据有限。

**所需评估。** 固定硬件／精度和任务质量，用多个批量／并发设置重放提示／输出分布。包含预处理、全部驻留教师／草稿器／验证器、预填充、EOS、部分提示、Unicode 缓冲、拒绝及修复。测请求 p50／p95 或其他预声明尾分位、首字节、首个完整标量、稳定显示单位、总吞吐及驻留内存峰值。

**核销标准。** 是实际负载的端到端前沿，不是接受字节或理论更新次数。区分吞吐优化和交互延迟；一项可改善而另一项恶化（[综述 §13](SURVEY_ZH.md#s13)）。

## 4. 工件与规格核销：不意味着新训练

<a id="oq12"></a>
### OQ-12. MtPC 优化随机封装是否保留指定目标概率律？

**已有支持。** V2 电路归一化，Algorithm 3 规定普通残差校正，报告吞吐是其设备／批量／预填充／EOS 条件下的实测观察。

**仍未解决。** Algorithm 2 部分接受分支未清楚区分可选全部接受奖励与拒绝后所需校正，也未规定保留残差状态。

**有限前缀诊断。** 设首个提议为确定性且被接受，下一位置 p=(.5,.5)、q=(.9,.1)。被接受的概率质量为 min(p,q)=(.5,.1)，拒绝概率 .4。正确残差校正贡献 (0,.4)，恢复 (.5,.5)。若丢掉校正、重启普通目标律周期，则贡献 .4p=(.2,.2)，得到 (.7,.3)。这是分析者针对指定“丢弃后普通重启”解释的反例，不是执行发布代码。保留残差状态或其他等价校正协议可避免它；仅保留已接受前缀隐藏状态并未规定该协议。

**核销证据。** 不可变代码及论文运行关联；零／部分／全部接受分支；输出与保留概率／缓存状态；实际变换后的 p／q；有限前缀概率论证。此前应说“优化随机精确性未验证”，而不是软件坏了。这一保证未核实，并不使已报告的计时结果失效（[CLAIM_RULES §3](../05_review/CLAIM_RULES.md#3-mtpc-exact-source-level-qualification-not-a-software-verdict)）。

<a id="oq13"></a>
### OQ-13. 什么计算产生了 TokSuite Figure 6？

**已有支持。** V2 C.2 印出 CE/log₂|V|，不是每原文字节比特数的一般转换。另行检查的训练器文件记录词元 CE，但不揭示全部绘图变换。

**仍未解决。** 实际运行→日志→绘图计算及出处。说明文字错误不证明图执行该公式，审查者提供正确公式也不修复原图。

**核销证据。** 不可变绘图／评估代码；原始字段／对数底；有效评分标签及匹配原字节总数；EOS／PAD／提示／重叠处理；语言／样本加权与平滑；运行到图的映射。此前不用 Figure 6 认证相等或训练充分。独立选项排序、四分词器文本对照及仅 Gemma 的精确字节附加评估，保留各自状态（[CLAIM_RULES §4](../05_review/CLAIM_RULES.md#4-toksuite-exclude-an-unverified-figure-inference-not-the-whole-study)）。

<a id="oq14"></a>
### OQ-14. MYTE 报告的评估语言集合与聚合结果之间是什么关系？

**已解决。** Table 8 列序是低资源在前、总体在后：MyT5 21.1／21.8，ByT5 21.9／23.1。抄录更正不需新增全文阅读。主 Table 4 的低资源摘要另给 MyT5 20.4、ByT5 20.1。

**仍未解决。** 运行／评估语言集合／聚合口径的关联，包括 C.2 十四名称与十五列、马耳他语／绍纳语与马拉地语命名之差。平行英语字节归一化仍不同于目标字节 BPB。

**核销证据。** 各表明确评估语言列表和运行 ID、原始逐语言指标、聚合权重及明确评分／对数／归一化约定。不要平均两表或挑喜欢的符号。第一补救是作者／工件说明，不是新模型训练（[CLAIM_RULES §5](../05_review/CLAIM_RULES.md#5-myte-explicitly-anchor-both-model-row-and-aggregate-column)）。

<a id="oq15"></a>
### OQ-15. 实际边界与预处理特征是否前缀稳定？

**已有支持。** 因果掩码不认证上游预处理。一般 BPE 例反驳普遍前缀稳定，但未因此测得实际 Llama 引导、右移 BPE 对照和 AU-Net 正则泄漏。

**核销证据。** 指明不可变分词器／正则及精确特征构造，包括特殊符号与输入结束行为。可行时给前缀论证或穷尽有限规则推理，配实际合并／正则边界的对抗扩展测试。注明任何延迟决策或允许缓冲。若实证因果主张依赖运行轨迹，须把轨迹关联到所称实验。

**结论边界。** 仅训练的未来标签可以合理教前缀策略；实际留出完整字符串侧信息是另一权限。缺证明不是软件判词，玩具反例不是泄漏率估计（[综述 §7](SURVEY_ZH.md#s07)）。

## 5. 优先级与停止规则

| 优先类别 | 首要动作 | 完成标准 | 不应做什么 |
|---|---|---|---|
| 标题主张所需既有保证 | 用指定工件／规格解决 OQ-12–15 | 受影响的精确分支／事件／人群有记录 | 重启广泛发现，或由 FULL 标签推断运行 |
| 机制归因 | 在实际控制匹配下开展 OQ-01–07 | 提出原因经得住最强替代解释 | 把无关文献均值当同一个实验 |
| 缺用户侧结果 | 为 OQ-08–11 做直接生成／服务测试 | 测得预声明结果及资源前沿 | 把缺证据称作已证失败 |
| 扩展覆盖 | 仅为缺机制或决定性对照加来源 | 身份、范围和新证据角色明确 | 把增论文数当目的 |

现有选定语料已足以支撑长篇综述，不必等全部未知消失才交付。整篇原文阅读、实现核验、统计识别与实验复现是不同任务。未报告字段可以仍未报告，理论假设可以保持条件式，历史窄摘读可以保持窄。研究价值在于，为实际问题选择最小而决定性的证据。
