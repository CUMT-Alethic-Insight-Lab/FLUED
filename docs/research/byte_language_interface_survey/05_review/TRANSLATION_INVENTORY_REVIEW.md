## 3. 需处理的问题与最小修订

级别定义：P0为整片缺译、来源/记录错置等阻断交付；P1为会改变接口单位、因果许可或技术含义的局部实质问题；P2为上下文已能消歧、但应改正的术语/可读性问题。以下是**3个问题组**，不是按每个重复位置另计一条。

### P1-01：若干 token 被压缩成“词”，包括当前可见范围和监督目标

**影响：** token/word不能在本调查中互换。最明显的是BIP-0233：已消费的当前**词元**可以只是一个词的前半部分，“整个已消费当前词”容易被读成允许看完整个词，扩大实际可见范围。BIP-0276/0277的目标实际为下一子词词元，不是下一完整词。邻近字段多处正确写“词元/子词”，说明是局部用词漂移，而非整条机制未译；但不宜以邻句正确为理由保留因果/监督字段中的歧义。

| 位置 | 英文 → 中文的具体差异 | 来源与最小修订 |
|---|---|---|
| I-EN:10409 ↔ I-ZH:9655（BIP-0233） | `entire current consumed token ... future-token characters` → “整个已消费当前词……未来词字符” | [R10/BIW-0113:7、13](../03_reading/R10/BIW-0113.md)：当前已消费词元及历史词元可见，未来词元字符不可见。只将该句改为“整个已消费的当前词元及过去词元可见，未来词元的字符被掩码”；不改块内可见性或宣称已验证代码。 |
| I-EN:12470、12479、12514 ↔ I-ZH:11567、11576、11606（BIP-0276/0277） | `nexttokenCE` / `next-token prediction` → “下一词CE” / “下一词Transformer” | [R04/BIW-0133:10–11](../03_reading/R04/BIW-0133.md)明确内部/标签/输出为子词。改为“下一词元交叉熵”“下一词元预测Transformer”；保留统计断点回归、nat结果单位及局部辨识前提。 |
| I-EN:12388–12390、12423、12432–12434 ↔ I-ZH:11495–11497、11526、11534–11536（BIP-0274/0275） | token反例/前缀被写作“下一词”“编码词前缀”“最大词长”“词模型”，非规范token序列写成“词序” | [R04/BIW-0132](../03_reading/R04/BIW-0132.md)，§§2–3/Appendix H。相应改为“下一词元”“编码词元前缀”“最大词元长度”“词元模型”“非规范词元序列”。不改A/B/AA反例、规范支持假设或掩码再归一化会改变分布的条件。 |

这是一个跨5条记录的单位一致性问题。**不要全篇机械把“词”替成“词元”**：Character-Aware LM、ELMo及词级困惑度中的“词”确实是word，必须保留。

### P2-01：lemma 过滤译名易与 token 归并混淆

- **成对位置：** I-EN:10136、10139–10140 ↔ I-ZH:9393、9395–9396，BIP-0229。
- **原文/译文：** `similarity/lemma filtering`、`lemma controls` → “相似/词元归并过滤”“相似/词元过滤”。
- **核查来源：** [R10/BIW-0110:18](../03_reading/R10/BIW-0110.md)明确：相似性过滤去掉每个测试嵌入的20个最近训练向量，lemma过滤在此基础上再去除同词形还原项；不是BPE词元合并，也不是再次分词。
- **最小修订：** 三处统一为“相似性/词形还原（lemma）过滤”；若需要一句定义，用“后者在相似性过滤后再排除共享同一基本词形的训练项”。既有18.2/17.7等六个数值及顺序不改。
- **等级理由：** 留出、相关类型过滤及探针而非主体执行的核心限制已保留，数值未错；问题是译名不够明确，不据此宣称原控制被取消。

### P2-02：MtPC 的 bonus token 不宜称“目标奖励”

- **成对位置：** I-EN:7791、7838、7887 ↔ I-ZH:7275、7316、7359，BIP-0171–0173。
- **原文/译文：** `optional all-accepted target bonus` → “全接受可选目标奖励”。这里是全部接受后可以从目标分布多抽出的**词元样本**，不是强化学习奖励或奖励函数。
- **核查来源：** [CLAIM_RULES:63–69](CLAIM_RULES.md)，MtPC v2 Appendix F Algorithm 3在`s=n`的第30–31行给普通目标额外样本，在`s<n`的第25–29行给正残差修正样本。I-ZH:7277、7318、7361的R2后文已经正确说“额外样本”。
- **最小修订：** 三处仅把“全接受可选目标奖励”改为“全部接受后可选的目标分布额外词元样本”。保留拒绝后正残差是另一角色、优化Algorithm 2仍未验证、代数反例不是已执行缺陷的全部条件。
- **等级理由：** 同条R2与中文导读已经正确消歧，未误把未验证写成软件失败，故不升级为P1。
