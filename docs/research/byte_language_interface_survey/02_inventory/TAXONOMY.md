## What was actually done

This is **human-readable, evidence-informed manual thematic grouping (人工主题归组)**. The owner read PLAN, all eight WORKS/inventories/handoffs and the independent audit, resolved source identities, and explicitly assigned canonical records to one or more dimensions/clusters. A short local script only materialized the manually defined ID/merge/classification relations and checked structure. No embedding model, vector search, similarity threshold, statistical clustering algorithm, external service or training was used. Do not describe C01–C12 as discovered algorithmic clusters.

BIW（字节接口作品编号）identifies one source entity; BIP（字节接口问题编号）identifies a specific problem/mechanism/evidence object. C labels are analyst organizational tags, not author-coined methods, genealogy claims or quality grades. A record can have several tags; a work can address many records. Cluster membership counts overlap and must not be added to obtain total problems or papers.

## Orthogonal classification dimensions

| Dimension | Required labels / values | Interpretation and evidence rule |
|---|---|---|
| Source entity and scope | paper empirical/theoretical/methodology; proposal-only; standard; official introduction; language/hybrid/background/nonlanguage comparator | A title says neither exact unit nor peer-review status. A normative target is not a trained model result; ToMe/PCGrad/VAE/ICAE retain their adjacent scope. |
| Era and source version | first release; fixed arXiv vN; formal venue; mutable introduction/config; unverified relation | A revised title is not a new work; a conference association is not automatic text equivalence. Use the specific source in WORK_CATALOG. |
| Four unit axes | input; expensive/internal positions or state; output; supervision/corruption selection | Unicode code point is not UTF-8 byte or grapheme; byte-derived BPE remains subword. Word-local byte CNN can output closed word labels; byte alphabet can have word masking or subword teachers. |
| Coverage and reversibility | prescribed alphabet/UNK; hash coverage/collisions; all byte strings; legal scalar encoding; canonical/compatibility normalization; verified encoding fallback | Representability, semantic knowledge, exact input encode/decode, arbitrary generated-stream legality and user-perceived character identity are different assertions. |
| Assembly operator | local recurrent/CNN/highway; mean/max; concatenation; cross-attention; contextual end-state selection; deletion survivor; quantized code; fixed latent array | Boundary choice does not identify the stored content. Membership ancestry is not value inversion. Full-length fusion is not compressed sequence length. |
| Boundary/update policy | fixed stride; observed-byte rule; external tokenizer; latent posterior; own-model entropy; separate teacher entropy; observed-target confidence; loss utility; repetition; task surrogate; policy gradient | Distinguish deployed action from offline training label, probability entropy from observed surprise, and stochastic surrogate from unbiased score-function identity/practical biased variance reduction. |
| Objective and optimization | next-unit likelihood; span/word denoising; annotation/translation labels; composite future-window loss; reconstruction/length/codebook; geometry/logit distillation; rate/controller; auxiliary CE; KL/ELBO; staged freezing | A future-offset CE sum is not automatically a normalized text law. VAE collapse is about stochastic posteriors, not a label for every deterministic bypass. |
| Time-visible information | full source; corrupted source; causal original-byte prefix; canonical token prefix; completed past group; observed partial group; offline full-string side information; suffix-permitted FIM | Trace convolution, pooling, masks and restoration as well as attention. A causal prefix predictor does not imply legal offline boundary hints. Full-source NMT is not a streaming-source LM. |
| Output distribution and policy | byte chain; intra-block AR; product marginals; dependent circuit; block diffusion; greedy match; exact rejection/correction; top-k/threshold approximate; oracle simulation | Specify named verifier/model identity, sampled-prefix conditioning, EOS/partial prompts and any constrained/renormalized target. Equal task score is not distribution identity. |
| Experimental attribution | matched/changed text, rate, architecture, parameters, FLOPs, tuning; correlation/probe; quasi-experimental regression discontinuity; controlled intervention | Prefix causality, generation-law correctness and statistical causal identification are three different questions; none certifies the others. |
| Sharing/geometry | encoder-input/decoder-input; input/output; head/head; cross-depth; tied/untied/transformed; row norm/hidden norm/scalar or per-class scale | Register paper specification/config/code/runtime evidence level and exact model/port. An algebraic condition such as V≥d is not an experiment on bytes. |
| Teacher and adaptation permissions | none; external entropy/subword/aligner/morphology; type target; frozen host; endpoint unfreezing; full unfreezing; head-only; discarded auxiliary head | Pure-byte deployment is not teacher-free training. Frozen parameter count is not zero host backward work; inherited source checkpoint costs do not disappear. |
| Task and population | causal LM; translation; masked understanding; byte-offset annotation; class/retrieval; spelling/count/position; copy; codeFIM; simulation; script/language/domain/noise | Keep probe decodability, attention analysis, generated exact match, legal scalar, correct scalar and task answer separate. Pixel/audio bytes are not UTF-8 text. |
| Resource and result type | equal positions/text/retained text/context/total or trunk params/FLOPs/time/quality; measured versus estimated/simulated/forecast | Extract language bytes, model tokens and bytes of loaded weights separately. No common hardware/quality/batch frontier is claimed. Unknown teacher/runtime cost is not zero. |
| Reading and uncertainty | A abstract; P named selected passages; RF scoped reused FULL; N normative passages; O introduction; code/static config; runtime; reproduction | Reading depth is field/version scoped, not one universal paper-quality stamp. An old FULL card does not guarantee an unmentioned formula; source/implementation contradictions remain open. |
| Negative/control type | simple rule matches learned; equal-FLOP reversal; domain/language/host failure; all-byte-rate collapse; leakage; near-chance tasks; valid-but-wrong; cost reversal; forecast beyond data | Record exact experimental contract and result; absence of a study remains missing evidence, not a negative outcome. |

These dimensions are joined from the work catalog (identity/version/unit baseline), detailed record fields (specific signal/permission/evidence/cost), and the C-tag memberships below. There is no invented scalar “byte-model maturity score.” Remaining A/P claims keep their source-depth ceiling; completed-card fields now override them where supported, while unreported fields are not promised to be filled by more reading.

## Counterexamples that must not disappear in synthesis

- Multiplicative RNN beats a memoizer but loses to dictionary-disabled PAQ in its character setup; deep uncompressed character models are not inherently inferior to compression.
- Embedding-free byte NMT’s apparent benefit changes after token-dropout matching; word-input elimination does not eliminate fixed word output in Character-Aware LM or CharacterBERT.
- DTP whitespace can match learned routes in English while Finnish differs; H-Net one-stage does not always beat space, and its implementation can be slower despite FLOP savings.
- MANTa requires a bottleneck to avoid per-byte blocks. Causal GBST repairs can be leak-free and still fail to learn translation; simple causal attention masks are insufficient.
- W0356’s byte same-parameter advantage coexists with subword same-compute superiority on a 3:1 hybrid-attention backbone; Bolmo’s stage1 helps without being universally necessary; another conversion recipe can still need alignment.
- Novelty patching improves selected forced-prefix values while overall BPB/domain transfer worsens; SOMBRERO higher surprise enrichment does not guarantee better BPB/downstream averages.
- Byte fallback does not ensure legal/intended Unicode; lossy NFKC can reduce style perturbation without preserving original text; universal byte coverage is not language position parity.
- Local Byte Fusion’s Lao failure and training/inference reversal, W0355 host-specific negative transfer, multilingual tuning reversals and chance-level downstream tests remain conditional results, not votes in a universal model leaderboard.
