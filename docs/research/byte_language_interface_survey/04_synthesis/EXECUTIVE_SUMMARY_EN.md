# Executive summary: byte-language interfaces as a field

## 1. The main finding

The useful question is not simply whether language models should remove tokenizers. It is **which connection between written text, internal computation, learning signals, and generated output should be fixed, learned, or transferred**. Bytes can remove dependence on a learned input alphabet, but that choice does not determine the internal clock, output distribution, supervision, Unicode behavior, or resource frontier. The strongest literature explains these connections separately.

The accompanying [long survey](SURVEY_EN.md) covers 141 source entities: 137 research documents—136 academic papers/preprints and one technical report—plus three standards and one official introduction. It draws on 296 traceable mechanism/evidence records and 92 distinct scoped FULL sources, comprising 62 new and 30 reused readings, with two additional intentional narrow PARTIAL historical extractions. These are not 141 native-byte models or 296 independent experiments. FULL denotes scoped source reading, not reproduced results or verified software. Detailed accounting belongs to the [methodology appendix](SURVEY_EN.md#appendix-a).

The survey is field-centered, not organized around a local project or a multigranularity proposal. Its recurring result is **redistribution of work**. Removing a large lexical table can buy contextual capacity, but longer fine-grained sequences increase processing and output decisions. Grouping can reduce expensive updates while delaying fresh context or increasing local-decoder responsibility. Parallel drafts can reduce serial calls while adding head, sampling, verification, and cache costs. Universal coverage can coexist with unequal context, weak knowledge, or incorrect output.

## 2. Four interfaces prevent false comparisons

Every system should be described by **input / internal positions or state / output / supervision**. A character-composed word LM uses spelling features but predicts words. CANINE takes Unicode code points and uses bucketed or subword pretraining targets; it is not a UTF-8 next-byte generator. ByT5 reconstructs byte spans from a corrupted full source; its near-competitive CharT5 ablation instead combines common character entries with byte fallback and changed capacity allocation. GPT-2 begins from bytes but predicts merged BPE pieces. T-FREE uses rule-split units, trigram features, and candidate-selected outputs. A common low-level ingredient does not make these systems one generative family.

The text unit also matters. A byte, Unicode code point, scalar, grapheme cluster, and restricted historical character are different objects. A valid unfinished UTF-8 prefix is not a complete valid string; a legal scalar need not be the intended scalar. Normalized equivalence is not exact original-byte preservation. These distinctions change counting, offsets, editing, latency, and evaluation rather than merely terminology ([survey §2](SURVEY_EN.md#s02)).

## 3. History supplies several routes, not one ladder

Early multiplicative RNNs and LSTMs learned distributed state over character or observed-byte streams. Their contributions include symbol-conditioned transitions, recurrent optimization, persistent state beyond gradient horizons, and byte-based representation learning. Classical compression remained competitive: the 2011 multiplicative RNN lost to dictionary-disabled PAQ in its restricted-character comparisons. Dynamic evaluation later improved scores by updating weights at test time, a different permission from retaining hidden state.

Character CNN/highway models addressed another problem: sharing word-internal statistics while retaining word positions and closed outputs. Their highway ablation—78.9 PTB perplexity with two highway layers versus 84.6 without and 92.6 with an ordinary MLP—shows that composition and optimization matter together. ELMo added contextual layer mixtures at word positions. Byte-complete BPE supplied yet another compromise: broad encoding coverage with fewer model positions and a large merged output vocabulary. These historical routes contributed useful mechanisms without establishing native-byte superiority ([survey §3](SURVEY_EN.md#s03)).

## 4. Efficient bytes need not mean learned segmentation

Full-resolution causal models are essential counterexamples to a patch-only account. Deep byte attention achieved competitive likelihood, and a large plain byte Transformer reached approximately 23 word-normalized perplexity on processed lm1b. That benchmark already contains preprocessing and UNK replacements, and its expensive full-window evaluator is not efficient serving. The result nevertheless shows that learned compression is not an intrinsic prerequisite for competitive byte likelihood.

Other techniques reduce different resources while retaining positions. Sparse attention changes edges; Reformer separately changes approximate connectivity, training activation storage, and feed-forward execution. Transformer-XL reuses stopped-gradient segment states. MambaByte maintains fixed-size selective recurrent state. ACT allocates extra recurrent transitions within a byte, rather than fewer byte positions; its Wikipedia evidence is training-only and near-tied with the baseline. These methods should be compared by the resource changed, not grouped under a vague sequence-length saving ([survey §5](SURVEY_EN.md#s05)).

## 5. Grouping has three separate design decisions

A grouped system must specify **where updates occur, what content is retained, and what pressure limits computation**. Fixed concatenation, contextual endpoint selection, means, attention pooling, deletion survivors, and latent arrays retain different information. A boundary does not identify its aggregation operator or guarantee invertibility.

Learning signals differ too. Charformer mixes candidate widths before fixed reduction. MANTa approximates cumulative frontier membership and needs a block bottleneck to avoid one block per byte. DTP combines several character-pooling routes; H-Net uses contextual state selection, smoothing, surrogate gradients, and rate pressure. REINFORCE uses sampled decisions and practical variance reduction, including discounting that introduces bias. English whitespace can match learned routes while Finnish differs. BLT's separate entropy teacher, SOMBRERO's observed-target confidence, and utility/repetition-derived targets are not the same statistic.

Learned hierarchy also achieves direct quality gains: H-Net's XL two-stage model reports 58.2% average downstream accuracy versus BPE's 55.5% at 0.69 GFLOPs/byte, with a strong space-rule control at 57.1% and 0.70. Parameters differ, and the text-per-batch/FLOP matching is approximate; this is a useful system comparison rather than an isolated boundary effect or a wall-time win ([survey §6.4](SURVEY_EN.md#s06)).

The strongest findings retain controls. SOMBRERO's ladder attributes much improvement to smoothing before the new confidence target. Utility patching improves selected forced-prefix values without solving free math generation, and novelty patching can worsen overall likelihood or domain transfer. Computational value and uncertainty are distinct; a universally superior cheap causal policy remains open ([survey §6](SURVEY_EN.md#s06)).

## 6. Causality and output dependence require explicit contracts

Causal attention cannot repair lookahead already introduced by convolution, pooling, offline boundaries, or positional features. MEGABYTE uses separate global-patch and local-byte shifts. Hourglass's shortened branch lacks current-group history, but its shifted-input residual can still convey the immediately previous symbol; its appendix demonstrates a specific copying restriction, not blanket within-group independence. Causal Charformer repairs can remove leakage and still fail translation. Legal visibility and useful prediction are separate achievements.

Output models then make another choice. Local autoregression gives a dependent patch joint but retains serial local decisions. Independent future heads provide parallel proposals, not sampled within-block conditionals. Circuits supply normalized dependence; denoising supplies iterative block generation. Greedy verification preserves a named scorer's greedy trajectory, while stochastic preservation needs actual proposal/target ratios and rejection-residual correction. Confidence or top-k acceptance changes the policy.

MtPC illustrates the separation: its circuit normalization and measured throughput are useful evidence, but optimized cached Algorithm 2's stochastic target-law preservation remains unverified. The source description does not clearly distinguish an optional all-accepted bonus from required post-rejection correction state. An analyst counterexample concerns one literal interpretation, not a measured released-code bug. Better acceptance also need not mean faster output: rank 128 accepts more than rank 32 yet runs slower in one reported sampling comparison ([survey §§7–8](SURVEY_EN.md#s07)).

## 7. Sharing and adaptation are specific relationships

Classical tying evidence mostly concerns large word/subword tables. A 256×2,048 table contains only 524,288 parameters, so byte tying needs more than a large-vocabulary storage argument. Input/output tying, encoder/decoder input sharing, two-head sharing, Q/K projection sharing, directional sharing, and shared initialization are different axes. MEGABYTE specifies local byte input/output reuse; LCA shares an unembedding between heads; Reformer shares Q/K. None establishes every other axis or a runtime tensor alias.

Readout formulas matter equally. Row normalization retains hidden norm as an input-dependent temperature; full cosine removes it unless scaling restores confidence. Rank and pseudo-inverse arguments must be checked against small-alphabet dimensions. A particularly strong byte-specific control comes from embeddingless NMT: apparent gains largely disappear after matching the token-erasing effect of one-hot dropout. Representation changes also change the training recipe ([survey §10](SURVEY_EN.md#s10)).

Pretrained conversion proceeds through different levels: static geometry, contextual compatibility, teacher distributions, routing, and actual byte output. Char2Subword, hypernetwork transfer, Bolmo, and staged token-to-byte distillation solve different parts. Alignment helps some configurations, yet Bolmo's no-stage-one control is not catastrophic. Temporary byte supervision does not automatically produce a byte-output model or preserve instruction behavior. Frozen weights still incur backward computation, and inherited checkpoints, teacher queries, saved logits, and conversion text remain lifecycle costs ([survey §11](SURVEY_EN.md#s11)).

## 8. Multilingual benefit is more than coverage

Universal bytes do not equalize positions for parallel meanings. Alternate encodings, morphology codes, and per-script internal rates target different causes of disparity. MYTE reduces seen-language code length but leaves an unseen script unchanged, worsening its English-relative ratio. Its MT summaries cannot be reduced to one ranking: Appendix Table 8 gives MyT5 low-resource/overall 21.1/21.8 versus ByT5 21.9/23.1, while main Table 4 favors MyT5 20.4 versus 20.1 on its low-resource summary. Populations/aggregation remain unreconciled; its English-byte denominator is not target-language BPB.

Byte fallback can remove unknowns without preventing translation collapse. Scarce in-language annotation can alter model rankings, and multilingual means can hide language reversals. Dialect tokenization-parity and information-parity associations have task/model-dependent signs; a positive Llama sentence may refer to information parity and is not a confirmed TP contradiction. Those correlations are not causal fairness interventions.

Robustness also requires the actual corruption process. Character access alone fails under natural and synthetic edits. Order invariance loses useful distinctions; mixed-noise training trades specialist and clean performance for breadth. Spelling probes establish recoverable information, not host competence; explicit character access can accelerate supervised tasks without producing mastery. Legal Unicode, intended characters, exact copy, arithmetic, and task answers need separate instruments. The finite-state copy bound concerns output begun after ingestion, with every input-dependent influence contained in the counted retained state and no outside source replay or side channel; it does not constrain online echoing or uncounted external storage ([survey §12](SURVEY_EN.md#s12)).

## 9. Compare events and resource frontiers, not slogans

For matching events, bits per original byte is summed NLL in nats divided by matching byte count and ln 2. A canonical token path can be transparently byte-normalized without becoming a string marginal. Raw-prefix covers, completed-string sums, marked EOT histories, and denoising objectives remain different probability objects. TokSuite's printed vocabulary-size normalization is not a general BPB conversion; actual Figure 6 computation remains unknown. That figure cannot certify equal training sufficiency, while separate option ranking and same-text controls remain usable ([survey §9](SURVEY_EN.md#s09)).

Resource reversals are equally substantive. A recent resolution-preserving 3:1 Gated DeltaNet/Gated Softmax Attention hybrid favors bytes on its fitted parameter frontier and subwords on its training-FLOP frontier. Input/hash tables are excluded from its fitted N. Packing can discard different amounts of sampled text by tokenizer. More compression need not improve task quality, and larger drafts can be slower. Training steps, estimated FLOPs, weight traffic, acceptance, and synthetic attention timing are not end-to-end request latency ([survey §13](SURVEY_EN.md#s13)).

## 10. What should be done next?

The immediate need is not another universal winner claim. Use complementary studies: mechanism-isolating controls, complete training-cost frontiers, and matched-quality serving. Report all four interfaces, legal information paths, exact probability events, retained/unique/repeated text, teachers, actual rate distributions, and subgroup outcomes. Measure generated whole-string behavior and raw legality before repair, not only local loss or probes.

For a practical design decision, start from the required output. A classifier may legitimately normalize spelling distinctions that an exact-copy system must retain. A translation encoder can use the complete source, whereas an online predictor needs prefix-computable features. A finite candidate output can be efficient when the application supplies the candidates, but cannot stand in for unrestricted spelling. This task-first choice avoids treating every hybrid as an incomplete version of a native byte LM.

Then identify the binding resource. Limited training memory motivates different tools from limited decode latency: reversible activations need not shrink inference caches, and fewer trunk positions need not reduce serial byte emission. Limited multilingual context motivates length and retention measurements alongside task accuracy, not a coverage claim alone. A useful comparison reports the strongest simple control—rules, ordinary noise training, matched token dropout, or an unchanged local decoder—before attributing benefit to a sophisticated component.

Finally, retain negative evidence as explanation. Failed leak-free padding shows that legal information flow is not sufficient for learning; larger drafts losing speed show that acceptance is not the system objective; and spelling recoverability without loss improvement shows that information access is not utility. These results guide smaller decisive follow-ups rather than justify abandoning an entire interface family ([taxonomy and evaluation](SURVEY_EN.md#s14)).

The most informative open intersections are cheap causal utility routing, boundary-versus-aggregation attribution, functional checkpoint preservation, mixed-script online processing, unseen-script generation, grapheme-preserving long copy, non-ASCII numeracy, and batched serving with first-complete-scalar and tail latency. Some questions need experiments; MtPC's wrapper, TokSuite's figure, and MYTE's aggregation instead need specific artifact or author clarification. [OPEN_QUESTIONS_EN](OPEN_QUESTIONS_EN.md) separates those evidence requirements. The field is coherent without making any one architecture its presumed endpoint.
