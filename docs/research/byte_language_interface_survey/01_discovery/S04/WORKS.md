## Vocabulary and independent scope

A byte is an eight-bit unit; Unicode code point is an encoded character identifier; a character can be dataset-defined and need not equal a code point or grapheme. A subword is a tokenizer vocabulary symbol representing a variable text span. **Byte-level BPE remains a subword interface**. These definitions are labels for this survey, not proposed project terminology.

Tying means sharing specified parameters, not necessarily a mathematical inverse. Keep separate: encoder/decoder input tables; decoder input/output table; corresponding encoder/decoder blocks; reuse across depth; hash/n-gram tables; teacher/student backbone initialization. A tied table can feed a linear, row-normalized, fully cosine-normalized or transformed head. A cosine *router* is not a cosine *output head*.

A linear head computes `logit_i = w_i^T h + b_i`. Row normalization gives `w_i^T h / ||w_i||`, still sensitive to `||h||`. A fully normalized cosine head uses `s * w_i^T h / (||w_i|| ||h||)` (possibly class-specific scales). These are analyst definitions; papers' actual formulas control classification. Cross-entropy probabilities, auxiliary targets and latent-posterior KL have different meanings.

## Configuration findings that survive this investigation

1. **No universal untied-byte assertion is supported.** This stream has one old, specific ByT5-Large static configuration finding, not a census. Other model tying statuses remain unknown unless explicitly recorded above. Search failures are not negative findings about model implementations.
2. ByT5-Large's shared encoder/decoder **input** embeddings are consistent with an **untied decoder softmax**. A single `shared_embedding` flag cannot answer both questions. Fresh fixed-commit [README](https://raw.githubusercontent.com/google-research/byt5/7d4efdddf7049a2aadfe65d032f264553508916e/README.md) only confirms training/example configuration paths and lengths. It does not replace the old gin evidence.
3. Press/Wolf and Inan supply historical mechanisms and positive results, W0366 supplies modern gradient diagnostics, N01/N02 geometry alternatives, and W0367/W0368 new constraints/optimizers. **All are background unless byte-specific tests are independently established.**
4. Saving an untied table of `V*d` parameters is simple accounting, not evidence of regularization benefit. Analyst example:256×2048=524,288 parameters versus100,000×2048=204,800,000. A smaller absolute saving does not mean sharing has no inductive effect; that requires an ablation.
5. Orthogonal-column constructions requiring `V≥d`, word-semantic soft labels, and rank-bottleneck claims all have assumptions that may change radically with a byte vocabulary. These are reasons for conditional comparison, not a priori verdicts for or against tying.
