### Units and boundary vocabulary

- **Byte:** an eight-bit value. A 256-value alphabet covers arbitrary byte strings, not only valid UTF-8 text.
- **Unicode code point:** a standardized integer in the Unicode code space; not a UTF-8 byte and not necessarily a user-perceived character.
- **Grapheme cluster:** a sequence of code points presented as one user-perceived written unit; none of the included models is established here to operate on grapheme clusters.
- **Character:** retained as the author's term when the concrete encoding/alphabet was not inspected. Do not silently replace it by code point or byte.
- **Byte-level BPE:** byte-pair encoding whose base alphabet is bytes but whose model symbols are learned variable-length byte strings; **subword**, not a pure next-byte interface.
- **Embedding-free:** no separate learned type lookup/output embedding in the stated experiment, not no learned input processing or no learned internal representation.
- Unit tuple below is **input / internal sequence positions / output / supervision**. Word segmentation, normalization, truncation, alphabet coverage and target vocabulary are separate constraints.

## Inclusion and generalization decisions

1. H01–H05, H07–H09, H11, H13 and H19 are **explicit character antecedents or character-named benchmark routes**, not automatically byte-language evidence. Sequence modules can accept a byte alphabet in principle (**A**), but token lengths, Unicode legality, receptive fields and training exposure change; that is not a reported byte result.
2. H06, H10, H12, H17, H20 and the pure-byte W works supply actual textual byte evidence. H15 supplies **word-local byte composition**, with a closed supervision head; H14 and W0359 supply **byte-derived subword** evidence. H16 is a character–subword hybrid, not a vocabulary-free model.
3. H18's exact output units, several historical character alphabets, and decoder-side contextualizer causality in H14 remain unresolved. These are explicit missing facts, not inferred from names.
4. Audio/image/file simulation, speech-only models and compiled binary prediction are excluded as independent language evidence. MEGABYTE's language experiment remains relevant, but multimodal scale does not fill its language evidence fields.
5. This register concerns the independent field, not the necessity of a source-revisit mechanism or validation of any local architecture. Optional finer access is one possible mechanism, not an inclusion criterion.
