# S01 — Granular problem → solution → researcher-technique inventory

2026-11-08 · **51 meaningful records / 33 distinct works**. This is a classification input, not a model-name list or a universal performance ranking.

## How to use the records

Each row joins to [WORKS.md](WORKS.md) by W/H ID. That work contract is an integral part of the record: **stable source/version, era/family, input/internal/output/supervision units, learning signal, causal behavior and reading depth** are inherited. This avoids reproducing long identical contracts in every problem row. Row-specific signal, visibility or budgets below override/narrow the contract. A source location is a section actually inspected directly or an explicit **old-card** location; `abstract` never means methods were read.

**E = technique explicitly used by authors; A = our conceptual analogy, never a claim of author borrowing.** No A techniques are asserted in the technique column; transfer-to-bytes analogies appear only in limitations. Researchers' AI techniques include recurrent neural networks (RNNs), long short-term memory (LSTM), convolutional neural networks (CNNs), learned gating/highway connections, attention, masked prediction, regularization and optimization. These are not our search software.

Depth codes: **P** = targeted primary PARTIAL; **A** = abstract/metadata only; **RF** = reused old FULL card actually read, not a new full reading. Unknown budget is deliberately retained. Comparator differences do not imply causal attribution to a single interface change.

## Preliminary classification dimensions, not an algorithmic clustering claim

1. **Coverage mechanism:** prescribed alphabet (H01/H03), within-word composition (H04/H05/H15), universal bytes (H06/H12/H17/H20/ByT5), codepoint hashing (CANINE), byte-derived subwords (H14/W0359), mixed character/subword channels (H16).
2. **Where semantics is first assembled:** local recurrent spelling, CNN/highway, source-side fusion, latent blocks, patch pooling, dense deep attention or selective recurrence. No one assembly route is a necessary definition of byte modeling.
3. **Where vocabulary dependence survives:** input segmentation, output word head, masked-supervision head, subword teacher/segmentor, external word-span mask, or downstream preprocessing. “No WordPiece input” is only one cell.
4. **Permission:** complete-source encoder vs prefix-causal LM vs autoregressive labels conditioned on an already complete input. Shuffled masked-target autoregression is not ordinary left-to-right text generation.
5. **Optimization:** second-order optimization, highway carry, intermediate supervision, byte/token dropout, staged bag targets and deletion regularization have roles distinct from symbol choice.
6. **Counterexample type:** task/domain reversal, equal-compute reversal, fixed-alphabet coverage failure, output-validity failure, pretraining supervision restriction, and encoder/decoder cost reversal.

These are analyst classification labels (**A**), not names of author-proposed techniques or new project terminology. S01 does not assert that every paper fairly isolates byte representation, nor require it to validate a local proposal.
