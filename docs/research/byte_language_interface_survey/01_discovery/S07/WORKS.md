## Reading and provenance conventions

- **RF** = reused FULL old evidence card, actually read in this stream; source claims are inherited from that card, not independently re-certified. Some old FULL labels cover selected appendices rather than literally every appendix; retain the card's scope.
- **A** = primary abstract/metadata actually fetched, not full reading.
- **P** = targeted primary text actually inspected; named sections only, remaining experiments/appendices are unread.
- **S** = tagged official implementation specification; not a separate research paper or empirical validation.
- Units are written input → internal sequence → output; supervision is recorded separately. “Character” in older papers is not silently promoted to Unicode code point or grapheme. A UTF-8 byte is an eight-bit encoding unit; a Unicode code point is a character identifier, not necessarily a grapheme.
- “Hybrid” covers character/word or byte/subword interfaces, including subword-derived supervision. Pure-byte deployment and subword-teacher training are separate axes.

## Scope controls

1. These works solve different problems: lexical coverage, robustness, reduced positional length, pretrained-backbone reuse, embedding geometry, objective transfer, and readout cost. No single hierarchy or source-revisiting requirement is assumed.
2. No direct byte evidence is claimed from word-level output, codepoint input, subword adaptation, or ICAE. They are explicitly labeled hybrid or adjacent techniques.
3. All numbers not supported by a table/card are left unquantified. No paper/code was run. New FULL reads: **0**.
