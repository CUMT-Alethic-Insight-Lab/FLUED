# S07 granular problem → solution → employed AI technique inventory

**52 records / 28 works.** Discovery evidence, not 50 validated effects. Sources, locked versions, provenance and exact titles are in [WORKS](WORKS.md). `W…` IDs preserve the old catalog; `S07-N…` are local candidates, not global additions. Each record inherits that work's era and version. `RF`, `A`, `P`, `S` reading levels mean reused FULL card, abstract, partial original, tagged specification. The “location” column says what was actually inspected; sections reported by an old card are explicitly inherited.

## Shared interpretation fields

- Units below use **I / H / O / Y** = input / internal sequence / output / supervision. `char` means the paper's character, exact Unicode inventory unknown unless explicitly specified; `cp` means Unicode code point; `sw` means subword; `w` means word; `b` means UTF-8 byte; `z` means continuous latent slots; `mix` means BPE plus byte fallback.
- `BI→AR` means complete/bidirectional source encoding and causal target decoding. It does **not** mean an unconditional causal byte-stream encoder. `BI` means noncausal representation learning; `AR` means causal prefix prediction. For adaptation the host determines causality, not the initialization algorithm.
- AI techniques listed under **Used** are explicitly described in the inspected text/card. **Analogy** is our cross-paper interpretation; it is not evidence authors used a named framework. No analogy is counted as a new research mechanism.
- Budget is multidimensional: training text, positions, teacher cost, parameters, optimization opportunity, and decoding length are not interchangeable. Unknown cells stay unknown. Results are authors' reports or card reports, not reproductions.

## Cross-record synthesis for later classification (analyst interpretation, not extra records)

1. **Where granularity changes:** lexical fallback (R07/R24), input vector composition (R05/R21), compressed encoder states (R09/R10/R16/R37), vocabulary parameter conversion (R27–R33), output distribution transfer (R46), or only corruption target selection (R11/R38). These are not synonyms and should not be combined into one “hierarchy” bucket.
2. **Borrowed technique roles:** CNN/highway/RNN supply local composition; Transformer pooling supplies contextual composition; static multilingual vectors provide semantic anchors; matrix factorization controls interface parameters; hypernetworks amortize tokenizer adaptation; distillation transfers teacher distributions; LoRA/frozen hosts constrain parameter updates; auxiliary geometric losses stabilize compatibility; sampling/corruption are data/target augmentation. The same broad technique can have different roles without implying a unified architecture.
3. **Training permissions:** Char2Subword freezes upper host during integration; ICAE freezes target decoder while training encoder LoRA; W0355 selectively unfreezes endpoint layers; MrT5 continues an existing model with a gate; ZeTT distinguishes trained hypernetwork from zero-shot target tokenizer and optional continuation. Do not mark all as “frozen-backbone methods.”
4. **Counterexamples worth preserving:** W0360 tuning and low-data reversals; W0514 Lao; W0355 Gemma negative transfer; W0356 same-compute subword advantage; W0509 invalid UTF-8 despite fallback; N11 low-compute token advantage. These answer different contracts, not contradictory votes on one byte leaderboard.
5. **Independent field scope:** No record requires source revisiting, a persistent document tree or FLUED-specific architecture. Applicability to bytes is either direct byte evidence, clearly hybrid evidence, or an adjacent technique to investigate—not proposal validation.
