## Recommended synthesis order and causal checklist

Start from four independent decisions: **when to close a group; what content to aggregate; when a coarse state becomes legally available; what prediction target teaches it**. Then compare representation compression, state-refresh frequency and serial output costs. This prevents a story in which every newer model is merely a better H-Net/BLT.

For each causal claim, answer: (1) Is an input symbol an eight-bit byte, a codepoint, a character symbol or a subword? (2) Does the boundary action depend on the current/past prefix or the full observed test string? (3) Does the coarse value summarize a completed past span or an unfinished span with future content? (4) Are convolution, score calibration, averaging and upsampling causal as well as the main attention? (5) Does a local path restore within-group dependence? (6) Is a future-informed training label being mistaken for deployment leakage? (7) Are actual rate, segment-length distribution, teacher budget and temporary-state cost separately reported?

No experiments, production changes, installs, commits or global catalogue edits were performed. Work is restricted to the four Markdown files in this directory.
