# S06 works — computational scaling, training, and serving

2026-11-08. **29 works: 22 old W-ID entities + 4 recovery-discovered entities + 3 fresh discoveries.** Fifteen old FULL cards were actually read. No new FULL paper reading is claimed. Forty-eight granular records are in the companion inventory.

## Evidence conventions and units

- **RF** = reused old FULL card, within its stated scope; no fresh full-paper verification. **P** = targeted original-paper PARTIAL; missing scope stated below. **A** = verified original abstract/identity only. These levels describe this fragment's evidence, not a paper's quality.
- Unit tuples are **input / expensive internal positions or state / output / supervision**. Byte means an eight-bit value; UTF-8 byte, Unicode code point, cleaned character, subword, and mixed units are not interchangeable. BPC is the authors' bits-per-character label; enwik8's symbol stream is actually bytes. BPB means bits per original byte only when the probability/denominator is valid.
- Learning/casual fields are inherited by inventory rows citing that work unless a row explicitly overrides them. Causal means predictions condition only on available prefixes; bidirectional encoders are marked separately. Teacher-forced causal evaluation is not free generation.
- FLOPs = floating-point operation counts; parameter budgets, original-text exposure, kernel wall-clock, throughput, persistent KV (attention keys/values) cache, and peak total memory are separate axes. Unreported values are **unknown**, not zero.
- No external-paper claim is judged by whether it supports FLUED or a prior multigranularity/source-revisiting proposal.

## Evidence map for synthesis

1. **Direct byte/backbone and system evidence:** N05 sparse kernels; N07 recurrent byte LM; W0352 selective state; W0009/W0010/W0011 local/global paths; W0351/W0511 encoder/decoder asymmetry.
2. **Historical character antecedent with exact byte arm:** N01. W0007 is cleaned-character evidence, not general UTF-8. W0004 is code-point encoding.
3. **Counterexamples to monotonic efficiency:** W0356 same-FLOP subword win; W0514 train/decode reversal; W0360 task latency reversal; W0011 wall-clock penalty; N03 H-Net equal-FLOP exception; W0023 larger cache deterioration.
4. **Do not mix units or budgets:** W0361 position parity; W0518 equal tokens versus equal text; W0512 fitted trunk parameters versus deployment total; W0010 teacher/preprocessing; N04 teacher logits.
5. **Recent serving claims needing full reads:** W0015 and N04 are abstract-only; W0014 RF is cost-estimation evidence, not measured throughput. N03's cache claim is persistent-trunk accounting, not a timing result.
