## 3. Central synthesis leads

- Byte coverage, legal UTF-8, target-character correctness, exact original text and task utility are five distinct objects. Byte-fallback BPE is not pure byte LM; code-point input is not grapheme input.
- Morphological/low-resource successes and failures exist in many non-English settings. Separate full-source character/byte NMT, masked/span-denoising understanding and causal byte generation before comparing.
- Direct matched comparisons remain conditional: W0360 separates label budgets, not pretraining text; W0518's same-text subset excludes bytes; N03 isolates mechanisms but changes curriculum/objective and uses English-centric text.
- Character reasoning has several evidence levels: token embeddings can encode probe-decodable spelling (N07); counting and position have different associations (N11); architecture interventions may change emergence (N10). None establishes all-language behavior.
- Long natural multilingual exact copy, grapheme-aware errors, non-ASCII numeracy and mixed-script causal routing are **missing comparisons**, not negative findings. Survey gaps do not license project-specific causal diagnoses.
