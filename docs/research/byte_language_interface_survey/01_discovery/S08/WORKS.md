## Definitions and field-centered families

- **Byte**: an eight-bit value; UTF-8 encodes a Unicode code point into one to four bytes. A Unicode code point is not necessarily a user-perceived grapheme. Historical papers' “character” is retained unless their encoding is verified.
- **Subword**: a vocabulary symbol spanning several base units; “byte-level BPE” normally predicts merged symbols, not one byte at a time. The 2016 BPE translation paper starts from characters, not the later GPT-2 byte alphabet.
- **U** below gives input → internal positions → output → supervision; **C** gives causal behavior. “Causal” here means prefix-only prediction, not causal-effect identification in statistics. **L** gives learning signal; optimizer is unknown unless inspected.
- **R** = actually read old FULL evidence card; **P** = selected original-paper text, incomplete full read; **A** = abstract/metadata only. These grades apply to this stream. A supplies candidate mechanisms and author claims, not certified comparisons.
- Bibliographic titles and established field techniques are not proposed project terminology. Families below organize the external field rather than a source-revisiting or FLUED architecture.

## Old-corpus bias: what this stream can actually establish

1. Catalog membership was checked with stable identifiers and titles, not assumed from familiar names. The old catalog contains many 2025–26 byte variants but omits the sampled 2011 direct recurrent LM, 2013 LSTM generator, 2015 character CNN classifier, character-input/word-output hybrid, 2017 byte sentiment model, and several primary probability/tokenization-control papers. This is a **sampled coverage finding**, not a numerical completeness score for the whole field.
2. The old recovery audit already found Al-Rfou and Cao/Rimell. They are explicit reuse here even though absent from CATALOG; finding them again does not count as new discovery.
3. The inspected recovery audit reports original T08 as 45 works, including21 source-revisiting/probe/long-context neighbors; the later T08 association has73 works. Those are the prior auditor's counts, not a new recount by this stream. The bias is in organizing questions and selected primary reads, not an accusation that all old cards lack rigor. Twelve actual cards supplied valuable counterexamples.
4. A neutral taxonomy starts with **representation → conditioning/objective → computation allocation → generation/decoding → task/language/robustness → probability/resource accounting**, with historical and non-LM evidence explicitly separated. Source revisiting is an optional cross-cutting capability; it is not an inclusion rule or the endpoint of every paper's value.
5. Classical/non-neural compression and formal segmental generation are still underrepresented here. This stream is a selected counterexample/methodology inventory, not a replacement for S01–S07 or a claim of exhaustive historical coverage.
