## Acceptance checklist for returned cards

- Identity: exact version/date/authors, stable URL, formal/preprint relation, distinct-work lineage.
- Units: input/internal/output/supervision; byte versus codepoint versus restricted alphabet versus merged byte-BPE; state exact preprocessing.
- Mechanism: one prior problem and concrete solution per finding; researcher-used techniques versus analogy; optimization and auxiliary sources/teachers.
- Probability: causal raw prefix versus token event; text marginal versus canonical path; EOS/normalization; exact versus approximate algorithms.
- Evidence: actual table/figure read locations; negative outcomes; budgets separated by text/positions/params/FLOPs/runtime; implementation not confused with theory.
- Completeness: FULL only after methods, experiments, key numerical evidence and relevant appendix are actually read; otherwise name the remainder. Reading does not certify reproduction or theorem correctness.
