# S08 — Granular problem → solution → technique inventory

**60 records, 34 works.** Stream discovery/inventory only; 0 new FULL reads. Work IDs resolve to exact titles, source versions, units, signals and comparison settings in [WORKS.md](WORKS.md). There is deliberately no model-name-only row.

## How to interpret a record

Each row is a specific prior problem and a one-sentence solution, not a proposed FLUED change. **E** marks a technique explicitly used/described by the researchers; **A** marks our conceptual analogy, not an author claim. No row relies on an analogy as evidence. Techniques mean research methods (e.g. convolution, importance sampling, surrogate gradients), not our search tools. Non-neural/statistical methods are named honestly rather than relabeled as neural AI.

Units are **input / internal positions or state / output / supervision**. “Inherit Wxx” inherits the exact four-unit tuple, causal behavior, signal and source identity from the corresponding WORKS row; the local row then specifies its own changed signal or permissions. **A-depth** = abstract/metadata; **P-depth** = named original-paper selections only; **R-depth** = old FULL card actually read, with old reader's scope retained. Source sections for R-depth are locations reported in that card, not newly read originals. No mathematical proof, implementation, or result is independently reproduced.

## Proposed evidence labels for the coordinator (synthesis, not new research claims)

Use these orthogonal labels rather than a single “byte model works” stamp:

1. **Language-unit identity:** character alphabet, Unicode code points, UTF-8 bytes, graphemes, merged byte-derived subwords, mixed fallback, or nonlanguage binary bytes. Missing encoder mapping stays unknown.
2. **Task identity:** next-unit density estimation; unconditional generation; conditional translation/infilling; classification/retrieval; representation transfer; legality/spelling; binary simulation; synthetic/pixel benchmark. None substitutes for all others.
3. **Conditioning event:** full observed source, corrupted source, causal raw-byte prefix, canonical token prefix, oracle segmentation, suffix-permitted FIM, or true-prefix simulation. Label look-ahead side information at the point of use.
4. **Probability object:** one segmentation path; finite candidate sum; estimated text marginal; exact byte conditional under specified assumptions; sampled/greedy/speculatively accepted continuation. Include end-of-string and tokenizer normalization permissions.
5. **Comparison contract:** same original text and order, same retained content after packing, same corpus mixture, same positions, same parameters, same non-embedding parameters, same training FLOPs, same runtime, or same output quality. Usually several cannot be simultaneously equal; report which were held and which changed.
6. **Evidence strength:** abstract assertion; selected original method/experiment; reused FULL card; selected new FULL reading; code inspection; independent reproduction. Reading completion is not theorem/effect certification.
7. **Meaningful negative outcomes:** simple rules tie/beat learned routes; byte advantage disappears at equal compute; extra output target hurts; Unicode valid but wrong; task near chance; oracle acceptance fails to establish speed; historical character model loses to a compression baseline. Retain these as substantive problem records, not generic caveats.
