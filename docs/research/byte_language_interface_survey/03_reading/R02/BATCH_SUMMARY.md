## Notes for inventory and synthesis owners

1. **ByteNet v2 internal disagreement:** PDF p.1 abstract gives WMT14/15 BLEU 22.85/25.53 and bpc .380/.389; p.6 Tables 2/4 visibly give 23.75/26.26 and .521/.532. Source does not reconcile them. Use the table with disclosure or leave the conflicting result unresolved; do not present the abstract's digits as the table's.
2. **Kit and Wilks objective:** Eq. (6) sums per-occurrence average DLG, while eq. (7)/the Figure 1 scoring description uses DLG. This is a source-level apparent mismatch, not an independently resolved implementation error. Evaluation includes the observed spaces as ordinary input characters. Data increase improves precision but reduces recall.
3. **No universal tying claims:** BIW-0057 explicitly shares the recurrent network across input and output phases; that is a different axis from input embedding/output projection tying. The other neural cards do not assume a head tie where not specified.
4. **Negative comparisons matter:** 0052 loses to PAQ, 0055 loses or ties certain morphology references and has ~half the reported training throughput of its word comparator, 0057 has weaker individual-language POS cells and untested code-switching, 0063 has poor SICK and a Yelp plateau. None is a controlled comparison of all choices, all-compute-equal result, or proof of a proposed project design.
5. Report original text unit and lossy transformations. Character UNK or transliteration scores are not raw UTF-8 byte likelihoods; changing a denominator does not recover lost events. Unreported normalization, FLOPs, teacher, exact validity/termination details and serving costs remain unknown as called out per card.
