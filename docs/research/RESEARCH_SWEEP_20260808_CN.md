# 文献侦察备忘录：循环塌缩 / 寻址冷启动 / 检索墙的 2026 地图

> 2026-08-08，九路并行侦察（~40 篇，绝大多数经 arXiv 摘要页或 HTML 原文节核实；
> 未核实处在文中标注）。透视镜 = FLUED 三个已被实验证实的机制困境：
> **P1 检索墙**（纯线性状态+单固定查询读出钉死 0.206 平台，E38-E44）、
> **P2 循环塌缩**（无监督思考循环推理时 2 轮收敛退化为前馈，E45）、
> **P3 寻址冷启动**（思考槽位噪声+位置初始化、memory 行无位置键，内容寻址无从启动）。
> 本备忘录是后续候选臂的文献依据层；判词以 CURRENT_STATE 证据表为准。

## 1. 一句话总结论

**我们不是在孤军奋战撞墙，而是独立复现了 2026 年正在收敛成定律的三件事**：
纯递归定长状态做不了精确联想检索（P1 有四条互不相干的理论证明线）；
无锚迭代循环退化为前馈是迭代架构的默认吸引子（P2 有至少四份独立尸检）；
"噪声+位置嵌入"是内容寻址的已知最差初始化（P3 有至少三条互不排斥的便宜解法）。
——三堵墙都不是我们的实现失误，而每一条墙文献里都已有标好价的绕行方案。

## 2. P1 检索墙：从"经验观察"升级为"多重理论定律"

**四条独立理论线**（互不相干，指向同一堵墙）：

- 电路复杂性：固定精度 SSM 表达力 ∈ TC⁰，无法做 NC¹-hard 状态追踪
  （Merrill 等，arXiv:2404.08819，ICLR 2025）；
- Copying 上界：定长潜状态模型的复制长度受状态比特数硬约束，两层 Transformer
  可复制指数长串（Jelassi 等，arXiv:2402.01032，ICML 2024）——"瓶颈是状态信息量，
  不是读出算力"，直接解释我们扩容（47M→124M）与加地址数（4→16 头）双无效；
- 精确注意力生成的空间下界 Θ(nd)：亚线性记忆 + 任意查询精确召回最坏情形不可兼得
  （Haris & Onak，arXiv:2502.15955，COLT 2025）；
- **Indexing 原语**：内容无关的固定查询读压缩状态 = index-at-end 最难形态，
  常数层 masked 线性注意力不可解（即使无限精度）；softmax 注意力一层可解
  （Kozachinskiy 等，arXiv:2607.22361，2026-07）——与我们的读出机制最同构的理论。
- 附带：Zoology/MQAR（arXiv:2312.04927）——20× 参数买不回召回，是我们容量
  矩阵（E39）全灭的先验版本；单人预印本 arXiv:2607.14144（未同行评审）把我们的
  s30/s31 对照几乎逐字理论化（"scissors gap"：64 标量状态 exact-retrieval error
  0.994，加一层全局注意力降到 0.000）。

**2026 工程共识**：没有任何规模化的方案敢用纯线性状态——Kimi Linear 3:1、
Qwen3-Next 3:1、Nemotron 3 注意力锚点层、Granite 9:1、Falcon-H1 层内并联。
**2026 上半年的新趋势（与我们最相关）**：HOLA（arXiv:2607.02303）与 HAM
（arXiv:2603.22325）独立收敛到同一设计——**压缩残差决定谁进精确缓存**：
delta-rule 压缩状态照旧，写入预测残差大（=压缩器坦白没压好）的条目额外保留
精确 KV，读出同时查压缩态+精确缓存。写入判据免训练，缓存有预算。
→ 这是我们的 s31 通道（0.206→0.797）的"原理化+预算化"版本，是 P1 的
架构级答案候选：**精确通道不必常驻全量，由压缩失败信号驱动写入**。

**镜像证据**：Compression-is-Routing（arXiv:2512.16963，独立研究者，强度中等）
——512 token → 8×512 维 latent 的自编码器：分布内 64× 压缩可 99.47% 精确重建，
分布外 0.57% 全拒。我们的补全任务里"被检索内容相对读出查询"正是分布外。

## 3. P2 循环塌缩：文献里的同名病与三类已验证解药

**同名尸检报告（塌缩是默认吸引子，不是我们的 bug）**：

- Huginn（arXiv:2502.05171，Geiping 等，3.5B/800B token）**Bad Run 2 与我们逐字
  同款**：模型学会忽略传入状态，r=1 与 r=32 的验证 PPL 完全相同，循环退化为前馈
  且锁死在该局部极小。修复是**纯结构五件套**：① 每轮把输入 e 重新注入循环
  （作者论证：算子若不每轮依赖输入，数学上不可能是稳定的数据依赖迭代——解只由
  边界条件决定）；② 迭代数从 log-normal Poisson **重尾**采样（均值 32）而非均匀；
  ③ 截断 BPTT（只反传最后 8 轮）；④ sandwich norm；⑤ 噪声初始化 + 降峰值 LR。
- HRM 尸检（arXiv:2510.00355，MIT）：只要训练目标允许"中间态→终态"一步映射存在，
  模型就会学它（等效 consistency model）；学好的 ACT 停止策略**任何阈值下不如
  跑满步数**。
- Readout Blind Spot（arXiv:2606.24898）：逐步 dense CE 只控制 readout 暴露的变量；
  LN/RMSNorm 这类尺度不变读出把径向尺度对损失隐藏——**循环内部自由度在损失视野
  之外时，塌缩成前馈是零成本解**。
- Soft Thinking 单线程分析（arXiv:2508.03440）：连续迭代在无显式随机性/监督时
  塌缩为贪心单路径；附探针方法（中间态扰动敏感度——可直接测我们的循环死活）。
- Prophet（arXiv:2508.19982）：即使端点监督齐全的 dLLM，97-99% 样本在一半去噪步
  时已内部定案（early answer convergence）——**迭代早饱和是该架构族的吸引子**，
  他们选择顺势 early-commit。

**三类已验证解药**（互不排斥）：

1. **结构包**（Huginn 配方，与"思考不监督"裁定完全兼容）：每轮重注输入 +
   重尾深度采样 + 截断 BPTT + sandwich norm。注意微妙处：我们的 cross-attention
   每轮"看得见"读出，但注意力权重可以被学成忽略（V 投影退化为常数）——
   Huginn 的 concat 注入**不可被忽略**，这是强度差异。
2. **中间态锚定**（与"思考不监督"裁定存在张力，如实登记）：LLaDA/MDLM 的标准
   答案——不给轨迹逐步标签，但把**随机噪声水平的中间态当作训练输入施端点监督**；
   LoopFormer（arXiv:2602.11451）stopgrad 长轨迹自蒸馏短轨迹 + (t,Δt) 时钟条件；
   CDLM（arXiv:2605.00161）闭式桥一致性；Jacobi Forcing（arXiv:2512.14681）
   轨迹自蒸馏；diffusion forcing 采样器（arXiv:2510.14961）**每轮必须发射一个
   token**（emission-anchored iteration，循环退化=生成停止，代价显式化）；
   ELF（何恺明组，arXiv:2605.10938）flow matching 每轮 velocity 回归目标。
3. **不动点目标化**（结构性消解）：DEQ（arXiv:1909.01377）→ FPRM
   （arXiv:2606.18206）→ Equilibrium Reasoners（arXiv:2605.21488）——收敛从 bug
   变成定义，halting 免费（测 ‖s_t−s_{t−1}‖）；判别准则：**思考循环有用 ⟺
   动力学里存在任务条件吸引子**；我们"一切输入 2 轮收敛"落在坏象限。
   breadth 轴白捡：噪声初始化天然支持多轨迹聚合。

**停止机制专项**（agent-29）：纯端点损失学出停止决策的**成功案例为零**；
三类活路：预算写死只学分配（MoD/MoR，arXiv:2404.02258/2507.10524）、随机深度
训练+推理期启发式退出（Huginn/EqR）、RL 训停止（HRM Q-learning / Thinkless
DeGRPO——后者明文报告 vanilla GRPO 下控制分布塌缩，与我们 GRPO 四轮教训同族）。

## 4. P3 寻址冷启动：货架行号的三条便宜解法 + 查询预热

- **反模式确认**："噪声+位置嵌入"是 Slot Attention 文献里的已知最差初始化
  （QSA，arXiv:2210.08990：随机初始化"几乎不起作用"）。
- **解法一：查询预热**（SmoothSA，arXiv:2508.05417）——先用便宜的内容前向把
  冷启动查询预热成内容条件查询再进迭代。→ 我们的 s34 内容播种臂（h₀=content
  投影+位置+噪声）正是此解的直译，文献背书成立。
- **解法二：查询从状态生成**（Resona，arXiv:2503.22913）——query encoder 吃
  递归状态学"我现在缺什么"，K/V 挂未压缩原始表示，α 门控混回。→ s31 通道的
  系统化形态。
- **解法三：货架加行号**——Retrievit（arXiv:2603.02874）：无位置编码的递归系统
  必须自费学习位置关联，给每行拼段序嵌入是廉价干预；Landmark（arXiv:2305.16300）：
  语义键+位置键双通道；RAM-Net/OVQ（arXiv:2602.11958/2602.03922）：学习稀疏
  内容地址码；MoVE（arXiv:2601.22887）：离散符号地址+内容门控。
  Memory Layers at Scale（arXiv:2412.09764）反证：参数记忆线不加位置键是因为
  查询恒带内容——**我们的病灶在查询侧，不在货架侧**。
- **熵即行号**：Scratchpad Patching（arXiv:2605.09630）把"段内内容不可寻址"
  命名为 patch lag，用下一字节预测熵触发瞬态槽位——免费的寻址启动信号。
- **NLA（Anthropic，见 §5）的纪律**：经过不可微瓶颈的双模块重构可行，但
  **冷启动必崩，必须先在代理任务上 SFT 暖启动**。

## 5. 点名参照核查（用户指定的五篇）

- **J-space = Anthropic《Verbalizable Representations Form a Global Workspace
  in Language Models》**（arXiv:2607.15495 / transformer-circuits，2026-07）。
  Jacobian lens（J-lens）：中间层激活对最终输出的平均 Jacobian 复合 unembedding，
  得到每层线性读出图；J-space = 可言语表征的稀疏非负组合，**只占激活方差 ~10%**
  却承载五种工作空间功能；只在中段层带成立；条目是 **token 索引的**（词表 token
  =天然内容键）。**counterfactual reflection training**：只训练"被打断时说出当前
  思考"，未打断场景的行为也改善——不碰逐步标签而塑造内部循环的第三条路。
  与我们 §22 纲领的关系：他们测到的工作空间是**涌现的、小容量的、有格式的**——
  我们要做的是把它解放为整个主干且显式化，方向获文献侧背书。
- **NLA = Natural Language Autoencoders**（transformer-circuits，2026-05，无 arXiv
  编号）。AV（激活→自然语言解释，GRPO：reward=−log 重构误差，KL 锚定）+ AR
  （解释→激活，监督回归），双侧解耦更新；**必须先摘要代理任务 SFT 暖启动否则
  训练不稳**。→ 我们 GRPO 线的直接参照（用户此前问的"NLA 强化学习方案"即此）。
- **锥形神经网络：已查清（用户描述二次定位）= Tapered Language Models**
  （arXiv:2606.23670，2026-06，Bayat-Behrouz-Courville，Mila/Cornell）。
  洞察：深层网络的后面层基本在精修残差流而非变换它，因此固定预算下
  参数应按深度渐缩——试验圆锥/余弦等形状，**余弦渐缩（面向原始模态的
  前层多分参数）最佳**。对 FLUED 容量分配的含义：参数预算向面向字节的
  前端倾斜（与我们 E39 容量矩阵"主干扩容无效"不矛盾——那测的是被接口
  卡死的主干；TLM 的正确施力点是前端/可响应规模的组件）。
- **ELF = Embedded Language Flows**（何恺明组，arXiv:2605.10938，2026-05）。
  连续 embedding 空间的 flow matching LM，最后时刻才映射回离散 token——
  迭代精化有效的关键是**密集逐步 velocity 目标**。
- **DSpark = DeepSeek 投机解码框架**（arXiv:2607.05147，已部署 DeepSeek-V4）。
  半自回归 drafter + rank-256 Markov head 补块内依赖 + 冻结目标模型 TV 蒸馏 +
  置信度调度。→ 我们 decoder 并行解字节的"块内多峰冲突/后缀衰减"有现成便宜
  药方（低秩 bigram 偏置头）。

## 6. 段级并行生成与可学习切分的 2026 状态

- **Fast BLT**（arXiv:2605.08044，BLT 原班）——与我们最同构：双目标训练
  （干净字节 AR loss + 随机噪声水平 masked 扩散 loss，**每个噪声水平都有监督**）、
  confidence/熵界自适应提交、**committed prefix 恒走因果注意力+KV cache**。
  建议列为精读+复现候选第一优先级。
- Block Diffusion（arXiv:2503.09573，ICLR 2025 Oral）→ Set Diffusion
  （arXiv:2607.01775，ICML 2026）：中间形态的标准化；集合级提交顺序可调。
- **DLCM**（arXiv:2512.24617）：token 级动态分段 + Global Parser batch 级比率
  约束（我们 GRPO 率失控问题的可移植方案）+ 首个 compression-aware scaling law
  L(N,D,R,P)；注意其验证范围 R≤8，我们 R≈22 处于文献未覆盖的高压缩区（风险标注）。
- **ByteFlow Net**（arXiv:2603.03583）：coding-rate Top-K 边界（信息增量判据，
  静态计算图）；诚实警示——其消融显示 entropy/cosine 动态切分在 0.6B 规模
  **输给静态 word boundary**，H-Net 单级社区复现亦见边界塌缩为 whitespace：
  可学习切分在小规模的优势窗口仍需证伪（与我们 S0 系列教师路线互为印证）。
- tokenizer-free 纲领：BLT→H-Net→Bolmo（arXiv:2512.15586，可廉价转换）→
  ByteFlow/Fast-BLT，"字节级追平 token 级"已成流水线，前沿移到生成吞吐与
  自适应粒度——**我们的差异化必须落在可学习语义边界+段级记忆，这正是还没有
  SOTA 答案的部分**。

## 7. 纲领级证据

- 压缩即智能：线性相关成立（arXiv:2404.09937），但朴素压缩指标可被 compression
  hacking 作弊（arXiv:2505.17793，高各向异性造假象）——**2026 正确版本：
  带几何约束的压缩才等于智能**。与我们 E45 的循环塌缩同构：目标上无防退化
  约束，退化就是免费的。
- 智能密度：Densing Law（arXiv:2412.04315，已登 Nature MI 2025-11）——
  能力密度约每 3 个月翻倍；是我们 §22 纲领最现成的挂靠点。
- GWT：Anthropic J-space 把全局工作空间从哲学变成可测量对象（发现式证据）；
  可微实现仍停留在玩具级——**我们做实现侧是有空档的**。
