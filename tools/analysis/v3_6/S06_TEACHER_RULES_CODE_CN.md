# S06 教师标注规则（代码专用版 v2，S05 的补充而非替代）

> 适用范围：codeparrot 代码窗（4096B）。散文统计口径见 S05；本文件只保留代码场景需要的规则。
> v2（用户裁定 2026-08-17）：粒度较 v1 翻倍——前缀与括号分离、嵌套传参按嵌套边界切。
> 6 条人工范本（v2）实测：段数 96–299/窗，段字节中位 11–24（随链式密度浮动），非原子段 p90 ≤ 48；>64 字节的段只能是原子语法单位（单个 HTML/XML 标签、字符串字面量等）。

## 0. 任务与铁律

你是语义切分标注员。唯一任务：在文本中插入半角竖线 `|` 标记语义段边界。

铁律（违反任何一条即作废）：

- 只插入 `|`，绝对不改、不增、不删任何原有字符（空白、缩进、换行、全角符号、注释、错别字一律照原样）。
- 输出只有标注后的文本本身。不要解释、不要前言、不要代码块包裹、不要复述。
- **语法完整高于一切**：宁可不切，不许劈坏语法。

## 1. 代码切分口径（v2）

1. **调用结构一分为二**：非空调用/索引的左括号前下刀——`前缀|( 参数表 )|`。前缀 = 接收者+首个方法名（`@txn.stub!|`）；链上后续每个 `.method` 各自独立成前缀段（`.and_return|`）。
2. **嵌套传参按嵌套边界递归切**：`foo(bar(x), y)` → `foo|(bar|(x)|, y)|`；闭括号挂参数表段尾。
3. **参数表内顶层逗号后下刀**：`( 'Allow',|'OPTIONS' )|`。
4. **顶层二元运算符前下刀**（`=`、`==`、`+`、`and`、`or`、`=~` 等）：`@uri|+|'/18'`。
5. **关键字后下刀**（if/for/while/return/def/class/it/describe/before…）：`it|"maps a HEAD with an ID to #not_allowed"|do|`。
6. **空括号 `()` 不与前缀拆**：`getCertificateId()|` 整体一段。
7. **绝不劈开**：标识符（含超长 camelCase 方法名）、字符串/正则/数字字面量、单个 HTML/XML 标签（属性绝不拆，`>` 之后才允许下刀）。
8. **空白与换行**：换行符挂前段段尾；连续空行不独立成段、随前段；行首缩进挂在该段段首。
9. **注释**：行注释整行成段后按 v2 继续细分（`#`/`//` 前缀可与内容分离）；块注释按逻辑行逐行处理。

## 2. 长行与长串

- 超过 64 字节的行：按第 1 节规则在顶层分隔点继续下刀；找不到语法安全切点就整行保留。
- URL、文件路径、base58/哈希短串（≤64 字节）：整体成段不劈。
- 超过 64 字节的无边界串：若是语法原子（字符串字面量、标签属性值），不劈，留给运行时容量哨兵；若在属性外裸奔（罕见），在 ~48 字节处均匀下刀。

## 3. 自检口径

- 全窗段数 ≈ 总字节 ÷ 20（±40%）。段数明显偏少=切粗了，返工。
- 段首出现 `)`、`"`、`;` 等闭符号=切点错位，返工。
- 非原子段 >64 字节=违规；原子段（单标签/字面量）豁免但应在少数。
