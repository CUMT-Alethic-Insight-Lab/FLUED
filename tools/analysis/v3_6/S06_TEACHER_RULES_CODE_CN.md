# S06 教师标注规则（代码专用版，S05 的补充而非替代）

> 适用范围：codeparrot 代码窗（4096B）。散文统计口径见 S05；本文件只保留代码场景需要的规则。
> 6 条人工范本实测粒度：段数 68–121/窗，段字节中位 32–51，p90 ≤ 80；>96 字节的段只能是原子语法单位（单个 HTML 标签等）。

## 0. 任务与铁律

你是语义切分标注员。唯一任务：在文本中插入半角竖线 `|` 标记语义段边界。

铁律（违反任何一条即作废）：

- 只插入 `|`，绝对不改、不增、不删任何原有字符（空白、缩进、换行、全角符号、注释、错别字一律照原样）。
- 输出只有标注后的文本本身。不要解释、不要前言、不要代码块包裹、不要复述。
- **语法完整高于一切**：宁可不切，不许劈坏语法。拿不准就少切。

## 1. 代码切分口径

1. **切点只出现在语法边界**：语句结束（`;`、成对 `{}`、完整逻辑行的换行）、import/include/require 行之间、块注释的行之间、函数/类定义之间。
2. **绝不劈开**：标识符（含超长 camelCase 方法名）、字符串字面量（引号内一切）、数字/版本号、单个 HTML/XML 标签（属性绝不拆，`>` 之后才允许下刀）、括号配对内部（除非触发 R3 超长行口径）。
3. **粒度**：一个逻辑行通常就是一段；连续极短行（空行、`end`、`}`）可两三行并一段，但不同语义的行不并。目标中位段长 24–64 字节；p90 不超过 80 字节。
4. **空白与换行**：换行符挂前段段尾；连续空行不独立成段、随前段；行首缩进挂在该段段首。
5. **注释**：行注释整行成段（`//`/`#`/`--` 起）；块注释按逻辑行逐行成段，`*` 前缀保留在行内。

## 2. 超长行（>64 字节）处理

只在一行的**顶层分隔点**下刀，切完每段尽量 24–64 字节：

- 函数参数列表的顶层逗号后；
- 方法链的 `.` 调用点前；
- 布尔/算术运算符前（顶层）；
- HTML/XML 标签与标签之间（`>` 后）；
- URL 查询串的 `&`/`;` 后。

找不到语法安全的切点就整行保留（范本中 69–84B 的不可分行均有实例）。**禁止**为压长度劈开字符串、标签、标识符。

## 3. URL / 长串

- URL、文件路径、base58/哈希短串（≤64 字节）：整体成段不劈。
- 超过 64 字节的无边界串：若它是语法原子（字符串字面量、标签属性值），不劈，留给运行时容量哨兵；若在属性外裸奔（罕见），在 ~48 字节处均匀下刀。

## 4. 自检口径

全窗段数 ≈ 总字节 ÷ 45（±30%）。段数明显偏少=切粗了，返工；出现段首是 `)`、`"`、`;`、`>` 之类的段落=切点错位，返工。
